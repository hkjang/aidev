# VisitFlow 사용자 가이드

## 방문 요청자

1. 방문 신청에서 사업장·시간·목적을 입력한다. 필요하면 매주 2~52회 반복을 설정한다.
2. 방문 유형을 선택한다. 유형에 따라 보안서약 확인, 안전교육 이수, 차량번호나 반입 장비 신고가 필수이며, 일부 유형은 항상 승인을 거친다.
3. 방문자를 한 명 이상 추가하고 개인정보 동의를 확인한다. 단체 방문은 CSV/XLSX 첫 시트에서 최대 100명까지 불러올 수 있다. 방문자별 안내 언어를 지정하면 모바일 방문증과 안내 문자가 해당 언어로 제공된다.
4. 제출 후 자동 승인 정책이면 즉시, 승인 정책이면 승인 후 방문자별 QR이 발송된다.
5. 내 방문 일정에서 상태, 모바일 방문증, 일정 수정, 취소·재발급·재발송을 관리한다. 단체 방문에서는 방문자 한 명만 취소할 수 있고, 매주 반복 일정은 해당 회차부터 이후를 한 번에 취소할 수 있다. 상세 화면에는 승인·반려 사유와 진행 기록(신청·승인·입실·퇴실)이 표시된다. 일정을 수정하면 발급된 QR의 유효기간과 예약 알림이 함께 갱신된다. 목록이 길면 `더 보기`로 이어서 조회한다.
6. 방문자 정보를 본인이 입력하게 하려면 방문 상세에서 사전등록 링크를 발급해 전달한다. 방문자가 직접 정보를 채우고 동의하면 상세 화면에 `본인 사전등록 완료`로 표시된다.
7. 반복되는 업체와 목적은 방문 템플릿으로 저장하고, 템플릿을 수정하거나 자주 방문자를 연결해 다음 신청에 다시 사용한다.
8. 휴가 등으로 자리를 비울 때는 프로필 메뉴에서 대리 담당자와 기간을 지정한다. 그 기간의 승인과 도착 알림은 대리 담당자에게 전달된다.

프로필 메뉴의 휴대전화는 방문자 도착 알림 수신에 사용된다. 새 번호를 입력할 때만 바뀌고, 비워 두면 기존 번호가 유지되며 삭제는 `등록된 연락처 삭제`를 선택해야 한다.

프로필 메뉴의 메일 알림에서 방문자 도착·퇴실, 방문 확정·반려·취소, (승인자라면) 승인 대기·지연 중 받을 항목을 고른다. 관리자가 SMTP를 켜고 계정에 이메일이 등록되어 있어야 발송된다.

로컬 계정의 비밀번호를 잊었으면 로그인 화면의 `비밀번호를 잊으셨나요?`에서 아이디 또는 이메일을 입력한다. 메일로 받은 링크는 한 번만 사용할 수 있고, 새 비밀번호를 설정하면 모든 기기에서 다시 로그인한다. SSO 계정은 Keycloak에서 변경한다.

## 로비 담당자

1. Lobby Dashboard에서 오늘 예정자와 현재 체류 인원을 확인한다.
2. QR Scan에서 카메라, USB Scanner 또는 QR URL 입력으로 검증한다. 담당 사업장이 지정된 로비 담당자는 그 사업장의 로비와 방문증만 처리할 수 있다.
3. 방문자·담당자·장소를 확인하고 필요하면 임시 출입증 번호를 입력해 체크인한다.
4. 체크인 즉시 담당자 알림이 발송 대기열에 들어간다.
5. 퇴실 시 현재 방문자 목록에서 퇴실 처리한다. 방문 중인 방문자는 `출입증` 버튼으로 인쇄용 출입증을 출력할 수 있다.
5-1. 방문자가 QR을 제시할 수 없으면(휴대폰 방전 등) 오늘 방문자 목록에서 `직접 체크인`을 눌러 신분 확인 방법을 기록하고 입실 처리한다. 해당 방문자의 QR은 사용 처리된다. 로비가 여러 개인 사업장은 로비 필터로 화면을 나눈다.
6. 비상 시에는 비상 대피 명단에서 현재 체류자를 인쇄한다. 네트워크가 끊겨도 마지막으로 받은 명단이 열린다.
7. 무인 안내데스크는 관리자에게 받은 키오스크 링크를 태블릿에서 한 번 열어 등록한 뒤 로그인 없이 사용한다.

## 승인자

방문 승인 화면에서 `검토`를 누르면 방문자 명단(회사·차량·반입 장비·동의 주체)과 담당자 메모를 확인한 뒤 승인·반려할 수 있다. 반려 사유는 요청자 화면에 그대로 표시되고, `방문 반려 시` 발송 규칙을 두면 담당자에게 문자로도 전달된다.

## 자주 방문자와 템플릿

1. 방문 템플릿 화면의 자주 방문자에서 이름·연락처와 개인정보 동의 여부를 저장한다.
2. 템플릿을 만들거나 수정할 때 필요한 자주 방문자를 선택한다.
3. `이 템플릿으로 신청`을 누르면 최신 자주 방문자 정보가 신청서에 채워진다. 템플릿에는 개인정보 원문 대신 자주 방문자 ID만 연결된다.
4. 더 이상 사용하지 않는 자주 방문자는 직접 삭제할 수 있으며 모든 템플릿 연결도 함께 제거된다. 직접 삭제하지 않아도 마지막 템플릿 사용 후 관리자가 정한 개인정보 파기 기간이 지나면 자동 삭제된다.

## 사용자 가이드 게시판

왼쪽 메뉴의 사용자 가이드에서 관리자가 게시한 최신 운영 안내를 확인한다. 초안 상태의 글은 관리자에게만 보인다.

## 개인 API 키

프로필 → 내 API 키에서 관리자가 허용한 `read`, `write`, `mcp` 범위를 키별로 선택·변경한다. 원문은 생성·회전 직후 한 번만 표시되므로 Password Vault에 보관한다. 주기적으로 회전하고 더 이상 쓰지 않는 키는 즉시 폐기한다.
