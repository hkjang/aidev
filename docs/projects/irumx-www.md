- 보류 아이디어: ① harfbuzzjs·fontverter 선언 + verify-deps.mjs 를 main 에 다시 올리기(차선 후보였고 1순위가 끝났으니 다음 회차 1순위로 적합) ② GitHub Actions ci.yml 재투입(이제 `npm test` 가 혼자 도니 녹색이 가능 — 보호 경로라 사람 승인 필요) ③ 서비스 페이지 목록 드리프트 감지(verify-build:210 vs tests/site.spec.ts:3 — 합치지 말고 감지만) ④ serve-static.mjs 가 제공할 폴더·404.html 이 없으면 기동 시 알려 주고 요청 한 번에 죽지 않게 ⑤ src/lib/inquiry.ts 순수 함수 단위 테스트(별도 설정이 필요 — 지금 설정에 넣으면 webServer 4개가 같이 뜬다)
- 과제서: 채택 — 과제서가 지목한 두 원인을 이 기계에서 그대로 재현해 확정했고, 지정한 6개 파일 범위와 수용 기준 4개를 모두 충족했다. 다만 과제서의 "검증 1회 6~10분" 예상은 틀렸다(실측 37초).
