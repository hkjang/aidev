- 보류 아이디어: Playwright 브라우저 시험에 silent SSO 루프 방지 + 새 안내 문구 시나리오 추가(가치 3/위험 2/M); SAML `/auth/saml/start`에도 return_to 보존 적용(가치 2/위험 2/S); SAML ACS 제공자 실패 상태도 `/login?sso=error`로 안내(가치 2/위험 2/S, 새 아이디어); OIDC 콜백의 madi 쪽 검증 오류(400/409/401 JSON)도 로그인 화면 `?error=`로 안내 — 로그인 화면은 이미 읽지만 서버가 붙이는 곳이 없음(가치 2/위험 2/S, 새 아이디어); mail·handoff 관련 항목(브라우저 시험, 발송 기록 보존, `/handoff` return_to)은 해당 브랜치 main 병합 뒤 재개.
