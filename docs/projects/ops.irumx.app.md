- 보류 아이디어: ui-*.spec.ts 첫 한 개(로그인→개요 스모크 + axe) — 그때 ci.yml 에 `npx playwright install` 한 단계가 같이 필요하다(1.63 의 `playwright` 패키지는 postinstall 이 없어 `npm ci` 로 브라우저가 깔리지 않는다 — `~/.cache/ms-playwright` 비어 있음을 확인) / `pretest: npm run build` 가 **지금 main(e85afae) 의 package.json 에 없다** — 직전 회차 변경이 아직 머지 전인 듯하고, 그래서 로컬 `npm test` 는 여전히 빌드 없이는 webServer 가 못 뜬다(CI 는 build 를 명시 단계로 두어 영향 없음) / `do:*` 집계 가짜 자원이 `resources.key` 와 안 맞아 `anomalies.service_id` null·알림 제목에 `do:*` 노출(라벨만 교체, 계측 공식 금지) / `npm ci` 가 보고하는 취약점 8건(moderate 4·high 4, 전부 devDependencies) 선별 — 메이저 업그레이드 없이 가능한 것만 / `migrations/meta` 가 0001 까지만 있어 drizzle 스냅샷이 0002~0004 와 어긋난다(위험 구역, 단독 회차)
