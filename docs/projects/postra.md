REST `GET /api/admin/mail/deliveries`, `POST /api/admin/mail/test`(저장된 설정으로 실제 한 통, 받는 주소 비우면 내 계정), 운영 콘솔 "알림" 탭에 시험 발송 폼 + 발송 기록 표(`MailNotificationsPanel`) 추가, `/app` 번들 재빌드·커밋. 검증: notifymail 단위 테스트 3개(기본값·파싱·헤더 인젝션/CRLF), application 테스트 8개(꺼짐 기본·호스트 없으면 경고 incident·배경 발송과 성공/실패 기록·행위자 제외와 종류별/개인/마스터 스위치·비밀번호 비되읽힘(카탈로그·레거시·감사·SecretStore 참조)·시험 발송 결과 보고·배정 메일과 자기 배정 제외·발송 실패 메일·critical incident 관리자 1회), 프런트 vitest 1개(기록 표·시험 발송 호출·결과 표시). `gofmt -l` 깨끗, `go vet ./...`, `go test -race ./...`, `go run ./cmd/postra-contracts -check`, `npm run typecheck && npm test && npm run build` 전부 통과. 실제 릴레이 도달 확인은 이 환경에 SMTP 서버가 없어 fake SMTP 어댑터 수준까지만(어댑터 자체는 기존 발송 경로와 동일). ADMIN_GUIDE 6.5 절(이벤트 표·설정 표·시험 발송·curl)과 NOTIFICATIONS.md 추가, PDF 는 재생성하지 않음.
