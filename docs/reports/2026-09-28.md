- 요약: `handleK8sNotifyScan` 이 조용한 시간을 `time.Now().Hour()` — 게이트웨이 컨테이너의 로컬 시각 — 으로 판정했다. 폐쇄망 배포 이미지에 `/usr/share/zoneinfo` 가 없으면 그 시계는 사실상 UTC 이고, 서울에서 `22-08` 을 저장한 운영자는 요청한 것의 반대를 얻는다(밤새 알림, 07:00~17:00 KST 침묵). 같은 제품의 노드 추세 "업무시간" 필터는 브라우저 타임존을 쓰고 그 사실을 화면에 적는데(admin_ui.go:11272), 조용한 시간만 어느 시계를 쓰는지 말하지 않았다. `GET/POST /admin/k8s/notify/config` 에 `timezone` 을 추가하고, 쓰기 검증을 읽기와 같은 호출(`time.LoadLocation`)로 해서 스캔이 불러올 수 없는 값은 400 `invalid_timezone` 으로 거절하며 이전 설정을 그대로 남긴다(부분 적용 없음 — quiet_hours 와 같은 순서). 빈 값은 기존 동작(서버 로컬)이라 이미 저장된 창의 의미는 바뀌지 않는다. 스캔 응답은 실제로 판정에 쓰인 `timezone` 을, 저장된 타임존을 못 불러온 경우 `timezone_notice` 를 함께 보고한다. 이미지에 zoneinfo 가 없어도 이름이 해석되도록 `time/tzdata` 를 임베드했다. 검증: 신규 종단 테스트 3개(실 SQLite + `Server.Routes` + httptest Mattermost webhook, 호스트 로컬 시각과 3시간 이상 떨어진 실제 IANA 존을 골라 양방향 단언) → `go build ./...` → `go vet ./...` → `go test ./... -count=1`(19 패키지 전부 ok, proxy 59.8s), 손댄 파일 gofmt 깨끗. 인과 확인으로 `.In(loc)` 만 되돌려 같은 테스트가 다시 빨강이 되는 것을 보고 복원했다. 62c9795 로 커밋(프로덕션 파일 2개: k8s_notify.go, admin_ui.go).
