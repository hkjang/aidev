  - globalLoading 병렬 요청 참조 카운트: 3/3/S, 호출 짝 감사 선행.
  - 테스트 가이드의 없는 문서 링크 정리: 2/1/S, 별도 문서 과제로 보류.
- 과제서: 채택 — 실제 원문 접근 가능 여부와 Git/JSON 결과가 과제서에 일치하며 AGENTS 추가를 금지하는 저장소 규칙은 발견되지 않았다.
