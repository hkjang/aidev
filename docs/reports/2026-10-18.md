- 보류 아이디어: ① 음수 step duration 클램프 — 이번에 3회 중 1회 재현(`durationMs: -203`), server.js:1210/1266/2435/4996 네 경로가 같은 Playwright 값을 패스스루한다. 이것이 `test` 잡을 게이트로 올리는 데 필요한 유일한 조각이다(가치 5) ② `npm audit` 이 이제 **critical 1건**을 보고한다 — proxy-addr 1.1.0-2.0.7(critical), qs(moderate), body-parser(low), 전부 `npm audit fix` 범위. lockfile 변경이라 `docker build` 까지 확인 필요(가치 4) ③ 녹화 중복 제거가 `step.value` 만 비교해 서로 다른 `selectOption` 을 삼킨다 — HEAD 에 여전히 있다(server.js:7477)(가치 4) ④ `npm test` 가 6스위트를 `&&` 로 엮어 첫 실패가 나머지 5개의 결과를 가린다 — CI 에서 잡 매트릭스로 쪼개면 한 번에 전체 신호를 본다. 단 러너 명령을 그대로 옮기라는 이번 지시 범위 밖이었다(가치 3) ⑤ CI 의 chromium 다운로드를 `actions/cache` 로 캐시 — 잡마다 수 분이 든다(가치 2). 덧붙여 미머지 수정 두 건(하네스 `stop()` 의 미settle await, 녹화 패널 동기화)은 HEAD 코드에서 재확인했다 — 둘 다 여전히 main 에 없다(`tools/smoke-test.mjs:2386` 의 `.unref()` 타이머, 4098/4115 의 고정 `sleepMs`).
- 과제서: 채택 — 요청된 명세 그대로 `.github/workflows/ci.yml` 한 파일만 추가했다. "지금 통과하는 것만 옮길 것" 과 "러너가 돌리는 테스트 명령을 옮길 것" 이 이 base 에서 다시 충돌했으므로(3회 중 1회 실패) 통과가 증명된 `npm run check` 만 게이트로, 테스트 명령은 보고 전용으로 넣고 측정값과 승격 조건을 파일에 적었다.
