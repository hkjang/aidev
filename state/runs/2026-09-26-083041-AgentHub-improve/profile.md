# AgentHub 프로필 (2026-09-26)
- 목적: 사용자별 격리 AI 런타임과 자동 작업을 정책·승인·DLP·감사로 통제하는 사내 플랫폼.
- 스택: Go 1.25(chi, pgx, go-oidc, OpenTelemetry), PostgreSQL, React/TypeScript/Vite, Kubernetes, Playwright/Node 22.
- 구조:
  - cmd/: control-plane·worker·runtime-proxy·offline 진입점.
  - internal/api/: catalog.go 라우트, 인증·게이트웨이·핸들러·live 테스트.
  - internal/store/: PostgreSQL 저장·마이그레이션·감사·메일 큐.
  - internal/execution/, internal/mail/: 자동 실행·이벤트 전달 및 SMTP 큐.
  - internal/runtimecfg/, internal/operator/: 런타임 설정 문서·Kubernetes 적용.
  - internal/dlp/, internal/tracking/: 내용 검사와 방문 추적/CSP.
  - web/src/: 콘솔. web/scripts/: 브라우저 e2e 40여 개 + Node 회귀 4개(*.test.mjs) + 가이드 촬영.
  - deploy/, scripts/: Kubernetes/offline 배포와 이미지 릴리즈 검사. docs/: ADMIN_GUIDE·USER_GUIDE(md+PDF), architecture.md, decisions/.
- 빌드·테스트: CI 는 `go test -race ./cmd/... ./internal/...`; web 은 `npm ci && npm run lint && npm run test:sso && npm run build`; `bash scripts/release-catalog-images.sh check-versions`; kustomize/compose 검사.
- 빌드·테스트: 값싼 로컬 확인 — `go test ./internal/api ./cmd/runtime-proxy`, `cd web && node --test scripts/guide-settings-check.test.mjs scripts/session-gateway-check.test.mjs scripts/runtime-settings-check.test.mjs scripts/silent-sso.test.mjs`, `node --check scripts/<name>.mjs`.
- 빌드·테스트: DB live 에는 격리 AGENTHUB_TEST_DSN 과 base64 32바이트 AGENTHUB_ENCRYPTION_KEY 필요, 패키지 동시 DB 오염 때문에 `-p 1` 권장. .github/workflows/live-agents.yaml 은 실제 이미지 빌드+실행으로 최대 90분.
- 관례: 한국어 설명 문장 + 영어 conventional 커밋(`fix: …` 뒤 한국어 요약)이 섞인다. 설정은 system_settings 의 키별 JSON 행 + 별도 secret 슬롯. 정본 문서는 docs/ 의 대문자 가이드.
- 관례: 현재 HEAD fd58af7, VERSION 0.251.0(2026-09-23 릴리즈). BASE_VERSION 은 런타임 base 이미지용으로 별도 — internal/dlp·cmd/runtime-proxy 등 base 소스를 바꾸면 상향이 따라온다.
- 위험 구역: internal/api/auth.go·mcpoauth.go, session gateway, internal/store 마이그레이션, .github/workflows. 변경 전 해당 코드를 직접 읽을 것.
- 위험 구역: policy/DLP/runtime-settings PUT 은 실행 중 런타임에 영향을 준다. 설정 스크립트 검증은 격리·폐기 배포에서만.
- 위험 구역: 정책 지점의 행위자는 작업 소유자(task.OwnerID). agent.OwnerID 는 자격증명 조회(SCMTokenFor)에만 맞다.
- 자주 깨지는 곳: API 응답 래퍼와 스크립트의 접근 경로 불일치, 전역 설정 백업/복원, DLP 의 복사된 필드(Category=Agent), 문서의 HTTP 메서드.
- 검증 함정: runtime-settings GET 은 `{settings:{profiles:[]},suggestions,runtimes,targets}`, PUT 은 `{profiles:[]}`. 일반 설정은 전체 GET body[key] + 키별 PUT `{value:…}`. policy 는 GET/PUT `document`, DLP 는 GET/PUT `settings`.
- 검증 함정: 관리자 API 는 관리자 세션 + CSRF 를 요구하며 API 키로는 안 된다.
- 검증 함정: web/scripts 의 Node 회귀 테스트는 실제 스크립트 소스를 문자열로 잘라 vm 컨텍스트에서 돌린다(guide-settings-check.test.mjs 의 `boundary` 슬라이스). 슬라이스 앵커 밖에 선언을 두면 ReferenceError 가 나고, vm 컨텍스트는 전역을 명시적으로만 받는다.
- 검증 함정: CI 의 `test:sso` 는 silent-sso.test.mjs 한 파일만 돌린다 — guide-settings-check·session-gateway-check·runtime-settings-check 는 어느 npm 스크립트에도 없어 CI 에서 실행되지 않는다(package.json 에서 확인).
- 검증 함정: web/node_modules 없음. eslint 는 src 의 TS 만 검사. DSN 없는 Go 성공은 DB 동작의 증명이 아니다.
- 검증 함정: 실물 브라우저 e2e·클러스터·Keycloak·SMTP 는 이 환경에서 미확인. 이전 회차의 성공을 현재 환경의 확인으로 쓰지 않는다.
- 미확인(2026-09-26 회차): Bash 명령 승인이 거부되어 이번 세션에서는 어떤 테스트도 직접 돌리지 못했다. 위 명령들은 이전 회차 기록과 package.json 근거이며 이번에 재실행된 것이 아니다.
- 미확인: CLAUDE.md·AGENTS.md·별도 roadmap 은 저장소 검색에서 발견되지 않았다.
