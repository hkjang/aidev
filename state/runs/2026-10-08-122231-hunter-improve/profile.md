- 자주 깨지는 곳:
  - 테스트 실행은 `${npm_node_execpath:-node}` 유지. npm PATH에 상위 구버전 node가 끼어 0건 실행된 과거 사고를 맨 node 호출로 되돌리지 말 것.
  - 선언된 입력·검사값·실제 wire가 다르면 폼 통과 후 서버 거절 또는 조용한 변환이 생긴다.
  - 숫자 서버 표의 fallback을 min으로 착각하지 말 것. scopes/policies 실제 min=1.
  - 테스트만 보강하는 과제·tracking/CSP의 반복 반려를 피한다. 서버 검증을 느슨하게 하거나 서로 다른 파서를 통합하지 않는다.
  - 기존 resource-number-bounds.test.mjs에 소스 문자열 검사가 있지만 신규 배선 검증의 충분한 근거로 복제하지 말 것.
