# v0.254.0

## 칸에 직접 친 `0x10` 이 16 으로 바뀌지 않습니다

칸에 값을 치면 브라우저의 `Number()` 가 먼저 읽었습니다. 그것은
스프레드시트보다 넓어 `0x1F` 를 31 로, `0b101` 을 5 로, `0o17` 을 15 로
바꿉니다. 엑셀도 구글 시트도 그렇게 읽지 않고, 숫자로 바뀌는 순간 사람이 친
글자는 사라져 되돌릴 길이 없습니다. 제품 코드·색상 코드·자재 번호처럼 `0x` 로
시작하는 값을 적어 넣으신 분은 칸을 떠나는 순간 다른 수가 남는 것을 보셨을
겁니다.

더 나빴던 것은 **같은 글자가 문마다 달랐다**는 점입니다. `0x10` 이 파일
가져오기나 붙여넣기로 들어오면 글자로 남는데 손으로 치면 16 이 되었으니, 한
표 안에 같은 값이 두 가지로 저장되어 있었습니다.

이제 숫자로 담을지는 **셈하는 자**(`spreadsheetNumber` — 서버 수식 엔진의
`decimalText` 와 같은 자)가 정합니다. 16진·2진·8진으로 적힌 글자는 친 그대로
글자로 남습니다. 덤으로 상태 줄 합계와 `=SUM` 이 갈리는 일도 없어집니다 —
서식 없이 숫자로 담기는 것은 셈하는 자가 같은 값으로 읽는 것뿐이기
때문입니다.

## 그 밖에 바뀌는 칸은 없습니다

이 릴리즈로 좁아지는 것은 비10진 리터럴 한 갈래뿐입니다.

- `1,234`·`50%`·`₩5,000` 은 예전처럼 표시 형식과 함께 숫자로 들어옵니다.
- `1e3`·`.5`·`5.`·`-12` 도 예전 그대로 숫자입니다.
- 사람이 친 `007` 은 예전대로 7 이고, 스무 자리 번호도 예전대로 수입니다.
  **칸에 직접 쳐 넣는 것은 파일·붙여넣기와 일부러 다른 문입니다**(v0.253.0) —
  파일에 적힌 것은 되돌릴 길이 없지만, 친 사람은 다시 칠 수 있기 때문이고
  엑셀·시트가 그렇습니다.

컴포넌트 안에 숨어 있던 이 규칙을 `web/src/lib/cellEntry.ts` 로 옮겨 파일·
붙여넣기 규칙과 나란히 두었습니다. 값이 칸에 담기는 문이 셋인데 그중 하나만
다른 곳에 적혀 있으면, 나머지 둘을 고칠 때 이 문이 함께 어긋납니다.

**눈에 띄는 차이 하나** — 데이터 유효성 검사에서 숫자 규칙이 걸린 칸에
`0x10` 을 치면 이제 글자이므로 거절됩니다. 의도한 결과입니다.

## 확인

- `web/src/lib/cellEntry.test.ts` — 칸에 직접 치는 문의 계약을 못 박습니다.
  붙여넣기·파일과 겹치는 곳은 같아야 하고, 일부러 다른 곳(`007`·긴 번호)은
  그것이 일부러임을 테스트에 적었습니다. 고치기 전 코드에서 `0x10`→16 과
  "서식 없는 수는 셈하는 자가 같게 읽는다" 불변식이 실제로 깨지는 것을 본 뒤
  통과시켰습니다(빨강 2 → 초록 7).
- 규칙을 파일로 옮기는 것과 판정을 바꾸는 것을 나누어, 옮긴 직후에는 동작이
  바뀌지 않는 것을 테스트로 확인했습니다.
- 옛 `Number()` 판정과 새 판정이 갈리는 곳을 세 글자 문자열 32768가지로 전부
  대조했습니다. 갈린 324건은 모두 `0x`·`0b`·`0o` 리터럴이었고 그 밖의 부류는
  없었습니다.

`npm run lint`·`npm test`(74파일 519개 통과)·`npm run build`, `gofmt`·
`go build ./...`·`go test ./...`(전체 통과), `scripts/check-release-docs.sh`·
`scripts/check-commit-identities.sh` 를 돌렸습니다. 브라우저 E2E 는 돌리지
않았습니다 — 바뀐 곳이 브라우저 안쪽 함수 한 군데이고, CanvasGrid 는 그
함수를 그대로 부르기 때문입니다.

## 올리실 때

마이그레이션도 새 설정도 없고 필수 런타임 환경 변수는 계속 `POSTGRES_DSN`
하나입니다. 바뀐 것은 브라우저에 실리는 웹 자산뿐이므로 v0.253.0 에서
올라오시는 분은 이미지만 바꿔 다시 띄우시면 됩니다(쓰시던 분은 새로고침 한
번).

이미 16 으로 담겨 버린 칸이 되돌아오지는 않습니다 — 이 릴리즈 뒤에 새로 치는
값부터 적힌 대로 남습니다. 16진으로 적어 수를 얻으시던 분이 있다면 그 칸은
이제 십진수로 쳐 넣으셔야 합니다.

## 오프라인 설치

이 릴리즈는 웹 자산과 서버 바이너리를 포함한 Docker 이미지 아카이브로 제공됩니다.

```bash
sha256sum -c kanpic-v0.254.0.tar.gz.sha256
gzip -dc kanpic-v0.254.0.tar.gz | docker load
docker run --rm -p 8080:8080 \
  -e POSTGRES_DSN='postgres://kanpic:password@postgres.internal:5432/kanpic?sslmode=require' \
  kanpic:v0.254.0
```

- 필수 런타임 환경 변수: `POSTGRES_DSN`
- Redis 및 외부 인터넷 연결: 불필요
- 관리자 초기 로그인을 보호하려면 `BOOTSTRAP_ADMIN_ID`와 `BOOTSTRAP_ADMIN_PASSWORD`를 함께 지정합니다.
- 무결성 검증 파일: `kanpic-v0.254.0.tar.gz.sha256`
