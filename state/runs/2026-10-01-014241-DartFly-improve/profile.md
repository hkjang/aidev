- 목적: 기존 Tadpole 메타 DB를 활용해 여러 DBMS 탐색·읽기 전용 SQL 실행·마스킹·감사·운영 관리를 제공하는 단일 바이너리 웹 플랫폼.
- 스택: Go 1.25.x, net/http·database/sql, MariaDB 메타 DB, MariaDB/MySQL·PostgreSQL·Oracle·SQL Server 드라이버; 임베드 HTML/CSS·ES 모듈 JS, Node 회귀 테스트, Python Playwright 스모크. (이어받음)
- 구조:

  - internal/history/service.go 가 이력 조회 서비스(여기서 limit/offset 클램프), internal/store/mariadb/history_repository.go 가 SQL.
  - internal/auth·sso·ssoconfig / query·dbconn·masking / access·rbac·governance·settlement·retention / apihub·mcphub / store/mariadb(+migrations). (이어받음)
  - internal/webui: 임베드 pages/js/css(app.js 2820줄이 최대), assets.go 서빙, jstest_test.go 가 test/js 를 glob 으로 묶음.
  - test/js: Node 회귀 18개(.test.mjs, glob 자동 배선, 공용 로더 load.mjs). test/livedb: 실제 DB. test/smoke: 실제 바이너리(run.sh) + 배포 이미지(artifact.sh) + pages.py/editor.py. deploy: build-release.sh·compose·k8s·master.key. docs: 보증·설정·관리 가이드.

  - JS 테스트: `go test -v -run TestBrowserModuleTests ./internal/webui/...` 또는 `node test/js/X.test.mjs`.
- 관례: 한국어 `feat:`/`fix:`/`test:` 커밋 + PR 병합, 릴리스 노트 제목 `vX.Y.Z`, 릴리스 커밋·버전 파일 없음(lightweight 태그를 머지 커밋에). 환경변수 DARTFLY_*·_FILE. 마이그레이션은 internal/store/mariadb/migrations + ensureColumn ALTER. 오류는 RFC7807 problem + `DF_*` 코드. 주석은 "왜"를 한국어로 길게. CLAUDE.md·AGENTS.md·로드맵·TODO/FIXME 없음.
