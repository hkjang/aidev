# aiportal-py 프로필 (2026-09-21)
- 목적: KCB AI 포털 FastAPI 백엔드로 지식 RAG·채팅 스트림·Confluence/법령 색인·피드백 평가 제공.
- 스택: Python · FastAPI/uvicorn · LangGraph/LangChain · PostgreSQL(psycopg2) · Milvus(pymilvus) · requests · Kiwi. Swagger 정적 자산 포함.
- 구조:
  - api.py: 라우트·lifespan·health·추천 질문 캐시 및 백그라운드 task 등록.
  - app/core/config.py, configs/: Settings와 ENV_STATE 기반 환경별 설정·컬렉션 상수.
  - service/: 채팅·히스토리·피드백·색인 서비스; 피드백 초기/주기 배치는 executor 경유(A-115).
  - util/: 워크플로·Milvus/DB·파일 추출 및 task_supervisor·feedback_batch 등 helper.
  - pipeline/kai, pipeline/kcb, pipeline/law: 수집·변환·색인.
  - pipeline/law/library: XMLParserFactory → SourceDocumentBuilder.build → JSONOutputFormatter.format_document 순수 변환.
  - pipeline/law/dynamic_fetcher.py:fetch_and_parse가 변환 체인을 연결; pipeline_task.py가 임베딩·적재.
  - collection_script/: 명시적 컬렉션 관리, import 부작용 제거 회귀 존재.
  - tests/unit/: 실제 런타임 테스트와 AST 검사 혼재; tests/conftest.py가 루트를 sys.path에 추가.
  - docs/: 감사(CURRENT_STATE_AUDIT), ROADMAP, TESTING, 운영·API·구조 문서.
- 빌드·테스트: `PYTHONDONTWRITEBYTECODE=1 python3 -m pytest -q -p no:cacheprovider` → 1052 passed in 2.46s(이번 정찰). `git diff --check` 통과. 별도 빌드 메타데이터 없음. requirements-dev.txt는 pytest·pyflakes; pyflakes 단독 실행은 이번 미실행.
- 관례: 최근 한국어 `fix: … (감사 A-nnn)` 및 PR merge. ENV_STATE/configs/.env.* 설정. DB migration 체계는 문서상 없음(운영 전체 절차 미확인).
- 위험 구역: auth/session·token_store, DB 풀 종료, Milvus 삭제/재색인. .gitlab-ci.yml은 main/develop에서 reset·재시작하는 deploy stage만 있고 테스트 gate 없음.
- 자주 깨지는 곳: shutdown 판정은 task.cancelled()가 아니라 _shutting_down; CancelledError를 삼키는 실제 Task로 검증. 외부 실패를 None/문자열로 성공처럼 반환하는 패턴; 피드백 조회(A-114), Confluence insert(A-113)/spacefile delete(A-116)는 해결.
