release: ReSSO v0.9.103

Reject an absent or unreadable CA before reusing the LDAPS test container,
and explain how to recover the existing certificate directory in the README.
The LDAP development guide now preserves that preparation failure through an
assignment followed by eval and tests joined with &&. It names the repository
root, same Bash shell, service reuse default, optional cleanup and shared
certificate directory explicitly.

Includes both merged changes since v0.9.102. Stamps the version in the
Makefile, console package metadata, .env.example and both compose files,
with Korean changelog entries and no production code, schema or runtime
configuration changes.
