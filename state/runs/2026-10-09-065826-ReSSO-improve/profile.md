# ReSSO 프로필 (2026-10-09)
- 목적: 오프라인 단일 바이너리 OIDC SSO 제공자와 사용자·Realm 관리 콘솔. RP 구현은 포함하지 않는다.
- 스택: Go 1.26/toolchain go1.26.7, chi v5, PostgreSQL/pgx v5, LDAP, React 19/TypeScript/MUI/React Query/Vite 7/vitest 4. CI Node 22.23.0.
- 구조:
  - cmd/resso: 서버·CLI·유지보수·예약 작업·메일 알림 및 개발 도구 검사 테스트.
  - internal/httpserver: OIDC·인증·관리·개인·MCP 라우트와 실제 DB HTTP 연동 테스트.
  - internal/store: DB 접근·세션·코드/refresh 회전; migrations/의 자동 SQL 마이그레이션.
  - internal/oidc: PKCE·서명·토큰 생성/검증; internal/federation: LDAP/TLS 연동.
  - internal/backchannel·mail·tracking·observability: 통지·추적·관측.
  - web/src: React UI; web/vite.config.ts의 jsdom 테스트 설정; webui/dist: Go embed 빌드 산출물.
  - scripts: Docker 테스트 서비스·smoke·릴리즈; docs: 운영·호환·LDAP 및 화면 가이드.
- 빌드·테스트:
  - 저장소 루트의 같은 셸에서 `test_env="$(scripts/test-services.sh)" && eval "$test_env" && go test ./internal/...`.
  - `make lint`: golangci-lint v2.13.1 + govulncheck + ESLint. `make test`: Go race + vet + vitest + build(통상 수분, Go 연동 테스트를 SKIP 집계로 재실행).
  - `make build VERSION=vX.Y.Z`. 빌드가 webui/dist/index.html을 바꿀 수 있음.
  - 이번 정찰: bash 구문 검사와 실제 누락 CA 기반 eval 실패 전파 프로브 통과. 정상 준비 후 TLS 테스트 race 실행 PASS(1.086s), SKIP 없음.
  - 추가로 준비 후 `go test ./internal/...` exit 0(httpserver 95.201s/store 61.504s, 일부 cached). 비상세 출력이라 전체 SKIP 0은 미확인.
  - 이번 full make lint/make test는 미실행. 과거 회차 전체 통과를 이번 결과로 인용하지 말 것.
- 관례: 영문 fix:/feat:/docs:/release: 커밋. HEAD a6a1a61(147fce8 병합), 버전 v0.9.102. 환경변수+platform_settings 설정.
- 문서: USER_GUIDE/ADMIN_GUIDE는 화면 정본, README는 개발·연동 참고, operations.md는 운영 진단, user-federation.md는 LDAP 가이드.
- 지침/로드맵: 저장소 CLAUDE.md/AGENTS.md/roadmap/TODO 파일 검색 결과 없음. TODO/FIXME 본문 검색도 결과 없음.
- 위험 구역: httpserver/auth.go·oidc.go·middleware.go(인증/토큰/CSRF), store/migrations, .github/workflows/release.yaml.
- 설계 관례: 없음과 조회 실패를 구별하되 Endpoint 계약은 개별적이다(token 500/revoke 503/introspection 200 active=false). 공통 응답 처리로 통합하지 않는다.
- 미검증 client_id/grant_type/Secret/code/verifier를 지표 라벨·감사 detail에 넣지 않는다. 취소된 호출은 장애 지표·Limiter 예산을 올리지 않는다.
- 자주 깨지는 곳: gofmt, 빌드 산출물, LDAPS bind mount/CA 경로, 추측한 HTTP 상태, 유지보수 SQL 순서 고정 테스트.
- 검증 함정:
  - 서비스 환경변수 부재 시 SKIP이어도 go test exit 0. 실제 PASS와 SKIP 여부를 확인한다.
  - CI verify는 세 서비스를 준비하지만 release는 PostgreSQL만 준비한다.
  - npm의 Node는 조상 node_modules/.bin에 영향받았던 이력이 있다. package.json의 npm_node_execpath PATH 고정을 유지한다.
  - Registry는 표본 없는 지표도 HELP/TYPE을 출력하므로 지표 부재는 샘플 행으로 검사한다.
  - 로그 동시 읽기는 lockedBuffer. DB 장애 주입은 테이블/컬럼 RENAME + 즉시 복구 + t.Cleanup 선례를 따른다.
  - govulncheck 실행 파일이 구형 Go로 빌드돼 Go 1.26 분석에 실패한 이전 사례 있음. 도구 빌드 버전과 대상 버전을 구분한다.
- 이전 기록의 정정: UpdateUser 세션 종료는 TestIntegrationDisablingAnAccountSignsItOutForGood가 이미 검증한다. 테스트 공백으로 재선택 금지.
- 코드 재사용 UserByID의 ErrNotFound는 계정 삭제 시 코드도 CASCADE 삭제되므로 해당 분기 도달 근거가 없다. AuthorizationCode.UserID는 포인터가 아닌 UUID 값이다.
- 사람이 받지 않은 접근: 코드 교환 저장소 장애 500 응답 변경(5bed9dc) 재제출 금지.
- 최근 완료: Client 인증 미판정 Endpoint 세 종류, 코드 재사용 폐기 실패 감사, actor 조회 실패 관측, Node 고정, LDAPS 재사용 CA 누락 감지(147fce8).
- 현재 선택: docs/user-federation.md 개발 예제의 단독 eval 실패 은닉 및 무조건 --stop 안내 수정. 문서 1개·서버 코드 0개.
- 재현: 실제 스크립트가 없는 CA 경로로 exit 1이어도 기존 eval은 0+후속 실행. assignment && eval && 후속 형태는 exit 1+후속 미실행.
- 환경: 세 테스트 컨테이너 running, LDAPS CA 마운트 /tmp/resso-test-certs. 실제 CA 삭제/컨테이너 제거 없이 프로브 수행.
- 주의: --stop은 모든 테스트 컨테이너·인증서를 삭제한다. 정상 검증 끝에 자동 실행하거나 환경 복구용으로 실행하지 않는다.
