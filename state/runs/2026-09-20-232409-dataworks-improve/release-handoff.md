# v0.9.59 릴리즈 인계

- 적용 스킬: marketing:product-launch, technology:release-and-deployment. 전용 Skill 도구가 없어 headcount의 SKILL.md를 직접 읽었다. 두 스킬에 별도 반환 템플릿은 없다.
- 출시 등급: Tier 3 개선. 릴리즈 노트만 준비하며 별도 홍보·메일 발송은 하지 않는다.
- 대상: 공백을 포함한 레거시 계약 valid_to를 사용하는 액션 센터 운영자. 미래 계약의 잘못된 high 경고와 조회 기간 밖 집계를 수정한다. 새 입력 POST는 이미 trim하므로 레거시 저장 행이 핵심 대상이다.
- 지원 답변: 저장 데이터 및 JSON 원문은 보존된다. 만료 계약 경고는 유지된다. 데이터 마이그레이션과 가격·패키징 변경은 없다. docs/OPERATIONS.md에 동작이 문서화되어 있다.
- 일정: 2026-09-20 머지 후 패치 릴리즈. 검사와 이미지 스모크 통과가 날짜보다 우선한다.
- 출시 조건: Go build/vet/test/API 감사, web ci/lint/test/build, 버전 일치, gzip/manifest/이미지/HTTP 스모크 검증 통과.
- 산출물: 기존 scripts/release.sh로 linux/amd64 이미지를 한 번 빌드해 저장한 tar.gz 하나를 러너가 게시한다. CI는 main push/PR/수동 검사만 수행하고 Release를 생성하지 않는다.
- 운영 배포 책임자: hkjang 또는 외부 릴리즈 러너 운영자. 이 세션은 운영 배포를 수행하지 않는다.
- 배포 제안: 먼저 검증 환경 한 곳에 동일 아카이브를 적재하고 health/ready/Workbench를 확인한 뒤 확대한다. health/ready가 60초 안에 200이 아니거나 기존 접근권 query 200/403 판정 또는 만료 경고가 한 사례라도 회귀하면 중단한다.
- 롤백: v0.9.58 이미지를 재적재하고 기존 DB·키 설정을 보존하여 컨테이너를 교체한다. 이번 패치에는 스키마 변경이 없다.
- 배포 후 목표: 첫 적용 환경에서 24시간 안에 공백 포함 미래 계약의 잘못된 high 경고 0건, 조회 창 밖 집계 0건, 기존 query 접근 판정 회귀 0건. 첫 지원 문의를 운영자가 확인한다. 아직 운영 데이터 관측 결과는 없다.
- 미수행: 운영 PostgreSQL·실제 계정 배포 및 팀 외부 사용자의 신규 사용 검증은 운영 접근과 무인 세션 범위 때문에 수행하지 않았다. 인증 비밀값을 만들지 않고 로컬 SQLite HTTP 스모크로 이미지 실행을 검증한다. 기존 문서 화면 자산은 재촬영하지 않았다.
