# dataworks 프로필 (2026-09-20)
- 목적: 데이터 상품의 생성·카탈로그·계약·접근권·출시 게이트와 운영 워크벤치를 제공하는 서버이며 MCP·OpenAI 호환 프록시 및 Clustara 운영 기능도 포함한다.
- 스택: Go 1.25, SQLite 기본/PostgreSQL 선택, React 19·TypeScript·Vite·Tailwind·TanStack, Vitest·Playwright, CI Node 24.
- 구조:
  - cmd/dataworks — 주 서버; cmd/clustara·clustara-agent·clustara-cli도 존재.
  - cmd/api-surface-audit — 서버 라우트·OpenAPI·CLI·SDK 정합성 감사.
  - internal/proxy — HTTP 라우트, 관리자 API, 런타임 상품 query, 인증·Keycloak·MCP, 레거시 콘솔.
  - internal/dataworks — publish gate·retirement·fit score 등 도메인 규칙.
  - internal/store — SQLite/PostgreSQL 접근, 코드 내 마이그레이션, 계약·접근권 영속화.
  - internal/config·tracking·secret·audit — 환경 설정, 추적 스니펫/CSP, 비밀값, 감사. internal/mail은 현재 main에 없음.
  - internal/kube·collector·analyzer·action·agent — Kubernetes/Clustara 운영·수집·분석·작업 기능.
  - web/src — React 워크벤치; web/e2e·capture — 브라우저 테스트·문서용 fixture; web/embed.go — SPA 임베드.
  - docs — USER_GUIDE/ADMIN_GUIDE의 md·PDF 정본, OPERATIONS, RELEASE_GUIDE, K8S_PHASE2_PLAN 등.
  - scripts·deploy·sdk — 릴리즈/운영 스크립트, 배포 설정, TypeScript SDK.
- 빌드·테스트: 루트 `go build ./...`, `go vet ./...`, `go test ./...`(전체는 분 단위 가능), `go run ./cmd/api-surface-audit`.
- 웹 검증: `cd web && npm ci && npm run lint && npm test && npm run build`; build가 tsc -b 타입 검사도 수행. 브라우저는 `npm run test:e2e`, 캡처는 `npm run capture:docs`(긴 실행).
- 관례: 최근 커밋은 영어 conventional 제목, 운영 설명·가이드는 한국어. 설정은 환경 변수 + 관리자 설정 레지스트리/DB override. DB 마이그레이션은 store 코드. UI 기준은 DESIGN.md.
- 위험 구역: internal/proxy/keycloak*.go·mcp_oauth.go·인증/session, internal/store 마이그레이션, 관리자 설정 검증, .github/workflows/ci.yml, web/embed.go의 dist 처리.
- 자주 깨지는 곳: 날짜·상태를 도메인/액션 센터/런타임에서 다르게 해석하는 문제. 과거 contract_key·entitlement id 재부모화 방지는 유지해야 함.
- 해결된 장애: web/dist/.gitkeep 삭제는 v0.9.57의 keepDistPlaceholder로 해결. emptyOutDir은 유지하며 stale 산출물 제거 후 원본 placeholder 복원. 수동 git checkout 안내는 폐기됨.
- 검증 함정: CI는 Go build/vet/test/API 감사 및 web lint/test/build만 실행. Playwright e2e·캡처는 CI 미포함이고 기존 workbench e2e는 HTTP route mock 위주라 실제 SSO/MCP 배선을 증명하지 않음.
- 검증 함정: 현재 main에는 메일 브랜치가 없어 이전 메일 테스트/문서를 현재 기능으로 가정하면 안 됨. 실제 Keycloak·SMTP 운영 연동은 미확인. 일부 dataworks_runtime.go 등은 CRLF.
- 기준: main@88f853a(v0.9.58); 저장소 내부 CLAUDE.md·AGENTS.md는 검색되지 않음. TODO/FIXME 검색에서 당장 선택할 명시 과제는 없었고 K8S 로드맵에는 완료/부분 완료 작업이 혼재.
