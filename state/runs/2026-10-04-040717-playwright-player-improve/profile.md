# playwright-player 프로필 (2026-10-04)

- 목적: Playwright 를 상태 유지형 REST API + Streamable MCP 로 감싸, 오프라인망에 `docker load` 로 반입해 쓰는 브라우저 자동화 서버. 산출물은 git 태그가 아니라 **동작이 검증된 도커 이미지**다.
- 스택: Node.js (`engines: >=22`, ESM, `"type": "module"`), express 4, playwright + @playwright/test 1.58.2, swagger-ui-dist. DB 없음 — `data/` 아래 파일시스템 영속화(runs, artifacts, storage-states, environments, datasets, schedules). 프런트는 `public/` 의 정적 HTML/JS. package.json version 0.16.0.
- 구조:
  - `server.js` — **11,581행 단일 파일**이 API·MCP·실행 큐·녹화·워크플로 컴파일러·권한까지 전부 담는다. 모듈 분리 없음.
  - `public/` — 내장 페이지(`/`, `/playground`, `/runs`, `/demo/test-page`, `/docs`)와 `/ui/*` 자산. 플레이스홀더 치환(`{{...}}`). 검사용 훅은 `data-testid`(예: `recording-steps` 컨테이너와 그 안의 `recording-step` 행).
  - `tools/smoke-test.mjs` — **4,205행 단일 E2E 스모크 스위트**. 유일한 자동 테스트. 스크래치 포트·디렉터리로 서버를 띄워 REST·MCP·실제 브라우저 세션을 모두 때린다.
  - `tools/offline-load-run.{sh,ps1}` — 오프라인 반입 스크립트. `scripts/` — API 로 실행되는 Playwright spec 샘플 9개(형제 모듈 import 있음). `docs/` — `RELEASE_CHECKLIST.md`(정본), `guides/` 한·영 쌍.
  - 루트에 한국어 보고서 `*_KO.md` 다수 + 66KB `README.md`(API 계약의 정본 서술이 여기 있다 — 예: `durationMs` 는 음수가 되지 않는다, README.md:948).
- 빌드·테스트:
  - `npm run check` → `node --check server.js`. 의존성 없이 돌고 빠르다. (`CHECK_OK` 류 출력 없음, 조용히 exit 0)
  - `npm test` → `node tools/smoke-test.mjs`. **느리다 — 1회 약 6분.** 브라우저가 없으면 browser-dependent 검사가 SKIP 된다.
  - 릴리즈 검증: `SMOKE_REQUIRE_BROWSER=1 npm test` → 브라우저 미설치를 FAIL 로 승격. 전부 초록이면 `150 passed, 0 failed, 0 skipped`.
  - 선행: `npm ci`(수 분), `npx playwright install chromium`(~360MB).
  - `docker build` → `docker run` 으로 `docs/RELEASE_CHECKLIST.md` 3절 표를 손으로 확인. 생략 금지가 문서에 명시돼 있다.
- 관례: 커밋 메시지는 **영어 한 줄, 명령형 현재형, 결과 지향**. 설정은 전부 **환경변수**(PORT, API_TOKEN, SCRIPTS_DIR, RUNS_DIR, URL_ALLOWLIST, LLM_BASE_URL, MAX_CONCURRENT_RUNS …). DB 마이그레이션 없음. CHANGELOG 파일 없음. 문서·보고서는 한국어, 가이드만 `-ko`/`-en` 쌍.
- 위험 구역:
  - `principals.json` 기반 역할·범위 권한, 승인 게이트(`decidedByVerified`), MCP `tools/list` 필터링 — 깨지면 `/mcp` 가 권한 우회로가 된다.
  - `secrets/` 와 `{{secret.NAME}}` 스크러빙 — 로그·감사에 평문이 남으면 이미지를 받은 모든 곳에 유출. 식별자만 넘길 것.
  - 도커 entrypoint 의 권한 축소(비root) + 마운트된 호스트 `scripts/` 소유권 — v0.3.0·v0.4.0·v0.5.1·v0.6.0 이 여기서 깨져 나갔다.
  - `URL_ALLOWLIST` 는 세션과 스크립트 실행이 **서로 다른 메커니즘**을 쓴다. 한쪽만 고치면 안 된다.
  - run 결과의 step duration 은 **세 경로**가 같은 값을 읽는다: 생성되는 step 리포터(server.js:1193-1197, 템플릿 문자열 안), `flattenReportSteps()` 폴백(server.js:1246-1255), 테스트 레벨(server.js:2421). 하나만 고치면 다른 쪽이 다른 값을 낸다.
- 자주 깨지는 곳:
  - **좋은 수정이 main 에 도달하지 못한다.** 2026-10-04 기준 `main@a2a44d4` 위에 검증까지 끝난 커밋 셋이 로컬 브랜치에만 있다: `254a099`(부팅 실패 보고 + `tools/harness-selftest.mjs`), `d2f428d`(녹화 패널 동기화), `5476435`(`.github/workflows/ci.yml`). **main 에는 `.github/workflows` 디렉터리 자체가 없다.**
  - 스모크의 **고정 `sleepMs` 대기**가 관측 가능한 사후조건을 대신하는 자리 — 부하가 걸린 verify 머신에서만 터지는 플레이크의 원천(`tools/smoke-test.mjs` 4094/4111 등).
  - 볼륨 마운트 없이 띄우면 통과하지만 마운트하면 깨지는 부류, 세션 생성 경로(스크립트 실행만 보면 놓침) — 각각 릴리즈 2회 유출.
  - 녹화(`startRecording`) 중복 제거가 `step.value` 만 비교해 `selectOption`(`values`)·`press`(`key`) 를 삼킨다 — **미수정**(server.js:7359-7366).
- 검증 함정:
  - **CI 가 main 에 없다.** "워크플로가 실패했다" 는 GitHub Actions 가 아니라 자율 러너의 릴리즈 단계(`npm test`)를 뜻한다.
  - **새 워크트리에 `node_modules` 가 없다.** 없으면 `npm test` 는 `Cannot find module 'swagger-ui-dist/package.json'` 로 죽는다. 회차 시간 예산을 먼저 떼어 둘 것. 샌드박스에 따라 `npm ci` 가 권한으로 막힐 수 있다(2026-10-04 정찰에서 실제로 막혔다).
  - 이 환경의 node 는 **v22.23.1** 이다(2026-10-04 실측). 이전 프로필의 "v20.19.2" 는 틀렸다.
  - 브라우저가 없으면 문제의 검사가 조용히 SKIP 되어 결함이 보이지 않는다. 결함을 보려면 chromium 을 깔 것.
  - 일부 지점은 그룹 SKIP 과 검사 SKIP 을 **두 줄로** 찍어 skipped 집계가 부풀려진다(`tools/smoke-test.mjs:34-45` 의 `check()` 가 bare `'skip'` 만 인식).
  - 스모크 내부 대기가 길다: `waitForRuns` 180초, `waitForHealth` 60초. 실패 시 벽시계가 빠르게 쌓인다.
