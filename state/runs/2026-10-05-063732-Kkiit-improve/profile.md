# Kkiit 프로필 (2026-10-05)
- 목적: 사람·기업·AI Agent의 전문 서비스를 주문·납품·구매확정·정산으로 연결하는 오프라인 운영 가능 마켓플레이스.
- 기준: main@6f7c6cd, v0.4.13. 2026-09-28 프로필의 버전과 남은 결함 목록을 갱신.
- 스택: Go 1.26, net/http, pgx/v5, PostgreSQL 16+; React 19, TypeScript 5.9, MUI 7, Vite 8; 웹 번들은 Go embed.
- 구조:
  - cmd/kkiit: 프로세스·HTTP 서버·워커 시작과 종료.
  - internal/httpapi: router.go가 라우트 정본; 도메인별 핸들러와 단위/통합 테스트.
  - internal/database/migrations: 번호 SQL, 시작 시 advisory lock 안에서 자동 적용.
  - internal/worker: Outbox·알림·웹훅·위험·정산·신뢰 점수 배경 처리.
  - internal/config·cryptox·password: 환경 설정, 비밀 암호화, 비밀번호.
  - internal/analytics·mail·netguard: 방문 추적, SMTP, 웹훅 주소 정책.
  - web/src: React UI, pages/AdminPage.tsx에 관리자 기능.
  - internal/ui/dist: 추적하는 embed 번들. 검증 빌드 산출물 커밋 금지.
  - docs: USER_GUIDE/ADMIN_GUIDE(md·pdf), architecture.md, mcp.md, openapi.yaml.
- 빌드·테스트:
  - `go test ./cmd/... ./internal/...` — 이번 정찰 PASS, DSN 없음으로 통합은 SKIP.
  - `go vet ./cmd/... ./internal/...`, `gofmt -l cmd internal` — 표준 검증, 이번에는 미실행.
  - `make test-integration KKIIT_TEST_DSN=postgres://…` — 전용 폐기 DB 필수. timeout 300s, 과거 80~100초.
  - `npm --prefix web test` — README 요구 Node 24+에서 실행. 과거 컨테이너에서 10건 확인; 이번 미실행.
  - `make check` — Go 포맷/test/vet, npm ci/lint/test/build. 설치 시간이 들고 추적 dist가 바뀔 수 있음.
  - `make build` — 웹 빌드 후 bin/kkiit 생성.
