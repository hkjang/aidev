# aiportal-py 프로필 (2026-09-20)
- 목적: KCB AI 포털의 FastAPI 백엔드로 지식 RAG·채팅 스트림·Confluence/법령 색인·피드백 평가를 제공.
- 스택: Python · FastAPI/uvicorn · LangGraph/LangChain · PostgreSQL(psycopg2) · Milvus(pymilvus) · requests · Kiwi. 프런트 앱 없이 Swagger 정적 자산 포함.
- 구조:
  - `api.py`: 라우트·lifespan·health·추천 질문 캐시 및 백그라운드 task 등록.
  - `app/core/config.py`, `configs/`: Settings와 환경별 설정·컬렉션 상수.
  - `service/`: 채팅·히스토리·피드백·색인 서비스. feedbackservice의 초기/주기 배치는 executor로 이동 완료(A-115).
  - `util/`: 워크플로·Milvus/DB·토큰·파일 추출; task_supervisor, feedback_batch, space_file_indexer 등 순수 helper.
  - `pipeline/kai`, `pipeline/kcb`, `pipeline/law`: 수집·변환·색인 파이프라인.
  - `pipeline/law/library`: xml_parser_core → source_document_builder → json_formatter 순수 변환; dynamic_fetcher.fetch_and_parse에서 연결.
  - `collection_script/`: 명시적 실행 시 컬렉션 생성·삭제, import 부작용 제거 완료.
  - `tests/unit/`: 순수 런타임 테스트와 AST 검사 혼재; tests/conftest.py가 루트를 sys.path에 추가.
  - `docs/`: CURRENT_STATE_AUDIT, ROADMAP, TESTING, OPERATIONS, API_REFERENCE 등.
- 빌드·테스트: `PYTHONDONTWRITEBYTECODE=1 python3 -m pytest -q -p no:cacheprovider` → 이번 정찰 1040 passed in 2.55s. 별도 빌드 설정 없음. requirements-dev.txt는 pytest·pyflakes. `python3 -m pyflakes .` 단독 실행은 이번 미실행.
- 관례: 최근 커밋은 한국어 `fix: … (감사 A-nnn)`, PR merge. ENV_STATE와 configs/.env.* 설정. DB migration 체계는 문서상 없음(실제 전체 DB 운영 절차 미확인).
- 위험 구역: `.gitlab-ci.yml`은 deploy 전용이며 main/develop에서 reset·재시작 수행, test stage 없음. util/token_store.py와 auth/session, DB 풀 종료, 운영 Milvus 삭제·재색인은 자동 소규모 회차에서 회피.
- 자주 깨지는 곳: shutdown 판정은 task.cancelled() 대신 `_shutting_down`; CancelledError를 삼키는 실제 Task로 검증. 실패를 None/문자열로 반환해 성공처럼 보이는 패턴: fetch(A-114), insert(A-113), spacefile delete(A-116)는 해결됨.
- 검증 함정: 기존 service/api AST 검사는 실제 배선 보장의 대체가 아님. 외부 모듈 import/startup은 Settings·/logs·DB·tokenizer에 의존; 이번 service/api 전체 import 및 운영 통합 테스트 미실행.
- 검증 함정: 법령 세 변환 모듈은 외부 의존성 없이 실제 import·체인 실행 확인. 행정규칙 가지조문 hierarchy_path 오류 재현했지만 운영 빈도/UI 영향은 미확인. 신규 변환 수정만으로 기존 색인 데이터는 바뀌지 않음.
- 문서 드리프트: CODEBASE_MAP의 현재 없는 구조에 tests/·pytest.ini 부재가 남아 실제와 다름. 이전 프로필의 삭제 실패 잔존·1025 tests 기록도 현재와 달라 갱신.
- 정찰 환경: 저장소 CLAUDE.md/AGENTS.md 검색 결과 없음. 요청된 pmo/technology 세 스킬은 callable 도구 및 로컬 SKILL.md 검색에서 발견 못함(절차 미확인).
