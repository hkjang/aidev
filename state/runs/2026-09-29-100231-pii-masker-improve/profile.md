# pii-masker 프로필 (2026-09-29)
- 목적: PDF/PNG/JPG의 PII 영역을 Upstage 호환 추론으로 찾아 마스킹 파일을 돌려주는 동기·비동기 HTTP API와 Playground UI.
- 스택: go.mod Go 1.25.0, 로컬 검증 Go 1.26.7 linux/amd64; gorilla/mux, pdfcpu, x/image, vendor 고정. DB 없이 job.json·입력·출력을 디스크에 보관. 단일 HTML UI, Docker/Compose.
- 구조:
  - cmd/pii-masker — 진입점(파일 목록 확인, 이번 내용 재독 안 함).
  - internal/app — HTTP 서버 배선, graceful drain, 보존 스위퍼 기동.
  - internal/config — PII_MASKER_* Load/정규화; timeout·mock 주소·MaxPages=0·양수 제한 테스트 존재.
  - internal/httpapi — mask/jobs/history/config/test-connection API, documentResponse(no-store/nosniff), static/index.html UI.
  - internal/service — 동기 슬롯·비동기 runner, draining, 보존 sweeper, 문서 처리.
  - internal/jobs — 메모리 맵·job.json 영속/복구, 고아 및 보존기간 삭제, 전체 clone 후 이력 정렬.
  - internal/upstage — 인증, allow-host, 리다이렉트 횟수·HTTPS 강등 검사, 응답 처리.
  - internal/document·internal/masking — 첨부 정규화와 이미지/PDF 마스킹; internal/core 공용 타입, internal/mock 테스트 추론.
  - scripts — smoke/export/run-from-archive; 이번 스크립트 내용 미확인.
- 빌드·테스트: `go test -count=1 ./...` 1초 내 통과, `go test -count=1 ./internal/config`, `go vet ./...`, `go build ./...`, `git diff --check` 통과(2026-09-29).
- 추가 검증: `go test -race -count=1 ./internal/config ./internal/httpapi`, `gofmt -l ./cmd ./internal`은 이번 정찰 미실행. 외부 Upstage 불필요.
- 관례: 영어 명령문 커밋+PR 병합, 한국어 README가 동작 문서. 환경변수 설정, DB 마이그레이션 없음.
- 문서/CI: CLAUDE.md·AGENTS.md·docs/·로드맵·.github CI 없음(추적 파일·디렉터리 확인). vendor 제외 TODO/FIXME 없음. 외부 러너 CI는 저장소 밖이라 미확인.
- 위험 구역: upstage 인증/호스트 검사, service draining/WaitGroup, jobs.load RemoveAll, 업로드 크기 제한. PDF는 사각형 덧그리기로 원문 텍스트 레이어 삭제 미지원(README).
- 자주 깨지는 곳: 전달된 실패·롤백 교훈 없음. 상태/시각/결과 경로/download_url의 생성·조회·이력·재기동 경로 일치에 주의. 과거 해결된 UTF-8 작업 재선정으로 과제서 기각 이력 있음.
- 검증 함정:
  - startAppServerWithUpstream/startAppServerWithConfig는 config를 직접 조립한다. Load 관련 회귀는 customize 안에서 실제 config.Load 결과를 사용해야 한다.
  - customize는 app.New 전에 실행된다. seedStoredJobFiles로 실제 core.JobRecord JSON을 디스크에 넣어 재기동/보존을 검증 가능.
  - t.Setenv 테스트 병렬화 금지; default 테스트 일부는 외부 환경 영향을 받으므로 신규 테스트는 값을 명시적으로 비운다.
  - app.orDefault와 upstage.httpClient는 비양수 timeout을 보정하지만 retention과 syncQueueWait는 보정 없이 사용한다.
  - Go overlay 재현에서 JOB_RETENTION_HOURS=2562048 및 SYNC_QUEUE_WAIT_SECONDS=9223372037이 음수가 됨. 이번 과제는 config의 여섯 duration 설정에 한정, 크기 오버플로는 미해결 후보.
  - Dockerfile은 Go 1.25.0, 로컬은 1.26.7이다. Docker 빌드·Windows Rename·32비트 실행 미확인.
  - JSON 키 omitempty, UTF-8 JSON 자동 치환, debug.response 이중 디코딩, root chmod 오류 재현의 함정은 이전 프로필 참조 내용 유지.
