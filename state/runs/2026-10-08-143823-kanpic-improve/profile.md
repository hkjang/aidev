- 구조:

  - internal/workbook·collaboration: 저장과 협업; auth·apikey: 인증·인가.
  - internal/formula·delimited·importexport·external: 계산·파일 규칙·가져오기·원격 수식.
  - internal/automation: schedule.go ParseSchedule/Next, service.go nextScheduleTime/advanceSchedule 및 DB 예약 실행.
  - internal/mail: SMTP·알림·기록/재시도; internal/observability/logs.go: 콘솔과 DB 로그.
  - internal/handoff·ai·analytics·presentation·settings: 문서 전송·AI·분석·슬라이드·설정.
  - migrations: 번호별 SQL; internal/integration: 실제 DB 통합 테스트.
  - web/src/pages·components·lib·workers: UI·격자·값/서식·붙여넣기; testdata: Go/TS 공용 픽스처.
  - docs: 사용자/관리자 가이드와 PDF, 릴리즈, 오래된 전략 로드맵.
- 빌드·테스트: 이번 go test ./internal/automation -count=1 → ok 0.012s; go test ./... → exit 0(일부 캐시).
- 추가 검사: go vet ./...; go build ./...; gofmt -l ./cmd ./internal ./pkg; ./scripts/check-release-docs.sh; ./scripts/check-commit-identities.sh HEAD.
