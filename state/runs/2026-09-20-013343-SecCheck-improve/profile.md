- 위험 구역: `internal/auth/*`·`internal/store/migrations/*` 는 러너 guard 가 사람 심사로 홀드. `.github/workflows/*` 완화 금지. 세션 미들웨어 `WithActor` 는 자기 알림 억제와 연결.
- 자주 깨지는 곳: 파괴적 확인 전 WIP 커밋을 안 만들어 편집을 날린 사례 3회; 가이드 원고를 바꾸면 PDF 재생성·docs_test 표 갱신이 따라옴; 컨테이너 trivy 게이트는 베이스 이미지 패키지로 막힘(Dockerfile apt-get upgrade 로 고침). 열린 자동 PR #9(go.mod)·#10(precheck.sh·operations.md·go.mod)·#11(docs/admin-guide.md 삭제)·#12(docs_test.go)와 같은 파일을 손대면 충돌.
- 검증 함정: **ci.yml step 7 `govulncheck` 는 vulndb 보고서 GO-2026-6452(excelize)에 `fixed` 이벤트가 없어 main 을 포함한 어떤 브랜치·어떤 excelize 버전으로도 초록이 안 된다(PR #8~#12, 2026-09-19 23:40 기준 여전히 없음)** — 코드로 못 풀고 워크플로 완화는 금지이므로, 게이트가 풀리기 전에는 새 PR 을 만들지 않는 것이 정답. 실패 run 의 로그 본문은 403 이라 `govulncheck ./...` 로컬 재현으로 step 을 확정. 정찰 환경은 curl·WebFetch·gh·go·govulncheck 실행이 승인 거부될 수 있음 — 원격 상태는 구현자가 직접 확인. 러너 `error` 가 저장소 실패가 아닐 수 있음(09-18 은 일일 예산 홀드). 각 worktree 의 로컬 `main` 은 stale 일 수 있어 비교 기준은 `origin/main`.
