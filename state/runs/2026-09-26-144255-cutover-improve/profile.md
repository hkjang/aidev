# cutover 프로필 (2026-09-26)
- 목적: 재해복구 모의훈련의 작업 트리 상태를 관리자가 변경하고 현장·상황실이 확인하는 폐쇄망 배포용 상황판.
- 스택: TypeScript 5, Next.js 16.3.3 App Router, React 19.2.8, Tailwind 4, SWR/Zustand, lucide-react, Node 22; DB 없이 data/*.json 파일 저장.
- 구조:
  - `app/page.tsx` 모바일/표준 뷰(10초 폴링), `app/pc/page.tsx` 전광판(2초), `app/admin/page.tsx` 관리자(1초 SWR).
  - `app/api/activities/route.ts` GET·PUT — PUT 은 `isAdminRequest` 확인 후 `action: add|move|delete` / `activities` 전체 / `targetId+newStatus` 분기, 저장 전 항상 `validateActivityImport` 통과, 응답 후 `after()` 에서 메일 알림.
  - `lib/activityData.ts` 읽기·임시파일+rename 원자 쓰기·백업·`validateActivityImport`(최대 5,000개, issues 50건 + `omittedIssueCount`).
  - `lib/treeUtils.ts` 트리 구성·추가·이동·삭제·`collectDescendantIds`(parentId BFS, visited 로 순환 종료).
  - `components/ActivityTree.tsx`(트리 행·인라인 편집·관리 버튼), `ActivityJsonImporter.tsx`, `TrackingSettings`·`MailSettings`.
  - `app/api/auth/*` + `lib/adminSession.ts` 공유 비밀번호/HMAC 서명 쿠키 `cutover_admin_session`(7일), `resolveAdminCookieSecure`/`shouldSecureAdminCookie` 가 X-Forwarded-Proto·`ADMIN_COOKIE_SECURE` 로 Secure 판정.
  - `proxy.ts` + `lib/tracking/*` CSP nonce·추적 설정·위반 버퍼, `app/momento/[...path]` 추적 프록시.
  - `lib/mail/*` 설정·이벤트·MIME·직접 net/tls SMTP·배경 발송·기록 500건; 기본 꺼짐.
  - `docs/` USER_GUIDE·ADMIN_GUIDE·EXECUTIVE_REPORT(+PDF·캡처), `scripts/guide-screenshots/`.
  - 잔존물: `lib/s3.ts`, `amplify.yml`, `next.config.ts_bak`, `next.config.js_bak_bak`, `sample.json`, `cutover-data.json`, 의존성 `@aws-sdk/client-s3` — 활성 API 는 S3 미사용.
- 빌드·테스트: `npm ci --legacy-peer-deps` → `npm run lint` / `npx tsc --noEmit` / `npm run test:unit`(`node --test "lib/**/*.test.ts"`, 현재 72건/24 suites) / `PLAYWRIGHT_CHROMIUM_PATH=/usr/bin/google-chrome npm run test:e2e`(현재 10건, workers=1) / `npm run build`. 설치·빌드는 수 분.
- 테스트 구성: `lib/**/*.test.ts` 8개(adminSession, treeUtils, mail/config·events·service·smtp, tracking/core·violations) — **`lib/activityData.test.ts` 는 없음**. `e2e/*.spec.ts` 6개(activity-import, admin-session-cookie, mail, mobile-clock, tracking, tree-ops); `global-setup` 이 data/activity.json 을 `test-results/e2e-data/` 로 복제, webServer 가 127.0.0.1:3100 dev 서버를 띄우고 ADMIN_PASSWORD=`e2e-admin-password` 를 넣는다.
- 관례: 한국어 `feat:`/`fix:`/`docs:` 커밋과 GitHub merge PR. 설정은 환경 변수 + `data/tracking.json`·`mail.json`. DB migration 없음. 문서는 `docs/` 와 README.
- AGENTS/CLAUDE: `CLAUDE.md` 는 `@AGENTS.md`; AGENTS.md 는 `next dev` 가 재삽입하는 nextjs-agent-rules 블록뿐이며 **코드 작성 전 `node_modules/next/dist/docs/` 의 해당 가이드 필독**을 요구한다(의존성 설치 후에만 가능).
- 위험 구역: `app/api/auth/**`·`lib/adminSession.ts`(서명·쿠키 Secure 판정), `proxy.ts`(CSP nonce), `Dockerfile`(NEXT_PUBLIC_*_PASSWORD 빌드 기본값), `lib/activityData.ts`(백업·원자 쓰기), `lib/mail/*`(SMTP·중복 발송), `amplify.yml`(빌드 경로).
- 자주 깨지는 곳: e2e 브라우저 부재 → `PLAYWRIGHT_CHROMIUM_PATH` 지정 필수. 실패 trace 가 `playwright-report/`·`test-results/` 에 남으면 `npm run lint` 가 trace 뷰어 번들을 검사해 수천 건을 냄(eslint globalIgnores 에 아직 제외 없음). 러너 예산 `hold` 가 회차 `error` 로 적재된 적 있으나 저장소 오류 아님.
- 현재 품질 공백:
  - 관리자 활동 PUT 6곳이 응답 미검사(`app/admin/page.tsx` 137·149·267·279·288·296·304) — 401/400/500 이 화면에 안 보임. 삭제 확인창 2회이며 둘째(287행)의 `node.title` 은 `tree.map` 최상위 노드라 제목이 틀림. `ActivityTree.tsx:70-73 handleSave` 는 결과를 기다리지 않고 편집을 닫음. ← 2026-09-26 선택 과제.
  - `validateActivityImport` 독립 단위 테스트 없음.
  - 상태 전파를 클라이언트(`admin/page.tsx` 228~265)가 계산하고 API 의 `targetId+newStatus` 분기는 대상 1건만 바꿈 — 같은 값을 두 경로가 다르게 읽는 구조.
  - activities 가 비면 관리 화면에 추가 버튼이 없음(`같은 레벨 추가` 가 isRoot 노드 안에만 있음).
- 검증 함정: `import type … from './types'` 는 Node 22 타입 스트리핑으로 `node --test` 에서 문제 없음(옛 '.ts 확장자 필수' 기록은 잘못됨). 로그인 후 세션 e2e 는 같은 browser context 의 `page.request` 를 써야 함(`request` fixture 는 별도 쿠키 저장소). **SWR 정기 폴링(관리자 1초)을 저장 성공 증거로 쓰지 말 것** — 실패를 덮는다. 실 SMTP/Momento 수집기는 로컬 릴레이·수집기로 실제 소켓·HTTP 사용.
- CI: 추적 파일에 `.github/` workflow·`.gitlab-ci.yml`·`Jenkinsfile` 없음. 릴리즈는 외부 러너가 수행.
