# relio 프로필 (2026-09-22)
- 목적: 에어갭 사내 B2B CRM을 Go 단일 바이너리의 REST·MCP·React 웹으로 제공한다.

- 구조:

  - internal/auth·oidc·apikey: 인증·SSO·개인 키. internal/audit: 감사 기록.
  - internal/crm·intelligence·relationship·voice·approval: 업무 서비스와 분석.
  - internal/mcp/server.go: 도구 스키마·dispatch. internal/api/openapi.go: 명세.
  - internal/admin·analytics·job·personal: 설정·방문자 분석·잡·개인 기능.
  - internal/platform: HTTP·DB·암호화·시간대 등 공용 기능. internal/webui: SPA embed.
  - migrations: SQL embed, 마지막 014_momento_provider.sql.
  - web/src/pages: React 화면. web/test: Node 내장 테스트.
  - scripts/guide: puppeteer-core 캡처. docs: md/PDF 가이드·설계·로드맵·릴리즈.
