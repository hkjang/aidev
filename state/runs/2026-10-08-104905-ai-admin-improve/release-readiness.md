# ai-admin v1.2.36 릴리즈 준비 기록

- 적용 스킬: marketing:product-launch, technology:release-and-deployment. Skill 도구가 없어 로컬 headcount SKILL.md와 references/sources.md를 직접 읽었다. 이번 작업에 적용되는 외부 상점·광고·라이선스 심사 항목은 없다.
- 출시 등급: Tier 3 개선. 대상은 chat API를 호출하는 기존 운영자·클라이언트이며, 고객 전달물은 기존 형식의 릴리즈 노트와 API 계약 문서다.
- 시점: 2026-10-08에 병합된 PR #42를 기존 패치 릴리즈 관례로 배포 준비한다. 검증 통과를 태그 생성 조건으로 둔다.
- 지원 답변: 첫 JSON 뒤에 객체/null/쓰레기가 붙거나 후행 공백으로 4 MiB를 초과하면 공급자 선택 전에 400 invalid_json이다. 정상 단일 JSON과 상한 안의 공백은 허용한다. 자유 확장 필드·float64 파싱·기존 오류 코드/메시지는 유지한다.
- 독립 사용 검증: 비평 단계에서 별도 PostgreSQL과 실제 Handler/HTTP 경로의 신규 8사례 및 관련 회귀를 재검증했다. 이번 릴리즈에서도 전용 DB로 전체 race 검증을 수행한다. 별도 사람의 신규 사용자 사용성 검증은 수행하지 않았다.
- 게시 경로: 외부 러너의 태그 푸시 후 release.yml이 패키지 생성·검증·SHA256SUMS 생성·GitHub Release 게시를 수행한다. 이 세션은 로컬 커밋/태그와 인계 파일만 준비한다.
- 중단 조건: 필수 검증 하나라도 실패해 복구할 수 없으면 새 태그를 만들지 않고 이 세션의 버전 변경을 되돌린 뒤 release.json을 failed로 기록한다.
- 운영 인계: 게시/배포 후 담당 운영자는 첫 chat 사용에서 정상 요청 성공 및 후행 JSON 거부를 확인한다. 정상 단일 JSON의 회귀가 1건이라도 확인되면 확대를 중단하고 이전 v1.2.35 이미지로 복귀한다. 판단 담당은 저장소 유지관리자 hkjang이다. DB 스키마 변경은 없다.
- 배포 후 확인 지표: 첫 24시간의 정상 chat 오류 보고와 invalid_json 문의를 확인하고, 대표 정상 요청 1건의 성공 및 잘못된 요청 1건의 공급자 호출 0회를 확인한다. 실제 운영 배포·관측·외부 알림은 이 세션에서 수행하지 않는다.
