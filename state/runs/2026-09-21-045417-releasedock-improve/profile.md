# releasedock 프로필 (2026-09-21)
- 목적: 폐쇄망 릴리즈 패키지 검증·배포·롤백 및 단순 파일 업로드/명령 실행과 로그 조회를 제공한다.
- 스택: Go 1.26.6 이상(backend/runner 별도 모듈), PostgreSQL/pgx v5, React 19 + TypeScript 5.8 + MUI 7 + Vite 7/vitest 3. 현재 main@4990505, v0.5.17.
- 구조:
  - backend/internal/server/ — HTTP/API/auth/OIDC/RBAC/MCP 및 simple.go의 업로드·실행·로그·SSE.
  - backend/internal/localexec/ — API 계정의 단순 모드 명령 실행; 전체 모드 executor 격리와 다르다.
  - backend/internal/store/migrations/ — 순번 SQL, 현재 024까지. 시작 시 embedded migration 적용.
  - runner/ — 별도 Go 모듈, PostgreSQL 큐·runtime·Harbor·격리 executor·롤백.
  - web/src/pages/simple/ — 단순 모드 UI, SimpleRunDetailPage.tsx에 저장 로그 페이지 수집과 SSE.
  - backend/internal/webassets/ — 릴리즈 빌드 때 SPA 내장; 개발 빌드는 디스크 자산.
  - scripts/, deploy/ — 빌드/오프라인 패키징, systemd와 standalone 제어.
  - docs/ — architecture.md, simple-mode.md, offline-install.md, quick-deploy.md. CLAUDE.md/별도 로드맵은 발견 못 함.
- 빌드·테스트: (cd web && npm ci) 선행 후 make test = backend/runner go test ./... + 웹 npm test -- --run. npm run build는 tsc -b 포함. make build / make package는 의존성 설치·테스트·빌드가 포함돼 더 오래 걸림.
- 관례: 영어 fix:/feat:/perf:/chore: 커밋, 한국어 운영 문서. 운영 설정은 관리자 API+DB, 환경변수는 부트스트랩/DB/암호화 키/포트. VERSION 변경은 릴리즈 담당. web/dist/내장 생성물 커밋 금지.
- 위험 구역: auth.go/oidc.go/rbac_policy.go의 권한·세션, migrations의 순번·불변성, workflows/release.yml의 태그 릴리즈. releases.go:persistArtifactTx는 행 잠금을 유지한 채 파일을 저장한다.
- 자주 깨지는 곳: simpleRunLogger/logBudget는 빈 줄·명령/시스템 예산·UTF-8 잘림을 최근 반복 수정; 계약이 테스트로 고정돼 있다. HELD 상태 enum 추가는 과거 사람 반려로 재시도 금지.
- 검증 함정: TEST_POSTGRES_DSN 미설정/공백이면 server fixture 및 backend/runner store 통합 테스트가 Skip한다. 일반 go test 출력은 이 생략을 드러내지 않는다. CI는 PostgreSQL 16과 Node 22를 준비한다.
- 검증 함정: 웹 타입 검사는 npm test가 아닌 npm run build 또는 npx tsc -b --noEmit. SPA embed 테스트는 웹 빌드가 없으면 별도로 Skip 가능. 테스트 DB는 스키마 생성 권한 필요.
- 현재 확인: Go 1.26.7 정상 실행. make test의 backend/runner는 성공, 웹은 node_modules가 없어 vitest not found로 실패. DB 통합 테스트 실행·웹 94건 재통과는 이번 정찰에서 미확인.
- 미머지 주의: make vet와 MCP OAuth/migration 025는 현재 main에 없다. 과거 회차 성공 기록만 보고 존재한다고 가정하지 말 것.
