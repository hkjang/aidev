# seaton 프로필 (2026-09-21)
- 목적: 사무실 도면 위 좌석을 편집하고 직원을 배정·검색하는 오프라인 우선 SeatOn 서비스.
- 스택: Go 모듈 1.24.0 / chi v5·pgx v5·go-oidc v3 / PostgreSQL 14+ 문서, CI는 16-alpine / React 19·TypeScript·MUI·Vite·Vitest·Playwright.
- 구조:
  - `cmd/seaton/`: 서버 진입점, Docker 빌드에서 프런트 dist를 임베드.
  - `internal/app/`: HTTP·OIDC·좌석·인사·CV/VLM·대시보드·키·MCP·설정·추적.
  - `internal/database/`: pgx pool과 migrations.sql. 시작 시 스키마 적용, 별도 버전 마이그레이션 도구 없음(이전 프로필 기준, 이번 초기화 구현은 미재확인).
  - `internal/platform/`: 환경변수·설치별 암호화 키. `internal/tracking/`: nonce·추적 스니펫·CSP.
  - `web/src/pages/`: 화면, `lib/`: 화면 규칙과 단위 테스트, `api.ts`·`auth.tsx`: 요청·세션.
  - `web/e2e/`: 실제 서버 Playwright, seed.mjs의 CV 시드, helpers.ts 복구 도우미, guide-shots.mjs 캡처.
  - `docs/`: Markdown 정본 및 생성 HTML/PDF·캡처. `scripts/`: 문서 생성·이미지 릴리즈.
- 빌드·테스트:
  - `go test ./...`, `go vet ./...`. 이번 정찰 go test 성공(캐시); database 테스트 없음. vet는 이번 미실행.
  - `cd web && npm ci && npm test && npm run build`; `npm run lint`는 tsc 검사.
  - `docker build -t seaton:e2e .` 후 별도 PostgreSQL+수정본 서버 기동, web에서 `E2E_BASE_URL=http://127.0.0.1:8080 E2E_USERNAME=admin E2E_PASSWORD=... npx playwright test`(준비 포함 수 분~10분 이상).
  - `python3 scripts/build-docs.py USER_GUIDE`는 해당 HTML만 생성; 가이드 PDF는 aidev 공용 md2pdf 사용.
- 관례: 최근 커밋은 한국어 feat/fix/docs/test/chore 접두. README·docs 가이드가 정본. 저장소 CLAUDE.md/AGENTS.md 없음, TODO/FIXME 검색 결과 없음.
