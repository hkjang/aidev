# dataworks 프로필 (2026-09-26)
- 목적: 데이터 상품의 생성·카탈로그·계약·접근권·출시 게이트와 운영 워크벤치를 제공하는 서버. MCP·OpenAI 호환 프록시와 Clustara(K8s) 운영 기능도 포함한다.
- 스택: Go 1.25, SQLite 기본/PostgreSQL 선택, React 19·TypeScript·Vite·Tailwind·TanStack, Vitest·Playwright, CI Node 24.
- 구조:
  - cmd/dataworks — 주 서버. cmd/clustara·clustara-agent·clustara-cli, cmd/api-surface-audit(라우트·OpenAPI·CLI·SDK 정합성 감사)도 있다.
  - internal/proxy — HTTP 라우트 전부. `admin_dataworks.go`(관리 API·액션 센터·publish gate 조립), `dataworks_runtime.go`(런타임 접근 게이트: `contractScopeActive`·`contractScopeCanServe`·`usableEntitlement`·`entitlementActive`), `keycloak*.go`·`mcp_oauth.go`(인증), `admin_k8s_*`(Clustara).
  - internal/dataworks — 도메인 규칙(`EvaluatePublishGateV2`, `EvaluateRetirementCandidate`, fit score).
  - internal/store — SQLite/PostgreSQL 접근, 코드 내 마이그레이션. `EntitlementActive`(dataworks_operations.go:541), `parseStoredTime`(reports.go:353, RFC3339Nano→RFC3339).
  - internal/config·tracking·secret·audit·kube·collector·analyzer·action·agent.
  - web/src — React 워크벤치. 액션 센터 관련: `lib/labels.ko.ts`, `pages/secondary/secondary-pages.tsx`(typeMap 199행), `pages/home/home-page.tsx`, `types/dataworks.ts`. web/embed.go 가 dist 를 임베드.
  - docs — USER_GUIDE/ADMIN_GUIDE(md+PDF 정본), OPERATIONS.md(PDF 없음), RELEASE_GUIDE 등. scripts·deploy·sdk.
- 빌드·테스트: `go build ./...`, `go vet ./...`, `go test ./...`(internal/proxy 만 30~40초, 전체는 분 단위), `go run ./cmd/api-surface-audit`(gap 0 이어야 함). 웹은 `cd web && npm ci && npm run lint && npm test && npm run build`(build 가 tsc -b 포함). Playwright `npm run test:e2e`·`npm run capture:docs` 는 길고 CI 미포함.
- 관례: 커밋 제목은 영어 conventional(`fix(dataworks): …`), 코드 주석과 운영 문서는 한국어·영어 혼용(주석은 영어, 가이드는 한국어). 설정은 환경 변수 + 관리자 설정 레지스트리/DB override. 마이그레이션은 store 코드. **판정에는 trim 한 값을 쓰고 저장·API 응답에는 원문을 그대로 둔다**(1e9045a, 36c665c 에서 확립).
- 위험 구역: internal/proxy/keycloak*.go·mcp_oauth.go·auth/session, internal/store 마이그레이션, 관리자 설정 검증, .github/workflows/ci.yml, web/embed.go 의 dist 처리. publish gate 의 masking 증거(admin_dataworks.go:1738)는 느슨해지는 방향으로 바꾸지 말 것.
