# cutover 프로필 (2026-09-29)
- 목적: 재해복구 모의훈련의 작업 상태를 관리자가 변경하고 현장·상황실이 확인하는 폐쇄망 배포용 상황판.
- 스택: TypeScript 5, Next.js 16.3.3 App Router, React 19.2.8, Tailwind 4, SWR/Zustand, Node 22; DB 없이 JSON 파일 저장.
- 구조:
  - app/page.tsx 표준/모바일(10초 폴링), app/pc/page.tsx 전광판(2초), app/admin/page.tsx 관리자(1초).
  - app/api/activities/route.ts GET·PUT: 관리자 인증 후 add/move/delete·전체 배열·단일 상태 변경, validateActivityImport 후 저장, after() 메일 알림.
  - app/api/activities/import/route.ts JSON 업로드; 같은 검증 관문 사용(이전 프로필 근거, 이번 본문 미열람).
  - lib/activityData.ts validateActivityImport: 최대 5000개·오류 50건+생략 안내; 로컬 파일 읽기·백업·원자 교체는 같은 파일에 위치.
  - lib/treeUtils.ts buildTree/addActivity/moveActivity/deleteActivity/collectDescendantIds; parentId 기준 하위 탐색.
  - components/ActivityTree.tsx 행·편집·관리 버튼. ActivityJsonImporter/TrackingSettings/MailSettings는 이전 프로필 기준.
  - app/api/auth/login/route.ts POST + lib/adminSession.ts 서명 관리자 세션. lib/mail/* 메일, lib/tracking/* 추적 및 CSP(세부는 이전 프로필).
  - docs/USER_GUIDE.md·ADMIN_GUIDE.md(+PDF/캡처)·EXECUTIVE_REPORT.md; scripts/guide-screenshots/ 가이드 캡처.
- 빌드·테스트:
  - 의존성 준비: npm ci --legacy-peer-deps (수 분). npm run lint / npx tsc --noEmit / npm run build (빌드는 수 분).

  - PLAYWRIGHT_CHROMIUM_PATH=/usr/bin/google-chrome npm run test:e2e. 이번 브라우저 경로 존재 확인, E2E 실행 안 함(이전 18건).
  - playwright.config.ts: workers 1, 127.0.0.1:3100 dev 서버, 독립 ACTIVITY_DATA_FILE와 테스트 인증 환경 변수.
  - global-setup이 data/activity.json을 test-results/e2e-data로 복제, teardown은 그 e2e-data만 삭제.

- 검증 함정:
  - 이 정찰 워크트리는 node_modules 없음. npm run lint는 eslint: not found(127); 단위 테스트는 실제로 가능하므로 '모든 검증 불가'라는 이전 기록은 잘못됨.
  - Node는 MODULE_TYPELESS_PACKAGE_JSON 경고를 출력하지만 단위 테스트 통과. 경고 해소를 위해 package.json type을 함부로 바꾸지 않는다.
  - 로그인 E2E는 같은 browser context의 page.request 사용. 1초 SWR 폴링을 저장 성공 증거로 쓰지 않는다.
  - 실제 page.route 실패 주입/실제 함수 호출로 검증; 손으로 만든 서비스 대역·소스 문자열 검사로 동작을 증명하지 않는다.
  - 이번 설정 확인에는 별도 저장소의 설치된 ESLint를 사용하는 격리 복사본 실험을 수행; 정식 워크트리 lint 통과와 구분한다.
- CI: git ls-files에서 .github workflow·.gitlab-ci.yml·Jenkinsfile 없음. 외부 러너 릴리즈 v1.11.0은 제공된 기록 기준.
- AGENTS/CLAUDE: CLAUDE.md는 @AGENTS.md. 코드 작성 전 설치된 node_modules/next/dist/docs 해당 가이드 필독; 이번 정찰은 코드 작성 없음.
- 현재 공백: UI와 단일 상태 PUT의 전파 규칙 불일치, 자기참조 오류 2건 중복, Date.now ID 충돌 가능성.
