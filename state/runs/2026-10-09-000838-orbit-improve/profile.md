  - openTestStore는 store.Open(ctx,dsn,nil), Bootstrap 미사용; DSN 없으면 Skip. 전체 Go 초록을 DB 동작 검증으로 쓰지 않는다.
  - server_test.go:TestResponsesStreamNormalization은 실제 httptest 제공자+proxyAIStream 경로지만 정상 단일 프레임/부분 문자열만 확인.
  - 이번 과제는 ai_test.go에 프레임 경계 시험 추가(아직 미구현). proxyAIStream은 실제 transport를 내부 생성하며 DB 불필요; 전체 인증 라우터 시험은 아님.
  - ai_db_test.go는 실제 streamAI 정상·provider 실패·취소 SSE/로그를 검사하나 DB 필요. slog 기본 로거·AI 설정은 전역이므로 원복·비병렬 필요.
