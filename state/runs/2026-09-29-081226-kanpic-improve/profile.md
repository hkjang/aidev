# kanpic 프로필 (2026-09-29)
- 목적: 온프레미스·폐쇄망용 웹 AI 스프레드시트와 데이터 협업을 제공한다.
- 스택: Go 1.26(module kanpic), PostgreSQL/pgx, excelize; React 19·TypeScript·Vite·zustand·React Query; Vitest/jsdom·Playwright; Docker.
- 구조:
  - cmd/api·internal/httpapi: 서버 진입점, REST/MCP 및 알림 수신자 조회.
  - internal/workbook·collaboration: 워크북 저장과 협업; internal/auth·apikey: 인증·인가.
  - internal/formula·delimited·importexport·external: 계산, 공통 파일 규칙, CSV/TSV/XLSX, 원격 수식.
  - internal/mail: mail.go 전송/검증/연결, message.go MIME, service.go 수신자/기록/재시도, config.go 설정.
  - internal/handoff: 서비스 간 문서 교환; migrations: 번호별 SQL; internal/integration: 실제 DB 통합.
  - internal/ai·analytics·automation·presentation·settings: AI, 분석, 자동화, 발표 자료, 설정.
  - web/src/pages·components·lib·workers: 화면, 격자, 값/서식 규칙, 붙여넣기 작업자.
  - testdata: Go/TS 공용 픽스처; docs: 가이드·PDF·로드맵·릴리즈.
- 빌드·테스트: go test ./... (이번 실행 통과, 일부 cached); go test ./internal/mail -race -count=1 (1.260s 통과). go build ./...·go vet ./...는 기존 검증 명령이나 이번 미실행.
- 웹: cd web && npm ci && npm run lint && npm test && npm run build (설치·빌드 시간 필요, 이번 미실행).
- 통합: POSTGRES_DSN=postgres://... go test -tags=integration ./internal/... (DB 필수, 이번 미실행).
- 브라우저: 서버를 먼저 띄우고 cd web && npm run test:e2e; 이번 미실행.
- 관례: 최근 커밋은 대체로 한국어 fix/feat/docs. 필수 POSTGRES_DSN, 나머지 관리자 콘솔/internal/settings. 이유를 설명하는 주석 사용. 사용자 가이드 변경 시 PDF 동반.
- 위험 구역: auth·apikey·handoff·migrations·.github/workflows, external SSRF/허용 목록, mail TLS/AUTH 정책. 테스트의 루프백/자체 서명 허용을 운영에 옮기지 않는다.
- 자주 깨지는 곳: 입력 경로 숫자 규칙 무리한 통합, XLSX 실수에 텍스트 자릿수 제한 적용, 이미 완료한 15자리 픽스처 재선정. 계산·파일·표시 파서는 목적이 다르다.
- 메일: normalizeBody는 CRLF/끝 개행만, 점 이스케이프는 net/smtp. Deliver가 수신자 trim과 내부 CR/LF 거절을 하고 봉투·헤더가 같은 값을 쓴다(73465c6 반영).
- 메일 취소: Notify 및 httpapi.notifyContext는 WithoutCancel + 10s; SendNow 전송도 취소 분리. caller가 전달한 새 컨텍스트의 시한은 SMTP 연결 뒤 적용되지 않는 결함이 이번 선택이다.
- 재현: greeting/ehlo × Deliver/Verify에서 context=150ms인데 500ms 뒤에도 반환 안 함. TLS와 명시 cancel은 이번 미실행. 기존 테스트는 정상 relay만 다뤄 통과했다.
- 메일 설정: config.go defaultTimeout=10s, 양수 timeout_seconds만 덮어쓴다. Timeout=0 유입 가설 기각. resolve는 wanted 구성 때 이미 TrimSpace하여 @ fallback 감사 공백 가설도 기각.
- 테스트 helper: mail_test.go startRelay/relayConfig, service_test.go newTestService는 실제 Deliver를 사용. 결함 재현에 SetSender로 전송을 대체하지 않는다.
- 숫자: delimited와 클립보드는 앞자리 0 정수·긴 번호 보호; 타이핑은 spreadsheetNumber로 비10진 리터럴 거절. 지수 입력/표시 계약은 임의 통일 금지.
- 프로필 정정: base 1d2d226의 external/fetcher.go parseCSV에는 ToUTF8 뒤 UTF-8 유효성 검사가 없다. 과거 기록 0a21ce7의 수정이 이 base에 있다고 가정하지 말 것; 반복 선정은 피한다.
- 프로필 정정: encoding_test.go에서 홀수 끝 바이트 사례는 확인했으나 고립 surrogate 사례는 확인 못했다.
