# Momento 프로필 (2026-10-01)

- 기준: main@12ba629, v0.34.52. 2026-09-26 프로필(v0.34.44)을 갱신함 — 그 사이 릴리즈 8개(v0.34.45~52)가 났고 **web/src/components 아래 새 순수 모듈이 10개 가까이 늘었다**. 작업 트리는 깨끗했다.
- 목적: 온프레미스에서 이벤트를 수집·소유하고 제품·직원·경험·AI 사용을 분석하는 사내 분석 플랫폼.
- 스택: Go 1.26(net/http+chi, pgx, go-oidc), PostgreSQL 17; React 19/TypeScript/MUI 7/Vite/react-query; TypeScript 수집 SDK.
- 구조:
  - cmd/momento — 진입점. internal/httpapi — REST/MCP 핸들러(admin.go 에 사용자·설정·역할 게이트), server.go 라우터, 실제 DB 통합 테스트.
  - internal/service(Collector·Worker·Automation·Maintenance), internal/auth(`roleRank`·`RoleAtLeast`·`RoleAbove` 가 역할 서열의 정본), internal/privacy·secret·segment·insight.
  - internal/database — Migrate/MigrateThrough; **embedded SQL 정본은 internal/database/migrations/**. 루트 `migrations/` 는 001 하나뿐이고 정본이 아니다.
  - web/src/pages — 화면. web/src/components — 공용 UI. **web/src/components/DataTable.tsx(466줄)가 15개 파일·62곳 표의 단일 구현**이라 여기 손대면 전 화면에 퍼진다. web/src/components/AppShell.tsx(1100줄+)가 사이드바·단축키·명령 팔레트.
  - **순수 로직 `.ts` 모듈**이 이 저장소의 테스트 가능성 패턴이다. components 쪽: tablePaging·tableSummary·tableSort·tablePrefs·preference·csvExport·shortcuts·navPrefs·relativeTime. pages 쪽: roleScope·passwordRule·visitorTrace·queryPolicyForm·mcpOauth 등. 새 로직은 반드시 이 자리로 간다.
  - web/test/*.test.mjs **36개**가 그것을 `"../src/components/X.ts"` 처럼 **확장자까지 적어** import 한다(node:test + tsconfig.app.json 의 allowImportingTsExtensions). 확장자를 빼면 모듈을 못 찾는다.
  - sdk/ — 브라우저 수집 SDK. scripts/guide/ — 배포 시드 + puppeteer-core 캡처(docs/assets/guide 를 덮어쓴다). docs/ — 가이드·PDF·ARCHITECTURE·ROADMAP·openapi.yaml(ROADMAP_PLAN 은 오래된 비전 문서).
- 빌드·테스트:
  - Go: `make test`, `go test -race ./cmd/... ./internal/...`(httpapi 60~70초), `go vet ./cmd/... ./internal/...`.
  - 웹: `cd web && npm ci && npm run lint && npm test && npm run build`. **worktree 에 web/node_modules 가 없으므로 npm ci 가 선행**(수 분). test = `node --test test/*.test.mjs`, build = `tsc -b && vite build`.
  - SDK: `cd sdk && npm ci && npm run typecheck && npm test && npm run build`. 전체 산출물은 `make build`.
- 관례: 한국어 conventional commit(`fix(web): …`, `feat(web): …`)이 주류이고 제목이 평서문으로 끝난다. 릴리즈 커밋은 `release: vX.Y.Z`. 설정은 DB settings 테이블 + 환경변수. Migrate 는 advisory lock 으로 직렬화. 사용자 보기 설정은 `components/preference.ts` 의 `usePreference`(localStorage + useSyncExternalStore, 예외는 모두 삼킴)로 통일돼 있다.
- 위험 구역: internal/auth(역할 서열·세션), internal/httpapi/admin.go·server.go(역할·세션·사이트 경계), internal/database/migrations, .github/workflows, docs/openapi.yaml(라우트 계약 테스트가 읽는다). **서버 검사가 권한의 정본이고 화면은 거울일 뿐** — 화면 게이팅을 이유로 서버 검사를 느슨하게 하지 말 것.
