# jasql 프로필 (2026-09-21)
- 목적: KCB JSON 메타데이터를 카탈로그·검색·조인·가드레일로 컴파일해 NL2SQL MCP/REST/웹 콘솔과 읽기 전용 Oracle 실행을 제공한다. 기준 e9f3fb2, v0.31.0.
- 스택: go.mod Go 1.25.0 선언, 로컬 Go 1.26.7, Docker 빌더 Go 1.26. godror(oracle 태그), pgx PostgreSQL, x/crypto 및 go.sum 존재. 프런트는 go:embed 정적 HTML/JS.
- 구조:
  - cmd/jasql-mcp: 서버 CLI; cmd/jasql-eval: 골든셋 평가; cmd/jasql-goldgen: 골든셋 생성.
  - internal/catalog: 로드·검색·조인·SQL 검증·시간 파싱·시멘틱·템플릿, mcp 비의존.
  - internal/mcp: HTTP/stdio 도구·REST·인증/SSO/OAuth·실행 가드·개인화; webui는 콘솔 자산.
  - internal/meta: 메모리/PostgreSQL 저장소와 사용자·세션·설정·프로파일.
  - internal/oracle: 프로파일·연결 풀·실행·SQL 가드·실행계획; 기본 빌드는 연결 불가 stub.
  - data/kcb: 실제 메타데이터·골든셋. 기존 테스트도 읽으므로 변경 테스트의 출력 대상으로 사용 금지.
  - docs: 한국어 가이드 정본; reports/executive_report.md는 전사 확산·이중화·이기종 DB 로드맵.
  - scripts: 로컬 크로스 빌드와 오프라인 도커 이미지 릴리즈.
- 빌드·테스트: 이번 정찰에서 go build ./..., go vet ./..., go test ./... 모두 통과. catalog 53.670초, mcp 9.270초, meta/oracle 캐시. CLI 3개는 no test files.
- 빌드·테스트: 구현 과제 부분 명령 go test ./cmd/jasql-goldgen -count=1 (현재 테스트 없음, 구현 후 CLI 회귀 테스트 실행용).
- 관례: 영어 명령형 커밋과 한국어 PR 머지 제목. 버전은 server.go/OpenAPI·README/배포 문서 동기화. 설정은 flag/env/메타 DB settings.
- 관례: 카탈로그는 로드 후 불변, 새 컴파일 결과로 원자 교체. 변경 테스트는 t.TempDir JSON 픽스처를 catalog.Load로 로드(newFixtureServer 참고).
- 관례: 전체 도구 등록은 server.go:tools(), 디스패치는 callTool(), 권한별 노출은 toolsForActor(). TestServeStdio가 전체 42개와 스키마를 실제 전송 경로로 단정.
- 위험 구역: auth.go/oauth.go/authapi.go(세션·권한), execguard.go 및 oracle/sqlguard.go(읽기 전용 정책), dbapi.go(비밀번호/소유권), meta/pg.go(스키마; 이번 세부 미확인), 전역 카탈로그 mutation.
- 위험 구역: goldgen 기본 출력은 data/kcb/golden_queries.json이며 os.WriteFile로 덮어쓴다. CLI 시험은 반드시 임시 -data/-out 사용.
- 자주 깨지는 곳: 반복 실패 기록 없음. 이전 성공인 SQL trailing 정리와 숫자 날짜 검증은 pinned HEAD에 반영되지 않은 상태이므로 이번에 다시 구현하지 않는다.
- 검증 함정: 기본 Oracle driverAvailable=false. 기본 테스트 통과가 실제 Oracle 실행을 증명하지 않음. TestPGStore는 JASQL_TEST_PG 미설정 시 skip; 이번 실제 PostgreSQL 실행 여부는 미확인.
- 검증 함정: 저장소 CLAUDE.md/AGENTS.md와 .github/workflows 없음. docs/development.md의 Go 1.24+, 외부 의존성 0/go.sum 없음, 도구 24개는 현재 소스와 불일치.
- 검증 함정: 최소 Go 1.25 툴체인 자체로의 실행은 이번 미확인; 로컬 검증은 1.26.7. Docker/Instant Client 환경도 이번 미검증.
- 이번 정찰: goldgen -keep -1의 slice panic과 -n -1 -keep 0의 빈 JSON 정상 저장을 재현. 두 음수 인자의 조기 거부와 실제 CLI 회귀 테스트를 선정.
