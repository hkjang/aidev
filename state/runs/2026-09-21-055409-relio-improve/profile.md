# relio 프로필 (2026-09-21)
- 목적: 에어갭 사내 B2B CRM을 Go 단일 바이너리의 REST·MCP·React 웹으로 제공한다.
- 스택: Go 1.24 선언(net/http, pgx/pgxpool, slog), PostgreSQL(개발/CI 17), React 19·TypeScript·Vite, Keycloak OIDC.
- 구조:
  - cmd/relio: 진입점. internal/server: 라우트·REST 핸들러·관리자 기능.
  - internal/auth·oidc: 세션/개인 키/SSO. internal/audit: 감사 DB 기록 및 실패 로그.
  - internal/crm·intelligence·relationship·voice·approval: 업무 서비스와 분석.
  - internal/mcp/server.go: 도구 스키마·dispatch. internal/api/openapi.go: API 명세.
  - internal/admin·analytics·job·personal: 설정·방문자 분석·잡·개인 기능.
  - internal/platform: 공용 httpx·DB·암호화·timezone·ids. internal/webui: SPA embed/서빙.
  - migrations: SQL embed, 현재 014_momento_provider.sql까지.
  - web/src/pages: React 화면(한 줄 압축 JSX 다수). web/test: Node 내장 테스트.
  - docs: ADMIN_GUIDE/USER_GUIDE md+pdf, architecture/security/api-mcp, releases, ROADMAP_PLAN.
- 빌드·테스트: go build ./...; go test ./...; go test -race ./...; go vet ./...; 변경 Go 파일에 gofmt -l.
- 프런트: cd web && npm ci && npm run typecheck && npm run build && npm test. CI는 Node 24 및 npm audit --audit-level=high 사용.
- 스크립트: ./scripts/check-env-contract.sh; ./scripts/check-static-assets.sh; ./scripts/previous-release-tag-test.sh. Docker offline/upgrade 테스트는 별도 장시간 작업.
- 정찰 검증: 2026-09-21 main@38c88ce에서 go test ./... 통과(대부분 캐시). 로컬 Go 1.26.7/Node 22.23.1, 프런트 의존성 설치·web 테스트는 이번에 미실시.
- 관례: type(scope): 요약 형태, 영어/한국어 혼용. 환경 변수 4개 계약 유지; 런타임 설정은 system_settings. 스키마는 새 번호 SQL. 화면 파일 전체 포매팅 금지.
- 문서: 사용자/관리자 가이드 md 정본과 PDF·실제 화면 캡처. ROADMAP_PLAN/architecture/security의 버전 표기는 v1.6으로 오래되어 현재 구현 여부의 근거로 단독 사용하지 않는다.
- 위험 구역: internal/auth·oidc·server/public.go(인증), migrations(번호 충돌/업그레이드), .github/workflows/release.yml(과거 실패·롤백), audit 쓰기 경로(본문·비밀 원문 저장 금지).
- 자주 깨지는 곳: 새 checkout에서 embed 자산 부재는 dist/README 및 web/public/README 앵커로 해결. web build 후 두 파일 동일성과 git status 확인.
- 기반 상태: 메일 98b6fae, 로그인 열거 0eb10f5, gofmt CI cc288f3, MCP OAuth e74e752의 기능은 현재 main 트리에 없음. 완료 기록만 보고 의존하지 않는다.

- 검증 함정: server의 DB 의존 API는 단위 테스트 통과만으로 SQL 실행을 증명할 수 없다. 필요한 경우 임시 PostgreSQL에서 실제 호출. 소스 문자열 검사·주입 오류 대역을 동작 증거로 쓰지 않는다.
