# sqlon 프로필 (2026-09-21)
- 목적: 다중 DB의 SQL 생성·읽기 실행 가드, 플릿 관측·진단·승인 기반 DBA 변경을 MCP/REST/Web UI로 제공한다.
- 스택: Go 1.25.0 단일 모듈, net/http ServeMux, PostgreSQL 또는 메모리 메타 저장소, embed HTML/인라인 JavaScript. Oracle은 별도 OCI/godror 빌드.
- 기준: main@57f99b7(v0.1.5). 이전 성공 기록의 DBA actor·카탈로그 인증·SSO 자동로그인·tracking·handoff·mail·MCP OAuth 변경은 현재 HEAD에 통합되지 않음. 성공 기록만 보고 재구현하지 말 것.
- 구조:
  - cmd/sqlon·internal/app: CLI/서버 부팅, Options/환경변수.
  - internal/mcp: MCP·REST·Web UI, 인증, 관리자·DBA API.
  - internal/meta: 사용자·세션·프로파일·권한·설정의 메모리/PG 저장소.
  - internal/catalog·metasync: JSON 카탈로그·검증·프로파일별 메타데이터 수집.
  - internal/dbconn·engine: 연결·SQL 실행·DB 방언, internal/change: 승인 변경 상태기계.
  - internal/fleet·observability·collector: 플릿·세션·워크로드 수집/조회.
  - data/: JSON 데이터, docs/: 가이드·보고서·PDF, docs/reports/: 중복 문서/생성 도구.
  - test/integration·deploy/test: 실 DB 통합 테스트, scripts/: 빌드·릴리즈.
- 빌드·테스트: 이번 go test ./... -count=1 및 go vet ./... 통과(mcp 3.699초). scripts/build.sh는 CGO=0 Windows amd64/Linux amd64·arm64 빌드; 이번 빌드 미실행.
