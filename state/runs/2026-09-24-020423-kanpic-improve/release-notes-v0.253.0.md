# v0.253.0

## 붙여넣기도 우편번호의 앞자리 0 을 파일 가져오기처럼 지킵니다

밖에서 온 표가 칸에 담기는 문은 둘입니다 — 파일(업로드 가져오기·`IMPORTDATA`)과
클립보드(평문·HTML 붙여넣기). 파일 문은 v0.251.0 부터 `00123` 을 **글자**로
둡니다. 우편번호·사번의 앞자리 0 은 숫자로 바꾸는 순간 사라지고 되돌릴 길이
없기 때문입니다. 그런데 클립보드 문은 그 값을 123 으로 읽었습니다. 같은 명단을
CSV 로 올리느냐 복사해 붙이느냐에 따라 다른 표가 되었고, 붙여넣은 쪽의 사번은
앞자리 0 이 사라진 채 VLOOKUP 에서 빠졌습니다.

이제 붙여넣은 글자를 뜯는 자(`decomposeNumberText`)가 열여섯 자리 넘는 번호를
놓아주던 것과 **같은 꼴로** 앞자리 0 도 놓아줍니다. 서버의
`delimited.HasSignificantLeadingZero` 와 같은 자입니다 — `0`·`0.5`·`-0`·`007.5`
의 0 은 자리이므로 지금까지처럼 수로 들어오고, `00123`·`007` 처럼 0 뒤에 숫자가
더 오면서 소수점이 없을 때만 번호로 보아 글자로 남습니다. 자릿점·통화 기호·
백분율이 붙은 것(`₩5,000`·`1,234`·`50%`)은 번호가 아니라 금액이라 걸리지
않습니다.

**칸에 직접 쳐 넣는 것은 다른 문입니다.** 셀에 손으로 친 `007` 은 예전대로
숫자 7 이 됩니다 — 스프레드시트가 늘 하던 일이고, 밖에서 옮겨 온 표만 적힌
대로 지킵니다.

## 데이터 정리도 `007` 을 건드리지 않습니다

**데이터 › 데이터 정리 › 텍스트로 저장된 숫자…** 는 붙여넣기와 같은 자를
쓰므로 함께 좁아졌습니다. 앞자리 0 이 붙은 정수는 이제 이 정리가 바꾸지
않습니다 — 붙여넣기로 지킨 것을 정리가 도로 123 으로 고쳐 놓으면 지킨 뜻이
없어지기 때문입니다. 열다섯 자리를 넘는 번호를 바꾸지 않는 것과 같은 까닭이고,
`₩5,000`·`1,234`·`(500)`·`50%` 는 지금까지처럼 고쳐 줍니다. `007` 을 정말 7 로
만들고 싶으시면 그 칸에 직접 쳐 넣으시면 됩니다.

엑셀과 구글 시트는 붙여넣은 `00123` 을 123 으로 바꿉니다. kanpic 은 파일
가져오기에서 이미 반대로 정해 두었으므로(v0.192.0·v0.251.0) 그쪽에 맞췄습니다 —
한 제품 안에서 **어느 문으로 들어왔느냐**에 따라 다른 값이 남는 편이 더
나쁩니다.

## 사용자 가이드의 붙여넣기 절이 지금 규칙을 적습니다

"다른 스프레드시트에서 붙여넣기" 절은 자릿수 구분으로 볼 수 없는 값·전화번호·
날짜만 글자로 둔다고 적혀 있었습니다. 앞자리 0 이 뜻을 갖는 번호와 열다섯
자리를 넘는 계좌·전표 번호도 글자로 둔다는 것, 그것이 CSV·TSV 가져오기와 같은
규칙이라는 것, XLSX 는 앞자리 0 만 같다는 것(엑셀이 수로 저장해 둔 칸은 이미
실수여서 자릿수를 되돌릴 것이 없습니다 — 긴 번호가 걱정되면 CSV 로 올리세요),
셀에 직접 쳐 넣은 `007` 은 숫자 7 이 된다는 것을 더했습니다. `USER_GUIDE.pdf`
도 다시 구웠습니다.

## 올리실 때

마이그레이션도 새 설정도 없고 필수 런타임 환경 변수는 계속 `POSTGRES_DSN`
하나입니다. 바뀐 것은 브라우저에 실리는 웹 자산과 문서뿐이므로 v0.252.0 에서
올라오시는 분은 이미지만 바꿔 다시 띄우시면 됩니다(쓰시던 분은 새로고침 한 번).
이미 123 으로 담겨 버린 칸이 되돌아오지는 않습니다 — 이 릴리즈 뒤에 새로
붙여넣는 값부터 적힌 대로 남습니다. 앞자리 0 을 일부러 떼어 내려고 붙여넣기를
쓰시던 분이 있다면 그 칸은 이제 손으로 쳐 넣으셔야 합니다.

## 오프라인 설치

이 릴리즈는 웹 자산과 서버 바이너리를 포함한 Docker 이미지 아카이브로 제공됩니다.

```bash
sha256sum -c kanpic-v0.253.0.tar.gz.sha256
gzip -dc kanpic-v0.253.0.tar.gz | docker load
docker run --rm -p 8080:8080 \
  -e POSTGRES_DSN='postgres://kanpic:password@postgres.internal:5432/kanpic?sslmode=require' \
  kanpic:v0.253.0
```

- 필수 런타임 환경 변수: `POSTGRES_DSN`
- Redis 및 외부 인터넷 연결: 불필요
- 관리자 초기 로그인을 보호하려면 `BOOTSTRAP_ADMIN_ID`와 `BOOTSTRAP_ADMIN_PASSWORD`를 함께 지정합니다.
- 무결성 검증 파일: `kanpic-v0.253.0.tar.gz.sha256`
