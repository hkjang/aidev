Core Features

Floorplan versioning, SVG seat assignment, anomaly detection, and AI assistant integration

👁️

Selectable Seat Detection

The offline CV engine strips walls and dimension lines and recovers the repeating desk lattice to produce seat candidates from PNG, JPG, or PDF blueprints. You can switch to cross-validating the result with an on-premise vision model such as Qwen2.5-VL.

🗺️

SVG Relative Coordinate Editor

100% offline SVG engine providing resolution-independent Drag & Drop seat assignment, selection, and zoom.

⚠️

Automated Anomaly Detection

Detects unassigned vacant seats, retired user occupied seats, org zone mismatches, and low-confidence seat candidates.

🔐

Keycloak OIDC & Break Glass

Standard Keycloak OIDC (PKCE) SSO paired with a non-deletable Break Glass bootstrap admin account for offline safety.

🤖

Streamable HTTP MCP Server

Enables Claude Desktop and Cursor to search available seats and query office layouts within permission boundaries.

📦

Single Air-Gapped Container

Go API and React 19 / MUI bundled into a single non-root Docker image with zero runtime CDN or font dependencies.

Air-Gapped Deployment Guide

Deploy quickly in offline environments using a single Docker image

🐳 Single Docker Execution

Import the single .tar.gz package from GitHub Release into your offline network.

docker load < SeatOn-v1.0.0-linux-amd64-image.tar.gz

# Run with 3 environment variables
export POSTGRES_DSN='postgres://seaton:password@postgres:5432/seaton'
export BOOTSTRAP_ADMIN='admin'
export BOOTSTRAP_ADMIN_PASSWORD='change-this-strong-password'
docker compose up -d

⚙️ 3 Required Environment Variables

SeatOn requires only three environment variables to boot.

POSTGRES_DSN=postgres://seaton:pass@localhost:5432/seaton
BOOTSTRAP_ADMIN=admin
BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!
