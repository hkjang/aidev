스마트 좌석 & 오피스 관리

사무실 도면과 직원 정보를 비율좌표 SVG와 선택형 좌석 판독 엔진으로 정확히 연결

SeatOn은 인터넷이 차단된 사내 폐쇄망 인프라에서 도면 좌석 자동 판독, 비율 좌표 SVG 좌석 편집기, 이상 좌석 자동 검출, Keycloak OIDC SSO 및 AI 에이전트를 위한 Streamable HTTP MCP를 단일 Docker 컨테이너로 제공하는 스마트 공간 관리 플랫폼입니다.

주요 기능

도면 버전 관리부터 비율좌표 좌석배정, 이상 감지 및 AI 연동까지 통합 제공합니다

👁️

도면 CV 좌석 자동 분석

PNG, JPG, PDF 건축 도면 업로드 시 오프라인 CV 엔진이 벽·치수선을 걸러내고 책상 배치의 반복 격자까지 복원해 좌석 후보를 만듭니다. 사내 비전 모델(Qwen2.5-VL 등)로 교차 검증하도록 전환할 수도 있습니다.

🗺️

비율 좌표 SVG 좌석 편집기

외부 지도 SDK 없는 100% 오프라인 SVG 좌표 엔진으로 해상도에 구애받지 않고 Drag & Drop 배정을 수행합니다.

⚠️

이상 좌석 상태 자동 검출

미배정 공석, 퇴직자 미반납 점유, 조직 구역 불일치 및 저신뢰 좌석을 자동으로 감지하여 보고합니다.

🔐

Keycloak OIDC & Break Glass

Keycloak OIDC (PKCE) 인증과 네트워크 단선 상황을 대비한 삭제 불가능한 Break Glass 부트스트랩 계정을 지원합니다.

🤖

Streamable HTTP MCP Server

Claude Desktop, Cursor 등 AI 에이전트가 호출자의 권한 범위 내에서 안전하게 빈 좌석 검색 및 배정 현황을 조회합니다.

📦

오프라인 단일 Docker

Go API와 React 19 / MUI 자산이 통합된 단일 non-root Docker 이미지로 외부 CDN 연결 없는 100% 폐쇄망 배포를 보장합니다.

개발자 API & Streamable MCP

REST API와 Streamable HTTP MCP로 사내 좌석 배정 자동화를 연동하세요

REST API OpenAPI 3.0 사양

`/api/v1` 경로로 도면, 좌석, 직원 및 이상 감지 API를 제공합니다.

json — GET /api/v1/seats/available
{
  "success": true,
  "data": [
    {
      "seat_id": "SEAT_10F_012",
      "floor": "10F",
      "zone": "DEVELOPMENT_TEAM",
      "x_ratio": 0.452,
      "y_ratio": 0.681
    }
  ]
}
MCP Streamable HTTP MCP Server

Permission과 Scope를 엄격히 검사하는 MCP 어댑터입니다.

json — MCP Authorization Token
{
  "Authorization": "Bearer stn_7f9c8d11a2b3c4d5_secret_digest",
  "Accept": "application/json, text/event-stream"
}

오프라인 설치 가이드

단일 Docker 이미지로 오프라인 폐쇄망 환경에 빠르게 배포하세요

🐳 Single Docker Archive Load

GitHub Release의 .tar.gz 패키지 하나만 오프라인망으로 반입하여 구동합니다.

docker load < SeatOn-v1.0.0-linux-amd64-image.tar.gz

# 3개 환경변수로 구동
export POSTGRES_DSN='postgres://seaton:password@postgres:5432/seaton'
export BOOTSTRAP_ADMIN='admin'
export BOOTSTRAP_ADMIN_PASSWORD='change-this-strong-password'
docker compose up -d

⚙️ 3대 필수 환경변수

SeatOn이 사용하는 필수 환경변수는 단 3개입니다.

POSTGRES_DSN=postgres://seaton:pass@localhost:5432/seaton
BOOTSTRAP_ADMIN=admin
BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!

자주 묻는 질문 (FAQ)

네. 외부 지도 SDK 대신 자체 개발된 SVG 비율 좌표 엔진과 오프라인 CV 도면 파서를 사용하여 인터넷 연결 없이 100% 오프라인 독립 구동합니다. 비전 모델 판독은 선택 기능이며, 사내 추론 서버 주소만 지정할 수 있습니다.

네. 내장된 오프라인 CV 파서가 건축 도면에서 좌석 후보를 자동 감지하고 배치 격자를 복원합니다. 신뢰도가 낮은 좌석만 검토 목록에 남으며, 사내 비전 모델과 교차 검증하면 검토 대상을 더 줄일 수 있습니다.

네. 인사 DB 연동 및 이상 탐지 규칙 엔진을 통해 미배정 공석, 퇴직자 미반납 점유, 조직 구역 불일치 및 저신뢰 좌석을 자동으로 감지합니다.
