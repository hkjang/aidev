`oidc.issuer_url`)이라 `mcp` 카테고리에 `oauthEnabled`·`oauthResource`·`oauthAudience`·`oauthScopes` 로 두고 문서에 표준 이름과의 대응표를 적었다. **리소스 식별자 출처**: `oauthResource` > `ui.publicUrl`(또는 cfg.PublicURL) + `/mcp` >
