MAIL-STANDARD.md와 kanpic 참조 구현을 따라 같은 능력을 이 저장소의 구조로 만들었다. `internal/mail`(전송·설정·발송 기록)은 릴레이가 알리는 대로 맞춘다: 포트 25·인증 없음·TLS 없음이 기본, `auto`면 STARTTLS를 제공할 때만 쓰고, PLAIN/LOGIN/CRAM-MD5는 사용자 이름이 있을 때만 시도한다(net/smtp의 DATA writer가 이미 dot-stuffing을 하므로 kanpic처럼 본문을 다시 escape하지 않는다 — 가짜 릴레이 테스트가 점이 한 번만 붙는 것을 확인한다). 메일은 요청 경로를 떠나 배경에서 한 번 재시도하며 나가고, 종료 시 진행 중인 발송을 기다린다. 시도마다 `mail_deliveries`(마이그레이션 011)에 이벤트·수신자·제목·상태·시도 수·릴레이 오류를 남기고 본문은 남기지 않는다. 주소는 users 표에서 조회 하나로 빌려 쓰며 비활성 계정·빈 이메일·`user_preferences.mail_opt_out`을 뺀다. 설정은 `mail` 키 하나에 표준의 이름 그대로 필드(`mail.enabled`, `mail.smtp_host`, …, `mail.notify_<event>`)를 두었고 tracking·oidc와 같은 모양이다. 비밀번호는 암호화 저장·설정 API에서 미반환(`password_configured`만)·감사 로그 `replaced`·빈 값 저장 시 이어받기·저장값을 읽지 못하면 503으로 거부(OIDC/AI와 같은 규칙)이고, 기본값은 꺼짐이라 저장한 적 없는 배포는 아무것도 달라지지 않는다. **고른 이벤트 셋과 이유**: (1) `approval_requested` — 게임 등록·수정 워크플로 요청과 RealmGuard·Defense 게시 승인 요청이 대기열에 들어올 때 관리자와 요청자(콘텐츠는 작성자) 팀의 팀장에게, 정책이 팀장 필수가 아니면 운영자에게도. 이 메일이 없으면 요청자가 검토자를 찾아다니거나 대기열이 며칠 잠긴다. (2) `approval_decided` — 승인·반려와 반려 사유를 요청자에게. 없으면 요청자가 화면을 계속 새로고침한다. (3) `ranking_moderated` — 운영자가 점수를 제외·검토 표시·복구했을 때 점수 주인에게, 상태가 실제로 바뀐 경우만. 순위를 잃고도 한마디도 못 듣는 것은 손해다. 이벤트 참가·공지·업적 같은 '무언가 바뀜'은 뺐다. 자기 행동은 자기에게 보내지 않고 두 자격으로 받게 되는 사람은 주소 기준 한 통이며, 종류별 스위치가 있다. 관리 화면 `/admin/mail`(새 메뉴 "메일 알림")에 설정·저장된 설정으로 실제 한 통을 보내고 릴레이의 대답을 그 자리에 보여 주는 시험 발송·상태 필터가 있는 발송 기록을 두었고, ADMIN_GUIDE.md 3.4(설정 표·이벤트와 수신자·시험 발송·장애표 한 줄)와 api.md를 갱신하고 공용 md2pdf로 PDF를 다시 구웠다. 검증: `gofmt -l`, `go vet`, `go build ./...`, `go test`·`go test -race` 전체 통과(새 Go 테스트: mail 8·api 7·PG 4), docker `postgres:17-alpine`으로 `internal/api` 전체 PG 테스트 통과(마이그레이션 011 포함), `npm run lint`·`tsc -b`·web 테스트 247개(새 6개) 통과, `scripts/check-release-contract.sh` 통과. 실제로도 띄워 확인했다 — 바이너리 + 가짜 SMTP(python)로 미저장 상태의 기본값 응답→꺼진 채 시험 발송 409→비밀번호 포함 저장이 비밀번호 없이 돌아옴·목록 API의 `secrets.mail.password:true`→비밀번호 없이 재저장해도 유지→AUTH를 제공하지 않는 릴레이에 사용자 이름을 두면 명확한 실패 기록→인증 없이 저장 후 시험 발송이 릴레이에 도착(QEncoding 헤더·Auto-Submitted)→릴레이를 끊고 보내면 15ms에 502와 실패 기록·감사 로그에 비밀번호 없음까지 curl로 확인했다. 관리 화면 캡처는 캡처 도구가 파괴적(전용 배포 필요)이라 찍지 않았다.
