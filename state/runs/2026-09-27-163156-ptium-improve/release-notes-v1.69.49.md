# Ptium 1.69.49

## 마크다운의 코드 블록이 슬라이드를 쪼갰습니다

마크다운을 올리면 한 줄씩 읽습니다. 그런데 ```` ``` ```` 로 감싼 **펜스 코드 블록도 다른 줄과
똑같이** 읽었습니다. 블록 안은 마크다운이 아니라 코드인데, 그 안의 `#` 는 제목으로, `-` 는
요점으로 읽혔습니다. 런북 한 장이 이렇게 도착했습니다.

~~~
올린 것:  # 배포 절차
          배포는 아래 순서로 합니다.
          ```bash
          # 1단계: 이미지 빌드
          make build
          # 2단계: 배포
          kubectl apply -f deploy/kubernetes.yaml
          ```
          끝입니다.

이전:  1장 → 배포 절차          - 배포는 아래 순서로 합니다.  - ```bash
       2장 → 1단계: 이미지 빌드  - make build
       3장 → 2단계: 배포         - kubectl apply -f …  - ```  - 끝입니다.
지금:  1장 → 배포 절차          - 배포는 아래 순서로 합니다.  - 끝입니다.
~~~

셸 주석의 `# 1단계` 가 슬라이드를 새로 열고, 여는 줄과 닫는 줄은 요점으로 남고, 블록 뒤의
"끝입니다." 는 마지막 코드 줄이 만든 슬라이드에 붙었습니다. 아무도 쓰지 않은 슬라이드가
두 장 늘어난 것입니다.

이제 코드 블록은 **그것이 실은 한 덩어리**로 읽힙니다. 덱에는 코드를 그리는 컴포넌트가 없어
블록의 내용은 슬라이드에 담기지 않으므로, 조용히 빠지는 대신 Word 문서의 그림을 두고 하던
것과 같은 자리에서 이렇게 알립니다.

~~~
코드 블록 1개(4줄)는 가져오지 않았습니다. 슬라이드에 필요한 줄은 요점으로 적어 주세요
~~~

줄 수까지 적는 것은, 블록이 몇 개인지만으로는 문서의 얼마가 빠졌는지 알 수 없기 때문입니다.
한 블록은 두 줄짜리 토막일 수도 있고 파일 마흔 줄일 수도 있고, 원본을 다시 열어 볼 만한 것은
뒤쪽뿐입니다. 세는 것은 펜스 두 줄을 뺀 사이의 줄입니다. 코드 블록이 없는 문서에는 이 줄이
붙지 않습니다.

`~~~` 도 같은 블록입니다. 블록을 닫는 것은 **펜스 문자만으로 이루어진 줄**이라, 셸 블록
가운데의 ```` ```python ```` 은 그 블록의 한 줄로 남고 블록을 끝내지 않습니다.

**닫히지 않은 펜스는 아무것도 삼키지 않습니다.** 혼자 떠 있는 ```` ``` ```` 는 누군가 잘못
남긴 한 줄이지 파일 끝까지 이어지는 블록이 아닙니다. 그것을 블록으로 보면 뒤의 모든 슬라이드가
사라지므로, 여는 줄까지 되돌려 **펜스를 몰랐을 때와 한 글자도 같게** 읽습니다.

펜스 문자 뒤에 문장이 이어지는 줄도 블록을 열지 않습니다 — ```` ``` 로 감싸면 코드 블록이
됩니다. ```` 는 펜스에 **대한** 문장이고, 마크다운을 설명하는 안내 문서의 한 줄이 바로 이렇게
생겼습니다. 블록을 여는 줄이 펜스 뒤에 적을 수 있는 것은 언어 이름 한 낱말뿐입니다.

표·요점·제목·`!source`·`(계속)` 를 읽던 방식은 **한 글자도 달라지지 않았습니다.** docx 와
pdf 를 읽는 쪽도 그대로입니다.

## 지키는 장치

`internal/docs/markdownfence_test.go` 의 검사 아홉 개가 봅니다. 위의 런북이 본문 한 장으로
읽히는지, 코드 블록이 없는 문서에 경고가 붙지 않는지, 닫히지 않은 펜스가 고치기 전과 한
글자도 같은 문서를 내는지, `~~~`, 셸 블록 가운데의 ```` ```python ````, 펜스에 대한 문장,
경고가 세는 줄 수, 그리고 코드 블록만 있는 파일이 내던 기존 에러 — 고치기 전 코드에서 본문이
세 장으로 갈라지고 경고가 하나도 붙지 않는 것을 먼저 확인했습니다. 기존 마크다운 검사
(`docs_test.go` · `wordbreaks_test.go` · `listmarker_test.go` · `told_test.go`)는 한 건도
바뀌지 않았습니다.

`go test -race ./...` 와 `go vet ./...` 모두 통과합니다.
