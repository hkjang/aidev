- 요약: 이 저장소는 메타 DB 모드에 사용자별 계정·Keycloak OIDC 웹 로그인(`UpsertSSOUser` 가 `sub` 를 `provider_subject` 로 기록)·개인 MCP 키(`ssk_`)가 이미 있어 표준을 그대로 적용했다. **고른 것과 이유**: (1) 설정 자리 — 기존 `meta.SettingDefs`(메타 DB 저장, `/admin/settings`, 재기동 없이 적용)에 표준 이름 그대로 `mcp.oauth.enabled`(기본 false)·`mcp.oauth.resource`·`mcp.oauth.audience`·`mcp.oauth.scopes`(기본 `mcp:read`)를 「MCP SSO (OAuth)」 그룹으로 넣고 인증 서버는 기존 `oidc_issuer` 를 재사용했으며, 환경변수 `SQLON_MCP_OAUTH_*`/플래그 `-mcp-oauth-*` 는 다른 설정처럼 기본값 층이다. (2) 리소스 식별자 출처 — 이 앱에는 공개 주소 설정이 없어 `mcp.oauth.resource` 가 비면 **`oidc_redirect_url` 의 오리진 + MCP 경로**로 만들고, 요청 `Host` 헤더는 마지막 수단으로도 쓰지 않았다(OIDC 가 구성된 곳엔 redirect URL 이 항상 있고, Host 는 누구나 바꿀 수 있다). 둘 다 없으면 켜 두어도 꺼진 것처럼 동작하고 카드에 「켜짐·미완성」+이유, 로그에 `mcp oauth: enabled but inactive: …` 를 남긴다. (3) go-oidc 가 없는 저장소라(웹 로그인이 userinfo 위임의 hand-rolled OIDC) discovery 의 `jwks_uri`(발급자와 같은 scheme+host 만, 리다이렉트 안 따름, 1MB 제한)를 읽어 RS/PS/ES 서명을 직접 검증하는 `jwksCache` 를 `internal/mcp/mcpoauth.go` 한 파일에 두었다(1시간 캐시, 모르는 kid 재조회는 10초에 1회로 제한). (4) 범위 — 이 앱의 키에는 범위 어휘가 없지만 도구가 `adminOnlyTools`/`dbaTools` 두 특권 계층으로 이미 나뉘어 있어 닫힌 어휘 `mcp:read`(그 밖 모든 도구·resources/read·prompts/get)·`mcp:admin`·`mcp:dba` 를 두고, 관리자 설정이 천장, 역할은 그대로 필요(교집합)하며, 토큰이 `mcp:*` 를 실어 오면 천장과의 교집합만 주고 **교집합이 비면 빈 목록이 아니라 401 로 거부**한다. 빈 값 센티널 점검: 이 앱에서 `userFrom(ctx)==nil` 은 stdio 신뢰이고 OAuth 주체는 항상 실제 계정이며, OAuth 표시(`oauthPrincipal`)는 존재 여부로 판정하고 Scopes 는 절대 비지 않는다; 외부 에이전트 게이트는 `handleMCP` 하나뿐(REST 는 `authenticate` 그대로)임을 확인했다. 거부는 모두 단일 생성자 `refuseOAuth` 를 지나 하위 원인이 로그(`sqlon: mcp oauth: refused: …`)에 남고 클라이언트 본문에는 조치가 적힌다(대상 불일치는 본 aud/azp 와 넣을 값). 계정은 `GetUserByProviderSubject(keycloak, sub)` 로만 찾고(username 폴백 없음 — 로컬 계정과 이름만 같은 토큰이 그 계정으로 들어오지 않게), 없으면 "웹으로 먼저 로그인", 비활성이면 거부, 생성·role 승격 없음. 401 도전(`resource_metadata`, 자격이 있었으면 `error="invalid_token"`)은 MCP 경로에만 붙고 REST 401 은 그대로다. 표준과 다른 점 하나: weekly 는 웹 로그인 `client_id` 도 대상으로 자동 허용하지만 이 구현은 브리프대로 리소스 식별자와 `mcp.oauth.audience` 만 받는다(웹 클라이언트와 MCP 클라이언트를 분리하라는 Keycloak 절차와 일치). 화면은 `/admin/settings` 카드(bool 스위치 — `SettingDef.Type`/`Validate` 를 새로 두어 저장 시 400 검증, 리소스 식별자·메타데이터 주소·issuer·허용 대상·범위 + 복사 단추)와 `/admin/keys` 「키 없이 SSO 로 연결하기」(`/auth/me` 의 `mcp_oauth{active,resource,metadata_url}` 로 표시). 문서는 관리자 가이드 §3.4(설정 표·켜지는 조건·Keycloak 공개 클라이언트/Redirect/Audience 매퍼 또는 azp 호환 경로/토큰 수명과 introspection 없음 한계·curl 3종·거부 메시지별 조치 표)·사용자 가이드 §2.3·README·OpenAPI·CHANGELOG Unreleased 이며 `docs/reports/generate_docs.py` 로 두 가이드의 HTML/PDF 를 다시 구워 `docs/*.pdf` 에 복사했다(playwright 브라우저가 없어 시스템 Chrome 을 executable_path 로 주는 임시 래퍼 사용, 스크립트는 수정하지 않음;
