## 2026-10-04
- 선택: 공통 자원 폼의 네 날짜 필드가 서버가 읽을 수 없는 확장 연도 RFC3339 를 보내지 않게 제출 값으로 막기 (가치 3 / 위험 2 / 작업량 M)
- 결과: 성공
- 요약: `resources.tsx` 의 `formBody` 는 `datetime` 필드를 `new Date(values[f.key]).toISOString()` 로 바꿔 검사 없이 POST/PUT 본문에 넣었다. ECMA-262 는 UTC 순간이 0000~9999 를 벗어나면 확장 연도(`+YYYYYY`/`-YYYYYY`)를 내고, 이 네 필드의 서버 판독기는 모두 `time.Parse(time.RFC3339, s)`(4자리 연도·부호 없음)를 지난다. 브라우저 시간대가 경계의 어느 쪽에 떨어질지 결정하므로 **평범하게 타이핑 가능한 `9999-12-31T23:59` 이 UTC 동쪽에서는 수락, 서쪽에서는 `+010000-01-01T04:59:00.000Z` 로 거절**된다(실측). 결과는 필드마다 다르고 findings `expires_at` 이 조용한 쪽이다: schedules `next_run_at`(`validateSchedule`)·scopes `expires_at`(`validateScope`)·findings `due_date`(`validateFindingOpsResource`)는 400 이지만 findings `expires_at` 은 쓰기 시점 검증기가 아예 없어 그 문자열이 **저장되고** `domain.go:704` 의 대시보드 집계와 `finding_ops.go:145` 의 `hunter_finding_timestamp` 에서 파싱에 실패해, 운영자가 먼 미래로 지정한 위험 수용이 비활성으로 읽히고 발견 건이 계속 미해결로 집계된다. ECMAScript 시간값 범위를 벗어나는 값(예: 6자리 연도)에서는 `toISOString` 이 `RangeError` 를 던져 번역되지 않은 `Invalid time value` 가 폼 오류 배너에 그대로 떴다. 그래서 **입력값이 아니라 실제로 보내는 wire 문자열**을 `/^\d{4}-/` 로 검사해 필드 라벨이 붙은 한국어 오류를 던지고, 테스트가 프로덕션 제출 경로 자체를 지나도록 `formBody` 를 `resource-form-state.ts` 의 `resourceSubmitBody` 로 **먼저 무변경 이동**(이동 직후 typecheck 0 / 106통과로 확인)한 뒤 그 안에 검사를 넣었다. 유효 입력의 wire 문자열은 한 글자도 바뀌지 않고 서버 계약은 손대지 않았다. 프로덕션 2파일. 새 공유 벡터 `internal/app/testdata/resource-datetime.json`(cases 11 + wireOnly 3 + unsendable 2)은 (시간대, 입력) 쌍마다 wire 문자열과 단일 `accepted` 판정을 적고, Go 는 `validateFindingOpsResource`·`validateSchedule`·`validateScope`(미래 행만 — `expires.After(time.Now())` 때문에 과거 행은 형식과 무관한 이유로 거절되므로 제외)와 집계 판독 재현에 돌리고(DSN 불필요), TS 는 `process.env.TZ` 를 바꿔 `resourceSubmitBody` 가 거절하거나 `accepted` 문자열만 만드는지 단언한다. 검증(실제 실행, Node v22.23.1 / Go 1.26.7): `npm --prefix web ci`, `npm --prefix web test` 기준선 **106통과/0실패/0skip** → **108통과/0실패/0skip**, `npm --prefix web run typecheck` 0, `npm --prefix web run build` 성공, `prettier --check` 통과, `go test -run '^TestResourceDateTimeSharedVectors$' -count=1 -v ./internal/app` 14서브테스트 PASS, `go test -count=1 ./internal/app` ok, `go vet ./...` 0, `gofmt -l internal/app/resource_datetime_test.go` 빈 출력, `node scripts/verify-pentagi.mjs` 312파일 확인, `cp -a web/dist/. internal/webassets/dist/` 후 `go build ./cmd/hunter` 성공(생성 바이너리는 커밋 전 삭제), `git diff --check` 0. 전체 `go test -race ./...`(HUNTER_TEST_DSN 필요)·원격 CI·Docker 빌드는 미실행.
