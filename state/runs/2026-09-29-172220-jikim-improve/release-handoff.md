# jikim v0.2.26 릴리즈 인계

- 등급: Tier 3. 방문자 추적 CSP 진단을 사용하는 관리자 대상 표시 오류 수정이며 릴리즈 노트로 안내합니다. 전체 CSP 파서 호환성이나 브라우저 실행 검증을 보장하는 변경은 아닙니다.
- 준비 기준: 기존 패치 관례의 버전·한국어 CHANGELOG·가이드 갱신, scripts/verify.sh 통과, 주석 태그와 소스 버전 일치. 실제 외부 배포와 공지는 이번 세션에서 수행하지 않습니다.
- 지원 답변: 연결만 허용한 출처가 script-src 진단에서 허용됨으로 보이던 문제를 지시어별 조회로 수정했습니다. DB 마이그레이션과 설정 변경은 없습니다. 최신 설명은 docs/ADMIN_GUIDE.md에 있습니다.
- PDF: 기존 변환기가 저장소에 없어 v0.2.18 PDF 유지. 화면 캡처 출처 v0.2.9 유지. 독립 사용자의 신규 설치 사용성 검증은 이번 세션에서 수행하지 않았습니다.
- 게시 게이트: release.yml이 태그·버전·커밋 일치, 소스 검증, linux/amd64 이미지 계약, PostgreSQL 폐쇄망 스모크, 전체 화면 E2E, 번들 무결성을 통과한 동일 이미지를 패키징하여 게시합니다. 어느 게이트라도 실패하면 게시 중단.
- 운영 인계: 운영 담당자가 초기 적용 인스턴스에서 CSP 진단을 확인한 뒤 확대합니다. CSP 헤더와 관리자 allowed 표시 불일치가 1건이라도 재현되거나 상태 점검이 실패하면 확대를 중단하고 직전 v0.2.25 이미지로 복귀합니다. 기존 환경·DB·암호화 키를 유지합니다.
- 후속 확인 제안: 게시 후 24시간 이내 초기 적용 인스턴스 1곳에서 연결 전용 출처의 script-src 차단이 허용되지 않음으로 표시되는지 확인하고, 7일 이내 관련 지원 문의의 재발 여부를 검토합니다. 운영 담당자 배정과 실제 관측은 외부 배포 단계에서 수행하며 아직 완료된 것으로 보고하지 않습니다.
- 자산: 이전 자산 jikim-v0.2.25.tar.gz 및 .sha256은 release.yml이 생성했습니다. 동일한 v0.2.26 자산도 CI가 생성하므로 로컬 assets=[]이고 github_release=false입니다.
