# Invenqor 프로필 (2026-10-03)
- 목적: 에이전트(Rust)가 호스트·프로세스·소프트웨어를 수집해 Server(Go)로 보내고, 관리 콘솔(React)·REST·MCP 로 IT 자산 인벤토리를 조회·관리하는 시스템.
- 스택: Agent — Rust 1.85(`src/`, `Cargo.toml`, `tests/`). Server — Go(`server/`, chi 라우터, PostgreSQL 기본 + SQLite 폴백, go-oidc). 콘솔 — React+Vite+TypeScript(`web/`), 빌드 산출물을 `server/internal/webui/dist` 에 체크인해 임베드. 문서 — `docs/*.md` + PDF.

- 위험 구역: `httpapi/auth.go`·`auth/`(세션·OIDC·API key, `authenticateAPIKey` 는 `/mcp` OAuth 분기 포함), `migrations/`(두 방언 동시 유지), `mergeAssets`/`splitAsset`(트랜잭션·`asset_changes`·`audit_logs` 기록), `webui/dist`(손으로 고치면 CI 실패), `.github/workflows`.
- 자주 깨지는 곳:
  - SQLite 에서 통과하고 PostgreSQL 에서 깨지는 SQL — JSONB 열에 LIKE(42883), 한 파라미터를 두 열에 재사용(타입 추론 충돌), LIKE 대소문자, 비정규형 UUID(22P02). PostgreSQL 의 UUID 입력은 대문자·중괄호·하이픈 없는 32자를 조용히 접고 `urn:uuid:` 는 22P02 로 거절하는데, SQLite 의 TEXT 비교는 전부 못 맞춘다 → 같은 요청에 200/500 과 400 이 갈린다. 방어는 `canonicalUUID`(`assets.go:661`) — 2026-10-03 기준 `splitAsset` 만 쓰고 `mergeAssets` 는 아직 `uuid.Parse` 모양 검사만 한다. `attributes_json` 은 방언별 표현(`querydsl/query.go attributeExpressions`). 시간 열은 방언별로 문자열/`time.Time` 이라 `any` + `apiTime()` 로 정규화.
  - **트랜잭션 안에서 `s.internalError` 를 부르면 SQLite 폴백이 교착한다** — `internalError` → `recordDiagnostic` → `DB().ExecContext` 가 새 커넥션을 요구하는데 열린 tx 가 `SetMaxOpenConns(1)` 의 유일한 커넥션을 쥐고 있다. `assets.go:724`(missingAssetID 오류 경로) 한 곳만 `tx.Rollback()` 선행으로 고쳐졌고 `mergeAssets` 의 745행 이후·`splitAsset` 의 나머지·다른 핸들러는 그대로다. 증상은 500 이 아니라 **응답 없음 → 테스트 타임아웃**. 새 검증은 `BeginTx` 전에 두어 이 구역을 비켜가는 것이 지금까지의 해법.
  - `asset_changes.after_json` 에 저장되는 id 가 요청의 글자 그대로면 MCP `merged_into` 조회(`mcp.go:747`·`752`, 두 방언 모두 문자 일치)가 못 찾는다.
- 검증 함정: 기본 `go test` 는 SQLite 폴백이라 PostgreSQL 결함을 못 본다 → 방언이 걸리는 변경은 반드시 `scripts/test-postgres.sh` 로도 돌릴 것(이 환경에 docker 있음). 실제 Keycloak·실제 MCP 클라이언트는 없음. 테스트는 프로덕션 배선(실제 라우터·실제 Runtime)을 통과해야 하고 손으로 만든 대역으로 결함을 증명하면 반려.
- 무검증 구역: `POST /api/v1/assets/{assetID}/split` 는 2026-10-01 회차가 테스트 7건을 넣어 더는 공백이 아니다(`asset_split_validation_test.go`). `merge` 는 3건(`asset_merge_validation_test.go`) — 비정규형 철자 케이스가 없다. 목록 핸들러의 `rows.Err()`, `assetRelations` 페이지네이션은 여전히 무검증.
