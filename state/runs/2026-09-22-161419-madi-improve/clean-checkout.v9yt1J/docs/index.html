Good questions

시작하기 전에 궁금한 것들.

madi는 어떤 서비스인가요?

Markdown 문서와 위키 링크, 그래프, 데이터베이스, AI·MCP를 연결하는 한국어 자체 호스팅 지식관리 서비스입니다. Go 서버가 React 화면을 함께 제공하고 PostgreSQL에 데이터를 저장합니다.

인터넷이 없는 폐쇄망에서도 운영할 수 있나요?

예. 실행에 필요한 웹 자산이 포함된 서비스 Docker 이미지를 반입해 운영합니다. Docker와 PostgreSQL은 별도 준비하며, 선택 기능인 Keycloak과 AI도 내부 서버를 사용할 수 있습니다. 오프라인 운영 가이드에서 반입과 검증 절차를 확인하세요.

실행 환경변수는 무엇이 필요한가요?

POSTGRES_DSN, BOOTSTRAP_ADMIN, BOOTSTRAP_ADMIN_PASSWORD, ENCRYPTION_KEY 네 개입니다. 그 외 운영 설정은 관리자 화면에서 관리합니다.

Keycloak과 사내 AI를 연결할 수 있나요?

관리자 화면에서 Keycloak issuer, client ID, client secret을 설정하면 OIDC discovery로 연결합니다. AI는 OpenAI 호환 API URL, 모델, 키를 설정하며 스트리밍과 최대 262,144 출력 토큰 설정을 제공합니다. 실제 한도는 모델을 따릅니다.

v0.2.0에서는 무엇이 달라졌나요?

작성·검색·공유를 중심으로 화면을 정리하고, 공동 편집 복구와 한국어 검색, 첨부 본문 추출, 재개 가능한 이관을 연결했습니다. AI 근거 보관함과 에이전트용 지식 패키지는 사용한 원문·버전·현재 권한을 확인합니다. 검증 조건과 운영 한계는 기능별 가이드에 공개하며 AI 결과의 사실성이나 운영 규모의 SLA를 보장하지 않습니다.
