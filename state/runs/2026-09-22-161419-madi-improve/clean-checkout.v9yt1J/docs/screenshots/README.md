# 실제 서비스 화면 캡처

이 디렉터리의 PNG는 자동 브라우저 검증에서 데모 데이터와 계정으로 촬영합니다. 서비스의 실제 페이지를 사용하며 홍보용 가상 목업으로 대체하지 않습니다. 화면 캡처 전에 암호, API 키 원문, 개인 정보가 보이지 않는지 확인합니다.

데스크톱 기본 화면은 1440×900, 모바일 기본 화면은 390×844를 권장합니다. 전체 페이지 촬영으로 실제 높이가 달라질 수 있습니다. 갤러리는 `docs/screenshots.html`에 구성합니다.

## 목록과 재생성

전체 목록은 [manifest.json](manifest.json)에 파일명·한국어 제목·분류·실제 크기·SHA-256으로 기록합니다. 고정된 수동 목록 대신 성공한 기능별 브라우저 시험의 최신 화면을 사용합니다.

```sh
node scripts/build-docs.mjs
node tests/docs.mjs
```

저장소 루트에서 실행합니다. 첫 명령은 이 폴더의 실제 PNG를 읽어 매니페스트와 [전체 화면 갤러리](../screenshots.html)를 갱신합니다. 두 번째 명령은 실제 GitHub Project Pages의 `/madi/` 경로에서 정적 링크·모바일·갤러리 검색/선택/새로고침을 검증합니다.

- 문서·협업·탐색, 데이터·업무, 검색·AI·Agent, 서비스·조직 운영, 개인화·공유·기기, 모바일로 분류합니다.
- `failure-*.png`와 `*-failure.png`는 진단용입니다. 공개 성공 갤러리에 포함하지 않으며 실제 실패 원인은 테스트 로그에서 해결합니다.
- `product-*.png`는 홍보 사이트 자체를 검증한 화면이므로 서비스 갤러리에서 제외합니다.
- 외부 연동 화면은 실제 어댑터에 계약 시험용 서버를 연결한 결과입니다. 운영 조직의 비밀번호나 실제 기업 데이터는 사용하지 않습니다.
- 키 발급 직후처럼 원문 비밀을 한 번 보여주는 화면은 토큰을 숨긴 후 촬영합니다. 갤러리 검색 결과가 없을 때 빈 상태도 실제 UI입니다.
