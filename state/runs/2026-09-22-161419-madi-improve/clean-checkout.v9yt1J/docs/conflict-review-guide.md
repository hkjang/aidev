# 문서 차이 검토 가이드

`전체 도구 → 문서 차이 검토`에서 현재 읽을 수 있는 문서를 선택해 비교합니다. 결과는 **규칙에 일치한 차이 후보**이지, 사실관계나 정책 충돌의 자동 판정이 아닙니다.

## 검사 범위

- 가까운 제목이 같거나 명시한 태그가 같은 문서에서, 문장 구조가 일치하는 수치·단위 또는 `허용/금지`, `필수/선택` 표현 차이를 찾습니다.
- 코드, 인용 예시, Front Matter는 검사 대상에서 제외합니다. 의미 추론, 적용 대상 해석, 서로 다르게 표현한 절차의 모순 판정은 하지 않습니다.
- 선택 문서 2~32개, 원문·속성 문서당 1MiB / 합계 8MiB, 문서당 2,000줄·200개 표현, 후보 최대 64개, 검사 최대 10초입니다. 한도에 도달하면 화면에 일부 제외를 표시합니다.
- AI 또는 외부 API를 호출하지 않습니다. 후보가 없다고 모순이 없는 것은 아닙니다.

## 비교와 개인 판단

1. `새 비교`에서 문서를 선택합니다. 선택 당시 버전이 바뀌면 최신 문서를 확인한 후 다시 시작합니다.
2. 구간을 개인 보고서에 보관하는 데 동의하고 비교 보고서를 만듭니다.
3. 두 구간의 문서·버전·줄·UTF-8 바이트 위치를 확인합니다. 전체 원문 해시는 제목·Markdown·태그·별칭을 포함한 정본 JSON의 SHA-256이고, 구간 해시는 표시한 원문 바이트의 SHA-256입니다. 해시는 사실성이나 승인 인증이 아닙니다.
4. `판단 기록`에서 `충돌로 판단`, `함께 적용 가능`, `추가 확인 필요`를 선택하고 근거를 남깁니다. 판단 버전이 바뀌었거나 원문이 변경되면 저장되지 않습니다.
5. `판단 이력 보기`에서 이전 판단을 확인합니다. 원문은 자동으로 수정되지 않습니다.

보고서와 판단 이력은 본인에게만 보입니다. 서비스 관리자도 다른 사람의 개인 보고서를 열 수 없습니다. 구간과 판단 메모는 서버의 `ENCRYPTION_KEY`를 사용해 암호화합니다. 현재 접근 권한과 민감정보 정책이 다시 적용되므로 권한이 회수되면 과거 구간도 숨깁니다. 새 민감정보 정책으로 처리할 수 없는 과거 기록은 원문 그대로 노출하지 않습니다.

## 변경안 연결

후보의 `첫째/둘째 원문 변경안`을 눌러 기존 지식 변경 제안 화면으로 이동합니다. 다른 원문 제목·구간이나 개인 판단 메모는 변경 이유에 자동으로 복사하지 않습니다.

제안을 공유할 때 일반 공유 동의와 **비교 출처 연결 동의**를 각각 확인합니다. 비교 보고서를 만든 본인만 출처를 연결할 수 있고, 두 원문의 현재 버전과 판단 버전을 같은 트랜잭션에서 검사합니다. 변경안과 출처 참조는 함께 저장되거나 함께 취소됩니다.

연결된 변경안은 대상 문서뿐 아니라 비교한 다른 문서의 현재 읽기 권한도 있어야 볼 수 있습니다. 변경안 열람자가 개인 비교 보고서 전체를 얻는 것은 아닙니다. 양쪽 원문이나 판단 기록이 바뀌면 `출처 다시 확인` 상태가 되어 반영을 중단합니다. 새 분석으로 새 변경안을 작성하세요.

변경안 반영은 기존 문서 저장 명령과 버전 충돌 검사를 사용합니다. 관리자가 게시 승인 정책을 설정한 경우 그 절차가 그대로 적용됩니다. 비교의 개인 판단은 게시 승인과 별개입니다.

## 보존과 운영

개인 비교 보고서는 최대 40개입니다. 보고서를 삭제해도 원문은 삭제되지 않습니다. 변경안의 출처로 연결된 보고서는 출처 보존을 위해 삭제할 수 없습니다. 암호화 자료와 출처 참조는 전체 서비스 백업 대상입니다. 복원 시 기존 암호화 키가 필요합니다.

`document:read` 범위의 개인 API 키는 본인 보고서를 읽을 수 있습니다. MCP의 `list_knowledge_conflicts`, `get_knowledge_conflict`도 같은 사용자·워크스페이스·양쪽 원문 ACL을 적용합니다. 비교 생성과 사람의 판단 기록은 로그인한 브라우저에서만 수행합니다. 키에 문서 작성 권한이 있더라도 개인 판단을 대행하지 않습니다.

API: `GET/POST /api/v1/knowledge/conflicts`, `GET/DELETE /api/v1/knowledge/conflicts/{id}`, `GET /api/v1/knowledge/conflict-candidates/{id}`, `POST /api/v1/knowledge/conflict-candidates/{id}/reviews`. 상세 입력과 현재 응답 계약은 서비스의 OpenAPI 문서를 확인하세요.
