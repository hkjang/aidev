# madi 사용자 가이드

## 1. 로그인과 내 공간

서비스 주소에 접속해 이메일과 비밀번호로 로그인합니다. 관리자가 SSO를 켜면 Keycloak 로그인 버튼이 표시됩니다. 로그인 화면 하단에서 현재 서비스 버전을 확인할 수 있습니다.

워크스페이스를 선택하면 해당 공간의 문서, 데이터베이스와 할 일을 탐색할 수 있습니다. 워크스페이스 권한에 따라 작성·수정 기능의 사용 가능 여부가 달라집니다. 개인 문서는 문서를 작성한 사용자에게 제한됩니다. 서비스 관리자 화면과 내 프로필·개인 API 키 화면은 분리되어 있습니다.

메뉴마다 URL이 있으므로 새로고침해도 현재 화면으로 돌아옵니다. 프로필 메뉴에서 서비스 버전 확인, 개인 설정 이동, 로그아웃을 할 수 있습니다.

홈에서는 이어서 작성할 문서와 최근 작업을 먼저 확인합니다. `개인 메모`는 제목·위치를 묻는 창 없이 비공개 초안으로 시작합니다. 팀 문서로 옮기거나 공유할 때는 실제 접근 범위가 바뀌는지 별도로 확인하세요. 기본 메뉴는 일상 작업 중심이고 나머지는 검색 가능한 `전체 도구`에서 열어 직접 고정할 수 있습니다. 목적별 메뉴와 고정 순서는 개인 설정이며 다른 사용자의 메뉴를 바꾸지 않습니다.

`내 처리함`은 담당 할 일·멘션·검토 요청을 모읍니다. 알림을 읽는 것과 실제 작업을 끝내는 것은 다릅니다. 작업 묶음·참고 선반·업무 홈 구성은 [작업 맥락과 개인화](ui-guide.md)를 참고하세요.

## 2. 문서 작성

새 문서를 만들고 제목과 본문을 작성합니다. 문서는 Markdown 원문으로 보관합니다. 제목, 목록, 체크리스트, 인용, 코드, 구분선, 이미지와 표를 활용할 수 있습니다. 편집 후 저장 상태를 확인하세요. 다른 사용자가 먼저 저장한 문서를 덮어쓰려고 하면 버전 충돌을 알리므로 최신 내용을 확인한 뒤 수정 내용을 다시 반영합니다.

블록 정리에서 여러 블록을 선택해 위·아래로 이동하거나 삭제하고 Drag & Drop으로 순서를 조정합니다. 블록 ID는 별도 메타데이터로 보관합니다. 문서 트리는 펼침 상태를 보관하고 하위 문서 생성 및 Drag & Drop 이동을 지원합니다. 고급 블록은 블록 링크·임베드·동기화, 2·3단 레이아웃, 접는 제목, 표, 각주·수식·Mermaid를 제공합니다. 참조 블록에도 원문 문서의 현재 권한이 적용됩니다.

```markdown
---
tags:
  - 운영
  - kubernetes
aliases:
  - K8s 운영
---

# Kubernetes 운영 가이드

관련 문서: [[장애 대응 절차]]

- [ ] 클러스터 상태 확인
- [x] 담당자 확인
```

`[[문서 제목]]`은 위키 링크입니다. 링크한 문서에서는 백링크로 원본 문서를 찾을 수 있습니다. 동명이거나 제목이 변경된 문서는 링크 대상과 별칭을 함께 확인하세요. 문서의 제목 구조는 개요 탐색에 활용합니다.

첨부한 이미지·파일은 서비스의 영구 저장소에 보관하며 해당 문서의 읽기 권한을 따릅니다. 관리자가 켜면 PDF·Office 본문 추출과 선택 페이지 OCR을 사용할 수 있습니다. [첨부 본문 검색·추출 가이드](attachment-extraction-guide.md)에서 원본 위치·검토·AI 전송 동의와 한도를 확인하세요. 추출 결과는 원본을 덮어쓰지 않으며 악성코드 검사나 모든 형식의 완전 호환성을 의미하지 않습니다.

문서 상단의 **서버 저장·연결·초안/게시·내부 공유·외부 링크** 상태를 각각 확인하세요. 저장됐다고 게시된 것은 아니고, 비공개 문서라도 외부 링크가 별도로 활성화될 수 있습니다. 문맥 패널에서 댓글·연결·AI·버전을 바꿔 보며 작성 위치를 유지합니다. 태그는 칩과 자동완성으로 정리하고, 한글 조합 중 Enter는 태그 확정으로 처리하지 않습니다. 원문 편집으로 전환할 때는 공동 편집 세대에 주는 영향을 먼저 안내합니다.

## 3. 검색, 그래프, 즐겨찾기

검색으로 제목·본문·태그를 찾습니다. 검색 결과에는 내가 접근할 수 있는 문서만 나타납니다. 지식 그래프는 문서와 위키 링크의 연결을 보여주며 노드를 통해 문서로 이동할 수 있습니다. 즐겨찾기는 개인별로 보관됩니다.

명령 팔레트 단축키를 사용하면 문서를 빠르게 찾거나 메뉴를 열 수 있습니다. 정확한 지원 단축키는 화면의 안내를 기준으로 사용하세요.

## 4. 데이터베이스와 할 일

데이터베이스를 만들고 속성의 이름과 유형을 지정한 뒤 행을 추가합니다. 선택 속성은 먼저 옵션을 지정한 뒤 셀에서 선택합니다. 날짜, 체크박스, 숫자 등의 속성은 지정한 유형에 맞는 값을 입력합니다. 수식·관계·롤업 같은 고급 속성의 지원 여부는 릴리즈 노트를 확인하세요.

표에서 검색·정렬하고 선택 속성으로 보드를, 날짜 속성으로 캘린더를 구성합니다. 보드 카드를 이동하면 선택 값이 변경됩니다. 기존 데이터와 맞지 않는 속성 유형·옵션 변경은 거부되므로 먼저 행 값을 정리한 뒤 속성을 변경하세요.

Markdown 및 편집기가 만든 HTML 표 안의 체크리스트를 **할 일과 일정**에서 모아 보고 담당자·기한·우선순위를 지정합니다. 칸반 손잡이 드래그나 상태 선택으로 원문 체크박스도 함께 바뀝니다. 내/팀 담당과 오늘/이번 주/기한 초과 필터를 지원합니다. 통합 캘린더에는 문서 날짜·일일 노트·할 일 기한·DB 날짜와 직접 만든 회의·마일스톤을 표시합니다. 구체적인 원문 고유 링크·권한·조회 한도는 [할 일과 통합 일정 안내](tasks-guide.md)를 확인하세요.

## 5. 버전, 복구, 가져오기와 내보내기

문서의 변경 이력에서 이전 버전을 확인하고 필요하면 복구합니다. 복구는 현재 내용을 변경하는 작업이므로 최신 문서 상태를 확인하세요. 삭제된 문서는 휴지통에서 복원할 수 있습니다. 관리자 보존기간(기본 30일)이 지나면 유지관리 작업에서 영구 삭제하므로 필요한 문서는 기간 안에 복원하세요.

가져오기에서 `.md` 파일 또는 Markdown 파일이 포함된 ZIP을 선택합니다. Obsidian Vault의 폴더는 상위 문서 구조로 만들고 YAML 제목·태그·별칭·공개 범위, Markdown·Wiki 파일 링크와 이미지 첨부를 가져옵니다. 연결되지 않은 파일은 개인 문서인 ‘가져온 첨부파일’에 보관합니다. 플러그인 설정, Canvas 및 모든 외부 도구의 전용 메타데이터가 변환되는 것은 아닙니다.

`/app/import`와 `/app/migrations`는 같은 가져오기 센터입니다. 파일·폴더를 선택하고 미리보기·확인 후 작업 큐에서 가져옵니다. 파일 50MB, 해제 총 100MB, 항목 5,000개, 문서당 4MB 한도를 적용합니다. Notion HTML의 로컬 이미지·링크와 CSV, HTML 문서, JSON 보관함도 지원합니다.

큰 이관은 같은 센터의 **재개 가능한 이관** 경로를 사용합니다. 청크를 전송하고 비공개 준비 영역에서 변환 차이·CSV 타입·중복·누락을 검토한 뒤 반영합니다. 위 단일 업로드 한도와 별도이며, [입출력 가이드의 분할 이관 한도](transfer-guide.md)를 먼저 확인하세요. 반영이 끝나도 자동 팀 공유되지 않습니다.

`/app/export`에서 Markdown 원문 ZIP, 상대 링크로 바꾸는 이동용 ZIP, HTML, JSON 보관함, DB CSV를 비동기로 만듭니다. 원문 모드는 Markdown 바이트를 그대로 보존합니다. 결과는 암호화해 24시간 보관하며 원본·권한 변경이나 세션 만료 시 재생성이 필요합니다. PDF는 문서 인쇄의 브라우저 ‘PDF로 저장’을 사용합니다. [입출력 가이드](transfer-guide.md)에서 형식별 보존 범위·한도·API를 확인하세요. 임시 결과는 운영 백업이 아닙니다.

## 6. AI 사용

관리자가 AI 연결을 설정하고 켜면 AI 화면에서 질문, 문서 요약 및 작성 지원을 이용할 수 있습니다. 답변은 생성되는 동안 순서대로 표시됩니다. 현재 문서나 워크스페이스를 질문 범위로 지정할 수 있으며, 제공된 출처 문서를 열어 내용을 확인하세요.

AI는 사용자의 문서 권한을 적용합니다. 외부 AI 제공자를 지정하면 질문과 선택된 문서 내용이 해당 제공자로 전송됩니다. 폐쇄망 운영에서는 내부 vLLM, Ollama 또는 사내 OpenAI 호환 게이트웨이를 설정합니다. AI가 연결되어 있지 않아도 문서 기능은 사용할 수 있습니다.

## 7. 개인 API 키

개인 설정의 API 키 메뉴에서 이름, 워크스페이스, 권한 범위, 만료일, 허용 IP 및 호출 제한을 지정해 키를 만듭니다. 발급된 비밀은 한 번 표시되므로 비밀 관리 도구에 저장하세요. 키는 내 계정이 가진 권한보다 더 넓은 권한을 가질 수 없습니다.

키를 회전하면 새 비밀이 발급되고 이전 비밀은 즉시 사용할 수 없게 됩니다. 사용하는 연동 시스템에 새 키를 반영하세요. 사용하지 않는 키는 폐기합니다. 키의 비밀을 문서, 채팅, URL 또는 저장소에 기록하지 마세요.

## 8. 검토와 승인

관리자가 승인 절차를 활성화한 경우에만 검토 요청, 승인 및 반려 기능이 표시됩니다. 설정하지 않은 서비스에서는 일반적인 문서 저장과 게시 흐름을 사용합니다. 승인 권한은 관리자가 지정한 검토자 역할을 따릅니다.

## 9. 개인화와 모바일

개인 설정에서 화면 테마, 글자 크기 등 제공되는 옵션을 조정합니다. 화면 글자는 읽기 편한 기본 크기로 제공됩니다. 모바일에서는 메뉴 버튼으로 탐색 영역을 열고 문서 조회·작성 및 검색을 사용합니다. 작은 화면의 데이터베이스 표는 표 영역을 가로로 스크롤할 수 있습니다.

문제가 발생하면 수행한 작업, 화면에 표시된 오류 메시지와 요청 ID가 있다면 요청 ID를 관리자에게 전달합니다. 암호·API 키와 민감한 문서 내용은 제외하세요.

## 10. 외부 알림과 개인 수집 채널

프로필 메뉴의 내 외부 알림에서 관리자가 허용한 이메일·팀 메시징 채널을 선택합니다. 문서 제목이나 본문은 외부로 보내지 않고 새 알림 안내만 전송합니다. 내 외부 수집 채널에서는 IMAP TLS 메일 또는 서명 Webhook을 비공개 수집함에 연결합니다. 생성 자료는 자동 공유하지 않습니다. 키 회전·중복·한도·실패 취소는 [알림·수집 가이드](notification-capture-guide.md)를 확인하세요.

## 11. 정보보호와 공개 링크

문서에는 상위 문서·공간을 포함한 유효 등급이 표시됩니다. 관리자가 마스킹을 켰다면 저장된 정본의 치환 결과를 확인하세요. 차단·마스킹 정책에서는 원문 편집으로 저장합니다. 공개 링크는 관리자가 허용한 경우 현재 문서 소유자만 생성하며, 비공개 문서도 링크 방문자에게 전달되므로 암호·만료·IP·첨부 설정을 확인해야 합니다. 원래 링크는 다시 조회할 수 없고 회전·폐기는 이전 주소를 무효화합니다. 자세한 동작과 한계는 [정보보호·공개 공유 가이드](information-protection-guide.md)에 있습니다.

## 12. 통합 검색과 AI 인용

검색 메뉴에서 문서·블록·코드·할 일·댓글·태그·파일 이름·DB 등을 필터링합니다. AI 답변의 번호 출처를 누르면 현재 권한·버전·원문 해시를 확인한 실제 조각이 표시됩니다. 문서별 임베딩 동의와 철회, 키워드·의미·통합 검색의 구분은 [검색·AI 출처 가이드](search-ai-guide.md)와 [RAG 운영 가이드](rag-guide.md)를 확인하세요.
문서 초안·요약·번역·태그·회의록 등 11종 AI 작업과 명시적으로 저장하는 개인 대화는 [AI 문서 작업과 개인 대화 기록](ai-writing-guide.md)을 참고하세요. 생성 결과는 검토한 뒤 새 비공개 초안으로 저장하며 기존 문서를 자동으로 덮어쓰지 않습니다.

선택 영역 AI는 원문과 제안을 비교한 뒤 부분 반영·아래 삽입·비공개 새 문서 중 선택합니다. 생성 중 원문이 바뀌면 그대로 덮어쓰지 않고 다시 비교합니다. [근거 보관함·지식 패키지](evidence-guide.md), [공식 답변](managed-questions-guide.md), [DB 구조화 초안](structured-drafts-guide.md)은 보관·공유·실제 변경 동의를 구분합니다. 해시 무결성과 내용이 옳다는 판단도 구분하세요.
