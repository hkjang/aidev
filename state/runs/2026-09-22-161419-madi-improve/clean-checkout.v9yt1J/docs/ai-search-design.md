# 통합 검색·RAG 구현 계약

이 문서는 진행 중인 구현 계약입니다. 현재 서비스의 단순 문서 검색·스트리밍 AI가 아래 전체 기능을 이미 제공한다는 의미가 아닙니다. 첫 릴리즈 전에 단계별 PostgreSQL·프로토콜·화면 검증을 완료합니다.

## 데이터와 권한

- Markdown 원문·문서 버전·바이트 및 줄 위치를 보존한 조각을 사용합니다. 인용은 모델이 쓴 제목이 아니라 서버가 검증한 문서 ID·버전·원문 범위와 연결합니다.
- 로컬 검색 투영은 현재 문서 버전과 일치하는 행만 사용합니다. 문서/상위 문서/공간 ACL과 현재 사용자의 키 범위를 쿼리 단계에서 적용합니다. 색인 당시의 접근 권한을 캐시해 재사용하지 않습니다.
- 외부 임베딩으로 내용을 보내는 작업은 기본 비활성입니다. 관리자 연결 정책과 현재 실행 주체의 문서 권한, 명시적 색인 요청을 확인합니다. 관리자가 개인 문서 내용을 우회해 읽거나 외부로 색인하지 않습니다.
- AI 처리 중 세션·키·문서 권한·참조 버전·공급자 설정이 달라지면 이후 텍스트를 차단합니다. UI에 `retract` 신호를 보내 이전 답변과 출처를 지우고 다시 요청하도록 안내합니다.

## 프로토콜

대화 생성은 기존 OpenAI 호환 Chat Completions SSE를 기본으로 유지하며 관리자 최대 출력 토큰 1~262144를 검증합니다. 임베딩은 별도 JSON 벡터 API입니다. `POST /embeddings`에 `model`, 문자열 배열 `input`, `encoding_format: float`를 보내고 응답의 `data[].index`로 입력 순서를 맞춥니다. 선택적 `dimensions`는 설정한 경우에만 전송합니다. 이는 [공식 OpenAI 임베딩 API](https://developers.openai.com/api/reference/ruby/resources/embeddings/methods/create) 계약을 따릅니다.

`rag_transport.go`는 내부 모델을 선택할 수 있게 모델명을 고정하지 않습니다. HTTPS/사설 CA, 명시적 HTTP 허용, 리디렉션 거부, 요청/응답 크기 제한, 중복/누락 인덱스·차원 불일치·0 벡터·비정상 숫자 거부를 검증합니다. 공급자 오류 본문을 사용자에게 그대로 돌려주지 않습니다. 운영 공급자의 입력 길이·차원·생성 토큰 지원 여부는 연결 진단과 실제 모델 계약에 따라 확인합니다.

## 구현 순서와 검증 지점

1. 원문 조각·임베딩 전송·스트리밍 권한 회수: 순수 함수 및 실제 TLS/SSE/PG 테스트.
2. 검색 투영·색인 작업: PostgreSQL dirty queue와 버전 일치 투영, 취소/재시도/진행률·명시적 외부 색인. 백업 카탈로그와 복원 시 과거 작업 실행 차단.
3. 통합 검색: 문서/블록/파일/댓글/사용자/태그/할 일/코드/DB/AI 대화, 작성자·기간·공간·태그·종류·상태 필터. 제목/태그/제목블록/본문 가중치와 최신성·조회 수. 범위/표본 한도를 API와 UI에 표시.
4. 하이브리드 검색: 키워드와 임베딩 순위 결합, 선택적 rerank와 pgvector. 모델/차원/설정 지문이 다른 벡터를 섞지 않음. 현재 ACL 밖 내용이 외부 reranker에 전달되지 않음.
5. 문서 AI 지원·대화 이력: 요약/작성/개선/번역/질의/태그/회의 결정·할 일/템플릿 제안, 인용 상세·스트리밍 취소·현재 권한으로 이력 조회.
6. 그래프 AI·Entity·Knowledge Gap: 추출/관계/유사 문서 추천은 확정 데이터와 분리해 저장. 원문/권한/버전이 유효한 추천만 사용자 확인으로 반영.
7. Workspace Agent: 지식/도구 범위와 현재 사용자 ACL 교집합, 제한된 도구 호출 횟수·승인/실행 분리·스트리밍 작업 이력. 외부 실행형 Runbook 권한을 우회하지 않음.

각 단계 후 실제 PC·모바일 메뉴, native select, URL 새로고침, 취소/재시도, 권한 회수, 인터넷 자산 요청 0을 검사하고 화면을 캡처합니다. 아직 연결하지 않은 구성 요소를 서비스 완료로 표시하지 않습니다.
