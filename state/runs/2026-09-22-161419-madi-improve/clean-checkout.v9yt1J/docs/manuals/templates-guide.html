사용자 템플릿 라이브러리

/app/templates에서 기본 템플릿과 워크스페이스의 사용자 템플릿을 구분해 관리합니다. 기존 홈·명령 팔레트의 일일 노트는 그대로 사용할 수 있습니다.

템플릿 만들기와 공유

  1. 새 템플릿에서 이름, 설명, 분류, 문서 종류와 Markdown 원문을 입력합니다.
  2. 공개 범위는 기본적으로 나만 보기입니다. 워크스페이스 공유는 구성원에게, 공간 공유는 선택한 공간의 현재 열람 권한이 있는 구성원에게 노출됩니다. 공간을 지정하면 모든 공개 범위에 공간 권한을 함께 적용합니다.
  3. 미리보기로 확인한 다음 템플릿 저장을 누릅니다. YAML Front Matter는 Markdown 원문에 보존됩니다. 원문에 tags가 있으면 별도 태그 입력보다 우선합니다.

템플릿은 소유자이면서 현재 작성 권한이 있는 사용자만 수정·삭제·복원할 수 있습니다. 서비스 관리자도 다른 사람의 비공개 템플릿 내용을 우회해서 열람하지 못합니다. 공유 사용자는 열람 가능한 템플릿을 자신의 비공개 사본으로 복제할 수 있습니다.

기본 템플릿과 문서 생성

기본 제공 모음에는 회의록, 의사결정 기록(ADR), 운영 런북, 일일 노트, 프로젝트 계획, 주간 회고, 지식 정리가 있습니다. 기본 템플릿 자체는 읽기 전용이며 내 템플릿으로 복제한 후 수정할 수 있습니다.

이 템플릿으로 문서 만들기에서 제목, 공간, 상위 문서와 공개 범위를 확인합니다. 새 문서도 기본적으로 비공개이며 초안으로 생성합니다. 일반 문서와 동일한 작성 권한, 민감정보 보호, 게시·승인 정책이 적용됩니다. 템플릿의 원문은 생성한 문서에 복사되며 이후 템플릿 수정이 기존 문서를 자동으로 바꾸지 않습니다.

문서를 만들 때 다음 두 변수만 개인 시간대 기준으로 치환합니다. 다른 표현이나 스크립트는 실행하지 않습니다.

변수 예시
{{date}} 2026-09-08
{{datetime}} 2026-09-08T14:30:00+09:00

템플릿 미리보기에는 원문의 변수를 그대로 표시합니다. 위키 링크는 새 문서가 속한 워크스페이스의 문서와 연결됩니다.

검색, 버전과 휴지통

  • 이름·설명·태그 검색과 분류·공개 범위·모음 선택은 URL에 유지되어 새로고침 후 복원됩니다.
  • 다른 창에서 템플릿이 변경되면 오래된 저장 요청은 409로 중단하고 현재 입력을 유지합니다. 새 버전을 확인한 뒤 다시 작업하세요.
  • 변경 이력에는 최근 100개 버전의 메타데이터를 표시합니다. 복원하면 당시 이름·내용·태그·공개 범위·공간을 새 버전으로 저장하고 현재 권한·보호 정책을 다시 검사합니다. 이력은 소유자만 확인할 수 있습니다.
  • 휴지통으로 이동은 복구 가능한 삭제입니다. 템플릿 휴지통에서 소유자가 복원할 수 있으며, 이미 만든 문서는 영향을 받지 않습니다.

템플릿의 이름·설명·분류·아이콘·태그·원문에는 서비스 민감정보 보호 정책을 적용합니다. 마스킹 모드에서는 정리된 결과만 현재 저장본과 새 버전 이력에 기록합니다. 차단 모드에서는 저장 전체를 중단합니다. 템플릿과 버전 이력은 서비스 논리 백업·복원의 대상입니다.

API

개인 API 키 사용 시 열람에는 document:read, 변경에는 document:write가 필요하며 기존 사용자·워크스페이스·공간 권한을 함께 적용합니다. 읽은 템플릿을 복제하거나 문서로 만들려면 두 범위를 모두 부여하세요.

경로 동작
GET /api/v1/templates/builtins?workspace_id=UUID 기본 템플릿
GET /api/v1/templates?workspace_id=UUID 현재 권한의 목록, 원문 제외
POST /api/v1/templates 사용자 템플릿 저장
GET /api/v1/templates/{id} 현재 원문과 메타데이터
PUT /api/v1/templates/{id} version을 포함한 전체 내용 수정
POST /api/v1/templates/{id}/duplicate workspace_id, expected_version으로 비공개 사본 생성
POST /api/v1/templates/{id}/documents workspace_id, expected_version과 목적지 설정으로 새 문서 생성
DELETE /api/v1/templates/{id}?version=N 휴지통 이동
POST /api/v1/templates/{id}/restore 현재 version으로 휴지통 복원
GET /api/v1/templates/{id}/versions 소유자용 이력 메타데이터
POST /api/v1/templates/{id}/versions/{N}/restore 현재 version을 포함해 과거 저장본 복원

목록은 기본 50개, 최대 100개씩 반환하며 items, has_more, offset, limit을 제공합니다. q, category, scope, trash=1로 필터링합니다. 원문은 최대 4MB입니다. 같은 워크스페이스의 현재 열람 가능한 템플릿만 문서 생성에 사용할 수 있습니다.
