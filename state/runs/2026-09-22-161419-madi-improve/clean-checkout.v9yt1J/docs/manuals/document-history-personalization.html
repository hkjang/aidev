원문과 문서 이력

문서는 Markdown 원문을 기준으로 보관합니다. 블록 편집과 원문 편집은 같은 문서를 다루지만, 원문 편집 저장 시에는 버전을 검사하고 공동 편집의 새 기준을 만듭니다. 읽기 화면은 문서를 저장하지 않습니다. 지원 범위를 벗어난 Markdown은 원문 보존 모드로 표시합니다.

문서 오른쪽 변경 이력에서 다음 작업을 할 수 있습니다.

  1. 작성자·시각·제목·원문 크기를 포함한 버전 목록을 확인합니다. 목록 응답에는 문서 본문이 없습니다.
  2. 원문 보기에서 선택한 버전만 불러옵니다. 미리보기와 Markdown 원문을 전환하거나 해당 버전 원문을 내려받을 수 있습니다.
  3. 두 버전을 선택하고 변경 비교를 누르면 추가·삭제 줄, 이전·다음 줄 번호, 제목·태그 변경을 확인합니다. 긴 동일 구간은 접어서 표시합니다.
  4. 이 버전으로 복원은 현재 문서를 새 버전으로 저장합니다. 기존 버전을 물리적으로 덮어쓰지 않습니다. 현재 공유 범위와 소유권을 유지하고 정보보호·승인 정책을 다시 적용합니다.

이력을 연 이후 누군가 문서를 저장했다면 복원은 충돌로 중단됩니다. 최신 이력을 다시 불러오고 변경 내용을 비교한 후 복원을 결정하세요. 읽기 권한만 있는 사용자는 이력을 볼 수 있지만 복원할 수 없습니다. 공유 권한이 철회되면 과거 버전도 조회할 수 없습니다.

비교 한도

비교는 서버 내 제한된 줄 단위 알고리즘으로 수행하며 원문을 외부로 보내지 않습니다. CRLF와 마지막 줄바꿈 차이도 비교 대상입니다. 입력 50,000줄, 계산 단계 400,000개, 표시 2,000줄·512KB·한 줄 8KB의 제한을 적용합니다. 계산 한도를 넘으면 최소 변경 대신 변경 구간 전체를 보여주고, 표시 한도를 넘으면 안내합니다. 정확한 전체 비교가 필요하면 두 버전의 원문을 내려받으세요.

API

GET  /api/v1/documents/{id}/versions?limit=50&before=100
GET  /api/v1/documents/{id}/versions/{version}
GET  /api/v1/documents/{id}/versions/diff?from=1&to=2
POST /api/v1/documents/{id}/versions/{version}/restore
     {"expected_version": 3}

복원 요청의 expected_version은 필수입니다. 현재 버전과 다르면 409 응답이며 저장되지 않습니다. API 키에는 기존 문서 읽기·쓰기 범위와 현재 사용자·워크스페이스·공간 ACL이 그대로 적용됩니다.

개인 설정

/app/profile의 설정은 로그인한 계정에 저장됩니다. 변경사항 저장 후 새로고침하거나 다른 기기로 로그인해도 유지됩니다.

설정 적용 범위
테마 밝은 화면 / 어두운 화면
글자 크기 16~24px의 정수
글꼴 내장 Noto Sans KR, 기기 기본 고딕, 기기 설치 명조
사이드바 너비 220~420px, 드래그 또는 선택
문서 본문 너비 표준 최대 880px / 넓게 최대 1,200px / 현재 화면 전체
기본 편집 모드 블록 / Markdown 원문 / 읽기; 명시한 URL 모드가 우선
맞춤법 검사 블록·원문 편집기의 브라우저 맞춤법 속성
코드 색상 화면 테마 따르기 / 밝게 / 어둡게
시간대 서울 / UTC / 도쿄 / 뉴욕
날짜 표시 한국어 기본 / 숫자형 YYYY-MM-DD / 연도·요일 포함
키보드 단축키 지원 명령별 변경, 중복·브라우저 예약 조합 금지

글꼴은 서비스에 내장되거나 기기에 이미 설치된 것을 사용하며 외부 폰트 요청은 없습니다. 명조 글꼴이 없으면 기기의 기본 글꼴로 대체됩니다. madi는 맞춤법 서버를 호출하지 않습니다. 브라우저의 향상된 맞춤법 검사 또는 운영체제의 온라인 검사 기능은 별도 조직 정책으로 제어하세요. 알림 채널은 별도 알림 설정에서 관리합니다.

PUT /api/v1/profile의 preferences는 전달한 키만 병합합니다. expected_user_id를 함께 보내면 로그인 계정 전환으로 다른 계정의 설정을 잘못 바꾸는 것을 방지합니다. 선택값·타입·숫자 범위를 서버에서 검증하고 전체 저장 용량은 32KB로 제한합니다. 암호 변경·이름 변경과 함께 요청한 설정이 잘못되면 요청 전체가 반영되지 않습니다.

팀 감사로그

/app/workspace-audit는 현재 워크스페이스 소유자와 관리자용 화면입니다. 서비스 전체 관리자의 감사 화면과 구분됩니다.

  • 현재 접근 가능한 문서·첨부·데이터베이스·공간·템플릿·캔버스 및 팀 설정·키·저장소 관리 동작을 표시합니다.
  • 서비스 관리자라도 다른 사람의 개인 문서 제목이나 기록을 우회해서 볼 수 없습니다. 현재 공유 권한이 없어지면 과거 기록도 목록에서 제외합니다.
  • 본문, 이전·이후 원문, 검색어, IP, 토큰, 비밀 설정은 노출하지 않습니다. 작성자 이름·동작·현재 자료명·시각과 제한된 버전·상태·개수·활성 여부만 제공합니다.
  • 원본이 물리적으로 삭제되어 현재 접근 권한을 확인할 수 없거나, 이 화면이 지원하지 않는 리소스 유형의 기록은 표시하지 않습니다. 전체 감사 기록을 대체하는 보존·감사 증빙 도구는 아닙니다.
  • 최근 1~365일, 동작별 필터, 100개 단위 이전 기록 탐색을 지원합니다. 필터와 페이지 커서는 URL에 유지됩니다.
GET /api/v1/workspaces/{id}/audit?days=30&action=DOCUMENT_UPDATE&cursor=...

별도 저장 테이블 없이 기존 감사 로그를 현재 권한으로 안전하게 조회합니다. 감사 로그와 사용자 설정·문서 이력은 기존 논리 백업·복원에 포함됩니다.
