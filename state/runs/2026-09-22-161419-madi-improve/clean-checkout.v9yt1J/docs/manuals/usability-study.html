madi 사용성 관찰 프로토콜

현재 증거의 한계

실제 신규·기존 사용자를 모집한 관찰은 아직 실시하지 않았습니다. 과제 완료율·완료시간 개선·도움 감소·공유 오해 감소에 관한 사람 측정 결과는 없습니다. PostgreSQL·Playwright의 통과와 실행 시간은 제품의 자동 회귀 증거이며 사람의 사용성을 대신하지 않습니다. 아래 도구는 관찰을 수행하고 결과를 구분하여 기록하기 위한 준비물입니다.

동일 과제와 조건

프로토콜 버전은 madi-usability-1입니다. 신규 사용자는 이전 madi 사용 경험이 없는 사람, 기존 사용자는 서로 다른 날 3회 이상 사용한 사람으로 정의합니다. 두 집단에 동일한 6개 과제와 동등한 샘플 문서·동료 계정·권한·AI 설정·DB를 제공합니다. 실제 기밀 자료 대신 관찰 전용 워크스페이스를 사용하세요.

과제 수행 완료 기준
개인 메모 홈에서 개인 메모 작성·저장 확인 나만 보기, 두 문장의 서버 저장 확인
찾기 지정 문서 검색·미리보기·돌아오기 올바른 자료, 검색 조건·선택 유지
공유 지정 동료에게만 읽기 공유 실제 동료 열람, 외부 링크 없음, 저장·내부 공유·게시·외부 링크 구분
선택 AI 한 문단 다듬기·비교·취소·다시 적용 전송 범위 이해, 취소 시 불변, 선택 범위만 적용
데이터베이스 세 셀·잘못된 옵션 수정·개인 보기 저장 타입 정확, 팀 보기 불변, 새로고침 유지
업무 복원 문서 위치·DB 필터를 작업 묶음으로 보관·다시 열기 현재 권한 아래 문서 위치와 DB 구성 복원

과제별 설명과 완료 기준은 tests/usability/model.mjs의 동일 목록을 기록기가 표시합니다. 테스트 순서는 고정하거나 사전에 균형 배정하고, 비교 중 설명·도움 기준을 바꾸지 않습니다. 동일인 전후 비교는 학습 효과가 있으므로 별도 표시하며 무작위 배정 없이 개선의 인과관계를 주장하지 않습니다. 빌드 ID·집단·화면·과제별 표본 수를 함께 보고하고 소수 표본을 전체 사용자로 일반화하지 않습니다.

동의와 기록 방법

참여자에게 목적, 중단 권리, 익명 기록 항목, 조직의 파일 보관·삭제 담당을 설명하고 동의를 받습니다. 동의 없이는 시작할 수 없습니다. 실명·메일·문서 ID·원문·키 입력·화면 녹화는 이 도구가 수집하지 않습니다. 참가자 번호 P001처럼 이름과 무관한 식별자를 사용하고 대응표가 필요하면 기록과 별도로 통제합니다.

저장소 루트에서 다음 명령을 실행하면 127.0.0.1의 임의 포트에 로컬 관찰 기록기를 엽니다. 표시된 주소를 제품과 별도 창에서 여세요. 외부 인터페이스에 바인딩하지 않고 4개 정적 파일만 읽습니다.

node tests/usability/serve.mjs

관찰자는 설명을 마친 뒤 과제 시작, 끝나거나 중단되면 과제 시간 종료를 누릅니다. 도움·되돌림을 관찰할 때 각각 기록하고 결과·공유 오해 여부를 선택합니다. 실제 사람의 수행을 관찰했다는 확인 후 기록을 추가합니다. 완료 기준에 못 미치면 부분 완료 또는 중단이며 완료로 보정하지 않습니다. 기록기는 제품을 자동 조작하거나 사람의 성공 여부를 추론하지 않습니다.

측정 시간은 설명을 제외하고 도움·오류·되돌림을 포함한 과제 전체의 단조시계 경과 시간입니다. 중간에 브라우저나 기기를 정지시키지 마세요. 진행 중 실수로 종료했으면 해당 시도를 부분/중단으로 보존하고 새 시도 번호로 다시 측정합니다. 도움은 관찰자가 구체적 경로·행동을 알려준 한 번의 개입, 되돌림은 잘못된 변경·공유·탐색을 인지하고 복구한 한 번의 시도로 정의합니다. 단순 취소가 과제 자체라면 되돌림으로 세지 않습니다.

공유 오해는 참가자가 설명한 범위와 실제 권한·상태가 다른 경우입니다. 직접 확인하지 못했다면 평가하지 않음이며 오해 없음으로 취급하지 않습니다. 최종 평가는 제품 서버에 저장된 상태와 동료 계정에서의 실제 열람으로 확인합니다.

집계와 공개

기록은 창 메모리에만 있으며 익명 관찰 JSON 내려받기를 명시적으로 눌러 파일을 만듭니다. 네트워크 전송·localStorage·sessionStorage는 사용하지 않습니다. 새로고침·닫기 전 내려받고 조직의 통제된 경로에 보관하세요. 현재 기록 지우기는 창 메모리만 지우고 내려받은 파일은 삭제하지 않습니다. 파일의 외부 게시나 서비스 반입은 자동 수행하지 않습니다.

node tests/usability/summarize.mjs /승인된/관찰/기록.json
node tests/usability/model.test.mjs
node tests/usability/recorder.test.mjs

집계는 표준 출력으로만 나옵니다. human_observation과 automated_probe, 빌드·집단·화면·과제를 절대 합치지 않습니다. 사람 기록은 동의·관찰자 확인이 모두 필요하고 자동시험은 둘 다 false여야 합니다. 자유 메모·허용하지 않은 필드·식별자 형식·중복 시도·음수/무한 시간·10MiB/10,000건 초과를 거절합니다.

완료율의 분모는 중단·부분 완료를 포함한 모든 시도입니다. 전체 시도 시간 중앙값과 완료 시도만의 중앙값을 구분하고, 도움·되돌림 합계와 참가자 수·시도 수를 함께 표시합니다. 공유 오해율의 분모는 직접 평가한 시도뿐입니다. 미실시 집단은 0% 성공이 아니라 관찰 미실시, 평가가 없으면 null입니다. 집계 도구는 통계적 유의성·인과관계·효과 크기를 자동 주장하지 않습니다.

도구의 자동 테스트에는 가상 입력을 사용합니다. 실제 사람으로 표시되는 경로의 유효성도 가상 입력으로 검사하지만, 그 파일은 임시 브라우저 컨텍스트에서 폐기하고 관찰 증거로 게시하지 않습니다. 실제 관찰 전에는 자동 테스트 결과를 이 문서의 사람 측정 표로 옮기지 마세요.
