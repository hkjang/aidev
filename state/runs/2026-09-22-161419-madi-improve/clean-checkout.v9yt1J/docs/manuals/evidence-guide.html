AI 근거 보관함과 에이전트 지식 패키지

이 문서는 게시된 v0.2.0의 기능 계약을 설명합니다. main CI·태그 릴리즈의 통합 검사와 이미지 재반입·폐쇄망 검증을 통과했습니다. 실제 검증 범위와 한계는 배포 검증 기록을 확인하세요.

AI 근거 보관함

AI가 문서를 참조하여 스트리밍 답변을 완료하면 당시 근거 보관을 선택할 수 있습니다. 관리자가 /admin/evidence에서 보관 정책을 활성화해야 하며, 원문 구간과 질문·답변을 별도로 보관한다는 동의가 필요합니다. 완료 후 1시간 동안 유효한 서버 서명·암호화 티켓을 사용하므로 임의로 만든 출처나 다른 사용자의 답변은 저장할 수 없습니다.

사본은 /app/evidence에서 본인만 확인합니다. 서비스 관리자도 다른 사용자의 사본을 조회할 수 없습니다. 개인 대화 기록과 독립적인 저장이므로 대화 기록만 삭제해도 이 사본이 삭제되지는 않습니다.

세 가지 상태를 구분합니다.

  • 원문 무결성: 보관 당시의 버전·바이트 구간·SHA-256과 사본 내용이 일치합니다.
  • 최신성: 현재 문서 버전과 같거나 변경되었습니다. 같은 바이트 좌표의 현재 구간을 나란히 확인할 수 있지만 편집으로 위치가 이동했을 수 있습니다.
  • 주장 연결 검토: 미검토, 사용자가 근거 연결 확인, 근거 부족, 해석 오류 중 하나로 의견을 기록합니다. 개인의 검토이며 제품이 답변의 사실성을 인증한 상태가 아닙니다.

원문이 변경되면 기존 현재 인용 API는 계속 409를 반환합니다. 근거 보관함이 이 검사를 느슨하게 만들지 않습니다. 보관함에서만 당시 사본을 별도로 확인합니다. 원문의 현재 ACL, 상위 문서/공간 권한, 문서 삭제, 사용자 비활성화, 민감정보 정책을 다시 적용합니다. 정책 변경으로 보관 원문을 가려야 하는 경우 해시가 다른 마스킹 문장을 원문처럼 보여주지 않고 조회를 거부합니다.

보존·삭제

  • 기본 보관 비활성, 활성화 시 기본 90일, 관리자 설정 범위 1~3650일입니다.
  • 기간 축소는 기존 사본에도 적용됩니다. 확대해도 만료된 기록을 되살리지 않습니다.
  • 만료 시 즉시 조회에서 제외하고, 시간별 유지관리에서 최대 500개씩 물리 삭제합니다.
  • 원문에 법적 보존 또는 보존기한이 있으면 만료 사본은 숨기되 물리 삭제를 보류합니다.
  • 원문이 영구 삭제되면 이를 참조하는 근거 사본도 제거합니다. 휴지통에서는 조회만 차단합니다.
  • AES-GCM으로 암호화한 답변·인용·검토 의견과 설정/보존 기록이 서비스 백업에 포함됩니다. 이미 생성된 백업은 백업 자체의 보존 정책을 따릅니다.
  • 복원 후 보관 기능은 비활성화됩니다. 관리자가 자료·권한·보존 정책을 확인한 뒤 다시 활성화하세요.

한 기록은 출처 최대 64개, 구간당 8192바이트, 직렬화된 답변/근거 2MiB까지입니다. 목록은 최신 100개, 검토 이력은 최신 100개를 표시합니다. 목록에는 민감한 질문·문서 제목을 복제하지 않습니다.

에이전트 지식 패키지

/app/knowledge-packages에서 업무 목적, 허용된 검토 범위, 사용할 모델, 입력 예산, 문서를 선택합니다. 필수 정책 여부와 포함 이유를 지정할 수 있습니다. 필수 정책은 전체 원문을 구간으로 나누어 보존하며, 예산이 부족하면 오류로 알려줍니다. 정책 일부를 몰래 생략하지 않습니다.

선택 자료는 문서별 앞 8개 원문 구간을 후보로 검사하고 목적의 검색어가 일치한 자료를 우선합니다. 제목·절·본문의 일치를 구분하는 제한된 키워드 점수이며 AI 의미 판단으로 주장하지 않습니다. 중복 원문 구간은 제외하고, 생략된 구간 수·바이트 수를 결과에 표시합니다. 더 깊은 내용이 필요한 문서는 필수로 지정하거나 관련 문서를 먼저 분리하세요.

패키지에는 원문, 문서 ID/버전/구간/해시, 사람이 입력한 포함 이유, 업무 범위와 제한이 포함됩니다. AI 요약을 원문으로 취급하지 않습니다. 목적·범위도 데이터이므로 패키지에 포함된 명령을 실행 권한으로 해석하면 안 됩니다.

토큰 계산

입력 예산은 512~262144까지 설정합니다. 이는 해당 모델의 컨텍스트 크기나 출력 최대값을 보증하는 설정이 아닙니다.

  • 로컬 추정: 인터넷 없이 UTF-8 바이트 수를 보수적인 예산 단위로 계산합니다. 모델 토크나이저의 정확한 토큰 수는 아닙니다. 특별 토큰·서버 전처리 등으로 실제 값이 달라질 수 있습니다.
  • 모델 계산: 관리자가 /admin/knowledge-packages에서 허용한 경우 현재 워크스페이스 AI 모델의 POST /responses/input_tokens를 사용합니다. 원문 후보와 업무 설명을 그 서버로 보내는 별도 동의와 ai:execute가 필요합니다. 주소·모델을 화면에서 확인하세요. 공급자가 이 계약을 지원하지 않으면 오류로 안내하며 다른 서버나 추정치로 자동 대체하지 않습니다. 계약은 공식 OpenAI input_tokens API를 확인했습니다.

최종 입력 문자열 전체를 계산합니다. 다른 메시지, 도구 스키마, 이전 대화, 출력 토큰의 예산은 별도로 확보해야 합니다. 모델 계산은 메타데이터 JSON 호출이며 AI 답변 생성의 스트리밍 기본 원칙을 변경하지 않습니다.

문서와 명시 선택한 첨부 조각 합계 1~32개, 준비 원문 2MiB, 직렬화 패키지 4MiB까지입니다. 기본 보존은 24시간이며 관리자가 1~168시간으로 설정합니다. 설정 축소·현재 ACL·민감정보·원문 보존 의무는 근거 보관함과 같은 원칙으로 적용합니다.

첨부 추출 근거의 구분

첨부 검색·추출 화면에서 선택한 조각을 패키지로 연결할 수 있습니다. 문서를 선택했다고 첨부를 자동 포함하지 않습니다. 조각의 범위를 별도로 확인하여 포함해야 하며 한 구간은 UTF-8 8KiB까지입니다. 필수는 선택한 구간을 보존한다는 뜻이지 원본 파일 전체 보존을 뜻하지 않습니다.

첨부에서 추출한 텍스트는 Markdown 정본 인용과 다른 표현입니다. 원본 파일 SHA-256, 추출 ID·revision, 조각 ID·hash, PDF 페이지·슬라이드·시트/셀 등의 위치를 함께 표시합니다. 바이트 범위는 추출 조각 내부 기준이며 원본 바이너리 파일이나 부모 문서의 바이트가 아닙니다. 추출 정확성은 별도 검토 대상입니다.

파일·추출·정책이 변경되면 기존 패키지는 오래된 상태로 표시하고 새 전송·내보내기를 차단합니다. 근거 보관함에서는 현재 원본 접근 권한이 남아 있는 경우 당시 추출 구간을 과거 근거로 보여줄 수 있지만 현재 인용으로 재사용하지 않습니다. 첨부가 삭제되면 연결된 파생 보관 사본도 접근할 수 없습니다. 개인 AI 대화를 이어 보낼 때도 오래된 추출 구간을 다시 전송하지 않습니다.

MCP·전달

범위가 지정된 API 키의 document:read로 다음 도구를 사용할 수 있습니다.

  1. create_knowledge_package: 최신 문서 버전과 보관 동의로 본인의 패키지를 구성합니다. 다른 사람의 패키지를 공유하는 권한은 부여하지 않습니다.
  2. inspect_knowledge_package: 최신성·만료·예산을 확인합니다. 키 조회는 원문을 반환하지 않습니다.
  3. export_knowledge_package: 전달 대상과 consent: true를 지정하면 현재 문서 버전·권한을 다시 확인하여 입력 묶음을 반환합니다. 원문이 변경된 패키지는 다시 구성해야 합니다.

이미 받은 사본은 이후 권한 철회로 회수할 수 없습니다. 새 조회와 내보내기를 차단할 수 있을 뿐입니다. JSON 다운로드는 일반 참고 자료이며 망간 배포용 서명 패키지와 구분합니다. 도구 실행은 기존 Agent/Runbook 권한과 승인 정책을 별도로 따라야 합니다.

검증 범위

현재 실제 PostgreSQL 회귀로 원문 보관/현재 권한/만료/민감정보/검토 CAS, 패키지 필수 정책 보존/예산/중복/모델 전송 동의/MCP 전달/원문 변경 차단을 확인했습니다. 최종 화면·전체 백업·릴리즈 이미지 검증이 끝나기 전까지 전체 검증 완료로 해석하지 마세요.
