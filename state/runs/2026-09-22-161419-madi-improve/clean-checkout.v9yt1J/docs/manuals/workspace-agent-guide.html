워크스페이스 Agent 가이드

madi Agent는 관리자가 선택한 지식과 도구 안에서 실제 사용자의 현재 권한으로 작업합니다. 서비스 프로세스에서 셸을 실행하거나 모델이 만든 임의 URL을 호출하지 않습니다.

관리자 설정

  1. 서비스 또는 워크스페이스 AI 설정에서 OpenAI 호환 API 주소·모델을 연결합니다.
  2. 워크스페이스의 Agent → Agent 만들기에서 이름·역할·허용 도구를 지정합니다.
  3. 지식 공간(하위 공간 포함), 개별 문서, 데이터베이스를 명시적으로 선택합니다. 공간을 지정해도 개인 문서 접근 권한이 추가되지 않습니다.
  4. 실행 단계(124), 단계별 출력 토큰(1262144)을 정하고 활성화합니다. 실제 토큰 요청은 서비스/워크스페이스 AI 한도와 교집합입니다.

vLLM은 모델에 적합한 tool-call parser와 자동 도구 선택 설정이 필요합니다. 서버는 완성된 도구 호출 JSON을 별도로 검증하며 모델 출력만으로 권한을 부여하지 않습니다. vLLM 공식 도구 호출 설정

사용과 변경 확인

  • 질문하면 모델이 검색·문서 읽기·DB 조회·그래프 도구를 선택하고 결과를 바탕으로 계속 답변합니다. 공급자 요청과 사용자 출력은 스트리밍입니다.
  • create_document와 update_document는 불변 변경 계획만 만듭니다. 실제 로그인 사용자가 대상 버전과 Markdown 본문을 읽고 확인란을 선택해야 저장됩니다.
  • 수정 전 문서를 읽어야 하며 그 버전이 바뀌면 기존 계획은 사용할 수 없습니다. 새 문서 작성은 관리자가 명시적으로 선택한 공간만 허용합니다.
  • 저장은 일반 REST 문서 저장 경로를 사용합니다. 정보보호·마스킹·버전 이력·선택적 승인 정책이 그대로 적용됩니다. Agent 확인은 문서 게시 승인을 대신하지 않습니다.
  • 거절하면 해당 계획은 저장하지 않고 거절 결과를 모델에 전달합니다. 취소하면 이후 도구 호출·출력을 중단합니다. 이미 전송한 공급자 요청이나 이미 커밋된 저장을 되돌리지는 않습니다.
  • API 키·서비스 계정·플러그인은 ai:execute와 각 도구 scope의 교집합으로 실행할 수 있습니다. 키/플러그인 자체는 사람 확인을 수행할 수 없습니다. 원래 실행 키가 폐기되면 소유자 세션에서도 그 계획을 확인할 수 없습니다.

보안과 운영 한도

현재 사용자·세션·키·플러그인, Agent 설정 버전, AI 공급자/모델, 참조 문서 버전, DB의 실제 사용 행·속성·수식 의존성을 재검증합니다. 변경 중단 검사는 공급자 요청 중 최대 1초 간격이고 각 출력 저장/도구 단계에도 수행합니다. 로그아웃 이후 세션 실행은 더 이상 결과를 사용하지 않습니다. 이미 공급자에 전달된 바이트는 회수할 수 없습니다.

문서·DB 읽기 도구는 Agent 지식 범위 밖 내용을 공급자에 보내지 않습니다. DB 관계/롤업도 대상 DB가 명시적 허용 목록에 있어야 합니다. 이력은 본인만 조회하며 현재 사용 원본에 접근할 수 없으면 표시하지 않습니다.

항목 한도
동시 유지 실행 사용자당 6개
지식 범위 종류별 100개
실행에서 참조하는 실제 원본 최대 256개
단계 실행당 최대 24
도구 호출 응답당 최대 8개, 변경 계획은 1개씩
문서 읽기 요청당 최대 16KB, 바이트 위치로 이어 읽기
문서 변경 제안 본문 60KB 이하
그래프 도구 최대 100문서·500연결, 문서당 앞 32,000자 및 제한된 alias 32개
DB 조회 500행 한정 스캔, 반환 100행/20속성 이하
도구 결과 64KB 이하
실행 출력/대화 컨텍스트 각각 최대 4MB
개별 작업 시간 30분

DB 스캔은 전체 데이터에 대한 무제한 분석이 아니며 결과에 scan_limit과 truncated가 표시됩니다. 출력 토큰은 공급자에 지정한 단계별 한도이며 모델별 정확한 입력 토큰 계산기나 무한 컨텍스트를 제공하지 않습니다. 검색은 권한 범위 내 PostgreSQL 키워드 검색이며 자동으로 외부 벡터 색인 동의를 대신하지 않습니다.

실행/이벤트/원본/계획은 PostgreSQL에 저장합니다. 문서 변경과 효과 영수증은 같은 트랜잭션에 기록하여 완료된 저장이 재실행되지 않도록 합니다. 백업 복원 시 Agent 설정과 진행 실행을 비활성/취소하며 자동으로 외부 모델 호출이나 문서 변경을 재개하지 않습니다.

REST 계약

경로 용도
GET/POST /api/v1/workspaces/{id}/agents 목록 / 관리자 생성
PUT /api/v1/agents/{id} revision 비교 설정 변경
GET/POST /api/v1/agents/{id}/runs 내 이력 / {prompt,expected_agent_version} 실행
GET /api/v1/agent-runs/{id} 상태·작업별 계획
GET /api/v1/agent-runs/{id}/events?after=123 영속 SSE, Last-Event-ID 지원
POST /api/v1/agent-runs/{id}/cancel 현재 실행 취소
POST /api/v1/agent-runs/{id}/actions/{action}/confirm {action_hash,confirm:true} 또는 {action_hash,reject:true}

쓰기 요청은 브라우저 세션에서 X-Madi-Request: 1이 필요합니다. bearer 키는 scope 및 현재 리소스 ACL을 별도로 적용합니다. 이 API는 임의 SQL·외부 URL·Runbook·셸 실행을 위한 우회 수단을 제공하지 않습니다.
