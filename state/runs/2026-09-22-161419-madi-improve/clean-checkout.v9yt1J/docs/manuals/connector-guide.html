외부 문서 커넥터 가이드

외부 커넥터는 관리자가 허용한 원격 시스템을 읽어 madi 문서로 가져옵니다. 원격 시스템을 수정하거나 실행 코드를 보내지 않습니다. 인터넷이 없는 환경에서는 해당 커넥터를 끈 상태로 로컬 기능을 사용하고, 사내망 서비스만 허용할 수 있습니다. 추가 서비스 환경변수는 필요하지 않습니다.

권한과 연결

서비스 관리자가 /admin/connectors에서 외부 연결을 켜고 접속할 정확한 호스트를 허용합니다. 워크스페이스 소유자·관리자는 /app/connectors에서 대상 공간, 전용 서비스 계정, 원격 주소와 최소 읽기 권한 비밀을 입력합니다. 전용 서비스 계정은 해당 공간의 문서 쓰기 권한이 필요하고 사람의 비밀번호 로그인은 불가능합니다.

원격 프로젝트의 개별 공개 범위가 madi에 자동 복제되지는 않습니다. 가져온 자료는 관리자가 지정한 대상 공간의 접근 권한을 따릅니다. 원격 비공개 자료를 일반 공간에 가져오지 않도록 공간 경계와 원격 계정의 읽기 범위를 먼저 검토하세요. 가져온 문서는 초안으로 생성합니다.

원격 토큰과 비밀번호는 암호화 저장하고 다시 표시하지 않습니다. 수정 시 빈 비밀은 유지하며 새 값을 입력하면 교체합니다. 한 연결의 대상 워크스페이스·공간·유형·서비스 계정은 임의로 옮기지 않습니다. 위치를 바꾸려면 새 연결을 만드세요.

TLS는 기본 검증하며 사내 CA를 별도로 입력할 수 있습니다. HTTP 및 인증서 검증 생략은 명시적 옵션입니다. 호스트 허용 목록, 실제 연결 시점 DNS/IP 검사, 외부 리디렉션 차단을 적용합니다. 원격 API가 돌려준 다음 페이지도 같은 출처 범위만 허용하여 비밀이 다른 호스트로 전달되는 것을 막습니다.

미리보기와 가져오기

먼저 미리보기를 실행해 수량·제목·변환 경고를 확인합니다. 미리보기는 문서를 생성하지 않습니다. 이후 가져오기를 실행하거나 예약 간격을 설정합니다. 작업 상태와 생성·갱신·건너뜀·충돌 수량을 상세 이력에서 확인합니다.

실행은 PostgreSQL 영속 작업 큐를 사용하며 현재 연결 관리자와 서비스 계정의 권한을 다시 검사합니다. 각 원격 페이지의 문서 변경, 버전, 이벤트, 중복 매핑과 다음 페이지 체크포인트를 하나의 트랜잭션으로 저장합니다. 실패 후 재시도는 같은 페이지를 다시 읽을 수 있으나 같은 원격 고유 ID와 체크섬으로 중복 문서 생성을 피합니다. 같은 연결의 동시 작업은 직렬화합니다.

기본 충돌 정책은 로컬 수정 보존입니다. 가져온 뒤 사람이 수정한 문서는 원격 내용으로 덮지 않고 충돌로 보고합니다. 원격 우선 교체는 명시적으로 선택한 경우에만 적용합니다. 원격 목록에서 사라진 문서를 자동 삭제하거나, madi 휴지통의 문서를 자동 복구하지 않습니다. 재시작·전체 다시 읽기로도 이 경계는 유지합니다.

원격 HTTP 429와 재시도 대기 정보를 반영하고, 일시 오류는 작업 큐의 제한된 재시도를 사용합니다. 다음 페이지가 반복되거나 대형 트리 결과가 잘렸다면 부분 성공처럼 처리하지 않고 오류로 보고합니다. 원격 응답은 요청당 8MB, 문서당 4MB, 작업당 페이지는 100개로 제한합니다. 항목 제한은 페이지 단위로 적용되므로 마지막 페이지의 항목 수만큼 초과할 수 있습니다. 모든 공급자의 전체 파일·이미지·권한 동기화를 제공하는 도구는 아닙니다.

운영과 검증 범위

실제 로컬 HTTP 서버와 PostgreSQL을 사용해 공급자별 페이지 처리, 429 재시도, 미리보기 무변경, 체크포인트와 중복 방지, 로컬 변경 보존, 권한 회수 및 URL 경계를 시험했습니다. 공급자 제품의 실제 운영 인스턴스·테넌트별로 토큰 범위, API 버전, 페이지 수, 변환 품질을 별도 수용 시험해야 합니다.

복원 뒤에는 원격 연결과 예약 작업이 중지됩니다. 대상 호스트·공간·서비스 계정·토큰과 체크포인트를 확인하고 다시 켜세요. 기존 외부 효과를 반복하지 않도록 실패 작업 재실행 전에 상세 이력을 검토합니다.

외부 SQL 데이터 소스, 관리자 가이드, 오프라인 백업·복원도 함께 확인하세요.
