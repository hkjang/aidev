# 개인 검색 기록과 지식 보완 제안

검색어는 사적인 업무 사실을 포함할 수 있으므로 madi는 기본적으로 원문 검색어를 저장하지 않습니다. 공용 감사로그에는 검색 결과 수와 성공 여부 등 제한된 메타데이터만 남깁니다.

## 저장 동의와 보존

`내 검색 기록 → 기록 설정`에서 저장에 동의하면 이후 개인 브라우저 검색부터 검색어·필터·횟수·결과 수를 기록합니다. 빈 검색어와 두 번째 이후 결과 페이지는 기록하지 않으며 API 키·플러그인의 검색도 기록하지 않습니다. 같은 UTC 날짜의 동일 검색어·필터는 하나로 묶어 검색 및 실패 횟수를 합산합니다. 결과 수는 전체 일치 건수가 아니라 첫 페이지에 표시된 개수입니다.

보존 기간은 7~365일, 기본 30일이며 사용자 전체 최대 2,000건입니다. 기간을 줄이면 기존 기록의 기한도 단축하고, 기간을 늘려도 기존 기한을 자동 연장하지 않습니다. 만료 기록은 즉시 조회에서 제외되고 유지관리에서 제거합니다. 저장을 끄면 이후 기록만 멈추므로 즉시 지우려면 워크스페이스별 삭제를 사용하세요. 백업 복원 후에는 저장 동의가 꺼집니다.

기록은 본인의 일반 사용자 세션과 현재 워크스페이스 접근 권한으로만 조회할 수 있습니다. 다른 사용자와 서비스 관리자에게 타인의 기록을 조회하는 API를 제공하지 않습니다. DB와 백업에는 일반 문서처럼 보관하므로 DB·서버·백업 운영자에 대한 종단간 암호화는 아닙니다. 이미 남은 백업 사본의 보존은 운영 정책에 따릅니다. 서비스 민감정보 정책의 차단·마스킹은 기록 저장에도 적용하고, 기록 저장 실패가 검색 결과 자체를 실패로 바꾸지는 않습니다.

## 실패 검색에서 지식 보완하기

결과가 없었던 검색을 최대 30건 선택하고 `지식 보완 제안`을 엽니다. 저장 동의와 별개로 선택한 검색어·필터·횟수를 현재 AI 공급자에 전송한다는 동의를 다시 받아야 합니다. 다른 사용자의 이력이나 문서 본문은 전송하지 않습니다.

AI는 보완하면 유용할 문서의 제목·이유·Markdown 개요·근거 검색 번호를 스트리밍으로 제안합니다. 검색 실패는 필터·권한·용어의 문제일 수 있으므로 실제 문서 부재나 조직 전체의 지식 부족을 확정하는 분석이 아닙니다. 서버는 닫힌 JSON과 정확한 기록 번호만 허용하며 최대 12개 제안을 검증합니다. 선택한 기록이 갱신·삭제·만료되거나 저장 동의·세션·워크스페이스 권한·AI 설정이 바뀌면 진행 중 분석을 중단합니다.

제안을 문서로 남기려면 `새 개인 문서로 저장`에서 내용을 검토하세요. 기존 문서를 덮거나 공개·게시하지 않고 비공개 초안을 생성하며 일반 문서의 민감정보·공유·선택적 승인 정책을 적용합니다. AI 생성만으로 문서가 자동 저장되지는 않습니다.

API는 `/profile/search-history/settings`, `/search/history`, `/search/history/gaps`입니다. 개인 쿠키 전용이며 변경 요청에는 동일 Origin과 `X-Madi-Request: 1`을 요구합니다. 설정은 revision 충돌을 거부하고, 전체 삭제는 `confirmation: "DELETE_ALL"`을 요구합니다.
