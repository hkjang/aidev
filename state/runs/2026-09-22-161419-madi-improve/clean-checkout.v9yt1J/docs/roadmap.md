# madi 기능 범위와 운영 한계

첫 릴리즈는 사용자가 확정한 **P0~P3 전체 범위**를 대상으로 제공했습니다. 최초 검증은 [전체 범위 검증 기록](../FULL_SCOPE.md)에 보존하며, 후속 운영 고도화는 [추가 검증 장부](../OPERATIONS_UPGRADE.md)에서 추적합니다. 실제 게시 여부와 버전은 GitHub Releases에서 확인합니다.

## v0.2.0 · 기능 연결과 운영 고도화

- 증분 협업 기록·편집 세대·안전한 구세대 복구·저장 상태·변경 알림·진단
- 한국어 용어 사전·검색 평가·해석·그룹/커서·실행 진단·벡터 색인 세대와 HNSW 검증 전환
- 격리된 PDF/Office 추출·선택 영어/한국어 OCR·위치 기반 첨부 인용, 재개 가능한 분할 이관·품질/타입 검토·중복 방지
- 과거 AI 근거 보관·에이전트 지식 패키지·문서 변경 영향·변경 제안·시점 검색·서명된 망간 배포
- 운영 카드·제한된 문서 조회·공식 답변·모순 후보 검토·문서→DB 초안·역할별 지식 경로
- 일상 메뉴·즉시 메모·문맥 패널·미리보기·선택 AI 비교·공유 영향·DB 인라인·모바일 행동·작업 묶음

각 기능은 아래 기반과 동일한 현재 ACL·정보보호·관리자 승인 경계를 사용합니다. AI나 규칙이 낸 후보와 사람의 판단, 해시 무결성과 내용의 사실성, 로컬 보관과 서버 저장, 이미 내보낸 사본과 현재 접근 제어를 구분합니다. 실제 사람 사용성 관찰은 자동 회귀와 별도로 진행해야 합니다.

## P0 · 문서와 자체 호스팅 기반

- Go 서버가 React 화면·로컬 폰트·로고·파비콘을 함께 제공하고 PostgreSQL에 문서·계정·설정을 저장합니다.
- Markdown 원문, YAML front matter, GFM, 위키 링크·별칭·백링크, 블록 ID·중첩·다중 선택·Drag & Drop을 지원합니다.
- 문서 트리·즐겨찾기·최근·개인/공유·휴지통·명령 팔레트·단축키와 화면 URL 상태를 제공합니다.
- 전역·지역 그래프, 깊이 1~5, 태그·공간·사용자 필터와 관계 유형을 탐색합니다.
- 로컬 계정·Keycloak OIDC, 역할·공간·문서 권한, REST·OpenAPI·HTTP MCP, 개인별 키 발급·권한 변경·회전을 제공합니다.
- 문서 변경 이력·diff·동시 버전 복원, 폴더·Obsidian/Notion/HTML/CSV/JSON 가져오기와 비동기 내보내기를 제공합니다.
- 관리자·개인화 분리, 한국어 기본·읽기 편한 글자·새로고침 복원·버전 표시를 적용합니다.

## P1 · 협업과 지식 운영

- 실제 Yjs 동시 편집·커서·presence·재접속과 현재 문서 권한 검사를 제공합니다.
- 동기화·임베드 블록, 다단 레이아웃·고급 표·각주·KaTeX·Mermaid를 제공합니다.
- 데이터베이스는 표·보드·목록·달력·갤러리·타임라인, 관계·안전 수식·롤업·AI 속성을 지원합니다.
- 문서 할 일·담당자·기한·칸반·달력, 토론·스레드·멘션·알림, 회의·의사결정·Runbook 템플릿을 연결합니다.
- 소유자·검토주기·보존·생명주기·지식 건강·품질·활동 지표를 관리합니다.
- 권한 기반 통합 검색·인기도, 하이브리드 RAG·재정렬·정확한 원문 인용, 자연어 검색과 선택 문서 요약을 제공합니다.
- 개인 AI 대화·개인 검색 기록은 별도 동의로 보관하며 검색 실패 기반 문서 제안을 제공합니다.
- PostgreSQL 작업 큐·outbox·Webhook·자동화, SMTP/협업 채널 알림과 수집, Local/S3/MinIO 저장소·예약 백업을 지원합니다.

## P2 · 기업 확장과 안전한 연결

- 조직·멀티워크스페이스·공간을 분리하고 AI·저장소·템플릿·감사·키·브랜딩을 범위별 관리합니다.
- 빠른 수집함·메일/Webhook 입력·Web Clipper, Canvas·Drawing, 격리된 Plugin SDK를 제공합니다.
- AI 엔터티·주제·관계·중복·지식 보완 추천은 현재 원문을 근거로 만들고 사용자가 개별 확인한 뒤 반영합니다.
- 관리자가 설정한 경우에만 1/N단계·부서·병렬 승인과 반려·재요청을 사용합니다.
- Jira·GitLab·Confluence·Google Drive·SharePoint·GitHub·REST 커넥터와 PostgreSQL·Oracle·MySQL·MariaDB·MSSQL 외부 데이터 메타데이터를 연결합니다.
- 민감정보 탐지·경고/차단/마스킹/감사, 문서 등급·워터마크·법적 보존·보안 공개링크를 제공합니다.
- SAML·TLS LDAP·SCIM·그룹 매핑과 관리자·대상 사용자의 현재 권한 교집합에 한정된 읽기 전용 지원 진단을 제공합니다.
- Tauri 데스크톱·PWA·개인 암호화 오프라인 보관함·Web Clipper, Git 미리보기·동의·충돌 감지 동기화를 제공합니다.
- 기능 플래그·설정 버전/복원·운영 오류/건강·실제 OpenTelemetry OTLP를 설정합니다.

## P3 · 지식에서 통제된 실행으로

- 실행형 Runbook은 고정 실행기·허용 명령·매개변수·격리·현재 권한·확인을 적용합니다. 무제한 서버 셸을 제공하지 않습니다.
- Workspace Agent는 허용 지식·도구·공급자 범위와 사용자의 현재 권한을 상속합니다. 쓰기는 사용자 확인과 단일 효과 영수증으로 통제합니다.
- 기업 데이터 지식 화면은 외부 데이터 소스·Entity·문서·SQL을 연결합니다. Text2SQL은 미리보기·승인·읽기전용 조회로 제한합니다.

## 정확한 운영 경계

- 실행 환경변수는 `POSTGRES_DSN`, `BOOTSTRAP_ADMIN`, `BOOTSTRAP_ADMIN_PASSWORD`, `ENCRYPTION_KEY` 네 개입니다. PostgreSQL·Docker 및 선택 IdP/AI/외부 실행기는 별도 인프라입니다.
- 서비스 이미지 하나를 `madi:v버전`으로 만들고 `madi-v버전.tar.gz`로 배포합니다. 데스크톱·클리퍼 소스와 빌드 안내는 저장소에 제공하며 첫 릴리즈에 별도 실행 파일을 첨부하지 않습니다.
- AI 설정의 출력 상한은 262,144 토큰입니다. 실제 컨텍스트·출력·임베딩 규격은 공급자 모델 한도를 따릅니다. AI 공급자에 이미 전달한 내용이나 다운로드한 사본은 회수할 수 없습니다.
- pgvector는 선택 확장입니다. 확장이 없는 PostgreSQL에서도 로컬 검색과 제한된 배열 기반 벡터 비교를 사용할 수 있습니다. 대규모 검색 운영은 측정 후 용량을 계획해야 합니다.
- 외부 연동은 실제 프로토콜 계약과 진단을 검증합니다. 특정 조직의 IdP·DB·클라우드·AWX 연결을 운영 자격증명 없이 검증했다고 주장하지 않습니다.
- 브라우저/PWA와 Linux Tauri 실행 검증을 Windows·macOS 네이티브 실행 검증으로 확대 해석하지 않습니다. 플랫폼별 패키징·배포 신뢰는 운영자가 확인해야 합니다.
- Notion·Obsidian의 모든 플러그인·독자적 블록·데이터 관계를 무손실 변환한다고 보장하지 않습니다. 가져오기 미리보기와 형식별 보고서를 확인하세요.
- 개인 문서와 AI/RAG/MCP는 동일한 현재 ACL을 적용합니다. 서비스 관리자라는 이유만으로 다른 사람의 개인 문서에 접근하지 않습니다. DB·백업 운영자에 대한 종단간 암호화와는 다른 보안 경계입니다.
- 천만 문서·동시 2,000명·P95 목표는 실측 없이 달성 수치로 표기하지 않습니다. 첨부 크기·작업·그래프·AI 등 개별 한도는 각 가이드에 명시합니다.
- 백업 복원 뒤 세션과 과거 외부 작업은 재개하지 않습니다. 같은 시점의 DB·첨부·암호화 키·배포 설정과 이미지를 함께 보관하고 격리된 환경에서 복원을 시험하세요.
