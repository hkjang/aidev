# hunter 프로필 (2026-09-25)
- 목적: 사내 폐쇄망의 서비스·발견 건·진단·개선·재검증을 연결하는 단일 이미지 보안 검증 플랫폼.
- 스택: VERSION **1.14.0**, Go(go.mod 1.26.5, net/http 표준 라이브러리), PostgreSQL, React·TypeScript·Mantine·Vite, Node 26 요구, PentAGI 로컬 `replace`.
- 구조:
  - `cmd/hunter`: 서버·워커 진입점. 8080 포트, 공개 환경변수 4개(`POSTGRES_DSN`, `BOOTSTRAP_ADMIN`, `BOOTSTRAP_ADMIN_PASSWORD`, `ENCRYPTION_KEY`)만 사용.
  - `internal/app`: API·권한·설정·도메인·진단·알림·에이전트(파일 100개 이상). `openapi.json`이 API 계약.
  - `internal/app/domain.go`: 일반 자료 저장·조회, 보고서 CSV/JSON, `csvSafe`.
  - `internal/app/tracking.go` / `tracking_violations.go`: 방문 추적 설정. `trackingOrigin`은 **순수 함수**(DB 불필요) — 원점 정규화의 서버 기준.
  - `internal/app/handoff.go`: 일회용 보고서 표. `handoffClaimsPerUser = 20`(32행) 상한 있음.
  - `internal/app/core_test.go`: 실제 `App.Routes`와 PostgreSQL 격리 스키마를 쓰는 `testApp`/`request` 헬퍼.
  - `internal/pentagicore`: 코어 어댑터. `third_party/pentagi` 원본 312파일은 바이트 보존.
  - `web/src`: 한국어 React 화면·공통 목록. `web/tests`: Node 내장 테스트(18개 파일)로 실제 TS 함수 호출.
  - `internal/webassets/dist`: Go 임베드 프런트 빌드 결과.
  - `docs`: 가이드(`docs/guides/admin-guide.md` 등)·`validation.md`·Pages. `scripts`: 빌드·가이드 생성·릴리즈·라이선스 검증.
  - `.github/workflows`: `ci.yml` 단일 verify 잡, `release.yml` 태그 이미지 릴리즈, `pages.yml` docs 변경 배포.
- 빌드·테스트:
  - 프런트: `npm --prefix web ci` → `npm --prefix web test`(빠름, 기준선 93 통과/0 실패/0 skip) → `npm --prefix web run build` → `mkdir -p internal/webassets/dist && cp -a web/dist/. internal/webassets/dist/`.
  - Go: `go vet ./...`, `go build ./cmd/hunter`. 전체 `go test -race ./...`는 **DB 필요·수백 초~650초**(기본 10분 timeout을 넘겨 `-timeout 45m` 필요했던 기록). **좁은 `-run` 회귀를 우선**할 것.
  - 원본·문서: `node scripts/verify-pentagi.mjs`, `node scripts/check-docs.mjs`, `node scripts/render-guides.mjs`(playwright chromium 필요, `npm --prefix docs ci` 선행).
- 관례: 커밋 메시지는 영어 conventional(`feat:`/`fix:`/`docs:`/`chore:`). 릴리즈 커밋은 `chore: release vX.Y.Z with <한 줄 요약>`. 설정은 DB·관리자 화면(환경변수 추가 금지); 마이그레이션은 Go `init`; UI 문구는 한국어. `VERSION`·web/docs package 버전·가이드 버전을 함께 맞춘다.
- 위험 구역: `auth*.go`·`mcp_oauth.go`(현재 키/역할 권한 교집합), `domain.go`의 권한·부모 범위, `campaigns.go`/`finding_bulk.go`(원자성·전체 롤백), `notifications*`(암호화·불명 재발송 금지), `third_party/pentagi`(312파일 해시 고정), `.github/workflows`·`scripts/release.sh`(릴리즈 반복 파손 이력 있음).
