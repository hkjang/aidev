AppStore v2.11.17

앱 등록·수정 완료 화면의 안내가 실제 저장 상태와 어긋나던 문제를 고친 patch 릴리스입니다.

- 저장 성공 응답의 상태를 완료 화면에 표시합니다. 초안으로 저장된 앱에 즉시 게시나 검토 대기를 예고하던 고정 문구를 없애고, 내 앱에서 상태와 다음 단계를 확인하도록 안내합니다.
- 등록과 수정 모두 실제 저장 결과를 사용하며, 수정 전 조회 상태를 완료 상태로 재사용하지 않습니다. 상태 표시는 기존 공용 라벨을 사용하고, 누락·미지 값도 기존 규칙대로 처리합니다.
- 문서 적용이 끝난 뒤에만 완료 화면을 표시합니다. 저장 또는 문서 적용이 실패하면 성공 화면으로 넘어가지 않습니다. 서버의 승인·보안 심의 정책과 문서 업로드 재시도 구조는 그대로입니다.
- 실제 화면·라우터·API 클라이언트를 사용하는 등록·수정 테스트 15건을 더했습니다(대상 19건, 전체 React 126건). 실제 번들의 desktop·mobile E2E에서도 초안 등록 완료와 내 앱 이동을 확인합니다.
- 버전 표기, 사용자 가이드의 완료 안내와 사용자·관리자 가이드 PDF를 갱신했습니다. 전체 화면 캡처 90개를 재생성했으며 88개는 v2.11.16과 동일합니다.

schema 변경은 없습니다. 기존 설치는 image만 교체하면 됩니다.
