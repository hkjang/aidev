chore(release): AppStore v2.11.17

앱 등록·수정 완료 화면이 실제 저장 응답과 관계없이 즉시 게시나 검토 대기를
예고하던 문제를 고친 patch 릴리스입니다. 저장 응답의 현재 상태를 공용 라벨로
표시하며 내 앱에서 다음 단계를 확인하도록 안내합니다. 문서 적용이 끝나야
완료를 표시하는 순서와 서버의 승인·보안 심의 정책을 유지합니다.

Version

web/package.json·package-lock.json, docker-compose.yml, README, GitHub Pages
문서와 docs/USER_GUIDE.md·docs/ADMIN_GUIDE.md의 버전 표기를 v2.11.17로
올렸습니다. 관리자 가이드의 롤백 예시는 appstore-v2.11.16-stopped를 가리킵니다.
사용자 가이드에는 저장·문서 적용 후 현재 상태를 확인하는 완료 안내를 반영했습니다.

Screenshots and guide PDFs

실제 번들에서 desktop/mobile 캡처 90개를 다시 생성했습니다. 88개는 v2.11.16과
byte 단위로 동일합니다. 기존 캡처는 등록·수정 양식을 열며 완료 화면은 새 E2E가
검증합니다. 관리자 AI 설정 desktop·mobile 캡처 높이는 각각 1905→1810,
8867→9012로 바뀌었으며 두 파일 모두 v2.11.15와 byte 단위로 동일한 기존
캡처 변동입니다. 이번 제품 변경은 관리자 AI route를 지나지 않습니다.
기존 PDF 스크립트를 sh로 실행해 사용자 27쪽·관리자 37쪽 PDF를 재생성하고,
표지 버전, v2.11.17 태그 문서 링크와 file:// 링크 부재를 검증했습니다.
Playwright에는 설치된 브라우저 경로를 명시했습니다.

Migration

서버·schema 변경은 없습니다. 기존 설치는 image만 교체하면 됩니다.
internal/webui/dist는 기존 관례대로 유지하며 Dockerfile이 번들을 새로 빌드합니다.

검증: Go race 전체 패키지(캐시)·vet·gofmt, 새 React 번들을 embed한 Go build,
React 126건, lint(--max-warnings 0)·전체 Prettier·build, 오프라인·환경·문서 검사,
버전 일치와 git diff --check 통과. Playwright --workers=2 --retries=2는 retry 없이
83 passed/1 skipped입니다. Skip 1건은 desktop 프로젝트의 모바일 전용 테스트입니다.
DB DSN 미설정으로 DB 통합 검증은 skip이며 실제 DB·Keycloak·SecCheck는 검증하지
않았습니다. Docker build/load/smoke, SHA-256 및 GitHub Release 게시는 태그
워크플로가 수행합니다. 이 세션에서는 원격 전송을 수행하지 않았습니다.
