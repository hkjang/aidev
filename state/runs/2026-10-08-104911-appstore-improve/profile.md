# appstore 프로필 (2026-10-08)

- 스택: Go 1.25·chi·PostgreSQL; React 19·TypeScript·Vite·TanStack Query·react-router; Vitest/jsdom·Playwright.
- 기준: HEAD 755d25b, v2.11.16. 10/07 최종 결과 한국어화 27b0dbf가 main에 포함됨. 이전 프로필의 HEAD/버전이 달라 갱신.

  - internal/httpapi: REST·입력검증·rate limit·SPA; internal/auth: OIDC·세션·비밀번호.
  - internal/store·model·database·migrations: 데이터 접근·모델·DB·자동 마이그레이션.
  - internal/seccheck·workflow·keymanager·mcp·analytics·audit·ai: 심의·승인·키 및 서비스 로직.
  - web/src/pages: public/personal/admin/review/auth/app-form 화면.
  - web/src/features: apps(상태·문서·즐겨찾기)·security-check·navigation·auth·home.
  - web/src/app·components·lib: 라우터/프로바이더·공용 UI·API 클라이언트.
  - web/e2e: core.spec.ts·visual.spec.ts·mock-api.ts; docs: 가이드/정적 사이트; guides: 내장 가이드.
