# Kkiit 프로필 (2026-10-09)
- 목적: 사람·기업·AI Agent의 전문 서비스를 주문·납품·구매확정·정산으로 연결하는 오프라인 운영 가능 마켓플레이스.
- 기준: pinned main@01e6b8b, v0.4.16. 10/08 문서 개선은 완료 기록(28d274f)이 있으나 현재 체크아웃에는 반영되지 않음. 원격 머지 상태 미확인.
- 스택: Go 1.26, net/http, pgx/v5, PostgreSQL 16+; React 19, TypeScript 5.9, MUI 7, Vite 8; 웹 번들은 Go embed.
- 구조:
  - cmd/kkiit: 프로세스·HTTP 서버·워커 시작과 종료. drain→HTTP Shutdown→dispatcher 대기.
  - internal/httpapi: 도메인 핸들러; router.go가 라우트 정본. integration_test.go와 mail_integration_test.go는 실제 DB 통합 테스트.
  - internal/database/migrations: 번호 SQL, 시작 시 advisory lock 안에서 자동 적용(README 기준).
  - internal/worker: Outbox·알림·웹훅·위험·정산·신뢰 점수 배경 처리(이전 프로필 유지).
  - internal/config·cryptox·password: 환경 설정·비밀 암호화·비밀번호.
  - internal/analytics·mail·netguard: 방문 추적·SMTP·웹훅 주소 정책(이전 프로필 유지).
  - web/src: React UI; pages/AdminPage.tsx에 관리자 기능.
  - internal/ui/dist: 추적하는 embed 번들. 검증 빌드 산출물 커밋 금지.
  - docs: USER_GUIDE/ADMIN_GUIDE(md·pdf), architecture.md, mcp.md, openapi.yaml.

  - README/Config의 “네 개뿐” 문구는 pinned main에 잔존하나 10/08에서 이미 구현한 문서 과제이므로 중복 선택 금지.
  - 가변 운영 정책은 PostgreSQL system_settings JSONB. compose는 .env를 env_file로 받음(이전 프로필 유지).

- 자주 깨지는 곳:
  - computeDiscount 퍼센트 곱셈과 createOrder 옵션 가격 합산 오버플로는 각각 10/05·10/07 수정 완료. 같은 과제 다시 고르지 말 것.
  - createOrder 옵션 루프는 Scan 실패 continue 및 rows.Err 미검사. 실제 HTTP→DB 실패 재현 수단 미확인.
  - validateTalent의 기본 DeliveryDays는 양수만 검사, 옵션 AdditionalDays는 0~365. 기본 기간 상한의 실제 피해는 미확인.
  - DB 오류/404 혼합의 남은 uuid·enum 입력 경로는 자연 HTTP 실패 증거를 확보하지 못함(이전 기록).
  - openapi_test.go는 경로 집합만 비교. HTTP 메서드와 응답 코드 검사 없음.
  - payOrder는 PAID→READY를 같은 트랜잭션에 커밋. REQUIREMENT_PENDING의 전체 HTTP 도달 불가는 이전 조사 결론.
  - ApprovalAdmin.save는 알려진 조건 5개로 재구성, toggle은 원본 조건 보존. 알 수 없는 조건 유실 가능. 이번 브라우저 미검증.
  - 요청 구조체 전체를 audit에 넘기는 10곳은 여전함. 검출 원문을 감사 details에 추가하는 해결책 금지.
  - Config.Load의 DrainSeconds 경계는 테스트 공백. 이번 과제는 config_test.go만 수정하며 아직 구현 전.
- 검증 함정:
  - integrationServer는 실제 Handler·DB·Worker와 apiUnderTest 전역 공유 — 테스트 병렬화 금지(이전 기록).
  - 메일 digest는 같은 DB 재사용뿐 아니라 깨끗한 DB에서도 간헐 실패한 이력. 40초 eventually/3초 sleep 단언 확인, 원인 미확인.
  - client.do의 map[string]any 숫자는 float64. 큰 정수는 pool로 int64 Scan하거나 정확히 표현되는 값 사용(이전 기록).
  - sellTalent는 옵션을 등록하지 않음. 옵션 ID는 이전 테스트처럼 DB 조회(이전 기록).
  - Node 20이 npm PATH에 끼어 테스트 0건이 된 환경 문제를 저장소 결함으로 다시 고치지 말 것.
  - release.yml은 v* 태그에서 Docker build/archive 재로드/Release만 실행, make check나 DB 통합 단계 없음.
  - 이번 Docker·DB·브라우저 미사용. 기존 주문 합산 통합 테스트 단독 -v에서 DSN 없음 SKIP 확인.
  - config 테스트는 환경변수를 다루므로 t.Parallel 금지. 실제 미지정과 빈 문자열을 구분하고 원래 환경을 복구할 것.
  - 스크린샷 스크립트는 시드·설정 쓰기를 하므로 폐기 루프백 인스턴스에서만 실행(이전 README 확인 기록).
