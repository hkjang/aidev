Kkiit v0.4.4 — 승인 정책 조건 표시·활성 전환 수정

v0.4.3 이후 들어온 개선과 수정을 담는다.

- 승인 정책 카드에 최소·최대 금액, 서비스 유형, 판매자 등급, 품질 점수를
  표시한다. 0·빈 배열·미산정 품질·알 수 없는 키·잘못된 배열을 구분하고
  모바일에서도 조건을 읽을 수 있게 줄바꿈한다.
- 활성 전환 요청을 저장 필드로 한정하여 id·타임스탬프 재전송으로 엄격한
  JSON 디코더가 요청을 400으로 거부하던 문제를 고친다.

버전 표기(VERSION·compose·web/package·openapi·README)를 0.4.4 으로 올린다.

gofmt · go build · go vet · go test, web lint · test · build 전부 통과.
