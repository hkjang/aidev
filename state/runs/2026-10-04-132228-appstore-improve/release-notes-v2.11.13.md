AppStore v2.11.13

`/my/apps` 의 빈 상태가 필터가 하나도 없는 화면에서 "조건을 바꾸어" 보라고 안내하던 문제를 고친 patch 릴리스입니다.

- 앱을 한 번도 등록하지 않은 소유자가 그 화면에서 처음 읽는 문장이 공용 기본 문구 "표시할 항목이 없습니다 / 조건을 바꾸거나 새 항목을 등록해 보세요." 였습니다. 그 화면에는 검색·필터·정렬이 없어 바꿀 "조건" 자체가 없었습니다.
- 같은 데이터를 읽는 대시보드가 이미 쓰고 있는 "등록한 앱이 없습니다" 로 제목을 맞추고, 설명을 "앱을 등록하면 상태와 검토 결과를 여기에서 확인할 수 있습니다." 로 바꿨습니다. 두 화면이 같은 상황을 같은 말로 설명합니다.
- 기존 "앱 등록" 버튼과 다른 화면 6곳이 공유하는 공용 기본 문구는 그대로입니다.
- 프로덕션 Provider·라우터·실제 API 클라이언트를 쓰고 HTTP 경계만 바꾼 Vitest 2건을 더했습니다(전체 99건).
- 버전 표기와 사용자·관리자 가이드 PDF를 갱신했습니다. 화면 캡처 90개 중 88개는 v2.11.12와 동일합니다.

schema 변경은 없습니다. 기존 설치는 image만 교체하면 됩니다.
