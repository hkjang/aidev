# Momento 프로필 (2026-10-08)

- 기준: main@992bb75, v0.34.60. 2026-10-01 프로필(v0.34.52)을 갱신 — 그 사이 릴리즈 8개(v0.34.53~60). 작업 트리는 깨끗했다. 이번 정찰은 **읽기만** 했고 `npm ci`·테스트는 돌리지 않았다(아래 '검증 함정' 의 미확인 표시를 볼 것).
- 목적: 온프레미스에서 이벤트를 수집·소유하고 제품·직원·경험·AI 사용을 분석하는 사내 분석 플랫폼.
- 스택: Go 1.26(net/http + chi, pgx, go-oidc), PostgreSQL 17; React 19.1 / TypeScript 5.9 / MUI 7.3 / Vite 7.3 / @tanstack/react-query 5.85 / echarts 6; TypeScript 수집 SDK(`sdk/`).
- 구조:
  - `cmd/momento` — 진입점. `internal/httpapi` — REST/MCP 핸들러. `admin.go`(1400줄+) 에 사용자·사이트·망 구분·Event Schema·설정이 모두 있고, `advanced_analytics.go` 에 보존 정책(`validateRetention`:80-97, `putRetentionPolicy`). `server.go` 가 라우터.
  - `internal/service`(Collector·Worker·Automation·Maintenance), `internal/auth`(`roleRank`·`RoleAtLeast`·`RoleAbove` 가 역할 서열의 정본), `internal/privacy·secret·segment·insight`.
  - `internal/database` — Migrate/MigrateThrough. **embedded SQL 정본은 `internal/database/migrations/`**. 루트 `migrations/` 는 001 하나뿐이고 정본이 아니다.
  - `web/src/pages` — 화면. **`AdminPage.tsx` 가 4000줄 가까운 단일 파일**로 사용자·사이트·설정·보존 정책·망 구분·Event Schema·dimensions 섹션을 다 담는다. 섹션은 `?section=users|sites|settings|retention|networks|schemas|…` 로 고른다.
  - `web/src/components` — 공용 UI. `DataTable.tsx`(466줄)가 15개 파일·62곳 표의 단일 구현이라 여기 손대면 전 화면에 퍼진다. `AppShell.tsx`(1100줄+)가 사이드바·단축키·명령 팔레트. `useUnsavedWarning.ts:7` 이 폼에 `beforeunload` 를 건다.
  - **순수 로직 `.ts` 모듈이 이 저장소의 테스트 가능성 패턴이다.** `web/src/pages` 에 22개(`adminErrors`·`cidrRule`·`retentionRule`·`passwordRule`·`roleScope`·`queryPolicyForm`·`scheduleDefinition`·`visitorTrace`·`mcpOauth` 등), `web/src/components` 에 `tablePaging`·`tableSummary`·`tableSort`·`tablePrefs`·`preference`·`csvExport`·`shortcuts`·`navPrefs`·`relativeTime`. **새 로직은 반드시 이 자리로 간다.**
  - `web/test/*.test.mjs` **40개**가 그 모듈을 `"../src/pages/X.ts"` 처럼 **확장자까지 적어** import 한다(node:test + tsconfig.app.json 의 allowImportingTsExtensions). 확장자를 빼면 **값 import 든 아니든** `ERR_MODULE_NOT_FOUND` 로 떨어진다(type-only import 만 예외).
  - `sdk/` — 브라우저 수집 SDK. `scripts/guide/` — 배포 시드 + puppeteer-core 캡처. `docs/` — 가이드·PDF·ARCHITECTURE·ROADMAP·openapi.yaml(ROADMAP_PLAN 은 오래된 비전 문서).
- 빌드·테스트:
  - Go: `make test`, `go test -race ./cmd/... ./internal/...`(httpapi 60~70초), `go vet ./cmd/... ./internal/...`.
  - 웹: `cd web && npm ci && npm run lint && npm test && npm run build`. **worktree 에 `web/node_modules` 가 없어 `npm ci` 가 선행(수 분).** `test` = `"${npm_node_execpath:-node}" --test test/*.test.mjs`(v0.34.53 에서 PATH 가림을 피하게 고침), `build` = `tsc -b && vite build`, `lint` = `eslint .`. `engines.node` 는 `^22.18 || >=24`.
  - SDK: `cd sdk && npm ci && npm run typecheck && npm test && npm run build`(`test` 도 v0.34.60 에서 같은 가림을 피하게 고침). 전체 산출물은 `make build`.
  - CI(.github/workflows/ci.yml): **sdk 게이트가 web 보다 먼저 돈다** — sdk 가 빨간불이면 web 단계는 실행되지 않는다. PostgreSQL 17 + Node 24 로 -race, govulncheck, `npm audit`, Docker build 까지.
- 관례: 한국어 conventional commit(`fix(web): …`, `feat(web): …`)이 주류이고 제목이 평서문으로 끝난다. 릴리즈 커밋은 `release: vX.Y.Z`. 설정은 DB `settings` 테이블 + 환경변수. Migrate 는 advisory lock 으로 직렬화. 사용자 보기 설정은 `components/preference.ts` 의 `usePreference`(localStorage + useSyncExternalStore, 예외는 모두 삼킴). **사용자에게 보이는 실패 문구는 `pages/adminErrors.ts` 의 `describe*` 함수가 정본**이고 폼 규칙은 `*Rule.ts` 순수 모듈이 정본이다(그 둘이 같은 상수를 공유하게 두는 것이 v0.34.58~60 의 패턴).
- 위험 구역: `internal/auth`(역할 서열·세션), `internal/httpapi/admin.go`·`server.go`(역할·세션·사이트 경계), `internal/database/migrations`, `.github/workflows`, `docs/openapi.yaml`(라우트 계약 테스트가 읽는다). **서버 검사가 권한·유효성의 정본이고 화면은 거울일 뿐** — 화면 게이팅을 이유로 서버 검사를 느슨하게 하지 말 것. 화면이 서버보다 **좁아지는** 것도 결함이다(서버가 받아 줄 값을 넣을 방법이 없어진다).
- 자주 깨지는 곳:
  - 순수 모듈 import 에서 `.ts` 확장자 누락 → node:test 가 모듈을 못 찾는다(2026-09-20·10-03 실제 발생).
  - 기존 테스트가 **출력 문자열을 글자 그대로 단언**하는 곳이 많다(`tablePrefs.test.mjs:12` 가 저장 키 전체를, `adminErrors.test.mjs` 가 안내 문장을). 문구 형식을 바꾸면 그 테스트를 함께 고쳐야 한다.
  - npm lifecycle PATH 가림 — 홈의 `~/node_modules/.bin/node`(v20.19.2)가 스크립트 안의 `node` 를 가려 `.ts` 가 `ERR_UNKNOWN_FILE_EXTENSION` 이 됐다. web·sdk 의 `test` 는 고쳤고 `lint`·`build` 는 **재현된 적이 없다**(손대지 말 것).
  - `TestRetentionReportsEachUnattendedPass`(integration_privacy_test.go) 의 -race 플레이크 1건 기록. 2026-09-26 이후 재현 미확인.
  - AdminPage.tsx 의 **행 번호가 회차마다 밀린다**. 과제서의 행 번호는 반드시 열어서 재확인할 것.
- 검증 함정:
  - `MOMENTO_TEST_POSTGRES_DSN` 이 없으면 Go 통합 테스트가 **조용히 skip** 된다 — "Go 테스트 통과" 를 DB 동작의 근거로 쓰지 말 것. 이 환경에 Postgres 는 없다.
  - **`npx prettier --check` 를 게이트로 쓰지 말 것** — 저장소에 prettier 의존성·스크립트·CI 단계가 없고(.prettierignore 만 있음) main 의 20여 개 파일이 이미 실패한다.
  - `gofmt -l` 에 `internal/segment/segment_test.go` 가 늘 뜨지만 한글 폭 정렬 문제이고 CI 는 gofmt 를 돌리지 않는다.
  - **`npm audit` 은 main 에서 녹색이다**(2026-10-07 에 실행으로 확인, `found 0 vulnerabilities`). `web/package.json` 에 `overrides: {"js-yaml": "^4.3.2"}` 가 있지만 npm 10.x 는 이 잠금 루트에 `overrides` 블록을 쓰지 않는다.
  - 최근 여섯 회차가 **headless Chrome 으로 실제 DOM 배선까지 확인**하고 통과했다. `google-chrome` 은 설치돼 있고 `puppeteer-core` 는 저장소에 없어 /tmp 에 따로 설치해 왔다. 폼을 채운 뒤 **같은 탭 재이동은 `useUnsavedWarning` 의 beforeunload 로 30초 타임아웃에 걸린다 — 사례마다 새 탭을 쓸 것.** 임시 하네스와 `web/dist`·`sdk/dist` 는 커밋 전에 지울 것.
  - 이 환경에는 네트워크가 있다(2026-10-07 에 `npm ci`·`npm audit` 실제 실행). "네트워크가 없어 못 돌렸다" 를 전제로 쓰지 말 것.
