# DartFly 프로필 (2026-09-26)
- 목적: 기존 Tadpole 메타 DB를 활용해 여러 DBMS 탐색·읽기 전용 SQL 실행·마스킹·감사·운영 관리를 제공하는 단일 바이너리 웹 플랫폼.
- 스택: Go 1.25.7(go.mod), net/http·database/sql, MariaDB 메타 DB, MariaDB/MySQL·PostgreSQL·Oracle·SQL Server 드라이버; 임베드 HTML/CSS·ES 모듈 JS, Node 회귀 테스트, Python Playwright 스모크.
- 구조:
  - cmd/dartfly: 진입점. internal/app/runtime.go: 환경변수 읽기·서비스 조립(server.Options 한 덩어리로 주입).
  - internal/server: HTTP 라우팅·세션 게이트·문제응답(http.go 의 writeProblem:1682/safeProblemDetail)·CSV. loginHandler 는 http.go:1697, 로그인 리미터는 http.go:1695 의 `logins`(loginlimit.go). resultsave.go 가 저장 결과 API.
  - internal/auth·sso·ssoconfig: 인증·서명 세션·OIDC·저장된 SSO 설정.
  - internal/query·dbconn·masking: 실행·정책·마스킹·값 정규화(Executor.normalizeValue 가 큰 정수를 문자열로 저장).
  - internal/resultsave: 저장 결과 서비스(exported Repository 인터페이스, 센티널 ErrNotFound/ErrInvalidID). internal/store/mariadb: 저장소 구현·migrations.
  - internal/access·rbac·governance·settlement·retention: 권한·거버넌스·결재·보존.
  - internal/apihub·mcphub: 외부 API/MCP. internal/webui: 임베드 pages/js/css(js 39개 모듈), assets.go 서빙, jstest_test.go 가 test/js 를 묶음.
  - test/js: Node 회귀(14개 .test.mjs + load.mjs 로더). test/livedb: 실제 DB. test/smoke: 실제 바이너리·MariaDB·Chromium. docs: 보증·설정·관리 가이드. deploy: 배포 스크립트.
- 빌드·테스트: `go test -race ./...`(38개 패키지) · `go vet ./...` · `gofmt -l .` · `go build ./cmd/dartfly`.
  - 화면 변경 시 `DF_SMOKE_REQUIRE_BROWSER=1 bash test/smoke/run.sh`(Docker·Chromium, 수분).
  - livedb 는 `bash test/livedb/setup.sh --fast` 후 `set -a; . /tmp/dartfly-livedb.env; set +a; go test -tags livedb ./...`(Oracle·SQL Server 준비는 오래 걸림).
  - JS 테스트는 `test/js/*.test.mjs` 를 **glob 으로** 잡으므로(`internal/webui/jstest_test.go:TestBrowserModuleTests`) 새 파일은 등록 없이 자동으로 돈다. `go test ./internal/webui/...` 또는 `node test/js/X.test.mjs`.
- 관례: 한국어 `feat:`/`fix:`/`test:` 커밋 + PR 병합. 환경변수 DARTFLY_*·_FILE, 화면에 저장된 SSO 설정이 env 폴백보다 우선. 마이그레이션은 internal/store/mariadb/migrations + 기존 설치는 ensureColumn ALTER. 오류는 RFC7807 꼴 problem + `DF_*` 에러코드(title 과 detail 에 같은 문구가 들어감). 주석은 "왜" 를 한국어로 길게 쓰는 편. 저장소에 CLAUDE.md·AGENTS.md·로드맵 파일은 없고 TODO/FIXME 주석도 0건(2026-09-26 재확인).
- 위험 구역: internal/auth·세션·SSO·return_to, 권한·마스킹·감사 정책, internal/store/mariadb/migrations, .github/workflows. CSV_FORMULA_GUARD 는 서버 CSV 설정이며 TSV 와는 연동 없음(TSV 는 js 의 tsvCell).
- 자주 깨지는 곳: 임베드 자산 누락은 배포에서만 드러남(모의 서버로 검증 금지). CSP `style-src 'self'` 가 HTML 인라인 style 속성을 막아 JS/CSS 클래스로 스타일을 줘야 함(2026-09-23 회차). 인라인 display 가 `hidden` 속성을 이겨 숨김이 안 먹는 함정. 스모크 하네스의 "모든 페이지 200" 기대가 새 302 라우트에 깨짐(2026-09-20 회차). 늦게 도착한 응답/타이머가 새 선택을 덮어쓰는 경합(2026-09-20 saved.js 회차).
