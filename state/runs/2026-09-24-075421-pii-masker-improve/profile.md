# pii-masker 프로필 (2026-09-24)
- 목적: PDF/PNG/JPG의 PII 영역을 Upstage 호환 추론으로 찾아 마스킹 파일을 돌려주는 동기·비동기 HTTP API와 내장 Playground UI.
- 스택: Go 1.25.0, gorilla/mux, pdfcpu, x/image, vendor 고정. DB 없음(디스크에 job.json/입력/출력 파일). 단일 HTML UI, Docker/Compose.
- 구조:
  - cmd/pii-masker/main.go — 환경 설정 로드와 서버 실행 진입점(33줄).
  - internal/app — HTTP 배선, graceful drain, 보존 스위퍼 기동(app.New).
  - internal/config — PII_MASKER_* Load/정규화. 테스트는 서버 timeout 3개뿐.
  - internal/httpapi — server.go(475줄): /v1/mask, /v1/jobs(POST), /v1/jobs/{id}(GET), /v1/jobs/{id}/result(GET·HEAD), /v1/history, /v1/health, /v1/config/public, /v1/test-connection. documentResponse가 no-store·nosniff. static/index.html이 UI.
  - internal/service — 동기·비동기 슬롯, draining/WaitGroup, CreateJob→startJobRunner→runJob, 오류 매핑.
  - internal/jobs — 메모리 맵 + 디스크 기록, job.json.tmp→Rename, 고아 디렉터리 삭제, 보존 삭제.
  - internal/upstage — 인증/allow-host/리다이렉트 검사, 8MB 응답 상한, 진단 문자열 UTF-8 안전 절단.
  - internal/document, internal/masking — 첨부 정규화, 이미지/PDF 렌더, PII 정책·좌표. internal/core가 공용 메타데이터 타입.
  - internal/mock — 로컬 추론 mock. scripts — PowerShell smoke/export.
- 빌드·테스트: `go test -count=1 ./...`(전체 2초 미만, 2026-09-24 통과), `go vet ./...`, `go build ./...`, `gofmt -l ./cmd ./internal`, `go test -race -count=3 ./internal/httpapi ./internal/service`. 오래 걸리는 테스트 없음.
- 관례: 영어 명령문 커밋 + PR 병합. README(한국어)가 정본이며 동작 변경 시 한 문장 추가가 관례. 코드 주석은 영어, 사용자 오류 메시지는 한국어. 환경변수 설정, 마이그레이션 없음. CLAUDE.md·AGENTS.md·docs/·.github CI 없음(2026-09-24 재확인). vendor 제외 TODO/FIXME 없음.
- 위험 구역: upstage 인증/allow-host 검사, service의 draining/WaitGroup, jobs.load의 RemoveAll(고아 삭제), 업로드 크기 상한. PDF는 사각형 오버레이이며 텍스트 레이어 제거는 미지원(README 명시).
- 자주 깨지는 곳: 사용자 제공 실패·롤백 기록 없음. 반복되는 함정은 "같은 값을 읽는 경로가 여럿"인 구조 — 상태·UpdatedAt·CreatedAt·결과 경로·download_url이 저장소/조회/이력/다운로드/생성 응답에 각각 있어 한쪽만 고치면 어긋난다(2026-09-21, 2026-09-22 회차가 모두 이 유형). 프로필이 낡으면 이미 고친 문제를 다시 고르는 실수가 난다(2026-09-22 과제서 기각 사유).
- 검증 함정:
  - HTTP 통합은 `startAppServerWithUpstream(t, upstream, customize)` → app.New → httptest 실제 리스너. 외부 Upstage 없이 돌고 customize는 app.New 전에 실행되어 config 조정·디스크 fixture 주입이 가능하다.
  - `newGatedUpstream()`로 업스트림을 붙잡아 두면 MaxConcurrentJobs=1과 함께 queued/running 상태를 결정론적으로 만들 수 있다.
  - `core.FileDescriptor`의 필드는 `omitempty`라 빈 값이면 JSON 키가 사라진다.
  - JSON 인코더가 잘린 UTF-8을 U+FFFD로 치환하므로 JSON 유효성만으로 문자열 손상을 못 잡는다. engine.debug.response는 JSON 문자열이라 한 번 더 디코딩해야 한다.
  - t.Setenv 쓰는 테스트는 병렬화 금지. 권한 오류는 root chmod 대신 파일/디렉터리 충돌로 유도.
  - Windows Rename 동작, Docker 빌드 실행, 의존성 갱신은 미확인.
- 현재 기준: main 머지 커밋 5d43c34(2026-09-22 created_at 보존까지 반영). 이전 프로필이 "남은 문제"로 적었던 truncateString UTF-8 절단은 7511062로 해결됨. 요청된 pmo/technology 스킬 3종은 이 세션에서 Skill 도구로 정상 로드해 절차를 따랐다.
