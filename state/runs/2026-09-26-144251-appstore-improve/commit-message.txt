chore(release): AppStore v2.11.6

즐겨찾기 하트를 누르면 카탈로그 목록 전체가 스켈레톤으로 사라지고 같은 목록을
서버에서 다시 받아 오던 문제를 고친 patch 릴리스입니다. 하트는 브라우저 쪽
state인데 TanStack 쿼리 키에 들어 있어 토글마다 캐시 없는 새 쿼리가 됐습니다.
서버와 schema는 바뀌지 않았습니다.

Version

web/package.json, package-lock.json, docker-compose.yml, README, GitHub Pages
문서와 docs/USER_GUIDE.md·docs/ADMIN_GUIDE.md의 버전 표기를 v2.11.6으로
올렸습니다. 관리자 가이드의 롤백 예시는 한 칸 밀어 appstore-v2.11.5-stopped로
맞췄습니다. package-lock에서는 이 패키지의 version 두 곳만 옮겼습니다.

두 가이드 PDF는 공용 변환기(aidev/tools/guide/md2pdf.mjs)로 이 환경의 Linux
Chrome 151에서 다시 구워 표지의 제목·버전을 확인했습니다. 사용자 가이드 27쪽,
관리자 가이드 36쪽으로 v2.11.5와 같습니다.

기능 커밋(73122f8)은 web/src/pages/public-pages.tsx의 카탈로그 queryKey에서
slugs만 빼고(pageSize 100/24를 가르는 favoritesOnly는 유지) Vitest 2건과
Playwright 1건을 더했습니다. 찍히는 화면이 달라지지 않으므로, screenshot
manifest는 90개 항목의 version만 갱신하고 캡처 파일과 SHA-256은 그대로
두었습니다.

Migration

제품 코드의 schema 변경이 없습니다. 기존 설치는 image만 교체하면 됩니다.

Embedded bundle

internal/webui/dist는 기존 관례대로 유지합니다. Dockerfile이 production
bundle을 새로 빌드합니다.

검증: 실제 PostgreSQL 16 통합 테스트를 포함한 go test -race -count=1 릴리스
패키지 목록, go vet, gofmt, go build, npm test 80건, lint, Prettier, build,
오프라인/환경/문서 검사 통과. Playwright desktop/mobile은 Chromium을 설치한 뒤
전체 실행하여 retry 없이 75 passed/1 skipped. Docker image build/load/smoke와
GitHub Release 게시·SHA-256 생성은 기존 태그 워크플로가 수행합니다. 이
세션에서는 원격 전송을 수행하지 않았습니다.
