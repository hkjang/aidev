# Quantoss 프로필 (2026-09-29)
- 목적: 토스증권 Open API 기반 국내·미국 자동 매매·모의/백테스트·전진 검증을 수행하고 Pages·리포트·알림으로 운영 현황을 게시하는 Go 에이전트.
- 스택: Go(모듈 `github.com/hkjang/Quantoss`), coder/websocket, Anthropic SDK(indirect). DB 없음 — JSON/JSONL·파일 캐시. docs 는 정적 HTML/JS.
- 구조:
  - cmd/quantoss — 단일 CLI. agent/backtest/research/swing/laoer/copilot/doctor/verify/orders 등 진입점.
  - internal/toss — REST/WS 클라이언트(client.go 740줄, ws.go 233줄). OAuth 토큰 공유 캐시, 그룹별 TPS limiter, 429/5xx 재시도. `Client.Sleep` 이 nil 이면 `time.Sleep`(테스트 주입점).
  - internal/config — Default·FromEnv(.env/환경변수)·Validate·ForMarket·VersionHash. gap 네 필드 검증 구현됨.
  - internal/engine·broker·risk·strategy·indicators — 매매 판단·체결·리스크. broker/live.go 는 2단 매도·서버 손절 예약(placeGuard/cancelGuard/restoreGuard) 보호 대상.
  - internal/swing·backtest·exitlab·selection·evaluation·forecast — 일봉/저빈도 전략과 연구.
  - internal/perf·journal·report·deck·track — 성과·JSONL 기록·리포트·HTML 덱.
  - internal/agent·github·notify·copilot·funding·tax·portfolio·holdings — 데몬·게시·알림·확인 명령·자금/세금/보유.
  - internal/universe·yahoo·catalyst·fundamentals·stockinfo·ontology·market — 시세·종목·공시 수집과 시장(KR/US/KST) 추상화.
  - docs / reports / testdata / firm / ontology / data — Pages·보고서·브라우저 시험 데이터·정적 자료.
  - scripts — boot.sh, run.sh, run_cmd.sh, lab.sh, quantoss.service, Quantoss-startup.vbs, check_dashboard.sh. **일반 Go 검증 스크립트(check.sh) 없음.**
  - internal/zz_dbg — `//go:build zzdbg` 태그 전용 스크래치(+ 태그 없는 doc.go). 실API·실거래 토큰을 쓰므로 실행 금지.
- 빌드·테스트: `gofmt -l .` → `go vet ./...` → `go build ./...` → `go test -count=1 ./...`. 성능 비교는 반드시 `-count=1`.
  - 이번 실측: `go test -count=1 ./internal/toss/ ./internal/broker/` → toss 0.139s, broker 7.753s(통과). 전체 벽시계는 이번 미계측(2026-09-20 기준 ~8.3s).
  - `scripts/check_dashboard.sh` 는 Chrome·Python HTTP 서버·포트 의존이라 일반 Go 테스트와 별개. 이번 미실행.
- 관례: 한국어 설명형 커밋. `git log -30` 은 거의 전부 `live.json: 실시간 현황` 자동 게시(코드 커밋은 그 사이에 드물게 섞임 — 기능 커밋을 찾으려면 `git log -- <경로>` 를 쓸 것). 설정은 `.env` + `QUANTOSS_*`/`TOSS_*` 환경변수. DB 마이그레이션 없음. CLAUDE.md·AGENTS.md·ROADMAP·TODO/FIXME 없음 — README 단계 표와 docs/PROPOSALS.md 가 계획 문서.
- 위험 구역:
  - `internal/toss` 인증 — client 당 유효 토큰 1개. 재발급이 실거래 프로세스 토큰을 죽인다(client.go:91 주석, 커밋 78ee1393·c9a2645f). `ensureToken`/`loadTokenCache`/`saveTokenCache`/`invalidateToken` 은 손대지 말 것.
  - `internal/broker/live.go` — 중복 주문(`createIdempotent`, :607), 미확정 체결(`waitFill`), 서버 손절 예약 이중 매도(`placeGuard`/`cancelGuard`/`restoreGuard`, :645~).
  - copilot 확인/실매도, swing/runner.go 전략별 계약, config `ForMarket`/`VersionHash`.
- 자주 깨지는 곳: 미국 가격 `%.0f` 포맷, 리터럴로 만든 구조체의 nil 필드(notify.http·toss.lim 계열 패닉), 스윙 누락 일봉, 체결 레코드와 포지션 통계 혼용.
  - 신규 확인(2026-09-29): 같은 루프 안에서 분기별 가드가 어긋나는 패턴 — `client.go:262` 의 5xx 는 `attempt < maxAttempts-1` 가드가 있으나 `:250` 의 429 는 없어 소진 시 서버 오류가 `Status=0 retry-exhausted`(:293)로 덮인다.
- 검증 함정:
  - `errors.As(err, &ae)` 뒤 `ae.Status` 로 분기하는 호출부가 셋(broker/live.go:616·676, cmd/quantoss/doctor.go:83) — toss 의 오류 반환 형태를 바꾸면 이 셋을 함께 볼 것.
  - `FromEnv` 는 `.env`/프로세스 환경을 읽으므로 임시 작업 디렉터리·`t.Setenv` 로 격리하고 병렬화 금지. `slog.SetDefault` 캡처도 병렬화 금지.
  - 테스트 통과가 로그 비밀 비노출을 보장하지 않는다(로그 단언을 따로 쓸 것).
  - broker 의 남은 7.7s 는 `live.go` 자체 sleep 과 limiter TPS 대기 — toss `Sleep` 주입으로는 사라지지 않는다.
  - `.github/workflows` 없음(빈 `.github`). 러너의 gofmt/vet/build/test 가 사실상 CI. 워크플로 쓰기 권한 미확인이라 CI 추가는 위험.
