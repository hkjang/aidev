'Keycloak SSO로 계속' 버튼도 return_to 를 실어 대화형 로그인 뒤 같은 깊은 링크로 돌아간다. 검증: Go 테스트 8건 추가(safeReturnTo·refusal 주소 표, status 공개 조건, auto_login off 에서 prompt 제거·on 에서 전달과 `//` return_to 폐기, silent 거절 → `/dataworks/products/x?sso=none&tab=contracts` + state 재사용 시 실패 경로, 대화형 오류는 종전 kc_error 유지, 스텁 토큰 엔드포인트로 실제 라우트 경유 silent 성공 → 깊은 링크+fragment 토큰+`/auth/me` 200, 설정 저장 왕복) + store 왕복 테스트, auto_login 가드를 제거하면 해당 테스트가 실제로 실패함을 확인, `go build ./...`·`go vet ./...`(0건)·`go test ./...` 전체 통과, `go run ./cmd/api-surface-audit` gap 0, 수정·신규 Go 파일 `gofmt -l` 클린(`sso_config.go` 의 기존 정렬 어긋남도 gofmt 로 정리). web: vitest 11건 추가(총 25건 통과), `npm run lint`·`npm run build` 통과(지워진 `web/dist/.gitkeep` 복원). 추가로 빌드된 SPA 를 임베드한 서버를 sqlite 로 띄우고 Node 스텁 Keycloak(discovery·prompt=none 을 IdP 쿠키로 판정·RS256 id_token·JWKS)과 headless Chromium(Playwright) 으로 15개 항목 확인 — IdP 세션 없음: 깊은 링크에 `?sso=none` 로 착지·로그인 화면·kc_error 없음·prompt=none 호출 정확히 1회·새로고침 2회와 sessionStorage 삭제 후 새로고침에도 재시도 없음·SSO 버튼은 대화형 로그인; IdP 세션 있음: 새 탭에서 로그인 화면 없이 깊은 링크로 착지·`/auth/me` 200·호출 1회; 실제 로그아웃 메뉴로 로그아웃 후 새로고침해도 자동 로그인 안 됨; auto_login 꺼짐: IdP 세션이 있어도 제공자 호출 0회, 수동 `?prompt=none` 은 서버가 prompt 없는 대화형 요청으로 바꿈. `docs/ADMIN_GUIDE.md` 4.3 절에 "자동 로그인 (Silent SSO)" 소절(동작·세 겹 루프 방지 표·점검 항목)과 4.6 환경 변수 표에 `SSO_KEYCLOAK_AUTO_LOGIN` 을 추가하고 `aidev/tools/guide/md2pdf.mjs` 로 PDF 를 다시 구웠다. 릴리즈 커밋은 남기지 않았다.
