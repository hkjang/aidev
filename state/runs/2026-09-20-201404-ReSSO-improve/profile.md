# ReSSO 프로필 (2026-09-20)
- 목적: 오프라인 단일 바이너리로 운영하는 OIDC SSO 제공자와 사용자·Realm 관리 콘솔; 외부 RP 클라이언트 구현은 포함하지 않는다.
- 스택: Go 1.26 / toolchain go1.26.7, chi v5, PostgreSQL·pgx v5, LDAP, React 19·TypeScript·MUI·React Query·Vite 7; vitest 4, Node CI 22.23.0.
- 구조:
  - cmd/resso: 서버/CLI·백그라운드 LDAP 동기화와 유지보수·메일 알림.
  - internal/httpserver: OIDC·로그인·관리/개인 API·MCP·미들웨어. integration_test.go는 실제 PostgreSQL 스키마와 HTTP 서버 사용.
  - internal/store와 migrations: PostgreSQL 저장·자동 SQL 마이그레이션, 최신 017_mail_deliveries.sql.
  - internal/oidc, cryptoutil, password, ratelimit: 토큰·키 보호·비밀번호·실패 제한.
  - internal/federation, backchannel, mail: LDAP, 로그아웃 통지, SMTP 알림.
  - internal/tracking, observability: 방문 추적/CSP와 Prometheus·서버 로그.
  - web/src: React 콘솔; webui/dist: Go embed 대상 프런트 산출물.
  - scripts: 테스트 서비스·스모크·오프라인 이미지·실제 가이드 캡처. docs: 운영·호환표·LDAP·사용자/관리자 가이드와 PDF.
- 빌드·테스트: make build VERSION=vX.Y.Z; make lint(golangci-lint v2.13.1, govulncheck, ESLint); make test(go test -race ./..., go vet, vitest, vite build).
- 빌드·테스트: 전체 연동에는 eval "$(scripts/test-services.sh)"로 PostgreSQL/LDAP/LDAPS 환경을 먼저 설정. 전체 make test는 과거 기록상 수분이며 이번 정찰에서는 미실행.
- 빌드·테스트: 이번 정찰은 RESSO_TEST_POSTGRES_DSN='postgres://resso:resso@127.0.0.1:55439/resso?sslmode=disable' go test -race ./internal/httpserver -run '^TestIntegrationUserInfoReadsTheTokenFromAPostBody$' -count=1 -v 실행, PASS/ SKIP 0 (패키지 1.945s).
- 관례: 영문 fix:/feat:/release: 커밋; 현재 HEAD 6eab1c2(v0.9.87). 환경 변수와 platform_settings 키별 설정. docs가 운영/연동 정본; README는 개발 참고.
- 관례: 이번 검색에서 저장소 CLAUDE.md·AGENTS.md·별도 roadmap·TODO/FIXME 발견하지 못함. 구현 설명 주석과 연동 테스트가 상세한 동작 근거다.
- 위험 구역: httpserver/auth.go(쿠키·요청 소진·로그인 code), oidc.go(인가/토큰/로그아웃의 세션·오류 계약), CSRF/API 키 예외 목록, store/migrations, .github/workflows/release.yaml.
- 자주 깨지는 곳: gofmt, 프런트 빌드로 바뀌는 webui/dist/index.html, LDAPS 컨테이너에 마운트된 빈 인증서 디렉터리, 추정한 HTTP 상태와 실제 응답 차이, 유지보수 SQL 순서를 잠근 테스트.
- 검증 함정: 환경 변수 없으면 연동 테스트가 SKIP인데 go test는 성공한다. 서비스가 필요한 검사에 SKIP가 있으면 통과 증거로 쓰지 않는다.
- 검증 함정: CI lint는 npm 설치 전 실행하고 로컬 make lint는 GO_PACKAGES로 vendored Go 파일을 제외한다. 전체 빌드 산출물을 소스 변경에 섞지 않는다.
- 검증 함정: README 수동 PostgreSQL 안내는 스크립트와 같은 컨테이너 이름이나 다른 포트/비밀번호를 사용한다. 실제 포트와 준비 명령 확인 필요.
- 검증 함정: 현재 정찰 환경은 docker와 Go 실행 가능(이전 프로필의 승인 제한 가능성은 현재 해당하지 않음). 전체 CI/LDAP/프런트 건강 상태는 이번 미확인.
- 최근 완료: POST UserInfo 본문 토큰 지원 및 중복 전달 거절, 로그인 실패/소진 안내, silent SSO 답별 카운터. 되풀이 구현하지 않는다.
- 현재 공백: userInfo POST만 다른 프로토콜 POST의 1MiB Reader 제한이 없음. Go 기본 폼 제한 10MiB는 존재한다. 이번 과제서가 이 한 곳을 다룬다.
