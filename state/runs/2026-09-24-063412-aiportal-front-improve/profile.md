- 자주 깨지는 곳:
  - **업무 실패(`isSuccess` false) 경로의 안내 누락.** 인터셉터는 세션 만료(`:223`), `status != 200 && code == 'BZ01'`(`:228-236`), axios 에러 + `BZ01` + `!url.includes('/app/simple')`(`:319-322`) 세 곳에서만 'COM' 을 던지므로 **HTTP 200 + 실패 코드는 화면까지 도달한다**. 게시판 상세·목록 3형제와 Sidemenu 는 정리 완료. **잔존: `ShareList` / `HeaderAlarm` / `PopWidgetSetting` 3곳**.
  - `catch` 의 `if (e == 'COM') return` 가드 누락/위치 오류로 전역 Alert 과 토스트가 겹치는 자리.
  - `catch (e) {}` 로 예외를 완전히 삼키는 보조 호출(`PopSimpleBot.vue:542,563`, `PopSimpleBotUpdate.vue:649`, `onToggleFav` 3곳).
  - **형제 경로 비대칭** — 같은 일을 한쪽만 다르게 처리하는 형태가 이 저장소 결함의 주류다(실패 안내, 검색 배선 등). 고칠 때는 형제 전부를 한 번에 볼 것.
  - **공유 컴포넌트가 계약을 지키지 않고 호출부가 각자 우회** — `SearchBox` 의 `v-model` 무동작이 대표 사례. 공유 쪽을 넓히지 말고 호출부를 형제와 같게 맞추는 방향으로 고칠 것.
  - 캐시 값이 배열이 아닐 때, `serviceCode` 비교, 비동기 조회 `await` 누락, 전역 스피너 start/stop 짝, 팝업 닫힘 경로(Escape/배경 클릭)의 콜백 유실.
  - **무효 변경**(관측 가능한 동작 변화 0)을 과제서 지시대로 넣었다가 비평에서 걸리는 일이 반복 — 줄을 넣기 전에 **빼고 돌려 실패하는 케이스가 있는지** 변이로 확인할 것.
