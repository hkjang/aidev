# v0.257.0

## 주소 끝에 빈 줄이 딸려 온 분도 제목이 있는 알림 메일을 받습니다

알림 메일은 같은 주소를 두 번 씁니다. 한 번은 SMTP 봉투(`RCPT TO`)로 릴레이에
"누구에게 보낼지" 알리고, 한 번은 본문 맨 앞의 `To:` 헤더로 받는 사람의 메일
프로그램에 보여 줍니다. 두 값은 같은 주소여야 하는데, kanpic 은 봉투만 앞뒤
공백을 털어 내고 헤더에는 저장된 글자를 그대로 붙였습니다.

주소 끝에 줄바꿈이 딸려 있으면 그 차이가 메일을 망가뜨립니다. 봉투 쪽은
털어 낸 뒤를 보므로 릴레이가 정상으로 받아들이는데, 헤더 쪽에는 줄바꿈이 그대로
들어가 `To:` 줄 다음에 빈 줄이 하나 생깁니다. 메일에서 빈 줄은 **헤더가
끝났다는 신호**입니다. 그래서 헤더 블록이 `To:` 에서 끊기고, 뒤따라야 할
`Subject`·`Date`·`MIME-Version`·`Content-Type` 일곱 줄이 전부 본문 글자가
되었습니다.

받는 분이 본 것은 이런 메일입니다 — **제목 칸이 비어 있고**, 본문 첫머리에
`Subject: =?utf-8?q?...?=` 같은 알아볼 수 없는 글자가 여러 줄 깔려 있고, 한글은
인코딩이 선언되지 않아 깨져 보입니다. 보내는 쪽에서는 아무 일도 없었습니다.
릴레이가 250 으로 받아 주었으니 kanpic 은 성공으로 기록했고, 발송 이력에도
정상으로 남았습니다. 누구도 알 수 없는 방식으로 깨졌습니다.

이제 수신자 주소는 `Deliver` 한 곳에서만 다듬고, 봉투와 `To:` 헤더가 **글자
하나까지 같은** 값을 씁니다.

## 이런 주소는 어떻게 생기나

사람이 일부러 넣는 것이 아닙니다. 다른 화면이나 문서에서 메일 주소를 복사해
붙이면 끝에 줄바꿈이나 탭이 함께 따라붙는 일이 흔하고, 그 상태로 저장되면
주소는 눈으로 보기에 멀쩡합니다. 화면에도 정상으로 보이고, 릴레이도 받아
주었으니 어디에서도 드러나지 않았습니다.

## 주소 가운데의 줄바꿈은 보내기 전에 거절합니다

끝에 붙은 것은 다듬어 없앨 수 있지만, 주소 *가운데*의 CR/LF 는 다듬을 수
없습니다. 그건 헤더를 하나 더 끼워 넣으려는 시도(헤더 주입)이기 때문에,
없애는 것이 아니라 **거절**해야 맞습니다. 이제 릴레이에 연결하기도 전에
`수신자 주소에 줄바꿈 문자를 쓸 수 없습니다` 로 막습니다.

전에도 이런 주소로는 메일이 나가지 않았습니다 — 릴레이에 붙은 다음
`smtp: A line must not contain CR or LF` 라는 영어 오류가 났습니다. 바뀐 것은
**언제·어떤 말로** 막히는지뿐이고, 새로 막히는 정상 주소는 없습니다.

## 그 밖에 바뀌는 것은 없습니다

- 누구에게 보낼지 정하는 규칙, 제목과 본문 문구, SMTP 주소·TLS·인증은 그대로
  입니다.
- 발송 이력에 남는 수신자(`Delivery.Recipient`)는 이미 따로 다듬어 두던 값이라
  달라지지 않습니다.
- 주소가 멀쩡했던 분들의 메일은 전과 완전히 같습니다. 이 릴리즈는 **주소에
  군더더기가 있을 때만** 달라집니다.
- 사용자에게 보이는 화면·API·상태 코드는 달라지지 않습니다.

## 올리실 때

마이그레이션도 새 설정도 없고 필수 런타임 환경 변수는 계속 `POSTGRES_DSN`
하나입니다. v0.256.0 에서 올라오시는 분은 이미지만 바꿔 다시 띄우시면 됩니다.

이미 잘못 나간 메일이 고쳐지지는 않습니다 — 이 릴리즈 뒤에 나가는 메일부터
적용됩니다.

## 오프라인 설치

이 릴리즈는 웹 자산과 서버 바이너리를 포함한 Docker 이미지 아카이브로 제공됩니다.

```bash
sha256sum -c kanpic-v0.257.0.tar.gz.sha256
gzip -dc kanpic-v0.257.0.tar.gz | docker load
docker run --rm -p 8080:8080 \
  -e POSTGRES_DSN='postgres://kanpic:password@postgres.internal:5432/kanpic?sslmode=require' \
  kanpic:v0.257.0
```

- 필수 런타임 환경 변수: `POSTGRES_DSN`
- Redis 및 외부 인터넷 연결: 불필요
- 관리자 초기 로그인을 보호하려면 `BOOTSTRAP_ADMIN_ID`와 `BOOTSTRAP_ADMIN_PASSWORD`를 함께 지정합니다.
- 무결성 검증 파일: `kanpic-v0.257.0.tar.gz.sha256`
