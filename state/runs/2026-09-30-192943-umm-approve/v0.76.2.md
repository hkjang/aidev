# v0.76.2 — 내려받은 파일에 어느 공간의 것인지 적혀 있습니다

한 공간은 두 가지 파일로 나갑니다. **백업**(`markdown`)과 **개요**(`outline`)입니다. v0.71.5 부터
백업은 공간의 이름을 달고 나갔지만, 개요는 어느 공간에서 받아도 `umm-outline.md` 한 이름이었습니다.
같은 폴더에 두 번째를 받으면 브라우저는 `umm-outline (1).md` 로 쌓았고, 헤더가 적어 준 이름대로
저장하는 것 — 백업 스크립트, `curl -OJ` — 은 앞의 것을 **덮어썼습니다.**

```
    "우리 팀" 과 "회고" 의 개요를 차례로 받으면

            전                                  후
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    umm-outline.md                  umm-outline-우리 팀.md
    umm-outline (1).md              umm-outline-회고.md
      또는 앞의 것을 덮어씀

    같은 공간의 백업과 개요를 함께 받으면

    umm-우리 팀.md      (백업)      umm-우리 팀.md          (백업)
    umm-outline.md      (개요)      umm-outline-우리 팀.md  (개요)
```

## 개요도 백업과 같은 길로 이름을 얻습니다

백업·인계·캔버스 그림이 쓰는 `attachmentDisposition` 을 개요도 그대로 지나갑니다. 사람이 쓴 공간
이름이 파일 이름으로 갈 때 필요한 것은 이미 거기에 다 있습니다.

- 따옴표·구분자·제어문자는 떨어져 나갑니다 — `"9월" 회의` 는 `umm-outline-9월 회의.md` 가 됩니다
- 한글은 `filename*=UTF-8''` 로 온전히 가고, 그것을 못 읽는 클라이언트를 위해 `filename=` 에
  ASCII 대체 이름이 함께 실립니다
- 이름이 길면 UTF-8 글자 경계에서 자릅니다

줄기(stem)는 백업의 것이 아니라 **개요 자신의 것**입니다. 둘은 서로 다른 내용을 담으므로 한 공간의
백업과 개요가 한 파일로 떨어지면 안 됩니다.

**아무도 이름 짓지 않은 공간**도 파일로는 나가야 합니다. 이름을 읽지 못했다고 내보내기를 거절하지
않고 `umm-outline-.md` 로 보냅니다 — 헤더는 어느 쪽이든 읽을 수 있고, 이름은 그것이 무슨 파일인지는
여전히 말합니다.

웹 캔버스는 원래 자기가 받을 이름을 스스로 지어 왔으므로 화면에서는 달라지는 것이 없습니다. 이
헤더는 **API 클라이언트에게 남는 전부**입니다.

## 공백뿐인 발표 제목은 제목이 없는 것입니다

발표는 제목을 주지 않으면 공간 이름을 표지에 씁니다. 그런데 제목 칸에 **스페이스 한 칸**을 남기면
빈 문자열이 아니므로 그대로 제목이 되어, 표지가 `# ` 뒤에 아무것도 없는 채로 컴파일됐습니다.

이제 제목은 먼저 다듬고 나서 비었는지 봅니다.

```go
title := strings.TrimSpace(req.Title)
if title == "" {
    title = s.spaceName(ctx, userID, req.SpaceID)
}
```

스페이스·탭·줄바꿈뿐 아니라 `U+00A0`·`U+2003`·`U+3000` 처럼 **눈에 보이지 않는 한글 입력기의
공백**도 함께 빈 제목으로 셉니다. 앞뒤에 공백이 붙은 보통 제목(`  임원 보고  `)은 다듬어진
`임원 보고` 로 들어갑니다.

생각과 그 순서는 제목과 무관합니다. 표지는 여전히 하나뿐이고, 첫 생각은 그 뒤 2번 자리에서
시작합니다.

## 검증

내보내기 이름과 발표 제목은 둘 다 **실제 스토어를 지나야** 보이는 것입니다 — 공간 이름은 데이터베이스에
있고, 손으로 만든 대역은 그것을 대신 말해 줄 수 없습니다. 그래서 증명은 실제 PostgreSQL 17 을 지나는
integration 시험입니다.

```
✓ TestOutlineExportNamesTheFileIntegration
    "9월" 회의 → umm-outline-9월 회의.md, 같은 공간의 백업 이름과 다름
✓ TestOutlineExportNamesAnUnnamedSpaceIntegration
    이름이 "" 인 공간과 "   " 인 공간 → umm-outline-.md, 헤더는 여전히 파싱됨
✓ TestMarkdownExportNamesTheFileIntegration
    백업 이름은 v0.71.5 그대로
✓ TestPresentationTitleFallbackIntegration
    생략 · "" · 스페이스 · 탭/줄바꿈 · 유니코드 공백 → 공간 이름
    보통 제목 · 앞뒤 공백 붙은 제목 → 다듬어진 그 제목
    일곱 경우 모두 생각과 순서·표지 개수·미리보기 본문이 제목 한 줄 빼고 동일
```

`TestPresentationTitleFallbackIntegration` 은 미리보기와 개요 내보내기를 **같은 시험 안에서** 함께
봅니다. 둘은 같은 컴파일을 지나므로 한쪽만 고쳐지는 일이 없어야 합니다.
