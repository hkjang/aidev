# Clustara 프로필 (2026-09-23)
- 목적: 폐쇄망 Kubernetes 운영 허브로 멀티 클러스터 수집·장애/보안/용량/비용 분석·승인 액션·LLM/MCP 프록시·Mattermost 알림을 제공한다.
- 스택: Go 단일 모듈 `clustara`(go.mod 1.25), net/http, 기본 SQLite(modernc)·PostgreSQL 지원, 선택 ClickHouse, 인라인 바닐라 JS 한국어 SPA(`internal/proxy/admin_ui.go`).
- 구조:
  - `cmd/` — clustara(서버)·clustara-cli·clustara-agent·api-surface-audit 엔트리.
  - `internal/proxy/` — HTTP mux(`server.go:Routes`)와 admin_* 핸들러, `admin_ui.go` SPA, MCP/SSO·Mattermost(`mattermost.go`)·DW 조립.
  - `internal/analyzer/` — 순수 분석 함수와 단위 테스트(rca.go·security.go·capacity.go·cost.go·workload.go·node_monitoring.go 등).
  - `internal/store/` — SQLStore, 인벤토리·이벤트·리비전·승인 원장·알림 dedup(`k8s_meta.go`); `sqlstore.go` 가 DDL.
  - `internal/kube/`, `internal/collector/` — Kubernetes 객체 변환(`InventoryFromObject`)·수집·exec.
  - `internal/action/` — 승인 영향도·액션; harbor/gitprovider 등은 별도 연동 패키지.
  - `docs/` — ADMIN_GUIDE·USER_GUIDE·K8S_OPERATIONS_HUB 가 정본. K8S_PHASE2_PLAN.md·ARCHITECTURE_MODULES.md 는 오래됐으니 코드 우선.
  - `scripts/`, `deploy/`, `sdk/` — 릴리즈(changelog.txt)·배포·클라이언트 SDK.
- 빌드·테스트: 이번 정찰은 `go test ./internal/proxy -run 'K8sNotify|Mattermost|QuietHours' -count=1` 통과(0.65s). 최종 게이트는 `go build ./...` → `go vet ./...` → `go test ./...`(전체 약 80s, proxy 단독 약 60s).
- 관례: 영어 `fix(scope)`/`feat(scope)` 커밋, 릴리즈는 별도 `chore: release vX` 커밋. 런타임 설정은 DB 플래그(`SetFlag`/`flagValue`)와 설정 레지스트리·환경변수. SQLite/PG 호환 bind·`CREATE TABLE IF NOT EXISTS`. 코드 주석은 영어, UI 문구는 한국어.
- 위험 구역: `proxy/server.go:currentAccessClaims`·`mcp_oauth.go`·`keycloak*.go` 인증, `analyzer/policy.go` Deny 게이트, `store/sqlstore.go` DDL, DW fact 스키마, `.github/`(FUNDING.yml 뿐, CI 없음). `restrictedProfileViolations` 는 포스처·정책 공용이라 파급이 넓다.
- 자주 깨지는 곳: 전 클러스터 입력을 namespace/name/nodeName 단독으로 조인·dedup 하던 경로 — RCA 이벤트·리비전(v0.9.286), PodSecurity/DW/notify cluster 전달(v0.9.285), AttachFindingResources(v0.9.287), NodePressure 영향 Pod(5b98765)까지 차례로 해결됐다. 남은 결함은 조인이 아니라 **부수효과 순서**(전달 전에 dedup 을 쓰는 notify scan)와 **키 구성 누락**(podsec/rbac dedup 키의 Kind)이다.
- 검증 함정:
  - `mattermostConfig` 스냅샷은 15초 캐시(`mattermostSnapshotTTL`) — 테스트에서 플래그를 바꾸면 `server.invalidateMattermostCache()` 필수.
  - Mattermost 전송은 `go func` 비동기 — httptest webhook 수신은 채널+`time.After`, 미전송 증명은 `select ... default`.
  - proxy 테스트 표준 배선: `openTestStore(t)`(t.TempDir SQLite) + `store.NewAsyncLogger` + `NewServer(testConfig(...))`(스케줄러 비활성) + `httptest.NewServer(server.Routes())` + `postJSON`.
  - 빈 `ClusterID` 는 wildcard 가 아니라 독립 식별자다. 기존 분석기 fixture 는 대개 단일 클러스터라 교차 오염을 못 잡는다.
  - `internal/proxy/docs_reference_test.go`·`release_gate_test.go` 가 docs 의 API 경로·버전 마커를 검사한다 — 무관한 문서/버전 편집 금지. gofmt 는 수정한 파일에만.
  - CI 워크플로가 없어 로컬 게이트가 전부다. SQLite·httptest 통과는 실 PostgreSQL·실 Kubernetes·Keycloak·ClickHouse·브라우저 검증을 대신하지 않는다(모두 이번 미확인).
- 정찰 범위(이번 회차): `git log -10`, `internal/proxy/k8s_notify.go`·`mattermost.go`·`k8s_notify_scan_test.go` 전문, `docs/ADMIN_GUIDE.md`·`K8S_OPERATIONS_HUB.md` 의 notify 절, analyzer/proxy 파일 목록. base main@907c8c1, 작업 트리 변경 없음.
- 환경: CLAUDE.md/AGENTS.md 는 저장소에서 미발견. 회사 스킬(`pmo:estimating-and-contingency`, `technology:implementation-planning`, `technology:solution-exploration`)은 이번 세션에서 Skill 도구로 실제 로드해 절차를 따랐다(이전 회차들의 '미발견' 기록은 갱신됨).
