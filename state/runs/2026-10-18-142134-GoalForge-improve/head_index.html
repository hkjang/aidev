CORE ADVANTAGES

GoalForge를 선택해야 하는 이유

환각과 통제 불능 코딩 에이전트의 시대는 끝났습니다. GoalForge가 개발자 중심 시스템 통제를 재정의합니다.

🎯

목표 중심 오케스트레이션

AI 세션이 아닌 Go 프로세스가 버전 관리되는 목표, 마일스톤, 작업 순서 및 검증 증거의 단일 진실 출처(Single Source of Truth)를 소유합니다.

🤖

이종 AI 모델 통합 통제

Codex, Claude Code, Qwen Code, OpenCode를 동일한 CLI 규격과 권한 매핑 정책 아래 유연하게 교체하고 실행할 수 있습니다.

🛡️

결정론적 자동 검증 게이트

`go test`, `go build` 및 사용자 정의 검증을 통과해야만 병합 및 발행 승인 요청을 생성합니다. 환각된 코드의 자동 릴리즈를 차단합니다.

🌴

Git Worktree 안전격리

AI 실행은 기본 브랜치가 아닌 격리된 Git 워크트리에서 일어납니다. 실패 시 메인 브랜치 오염 없이 즉시 롤백 및 작업 재시도가 가능합니다.

🔌

빌트인 MCP 서버 지원

stdio 및 Streamable HTTP(POST /mcp)를 통해 Claude Code 및 AI 에디터와 대화형으로 연동되는 15가지 관리 및 제어 도구를 제공합니다.

⚡

예산 및 API 쿼터 자동 관리

프로젝트 토큰/비용 예산과 프로바이더 쿼터를 독립 평가합니다. Quota 초과 시 자동 대기(WAITING_QUOTA) 및 복구 체크포인트를 기록합니다.

TRADITIONAL AI AGENTS

기존 프롬프트 기반 코딩 에이전트

  • ✕ 메인 브랜치 직연결 수정으로 코드베이스 오염 리스크
  • ✕ 검증 없는 환각 커밋 및 반복 실패 시 무한 루프 비용 발생
  • ✕ API Quota 초과 시 무한 폴링으로 계정 잠금 또는 오류 종료
  • ✕ .env, 개인키 등 보안 파일 무단 변경을 사전 차단할 메커니즘 부재
GOALFORGE ORCHESTRATOR

GoalForge 통제형 오케스트레이터

  • ✓ 격리된 Git 워크트리에서 일어나는 단일 임대 실행으로 메인 보호
  • ✓ go test, 빌드 게이트 100% 성공 시에만 승인 및 커밋 트레일러 기록
  • ✓ Quota 초과 시 무한 폴링 대신 체크포인트 보관 후 WAITING_QUOTA 자동 대기
  • ✓ SHA-256 핑거프린트 검증으로 비승인 보안 파일 변경 시 자동 롤백
DEEP DIVE & SECURITY

핵심 보안 및 제어 메커니즘

단순한 에이전트 호출을 넘어 코드베이스 오염 차단과 결정론적 안정을 보장하는 4대 차별화 기술

🔒

보호 파일 핑거프린팅 & 단일 임대

`.env`, SSH 키, 보안 세팅 파일의 SHA-256 해시 기준선을 사전 기록합니다. AI의 무단 변경/삭제 시 변경사항을 즉시 롤백하고 실행을 차단합니다.

🔄

무한 루프 차단 & 중복 필터링

`same_work`, `same_change`, `no_change`, `same_error` 신호를 실시간 추적합니다. 동일 오류 반복 시 자동으로 세션을 교체하거나 리뷰용으로 멈춥니다.

⏳

Quota 회복 및 체크포인트 복구

API Rate Limit 초과 시 무한 폴링 대신 `continuity/.md` 체크포인트를 남기고 `WAITING_QUOTA` 대기 후 리셋 시각에 자동 복구됩니다.

🔐

AES-GCM 암호화 감사 트레일

`GOALFORGE_AUDIT_KEY` 설정 시 모든 AI 전송 프롬프트 원본을 AES 암호화하여 저장하며, Slack/웹훅 알림 시 민감 데이터를 자동 Redact 처리합니다.

MODEL CONTEXT PROTOCOL

15가지 빌트인 MCP 서버 제어 도구

Claude Code, Cursor, AI 에디터와 대화형으로 연동되어 오케스트레이터를 실시간 통제합니다.

status & goal_show

프로젝트 상태, 가중 마일스톤 완료율 및 검증 게이트 통과율 실시간 리포팅

backlog_list & edit

우선순위(0~100), 가치 점수 및 작업 상태(APPROVED/BLOCKED) 대화형 관리

verify_gate_add

CLI 테스트 명령어를 결정론적 검증 게이트로 대화 중 즉시 등록

approval_request & approve

Protected-files, merge-branch, publish-branch에 대한 개발자 승인 처리

usage_report

프로바이더별 토큰 소비량, 비용 ledger 및 Quota 리셋 시각 정밀 조회

continue_enqueue & replay

자율 백그라운드 워커 작업 인큐ing 및 과거 실행 세션 타임라인 재생

CLI COMMANDS & WORKFLOW

실전 개발자 명령어 가이드

GoalForge CLI를 통한 초기화부터 검증 게이트 등록, 자율 실행 및 안전 병합까지

STEP 1

1. 진단 및 프로젝트 초기화

# 환경 검증 (Git, CLI, 권한)
goalforge doctor

# 프로젝트 초기화 (워크트리, 자동 커밋)
goalforge project init --name demo \
  --provider claude --model haiku \
  --worktrees --auto-commit \
  --fallback-model sonnet
STEP 2

2. 목표 및 검증 게이트 설정

# 버전에 맞는 목표 생성
goalforge goal set --title "Ship API" \
  --objective "Implement REST endpoint" \
  --criterion build_passed=true

# 결정론적 검증 게이트 추가
goalforge verify gate add \
  --type build_passed \
  --command-json '["go","test","./..."]'
STEP 3

3. 자율 작업 Discovery & 실행

# 작업 탐색 & 가치 점수 측정
goalforge audit
goalforge ideas

# 연속 자율 실행 (Quota까지)
goalforge run --until-quota --max-runs 50
goalforge worker --once
STEP 4

4. 승인, 병합 & 안전 롤백

# 병합 승인 요청
goalforge approval request \
  --action merge-branch --reason "Gate passed"

# 메인 브랜치 병합 또는 롤백
goalforge merge --work-item WORK-101
goalforge rollback --work-item WORK-101

자주 묻는 질문

GoalForge의 핵심 개념 및 동작 방식에 대한 완벽한 가이드

GoalForge는 AI 코딩 에이전트(Codex, Claude Code, Qwen Code, OpenCode)를 통합 관리하는 목표 중심(Goal-First) 개발 오케스트레이터입니다. AI 세션에 프로젝트 상태 관리를 의존하는 대신, Go 기반 고성능 프로세스가 프로젝트 목표, 마일스톤, 검증 게이트, 토큰 예산을 결정론적으로 관리합니다.
기존 에이전트는 프롬프트 기반으로 무제한 자유도를 가집니다. 이로 인해 메인 브랜치 훼손, 검증되지 않은 코드 커밋, 환각 현상 등의 리스크가 있습니다. GoalForge는 AI를 단순 '실행 도구'로 격리하고, Go 프로세스가 검증 게이트(`go test`, 빌드 등)를 통과한 결과만 승인 절차를 거쳐 반영하도록 통제합니다.
GoalForge CLI로 `goalforge verify gate add --type build_passed --command-json '["go","test","./..."]'`과 같이 등록합니다. AI 에이전트가 작업을 수행한 후, 해당 검증 게이트가 100% 성공을 반환해야만 작업이 완료(DONE)로 승인되며 Git 커밋 트레일러가 작성됩니다.
GoalForge는 `goalforge mcp` 명령어로 stdio 또는 Streamable HTTP(POST /mcp) 서버를 시작할 수 있습니다. 15가지 MCP 도구를 통해 Claude Code, Cursor 등 외부 MCP 클라이언트에서 프로젝트 상태 조회, 목표 및 작업 수정, 쿼터 리포트 확인, 승인 요청 등을 대화형으로 처리할 수 있습니다.
GoalForge는 프롬프트 호출 전 프로젝트 비용 ledger와 프로바이더 Quota 리셋 시각을 사전 평가합니다. Quota 부족 시 무한 폴링 대신 Git/세션 체크포인트를 저장하고 `WAITING_QUOTA` 상태로 대기하며, Quota 리셋 후 `worker`가 안전하게 작업을 복구합니다.
GoalForge는 단기적으로(2026 Q3~Q4) PostgreSQL 분산 스토리지 완결, 웹 UI 모니터링 대시보드, Gemini/DeepSeek/Ollama 어댑터 추가 및 GitHub Actions 플러그인을 제공하며, 중기적으로(2027 H1~H2) 멀티 에이전트 자율 스웜 오케스트레이션, 자가 치유 검증 게이트, 엔터프라이즈 보안 팩 및 Managed Cloud SaaS 서비스를 런칭할 계획입니다.
GoalForge는 execution 시작 전 `.env`, SSH 키, 개인키 등 프로젝트 내 모든 보호 파일의 SHA-256 해시 핑거프린트를 생성합니다. AI 실행 중 비승인된 변경/삭제가 발생하면 해당 run을 즉시 취소하고 원래 상태로 롤백하며, `GOALFORGE_AUDIT_KEY`를 통해 원본 프롬프트 또한 AES-GCM으로 암호화 보관합니다.
