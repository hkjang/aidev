# VisitFlow 프로필 (2026-10-09)
- 목적: 사내 방문 신청·승인·QR 방문증·로비 입퇴실·알림·감사를 단일 컨테이너로 제공한다.
- 스택: Go 1.24(chi·pgx·go-oidc·excelize), PostgreSQL 14+, React 19·TypeScript 5.9·Vite 7·Material UI 7, Vitest 3·Playwright 1.56.
- 기준: HEAD 627adbf, v2.8.18(web/package.json 동일). 이전 10/05 프로필의 미완료 승인/화면 오류 설명을 최근 머지 기록으로 갱신.
- 구조:
  - cmd/visitflow/: 서버 진입점·임베드 webdist. 스텁과 실제 UI 번들을 구분한다.
  - internal/app/: REST·MCP·SSE·방문·QR·알림. checkIn은 별도 qr.go가 아니라 visits.go에 있다.
  - internal/platform/: 설정·암호화. internal/database/migrations/: 번호별 SQL·schema_migrations.
  - web/src/pages/: 신청·목록·승인·로비·관리자 페이지. 화면별 상태 관리.
  - web/src/components/: 공통 UI/AppShell. web/src/*.test.ts: 순수 함수 단위 테스트.
  - web/e2e/visit-flow.spec.ts: 실제 서버 브라우저 회귀 스펙, login/createVisit/openVisitDetail 헬퍼.
  - scripts/local-e2e.sh: 실제 dist 임베드·전용 새 DB/서버 컨테이너·브라우저·복원.
  - docs/: USER_GUIDE·ADMIN_GUIDE·API_AND_MCP·ARCHITECTURE 및 PDF/이미지.
- 빌드·테스트:
  - `go test ./... -count=1`: 이번 PASS(internal/app 0.141s); VISITFLOW_TEST_DSN 미설정으로 PostgreSQL 통합 SKIP.
  - DB 통합은 VISITFLOW_TEST_DSN에 CREATE DATABASE 권한 계정 필요. 과거 기록 약 58초, 이번 실측 아님.
  - `cd web && npm ci && npm run lint && npm test && npm run build`: lint=tsc -b, test=vitest run. 이번 node_modules 없어 미실행; 직전 기록 98 tests.
  - `bash scripts/local-e2e.sh`: Docker·Go·Node·npm·curl 필요. 실제 dist·새 DB·자동 빈 호스트 포트. 인자 지원 없음. 수분 소요 가능.
  - Chromium 번들→시스템 Chrome→다운로드 순. VISITFLOW_E2E_BROWSER_CHANNEL 지정 가능. webdist 임시 백업 복원.
  - 기존 실행 서버에는 `cd web && VISITFLOW_BASE_URL=http://127.0.0.1:8080 npm run test:e2e`; Playwright webServer 설정 없음.
  - `go vet ./...`, `go build ./...`는 CI/기존 검증 명령(이번 미실행). `git diff --check`, `bash -n scripts/local-e2e.sh` 이번 PASS.
  - CI: PostgreSQL16·Go test/vet·npm ci/test/build·Docker build, 별도 실제 UI E2E. release.yml은 태그 기반 amd64 이미지 배포.
