- 자주 깨지는 곳:
  - 설정 캐시 LISTEN 전 NOTIFY 유실 flaky는 v0.1.39에서 테스트 장벽으로 해결. 이전 실패를 새 변경 탓으로 단정하지 않는다.
  - 프런트 테스트의 `findBy` 직후 비-DOM 단언 — RTL asyncWrapper의 단일 drain tick과 React Scheduler `setImmediate`의 경합. AuthContext는 고쳤고 같은 패턴이 다른 파일에 남아 있을 수 있다.
  - 시각 회귀는 한글 폰트·origin 영향. playwright:v1.62.1-noble 및 127.0.0.1:18080 사용.
  - 로그인 5분/동일 IP 5회 제한 — 검증을 여러 번 반복하면 인증 단계에서 실패한다.
  - SELECT 실패는 sentinel 트리거로 재현 불가. 전용 스키마 헬퍼 없이 대역 테스트로 때우지 않는다.
  - 회차 TIMEOUT 사례 2건: 검증 39회+probe로 작업이 유실됐다. 인과 증명 후 회귀 확인을 과잉 반복하지 않는다.
