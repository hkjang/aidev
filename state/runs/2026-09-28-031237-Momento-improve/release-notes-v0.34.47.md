# Momento v0.34.47 — 설명이 있는 표는 검색해도 몇 건 찾았는지 말해 주지 않았습니다

## 캡션이 설명과 건수 중 하나만 골랐습니다

표의 캡션 한 줄은 두 가지를 겸합니다 — 이 표가 **무엇인지**(description)와 지금 **몇 건을 보고 있는지**(건수).

그런데 `DataTable` 은 둘 중 하나를 골랐습니다.

```
description || `${Intl.NumberFormat("ko-KR").format(filtered.length)}개 항목`
```

`description` 을 넘긴 표는 **건수 쪽이 영원히 닿지 않는 가지**입니다. 검색어를 쳐서 1,240건이 3건으로 줄어도 캡션은 검색 전과 **글자 하나 다르지 않습니다.**

## 그리고 건수가 남아 있을 다른 자리도 사라집니다

일치 건수를 말해 줄 수 있는 곳은 캡션 말고 `TablePagination` 의 `1–N / N` 뿐입니다. 그 컨트롤은 `filtered.length > 10` 일 때만 붙습니다.

- 일치가 **11건 이상**이면 페이저가 규모를 말해 줍니다 — 캡션이 침묵해도 어딘가에는 숫자가 있습니다.
- 일치가 **10건 이하**로 줄면 페이저도 사라집니다. 규모를 알 수단이 **0** 이 됩니다.

검색이 잘 좁혀졌을 때, 즉 숫자가 가장 필요한 순간에 숫자가 없어집니다. 0건과 3건과 "검색이 안 걸렸나"를 화면만 보고 구별할 수 없었습니다.

`description` 을 넘기는 표는 **16곳**입니다(`FunnelPage.tsx:350`, `VisitorInsightsPage.tsx:764`, `EnterpriseAdminPage.tsx` 의 9개 표 등). 검색 상자는 `searchable` 을 적지 않아도 **행이 8개를 넘으면 기본으로 켜지므로**(`searchable ?? rows.length > 8`), 이 표들은 대부분 검색할 수 있으면서 검색 결과를 말해 주지 못했습니다.

## 검색 중에는 설명과 건수를 둘 다 보여줍니다

새 순수 모듈 `web/src/components/tableSummary.ts` 의 **`tableCaption({description, total, matched, searching})`** 하나가 캡션을 정합니다. `DataTable.tsx` 는 그 호출로 바뀐 **한 줄**입니다.

- **검색 중** — `설명 · 전체 1,240개 중 3개 일치`, description 이 없으면 `전체 1,240개 중 0개 일치`. 일치가 0건이어도 **전체 규모와 0을 함께** 말합니다.
- **검색 전** — 출력이 이전과 **한 글자도 같습니다.** description 이 있으면 description, 없으면 `1,240개 항목`. 검색하지 않는 화면의 문구는 변하지 않습니다.
- `searching` 은 `query.trim()` 으로 판정하므로 **공백만 입력**해도 캡션이 움직이지 않습니다 — 그때 `filtered` 는 전체이고 「1,240개 중 1,240개 일치」는 아무것도 말해 주지 않습니다.

**손대지 않은 것**: `filtered` 의 useMemo, 페이지를 되돌리는 effect, `clampPage`/`safePage`/`slice`, 기본 `rowKey`, Empty 분기, `filtered.length > 10` 페이저 조건, CSV 내보내기. 프로덕션 파일은 **두 개**입니다.

## 테스트

`web/test/tableSummary.test.mjs` 가 순수 함수를 고정합니다 — 검색 전 출력 보존, 검색 중 두 형태, 0건, 공백 입력, 천 단위 구분자. 테스트 수는 121 → 130 입니다.

순수 함수만으로는 **배선**을 증명하지 못하므로 거기서 멈추지 않았습니다. vite dev 로 **진짜 `DataTable`** 을 실제 React·MUI 로 마운트하고 headless Chrome 으로 1,240행 표를 여섯 경우 돌려 DOM 에서 읽었습니다.

- 수정 전, 설명이 있고 3건이 일치할 때 — `{"caption":"첫 페이지별 … 대상입니다.","pager":null,"rows":3}` — 1,240 중 3건인데 건수가 캡션에도 페이저에도 없습니다.
- 수정 후 — `첫 페이지별 … 대상입니다. · 전체 1,240개 중 3개 일치`.
- 설명이 없는 표는 수정 전 `3개 항목` 으로 **전체 규모를 잃었고**, 수정 후 `전체 1,240개 중 3개 일치` 입니다.

긴 description 뒤에 건수를 이어 붙인 캡션의 줄바꿈도 봤습니다 — 720px 폭에서 두 줄로 감싸고 부모 `Box` 를 넘치지 않습니다.

## 그 밖에

Go 쪽 변경은 없습니다. Database Migration, SDK, API, 환경변수 변경 없음.
