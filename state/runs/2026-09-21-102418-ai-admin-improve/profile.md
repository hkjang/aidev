# ai-admin 프로필 (2026-09-21)
- 목적: 폐쇄망에서 AI 공급자·사용자/RBAC·API 키·승인·레거시 AI Portal 데이터를 관리하는 단일 컨테이너 콘솔(v1.2.23, 기준 e41932a).
- 스택: Go 1.26(go.mod toolchain 1.26.6, 정찰 로컬 1.26.7), chi/pgx/go-oidc, PostgreSQL 16+, React 19/TypeScript/Vite 8/antd 6/TanStack Query, Vitest/jsdom.
- 구조:
  - `cmd/ai-admin`, `internal/config`: 시작·환경변수 4개·고정 :8080.
  - `internal/server`: REST/AI 프록시/MCP/레거시/승인/감사/설정/SSO 핸들러 및 통합 테스트.
  - `internal/auth`, `internal/keyscope`, `internal/secrets`: 세션·API 키·RBAC·scope·암호화.
  - `internal/database`: DB pool, seed, 번호순 내장 SQL migration 001~005.
  - `internal/settingscatalog`: 설정 카탈로그·검증·레거시 YAML 매핑; system_setting이 런타임 설정 저장소.
  - `internal/tracking`: 방문 추적·nonce CSP; `internal/ui/dist`: 커밋된 내장 SPA 산출물.
  - `web/src`: React 화면·API 클라이언트·silentSso 유틸·Vitest 테스트.
  - `docs`: API/security/architecture/operations 및 사용자·관리자 가이드/PDF/캡처; `scripts`: 캡처·버전/오프라인 패키지 검증.
- 현재 코드와 과거 기록의 차이: 고정 커밋에 internal/mail·006 migration·MCP OAuth 추가 패키지가 없다. 과거 성공 기록만으로 존재한다고 가정하지 말 것.
- 빌드·테스트:
  - `go test -count=1 ./...`, `make lint` 이번 정찰에서 통과. server 0.025초는 DB 통합 실행 결과가 아니다.
  - `go test -v -count=1 ./internal/server -run '^TestListUsersRejectsOverlongQuery$'`는 TEST_POSTGRES_DSN 미설정으로 SKIP 확인.
  - 전용 폐기 DB로 TEST_POSTGRES_DSN 설정 후 `go test -race -count=1 ./...`; 통합 전체는 과거 약 1분 이상, 이번 시간 미측정.
  - TEST_KEYCLOAK_ISSUER도 설정해야 실제 OIDC E2E 실행. CI는 PostgreSQL 16·Keycloak 26.7.2·Go 1.26.6·Node 26을 준비.
  - `cd web && npm ci && npm test && npm run build`; 명령 정의 확인, 이번 웹 테스트/빌드 미실행. jsdom timeout 15초.
  - `make build`는 웹 빌드 후 internal/ui/dist 교체 및 바이너리 생성: 정찰에서는 실행하지 않음.
- 관례: fix/feat/docs/chore 접두 한국어 또는 영어 커밋. VERSION/CHANGELOG/웹·문서 버전 동기화는 릴리즈 작업. writeError(status, code, 한국어 메시지), API 계약은 docs/api.md.
- 위험 구역: internal/auth, server/auth_handlers.go·oidc.go(세션/SSO), workflow.go(승인 트랜잭션), database/migrations, .github/workflows, internal/ui/dist. 레거시 범용 조회는 읽기 전용·전용 allowlist만 쓰기 가능.
- 자주 깨지는 곳: 조회 오류를 0/빈 배열로 숨기는 처리, DB 컬럼 상한보다 느슨한 입력 검증, 같은 값의 소비 경로별 계약 불일치. listUsers q·키 소유자 활성 검사는 과거 해결; safeCSVCell tab/CR도 현재 해결됨.
- 검증 함정: DB 통합 테스트가 DROP SCHEMA하므로 운영/공유 DB 금지, 같은 DB로 병렬 실행 금지. DSN 없으면 skip이라 -v 결과 확인 필수. Keycloak E2E는 별도 서비스 의존.
- 검증 함정: Pages CI는 index/README/캡처 스크립트/실제 WebP가 정확히 44개로 일치해야 한다. 캡처 하나만 추가하면 실패.
- 정찰 확인: 최근 git log -30·CI 3개·README·주요 docs 및 후보 코드를 읽음. 저장소 및 확인한 상위 경로에 AGENTS.md/CLAUDE.md 없음; 로드맵/TODO/FIXME 검색 결과 없음. 원격 CI 실행 결과·실제 DB 재현·웹 검증은 미확인.
- 스킬 가용성: 요청된 pmo/technology 세 스킬과 Skill 도구를 찾지 못했으며 고유 절차는 적용하지 못함. 별도 사용자 절차로 정찰 산출물을 작성.
