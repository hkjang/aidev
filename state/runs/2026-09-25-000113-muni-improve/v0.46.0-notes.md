한글 제목의 문서를 내려받을 때 **파일 이름이 제목을 잃고 `document.md` 로 저장되던 것**을 고쳤습니다. 화면은 바뀌지 않았고, 마이그레이션도 설정 변경도 없습니다.

## 고친 것

### 한글 제목이 `filename*` 을 통째로 무효로 만들던 것

muni 의 모든 내려받기는 `Content-Disposition` 에 파일 이름을 두 번 적습니다 — 아무것도 모르는 클라이언트를 위한 ASCII `filename="document.md"`, 그리고 제목을 실제로 실어 나르는 `filename*=UTF-8''…`. 뒤의 것을 RFC 8187 은 **ext-value** 라고 부르는데, ext-value 는 URL 경로가 아니라 헤더 토큰입니다. 짧은 attr-char 집합 밖의 모든 것은 퍼센트 인코딩되어야 하고, 그러지 않으면 그 매개변수는 매개변수이기를 그만둡니다.

네 경로가 같은 `filename*` 에 **서로 다른 인코딩을 넣고 있었고, 어느 쪽도 그 규칙이 아니었습니다.**

- **문서 내려받기 · 발표자료 내려받기 · 첨부 내려받기** 는 주소를 만들 때 쓰던 다섯 글자 치환기(`%`, 공백, `#`, `?`, `"`)를 그대로 가져다 썼습니다. 한글 제목의 UTF-8 바이트는 매개변수 안에 raw 로 남았고, 헤더 파서는 그것을 받지 않습니다 — `mime.ParseMediaType` 이 **값 전체를 잘못된 매개변수로 거부**하므로, 이름을 다시 읽는 쪽(`internal/handoff` 의 `filenameOf` 가 muni 가 보낸 헤더에 대해 정확히 그 일을 합니다)은 아무것도 얻지 못하고 ASCII 쪽 `document.md` 로 떨어졌습니다. **제목 길이와 무관하게 모든 한글 제목**이 그랬습니다.
- 더 나쁜 경우가 있습니다. **제목에 쌍반점이 있으면 헤더는 파싱에 성공하면서 틀린 값을 줍니다.** 쌍반점에서 매개변수가 끝나므로 `구분;키=값.md` 는 `구분` 으로 잘려 돌아오고, 오류는 아무 데도 남지 않습니다.
- **넘겨받기**(`/api/v1/handoff/claims/{claim}`)는 `url.PathEscape` 로 더 가까웠지만, 그 함수는 URL 경로에서 합법인 `=` · `:` · `@` 를 남겨 둡니다. 매개변수 안의 `=` 하나면 파서가 값 전체를 거부하기에 충분합니다.

이제 파일 이름 전용 `extValueEscape`(`export.go`)가 **attr-char(영숫자와 `` !#$&+-.^_`|~ ``) 밖의 모든 바이트를 한 바이트씩 대문자 16진수로 퍼센트 인코딩**합니다 — RFC 8187 의 예시가 쓰는 바로 그 형태입니다. 네 경로가 이 하나의 규칙을 씁니다. 공백도, 쌍반점도, 따옴표도, 한글 음절의 모든 바이트도 예외가 없습니다.

검증은 **프로덕션 치환기와 비교하지 않았습니다** — 그러면 자기 자신과만 일치합니다. 라우트가 만드는 모양 그대로 헤더를 짓고, 그것을 **받는 쪽 파서**(`mime.ParseMediaType`, 곧 `filenameOf` 가 부르는 것)로 다시 읽어 원래 제목과 룬 단위로 같은지 봅니다.

**바뀌지 않은 것:** ASCII 쪽 `filename="document.md"` 와 확장자, 자르는 길이 100, `safeFilename` 의 치환과 절단(v0.45.0)은 한 바이트도 달라지지 않습니다. 영숫자와 attr-char 만으로 된 이름(`quarterly-report_v2.final`)도 전과 똑같이 그대로 나갑니다 — 규칙이 요구하는 것보다 더 escape 하면 안전하지만 읽을 수 없게 되므로, 경계를 정확히 그 자리에 두었습니다. **워크스페이스 ZIP 내려받기(`export.zip`)는 `filename*` 자체가 없어 이번 범위 밖으로 두었습니다** — 남아 있는 다섯 번째 자리입니다.

단위 테스트 셋(헤더를 지어 파서로 다시 읽는 제목 13건, attr-char 가 그대로 남는지 3건, 그 밖의 문자가 escape 되는지 10건)과 실제 라우트를 도는 live 테스트 셋(문서 내려받기, 첨부 내려받기, 넘겨받기 표 회수)이 이것을 지킵니다. 여섯 모두 고치기 전에 먼저 실패하는 것을 확인했고, 헬퍼 본문만 되돌리자 그 여섯과 기존 `TestAClaimIsIssuedOnceAndRedeemedOnce` 가 다시 실패해 인과를 확정했습니다.

v0.45.0 이 **"이 헤더는 아직 `mime.ParseMediaType` 을 통과하지 못한다"** 고 테스트에 적어 두었던 알려진 공백이 이번에 닫혔습니다. 그 주석과 `t.Logf` 도 함께 걷어냈습니다. 검증은 받는 쪽 파서로 했고, **실제 브라우저가 저장하는 이름까지 확인하지는 않았습니다** — 인코딩은 RFC 8187 이 정한 형태 그대로입니다.

## 업그레이드

마이그레이션과 설정 변경은 필요하지 않습니다. 화면은 손대지 않았고, 서버는 내려받기 헤더에 파일 이름을 적는 자리만 v0.45.0 과 다릅니다.

```bash
gzip -dc muni-v0.46.0.tar.gz | docker load
docker compose -f compose.example.yaml --env-file .env up -d
```

**이미 내려받은 파일의 이름은 그대로입니다.** 이 고침은 헤더를 만드는 순간에만 적용되므로, `document.md` 로 저장된 파일은 다시 내려받으면 제목으로 저장됩니다.

## 오프라인 설치

릴리스 asset 에는 `muni:v0.46.0` Docker 이미지가 포함되어 있습니다.

```bash
gzip -dc muni-v0.46.0.tar.gz | docker load
docker image inspect muni:v0.46.0

cp .env.example .env
# .env의 네 값을 운영 환경에 맞게 변경합니다.
docker compose -f compose.example.yaml --env-file .env up -d
```

애플리케이션이 반드시 필요로 하는 런타임 환경변수는 다음 네 개입니다.

| 환경변수                   | 설명                                 |
| -------------------------- | ------------------------------------ |
| `POSTGRES_DSN`             | PostgreSQL 접속 문자열               |
| `BOOTSTRAP_ADMIN`          | 최초 관리자 아이디 또는 이메일       |
| `BOOTSTRAP_ADMIN_PASSWORD` | 최초 관리자 비밀번호(12자 이상)      |
| `ENCRYPTION_KEY`           | base64로 인코딩한 32-byte master key |

PDF 변환 동작만 조정하는 선택 환경변수가 두 개 있습니다.

| 환경변수               | 기본값    | 설명                                       |
| ---------------------- | --------- | ------------------------------------------ |
| `MUNI_CHROMIUM_PATH`   | 자동 탐색 | PDF Export에 사용할 headless 브라우저 경로 |
| `MUNI_PDF_CONCURRENCY` | `2`       | 동시에 실행할 Chromium 프로세스 수(1~32)   |

## 운영 정보

- 서비스 포트: `8080`
- Liveness: `/healthz`
- Readiness: `/readyz`
- REST API: `/api/v1`
- 공개 링크: `/s/{token}` — 인증 없이 열리는 유일한 화면입니다
- 문서 넘기기: `/handoff?source&claim` (받는 쪽, 세션 필요, 허용 목록의 오리진만) · `/api/v1/handoff/claims/{claim}` (내주는 쪽, 인증 없이 5분짜리 단일 사용 표로만 열립니다)
- 메일 알림: 사내 SMTP 릴레이로 1분마다 배경 발송, 기본 꺼짐 · 발송 기록 `/api/v1/admin/mail/deliveries` (관리자 인증 필요)
- OpenAPI: `/api/openapi.yaml` — 실제 라우트와 일치하며, 테스트가 그것을 지킵니다
- Prometheus: `/metrics` — 관리자 인증 필요
- MCP: `/mcp`
- Momento 프록시: `/momento/*` — 방문 추적을 Momento 로 켜 둔 동안에만 답합니다
- 지원 DB: PostgreSQL 15 이상
- 이미지에는 PDF Export용 Chromium과 Noto CJK 글꼴이 포함되어 있습니다.
