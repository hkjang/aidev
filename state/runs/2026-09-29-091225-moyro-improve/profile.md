# moyro 프로필 (2026-09-29)
- 목적: Mattermost v4 API 호환 채팅에 작업·승인·자동화·지식·MCP를 얹은 자체 호스팅 협업 앱.
- 스택: Go 1.27.0, chi, pgx v5, PostgreSQL / React 18·TypeScript·Vite·Redux·MUI / Vitest·Playwright / Docker.
- 구조:
  - server/cmd/moyro: 서버 진입점; server/cmd/fakeoidc: 테스트 IdP(이전 프로필, 이번 미재검증).
  - server/internal/httpapi: compat_* 및 handlers.go는 /api/v4, native_*는 네이티브 API, router.go는 배선.
  - server/internal/{auth,teams,channels,posts,preferences,customprofile,bookmarks}: 도메인 서비스.
  - server/internal/{reminders,automations,ws,audit}: 워커·이벤트·비동기 감사.
  - server/internal/store/migrations: 번호형 checksummed 마이그레이션, baseline 수정 금지.
  - server/internal/pluginhost → rpcbridge: 플러그인 런타임, 웹은 webapp/src/plugins/runtime.ts → registry.ts.
  - webapp/src/{api,features,components}: React 앱; webapp/e2e: 브라우저 계약.
  - docs/: 가이드·OpenAPI·로드맵·사이트; scripts/: 검증·배포·캡처; deploy/: 개발 서비스.
