# git-ctx 프로필 (2026-09-20)
- 목적: 사내 GitLab·Bitbucket의 코드·문서를 색인하여 ACL을 지키는 MCP/REST 개발 컨텍스트와 관리 콘솔을 제공한다.
- 스택: Go 1.25.0, toolchain go1.26.6; SQLite(FTS5 빌드 태그)·PostgreSQL, 선택적 pgvector/Milvus/OpenSearch·Vault, Keycloak OIDC, 바닐라 JS 콘솔, Docker/Kubernetes.
- 기준: main@cf3b598, v0.77.14. 이전 기록의 성공과 현재 main 반영 여부는 다르다. ${VAR} 마스킹 예외·Authorization 공백 보존·MCP OAuth 리소스 토큰 변경은 이 트리에 없음. 다시 구현하지 말고 대상 기준을 먼저 확인한다.
- 구조:
  - cmd/git-ctx — 실행 진입점; internal/version/version.go — 릴리즈 버전 원본.
  - internal/contentsecurity — Sanitize·Revision, 마스킹과 재색인 지문; internal/indexer — 수집·청킹·정책.
  - internal/search — ACL 적용 검색·원격 소스·ReadFile, 의존성 분석; internal/manifest — 매니페스트·락파일 인벤토리.
  - internal/mcp — 도구 dispatch·정책·응답 예산·캐시; internal/app — HTTP 배선; internal/auth — OIDC·키·세션.
  - internal/store — SQLite/PostgreSQL 스키마·migration; test/store — 빌드 모드 교차·옛 릴리즈 업그레이드 검증.
  - web — JS 관리 콘솔; test/web — 계약 테스트·실제 브라우저 render-sweep.
  - docs — requirements.md·configuration.md·operations.md·test-plan.md·completion-audit.md·openapi.yaml·릴리즈 노트.
  - scripts — 릴리즈·버전 동기화·오프라인 이미지 패키징/검증; .github/workflows — CI·릴리즈 게이트.
- 빌드·테스트: `go build -tags sqlite_fts5 ./...`; `go vet ./...`; `go test -tags sqlite_fts5 ./...`(수 분), `go test -tags sqlite_fts5 -race ./...`(더 오래 걸림).
- 빠른 검증: `go test -tags sqlite_fts5 ./internal/contentsecurity ./internal/mcp` 및 `go test -tags sqlite_fts5 ./internal/indexer ./internal/search` — 이번 정찰 exit 0. 전체 suite·race는 이번 미실행.
- 형식: `gofmt -l ./cmd ./internal` 출력이 비어야 함. JS: `for file in web/app.js web/clients.js web/guides.js web/roles.js; do node --check "$file"; done`; `for file in test/web/*.test.js; do node "$file"; done`.
- 관례: 최근 커밋은 영어 fix(scope): … / release: vX.Y.Z. 설정은 카테고리별 JSON, 버전 동기화는 scripts/verify-version-sync.sh, 릴리즈 절차는 scripts/release.sh. 마이그레이션은 store가 관리.
- 위험 구역: internal/auth·app의 인증/세션/ACL; internal/store migration·백업 복원; .github/workflows와 scripts 릴리즈 게이트; internal/version/version.go 및 연결된 버전 문서.
- 자주 깨지는 곳: 마스킹이 줄바꿈이나 비밀 이외 텍스트까지 삭제함. 정규식 외 동작만 바꾸면 Revision이 그대로여서 기존 색인에 개선이 안 적용될 수 있음. 매니페스트 확장 반려 2건(제공 기록), 같은 접근 재시도 금지.
- 검증 함정: 기존 curl 테스트는 URL만 검사하므로 명령어 소실을 못 잡음. truncation_test 일부는 예산+320을 허용. 공유 Sanitize는 색인·ReadFile·원격 검색에서 사용하므로 최종 출력도 검사해야 함.
- 검증 함정: CI 통합은 GIT_CTX_TEST_POSTGRES_DSN·GIT_CTX_TEST_PGVECTOR_DSN·GIT_CTX_TEST_VAULT_URL/TOKEN을 설정하며 로컬 미설정 시 skip 가능. 실제 DB가 필요한 검증은 이번 미실행.
- 검증 함정: govulncheck@v1.7.0은 갱신되는 DB에 의존; grpc는 현재 v1.83.2. CI는 별도로 Docker와 실브라우저 및 옛 태그 업그레이드를 실행. 네트워크 가용성은 이번 미확인.
- 정찰 환경: 저장소 내부 CLAUDE.md·AGENTS.md·별도 roadmap 파일은 검색에서 발견되지 않음. 요청한 pmo/technology 3개 스킬과 Skill 호출 도구도 발견하지 못했으므로 스킬 반환 형식은 미확인.
