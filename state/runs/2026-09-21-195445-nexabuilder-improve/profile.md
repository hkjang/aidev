# nexabuilder 프로필 (2026-09-21)
- 목적: 엔티티·폼·목록·워크플로 메타데이터로 업무 화면을 만드는 Spring Boot 로우코드 플랫폼과 관리 콘솔.
- 스택: Java 21, Spring Boot 4.1.1, Gradle 8.14.3 Kotlin DSL, JPA/JdbcTemplate, Liquibase XML, 기본 H2와 외부 DB 프로필, Thymeleaf/Bootstrap/htmx/jQuery 4+migrate/jqWidgets, Groovy, POI 5.3.0/OpenPDF 3.0.5.
- 구조:
  - src/main/java/com/nexabuilder/core/ui — NexaUiService, 목록·폼·atom 정의. requireLiveList가 정의/builder 데이터/내보내기의 존재+deletedAt 판정 공통화.
  - core/data — DataAdapterService, jqxgrid용 Rows/totalCount 조회. queryList는 아직 공통 판정 미사용(이번 과제).
  - core/entity·core/sql — 동적 엔티티 DDL/DML, SQL 메타데이터 실행과 DB별 페이징.
  - core/* — permission, auth, session, audit, llm/ai, menu, version 등 도메인 서비스.
  - api/controller·api/dto — REST와 ApiResponse; GlobalExceptionHandler의 IllegalArgumentException 매핑은 400 JSON.
  - web/controller·resources/templates·resources/static — 서버 화면과 브라우저 UI. nexa-data.js는 layout에서 전역 로드.
  - infra/security·infra/web·plugin/groovy — 필터·세션/토큰 보안, Jackson 2 호환, Groovy 실행.
  - resources/db/migration — Liquibase 001~079 XML 및 changelog-master.xml; 027이 목록/폼/엔티티 deleted_at 추가.
  - src/test — 파일 152개, api 패키지 Java 파일 146개. SpringBootTest/MockMvc/H2 통합 테스트와 일부 단위 테스트.
  - docs/ — 개발·운영·사용자 문서; README/roadmap/agent.md 일부 버전과 환경 설명은 낡음.
- 빌드·테스트: 로컬 `sh ./gradlew --no-daemon test`; 단일 클래스는 `--tests 'com.nexabuilder.api.DataAdapterIntegrationTest'`; 패키징 `sh ./gradlew --no-daemon bootJar -x test`. 전체 강제 실행 `sh ./gradlew --no-daemon cleanTest test`는 수 분/테스트 힙 2g.
- 검증 현황: 이번 정찰 BuilderListDataSoftDeleteIntegrationTest+ListExportIntegrationTest 7건 성공(30초). 전체 575건 성공·컨텍스트 22개는 이전 회차 기록이며 이번에 재측정하지 않음.
- 관례: Lombok 생성자 주입, UUID 테스트 픽스처 격리. 최근 커밋은 한국어 type(scope): …합니다, 버전 커밋/PR merge는 영어. Liquibase 새 XML을 master에 include. 설정은 application.yml과 nexa_config 런타임 설정을 함께 사용.
- 위험 구역: core/auth·core/session·infra/security·core/permission, DB migration, workflow의 비동기 감사·종료 경합. Jackson2JsonConfig에는 removal 경고가 있어 Jackson 3 이전은 별도 큰 작업.
- 자주 깨지는 곳: @DirtiesContext로 컨텍스트 재생성하면 시간/힙/비동기 종료 경합 악화. webjar 버전 고정 URL은 404, jQuery 4에서 migrate 제거 시 jqWidgets 오류(이전 기록).
- 검증 함정: gradlew는 100644이므로 로컬 sh 사용; CI는 chmod 후 직접 실행하고 setup-java Temurin21 사용. foojay가 로컬 누락 JDK를 다운로드. CI는 test+bootJar, CodeQL은 public 저장소에서만 실행.
- 검증 함정: DataAdapter queryList는 nullable pageSize를 int로 언박싱하므로 이번 삭제 테스트 픽스처에는 페이지 크기를 명시. GET 어댑터는 Rows/totalCount이며 builder API의 success/data 형식과 다름.
- 검증 함정: SQL 어댑터와 엔티티 어댑터의 컬럼 키 대소문자 처리가 다름. PDF 한글 글리프는 환경 폰트 의존(이전 기록). 전체 외부 서비스 의존 여부는 이번 미확인.
