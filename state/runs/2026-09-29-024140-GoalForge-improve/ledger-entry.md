- 과제서와 달라진 점(중요): 과제서가 제시한 프로브(`git push <bare> HEAD:refs/...`, 경로 직접 지정)는 **오작동한다.** 차단 기전을 직접 재현해 확정했다 — 하네스는 `GIT_CONFIG_COUNT=2`/`remote.origin.pushurl=DISABLED`/`credential.helper=`(빈값) 을 주입하며, 이는 **`origin` 이라는 이름의 remote 에만** 걸린다. 경로를 직접 준 push 는 그대로 성공한다(직접 실측). 따라서 경로 프로브는 통과해 버리고 정작 테스트는 `origin` 으로 밀다 죽는다. 프로브를 테스트가 실제로 쓰는 remote 이름(`origin`)을 지나가도록 바꿨다 — 맨 git 이라는 성질은 유지되고 충실도는 오히려 높다. 정찰이 "미확인" 으로 남긴 기전을 이번에 확증했다.
