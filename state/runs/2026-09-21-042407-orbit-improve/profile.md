# orbit 프로필 (2026-09-21)
- 목적: 인간관계를 궤도로 시각화하고 교류·기억을 기록하며 승인·AI·MCP로 활용하는 자체 호스팅 웹 앱.
- 스택: Go 1.26.6, chi v5, pgx v5, go-oidc v3, PostgreSQL(compose 18-alpine, README/DB 테스트 예시 16-alpine); React 19·TypeScript 6·Vite 8·MUI 9·Vitest 4/jsdom/testing-library.
- 구조:
  - cmd/orbit — 실행 진입점, version/commit/builtAt ldflags.
  - internal/server — HTTP 라우팅(server.go), 인증(auth.go/throttle.go), 사람·교류·궤도(data.go), 과거 궤도(timetravel.go), AI/MCP, 승인, 관리자 설정, 개인 기록 내보내기.
  - internal/server/timetravel_db_test.go — openTestStore/seedUser/seedPerson/seedInteraction, 실제 DB orbitRange 회귀 테스트.
  - internal/store — pgxpool 연결·embed migrations 001~005 순차 적용·Bootstrap; settings는 namespace/key/value 구조.
  - internal/config·internal/secure·internal/id — 실행 설정·암호화·식별자.
  - internal/webui/dist — 단일 Go 바이너리에 임베드되는 웹 산출물.
  - web/src/pages·components — React 화면·OrbitCanvas·TimeTravel; 순수 로직은 timeTravel.ts/eclipse.ts 등과 옆 테스트.
  - docs — API.md·ARCHITECTURE.md·guide.md·cru-manual.md·OFFLINE.md, 홍보 HTML·PDF·이미지·영상.
- 빌드·테스트: 루트 `go test ./...` 정찰에서 통과(캐시). DB 없으면 SQL 테스트는 SKIP.
  - `ORBIT_TEST_DATABASE_URL='<격리된 DB DSN>' go test -count=1 -v ./internal/server -run TestOrbitRange`는 기존 opt-in 테스트 명령; `go test -race ./...`는 CI 명령.
  - 웹 `cd web && npm ci && npm run test -- --run`; `cd web && npm run build`는 tsc -b + vite build. 이번 정찰에서 웹 테스트 미실행, node_modules 없음.
  - `make build`는 npm ci/웹 빌드→internal/webui/dist 복사→Go 빌드; `make docker`는 이미지 빌드(다운로드 포함 시 오래 걸림).
- 관례: feat/fix/perf(scope): 한국어 설명, chore(release): vX.Y.Z; VERSION으로 릴리즈 버전 관리. 현재 기준 main@e4a2ca0, v0.6.2.
  - 설정은 settings 표 + 관리 콘솔, DB 변경은 NNN_name.sql; 코드 주석·사용자 가이드는 주로 한국어.
- 위험 구역: auth.go·throttle.go(세션/OIDC/키/로그인 잠금), internal/secure(사용자 데이터 키), internal/store/migrations(기존 데이터/번호), .github/workflows(배포·권한).
- 자주 깨지는 곳: 제공 기록에 실패/롤백 교훈 없음. 미머지 SSO·추적·handoff·메일·MCP OAuth가 마이그레이션 006~009 및 ADMIN_GUIDE를 따로 사용했다는 과거 기록 있음; 원격 현재 병합 상태는 미확인.
- 검증 함정: 과거 프로필과 달리 main에 DB 테스트 있음. openTestStore는 실제 store.Open 마이그레이션을 적용하고 사용자 cascade로 정리하므로 전용 DB만 사용한다; Bootstrap은 사용하지 않는다.
  - CI는 postgres 서비스/ORBIT_TEST_DATABASE_URL 없이 Go -race·Vitest·웹 빌드·Docker 빌드. SQL 테스트가 SKIP돼도 CI는 초록.
  - main에 fakeIDP/newDBServer/mcpoauth.go는 없음. 다른 브랜치 테스트 헬퍼가 있다고 가정하지 않는다.
  - npm lint 스크립트는 있지만 eslint 의존성/설정이 없고 CI에서도 실행 안 함. WSL /mnt/에서 Vite는 polling.
  - first_met은 date, created_at/occurred_at은 timestamptz; 시점 경계는 DB TimeZone 및 실제 반환값 왕복으로 확인해야 한다.
  - 최근 개선: 슬라이더는 커밋 때만 요청, 페이지는 마지막 요청만 반영; orbitRange는 두 표 독립 집계. 두 개선을 되돌리지 않는다.
  - docs/cru-manual.md의 예시 API/테이블과 현재 코드 일부가 다름; API 설명은 실제 라우트/핸들러에서 확인한다.
