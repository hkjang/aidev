- 기준: main@eba092b, VERSION 1.69.58. 2026-10-06 프로필과 버전·문서 상태가 달라 갱신.
- 구조:
  - server/cmd/ptium: 실행 진입점. internal/httpapi·mcp: REST/MCP, auth: 인증.
  - internal/db: 기동 마이그레이션·시드, settings/store: 설정/영속화.
  - internal/docs: CSV/TSV/XLSX/DOCX/PDF/MD/TXT → 덱 소스. docs.go:Read 확장자 분기.
  - internal/docs/prose.go:readMarkdown(205), readWordDocument. writer.go:deckWriter는 Word/PDF/Markdown 공유.
  - internal/docs/listmarker.go:withoutListMarker는 목록 마커·UTF-8·음수 보존 계약.
  - internal/deck: 덱 DSL 파싱/컴파일. pptx: PPTX/SVG/PDF 출력. golden: 출력 회귀.
  - internal/generation: 생성/워커; mail·analytics·handoff: 알림/추적/전달.
  - web/src/pages·components: 편집기/관리; GuidePage.tsx:GuidePage는 제품 내 사용 안내.
  - docs/USER_GUIDE.md: 정본 가이드, docs/deck-source.md: DSL, api/openapi.yaml: API 계약.
