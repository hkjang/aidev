# orbit 프로필 (2026-09-21)
- 목적: 인간관계를 궤도로 시각화하고 교류·기억을 기록하며 승인·AI·MCP로 활용하는 자체 호스팅 웹 앱.
- 스택: Go 1.26.6·chi v5·pgx v5·go-oidc v3, PostgreSQL(compose 18-alpine, README/DB 테스트 예시 16-alpine), React 19·TypeScript 6·Vite 8·MUI 9·Vitest 4/jsdom/testing-library.
- 구조:
  - cmd/orbit — 실행 진입점과 빌드 버전.
  - internal/server — 라우팅·인증·사람/교류(data.go)·과거 궤도(timetravel.go)·AI/MCP·승인·관리·내보내기.
  - internal/server/timetravel_db_test.go — openTestStore/seedUser/seedPerson/seedInteraction, 실제 DB orbitRange 테스트.
  - internal/store — pgxpool·embed migrations 001~005·Bootstrap. store.Open이 마이그레이션을 적용.
  - internal/config·internal/secure·internal/id — 설정·사용자별 암호화·식별자.
  - internal/webui/dist — 단일 Go 바이너리 내장 웹 자산.
  - web/src/pages·components — React 화면·OrbitCanvas·TimeTravel. 순수 계산과 테스트는 web/src에도 위치.
  - docs — API.md·ARCHITECTURE.md·guide.md·cru-manual.md·OFFLINE.md 및 PDF/홍보 자산.
- 빌드·테스트: 루트 `go test ./...` 이번 정찰 통과(캐시); DB SQL 테스트는 DSN 없으면 SKIP.
  - `ORBIT_TEST_DATABASE_URL='<전용 DB DSN>' go test -count=1 -v ./internal/server -run TestOrbitRange`는 실제 DB 테스트. 공유/운영 DB 사용 금지.
  - 웹 `cd web && npm ci --no-audit --no-fund`, `cd web && npm run test -- --run`, `cd web && npm run build`(tsc -b + vite build).
  - 이번 정찰 웹 미실행(node_modules 없음). 로컬 Node v22.23.1/npm 10.9.8, CI Node 24.
  - `make build`는 npm ci·웹 빌드·내장 자산 복사·Go 빌드; `make docker`는 이미지 빌드(다운로드 시 오래 걸림).
- 관례: feat/fix/perf(scope): 한국어 설명, chore(release): vX.Y.Z; VERSION 관리. 현재 main@e4a2ca0, v0.6.2.
  - 설정은 settings 표 namespace/key/value 및 관리 콘솔, 마이그레이션은 NNN_name.sql, 문서는 docs/.
  - CLAUDE.md/AGENTS.md·독립 로드맵·TODO/FIXME는 검색에서 발견 못함.
- 위험 구역: internal/server/auth.go·throttle.go(세션/OIDC/키/잠금), internal/secure(암호화), internal/store/migrations(영구 데이터), .github/workflows(배포 권한).
- 자주 깨지는 곳: 제공 기록에 롤백 없음. 직전 first_met 시작일 확대 과제는 no-change, 원인 미확인; 반복 선택하지 않는다.
  - 과거 성공 기록의 SSO·추적·handoff·메일·MCP OAuth는 현재 main 파일 구성과 다르다. 다른 브랜치 헬퍼를 있다고 가정하지 않는다.
- 검증 함정: CI는 postgres/ORBIT_TEST_DATABASE_URL 없이 Go -race·웹 테스트/빌드·Docker 빌드를 수행하므로 DB 테스트 SKIP도 초록.
  - openTestStore는 store.Open을 사용하고 Bootstrap은 미사용. 테스트 사용자를 삭제해 cascade 정리한다.
  - web/vitest.config.ts는 jsdom, src/test/setup.ts에서 afterEach cleanup. 실제 페이지 테스트는 아직 없음.
  - MUI 9 Slider는 pointer 이벤트·buttons:1·포인터 캡처 보완 필요. 커밋은 마지막 onChange 값 기준.
  - OrbitCanvas에는 ResizeObserver가 필요하며 getContext가 null이면 그리기 effect만 조기 종료.
  - npm lint 스크립트만 있고 eslint 의존성/설정은 없다. CI에서도 lint 미실행.
  - first_met은 date, created_at/occurred_at은 timestamptz. 시간 경계는 DB TimeZone 및 반환값으로 확인.
  - 완료된 슬라이더 커밋 최적화·createLatestGuard 양쪽 응답 검사·orbitRange 독립 집계를 되돌리지 않는다.
  - OrbitPage는 오류/빈 결과 조기 반환에서 TimeTravel까지 숨기는 문제가 있어 이번 구현 과제로 선정(아직 수정 안 됨).
  - docs/cru-manual.md의 일부 API/표 설명은 현재 코드와 다름. API 설명은 실제 핸들러를 정본으로 삼는다.
