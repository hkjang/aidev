# madi 프로필 (2026-09-22)
- 목적: 사람과 AI가 함께 쓰는 한국어 자체 호스팅 지식관리 서비스; 오프라인 서비스 이미지 하나로 제공.
- 스택: Go 1.26.8, PostgreSQL, React 19·TypeScript 5.9·Vite 7, Node 22, Playwright; Docker runtime Alpine 3.24.1 digest 고정.
- 기준: main@fd2c3b5(v0.3.0 후보). git log -30은 전체 10개 커밋만 반환. 과거 성공 기록의 390b53e/83239b9/e8e0960/8451b5b/5dc7f95 및 MCP OAuth는 이 기준에 반영되지 않음.
- 구조:
  - cmd/madi: 실행 진입점; internal/server: HTTP·문서·검색·RAG·작업·인증 등 단일 대형 서버 패키지.
  - internal/server/*.sql: 스키마; 기동 시 멱등 CREATE/ALTER 관례, backup_tables.go는 백업 대상 목록.
  - web/src: React 화면; personalization/naturalDate.ts와 auth/silentSso.ts는 직접 Node 시험 가능한 순수 함수.
  - web/embed.go: all:dist 임베드; 현재 추적 web/dist 파일 없음. Go 전체 빌드보다 웹 빌드가 먼저 필요.
  - tests: Node/Playwright 및 deployment-contract·image-smoke Go 패키지.
  - scripts: 이미지 빌드·검증, 문서 생성, 논리 외부 PostgreSQL 백업/복원 도구.
  - deploy: Kubernetes 예제·runtime-apk.lock; 현재 APK 사전 점검 스크립트 없음.
  - docs: 사용자/관리자/API 등 Markdown 정본, manuals/는 scripts/build-docs.mjs 생성물.
- 빌드·테스트: `cd web && npm ci && npm run build`는 tsc -b와 vite build 둘 다 수행; 이후 `go build ./...`, `go vet ./...`.
- 좁은 확인: `go test -count=1 ./tests/deployment-contract`, `node --test tests/natural-date.mjs tests/silent-sso.mjs`는 이번 정찰에서 통과.
- 전체 검증: CI는 PostgreSQL17 및 Chromium과 기능별 MADI_BROWSER_* 옵션을 켜 `go test -race -failfast -count=1 -timeout 45m ./...`; 상당히 오래 걸리므로 국소 변경마다 반복 금지.
- 호환성 CI: PostgreSQL17/18 × Chromium/Firefox/WebKit, `TestBrowserCompatibility` 옵션 게이트. release.yml은 호환성 이후 전체 검증·이미지 배포.
- 관례: 영어 conventional commits, 한국어 사용자 문구; settings jsonb 평면 키 및 별도 비밀 설정 관례. README·docs·BUILD_PLAN.md·FULL_SCOPE.md·OPERATIONS_UPGRADE.md에 범위 기록. 현재 CLAUDE.md/저장소 AGENTS.md 없음.
- 위험 구역: integrations_oidc.go·identity_saml.go·server.go의 인증, SQL 스키마·backup_tables.go의 복원 계약, .github/workflows의 필수 검증, Dockerfile/lock/대응 소스의 일치.
- 자주 깨지는 곳: 과거 성공 커밋을 main에 있다고 가정하기; web/dist 없는 상태로 Go 전체 빌드; 전체 -race와 브라우저 중복 실행으로 러너 예산 소진; 여러 읽기 경로 중 하나만 수정.
