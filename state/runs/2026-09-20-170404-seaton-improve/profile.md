# seaton 프로필 (2026-09-20)
- 목적: 사무실 도면 위 좌석을 편집하고 직원을 배정·검색하는 오프라인 우선 SeatOn 서비스.
- 스택: Go 1.24 / chi v5·pgx v5·go-oidc v3 / PostgreSQL 14+ 지원 문서, CI는 16-alpine / React 19·TypeScript·MUI·Vite·vitest·Playwright.
- 구조:
  - `cmd/seaton/`: 서버 진입점 및 Docker 빌드에서 프런트 dist 임베드.
  - `internal/app/`: HTTP·OIDC·좌석·인사·도면 CV/VLM·대시보드·키·MCP·설정·추적.
  - `internal/database/`: pgx pool, 시작할 때 migrations.sql 전체 실행. 별도 버전 마이그레이션 도구 없음.
  - `internal/platform/`: 환경변수·설치별 암호화 키. `internal/tracking/`: 스니펫·nonce·CSP.
  - `web/src/pages/`: 화면, `lib/`: 화면 판단 함수와 테스트, `api.ts`·`auth.tsx`: API·세션 처리.
  - `web/e2e/`: 실서버 Playwright, seed.mjs(실제 CV 분석 시드), helpers.ts(복구), guide-shots.mjs(캡처).
  - `docs/`: Markdown 정본 및 HTML/PDF·화면 캡처, `scripts/`: 문서 생성·이미지 릴리즈.
- 빌드·테스트:
  - `go test ./...`, `go vet ./...`. 이번 정찰에서는 go test 성공(app/tracking 캐시). database 패키지는 테스트 없음.
  - `cd web && npm ci && npm test && npm run build`; `npm run lint`는 tsc 검사다.
  - `docker build -t seaton:e2e .`; 실제 PostgreSQL과 서버를 기동한 뒤 `cd web && E2E_BASE_URL=http://127.0.0.1:8080 E2E_USERNAME=admin E2E_PASSWORD=... npx playwright test` (준비 포함 수 분~10분 이상).
  - `python3 scripts/build-docs.py USER_GUIDE`는 해당 HTML만 생성. 가이드 PDF는 aidev 공용 md2pdf를 사용한다.
- 관례: 최근 커밋은 한국어 feat/fix/docs/test/chore 접두가 일반적. README·가이드가 운영 정본이며 CLAUDE.md/AGENTS.md는 저장소에 없다. TODO/FIXME 검색 결과 없음.
- 설정: 런타임 환경변수는 POSTGRES_DSN·BOOTSTRAP_ADMIN·BOOTSTRAP_ADMIN_PASSWORD, 나머지 기능 설정은 settings 테이블. 프런트와 서버 오류는 `{error:{code,message}}` 계약.
- 위험 구역: auth.go(세션·CSRF·OIDC·권한), migrations.sql(매 시작 실행), MCP 범위 검사, tracking CSP·도면 PDF 응답, .github/workflows.
- 주의 계약: seats.go의 createSeat는 organizationId 미지정 null/생략, updateSeat는 빈 문자열일 때 해제하고 null/생략은 보존. 빈 문자열을 생성에 보내면 조직 FK 오류다.
- 자주 깨지는 곳: 이전 기록에 롤백 없음. e2e가 바꾼 좌석·배정을 복구하지 않으면 후속 테스트가 깨진다는 helpers.ts 주석이 있다. restoreSeat는 위치만 복구한다.
- 미머지 변경: 로컬 refs 기준 auto/2026-09-16-1022(메일), auto/2026-09-18-0413(MCP OAuth)이 main에 미포함. main에는 메일·OAuth 토큰 기능이 없다. 원격 최신 PR 상태는 미확인.
- 충돌 주의: 두 브랜치는 SettingsPage·ADMIN_GUIDE·API_AND_MCP·openapi 등을 함께 변경. 메일은 seats.go, OAuth는 auth.go 변경. SeatMapPage는 두 브랜치의 merge-base 이후 변경 목록에 없다.
- 검증 함정: CI Node 24, 정찰 로컬 Node v22.23.1. npm 실행 금지 근거는 없으나 web/node_modules가 없어 프런트 테스트는 미실행. Docker 명령 존재만 확인, daemon·이미지·브라우저 실행은 미확인.
- 검증 함정: Playwright 기본 URL은 127.0.0.1:18781, CI는 명시적으로 8080. globalSetup은 서버를 띄우지 않고 실서버를 시드하며 workers=1.
- 검증 함정: CI e2e는 --network host. tracking.spec의 테스트 수집기를 Linux 브리지 컨테이너에서 부르려면 host.docker.internal 해석 및 E2E_COLLECTOR_HOST 설정이 필요하다.
- 검증 함정: Go 단위 테스트 성공은 DB/UI 배선을 보증하지 않는다. 실제 기능 변경은 실서버+DB+브라우저로 증명하고 외부 사내 IdP/VLM/수집기 실서비스 검증은 별도다.
