# Quantoss 프로필 (2026-09-21)
- 목적: 토스증권 Open API 기반 국내·미국 자동 매매·모의/백테스트·전진 검증을 수행하고 Pages·리포트·알림으로 운영 현황을 게시하는 Go 에이전트.
- 스택: Go 1.26(go1.26.7 linux/amd64 실측), coder/websocket, Anthropic SDK(go.mod에는 indirect). DB 대신 JSON/JSONL·파일 캐시, docs 정적 HTML/JS.
- 구조:
  - cmd/quantoss — 단일 CLI, agent/backtest/research/swing/laoer/copilot/doctor/verify 등 진입점.
  - internal/config — Default·FromEnv(.env/환경변수)·Validate·ForMarket·VersionHash. gap 네 필드의 유한성/범위 검증은 이미 구현됨.
  - internal/toss — REST/WS·OAuth 토큰 캐시·TPS limiter. Client.Sleep은 request 백오프용이며 nil이면 time.Sleep; limiter는 별도 대기.
  - internal/engine·broker·risk·strategy·indicators — 매매 판단·체결·리스크. broker 2단 매도/서버 손절 복원 보호 필요.
  - internal/swing·backtest·exitlab·selection·evaluation — 일봉/저빈도 전략과 연구. runner 청산은 마지막 봉 판정 유지.
  - internal/perf·journal·report·deck — 포지션 성과, JSONL 기록, 리포트·HTML 덱. weekly는 perf.ComputeFn 사용.
  - internal/agent·github·notify·copilot·funding — 데몬·게시·알림·확인 명령·자금 계획. LLM은 의도 분류용.
  - internal/universe·yahoo·catalyst·fundamentals·stockinfo·ontology — 가격·종목·공시 정보 수집.
  - docs — Pages와 docs/PROPOSALS.md 설계; docs/reports·reports는 보고서; testdata/dashboard는 브라우저 시험 데이터.
  - scripts — 운영 실행/서비스와 check_dashboard.sh. 일반 check.sh·.github/workflows는 없음. internal/zz_dbg는 태그 전용 스크래치.
- 빌드·테스트: go build ./... / go vet ./... / gofmt -l . / go test -count=1 ./... 이번 통과, 포맷 출력 없음.
- 빌드·테스트: go test -count=1 -race ./internal/notify 통과(1.020s). 전체 race와 scripts/check_dashboard.sh는 이번 미실행.
- 빌드·테스트: 전체 테스트 패키지 시간 broker 7.713s, engine 2.007s, config 0.015s, toss 0.363s. 전체 벽시계는 미계측.
- 관례: 한국어 설명형 커밋. 최근 git log -30은 live.json/리포트 자동 게시. 설정은 .env 및 QUANTOSS_*/TOSS_* 환경변수. DB 마이그레이션 없음.
- 관례: CLAUDE.md·AGENTS.md·별도 TODO/ROADMAP 파일 및 Go/Markdown TODO/FIXME 검색 결과 없음. README의 단계 표와 docs/PROPOSALS.md가 계획 문서.
- 위험 구역: broker/live.go 중복 주문·미확정 체결·서버 손절 복원, toss 인증/공유 토큰(발급 시 다른 프로세스 무효화), copilot 확인/실매도, swing/runner.go 전략별 계약, ForMarket/VersionHash.
- 위험 구역: notify.send는 HTTP 오류에 토큰/웹훅 URL이 포함되어 로그에 남는 결함 확인(이번 구현 과제, 아직 미수정). copilot.Bot.call에는 별도 토큰 마스킹이 이미 있음.
- 자주 깨지는 곳: 미국 가격 %.0f, 리터럴 nil 필드, 스윙 누락 일봉, 체결 레코드와 포지션 통계 혼용. 구체적 반려/롤백 목록은 제공되지 않음.
- 검증 함정: 성능 비교는 -count=1 사용. broker 자체 sleep과 limiter 대기는 남음. 테스트 통과가 로그 비밀 비노출을 보장하지 않음(기존 notify 실패 테스트에 로그 단언 없음).
- 검증 함정: zzdbg는 실API·운영자 절대경로·실거래 토큰을 쓰므로 실행 금지. 워크플로 쓰기 권한 미확인; CI 추가보다 로컬 스크립트 우선.
- 검증 함정: FromEnv는 .env/프로세스 환경을 읽으므로 환경 테스트는 임시 작업 디렉터리/t.Setenv로 격리하고 병렬화하지 않는다. slog.SetDefault 캡처도 병렬화 금지, 비동기 Send 완료를 동기화할 것.
- 검증 함정: check_dashboard.sh는 Chrome·Python HTTP 서버·포트 의존. 일반 Go 테스트와 분리되어 있으며 이번 브라우저 동작은 미확인.
