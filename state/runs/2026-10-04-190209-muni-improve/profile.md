# muni 프로필 (2026-10-04)

- 기준: main@b84a38b / VERSION 0.52.0. 직전 프로필(2026-09-29)은 dc7ad1e·0.50.0 기준이었고, 그 뒤 9e19ea8·c991f0b 두 수정으로 **한 항목이 어긋나** 새로 씁니다(아래 ★).
- 목적: 폐쇄망 배포용 협업 문서 편집·검토·버전 관리와 다중 형식 가져오기/내보내기를 주는 단일 바이너리 서비스.
- 스택: Go 1.27.0, PostgreSQL 15+(CI 16-alpine), React 19·TypeScript·Vite·MUI 7·Tiptap 3·Yjs; PDF 내보내기에 Chromium.
- 구조:
  - `cmd/muni` 기동, `internal/config` 부트스트랩 환경변수, `webui` 프런트 번들 embed.
  - `internal/httpapi`: 인증·문서·import/export·관리·outbox·tracking·handoff·AI 라우트가 한 패키지(약 25,000줄)에 전부 있고 live 테스트가 같은 패키지에 섞여 있음. 라우트 표는 `server.go:100~` 한 곳.
  - `export.go`: `renderExport`/`exportFile`/`safeFilename`(308)/`cutFilenameRunes`(335)/`extValueEscape`/`urlPathEscape`/`fullHTML`/`renderHTML`. `safeFilename` 은 문서 내려받기·발표자료·워크스페이스 ZIP 이름·ZIP 항목 이름·폴더 세그먼트 다섯 경로가 공유 — 본문을 바꾸면 파급이 넓음. `/ \ CR LF NUL` 만 치환하므로 `: * ? " < > |` 는 남는다(Windows 미확인 후보).
  - ★ **Content-Disposition 다섯 자리는 이제 완전히 통일됨** — escape·ext-value(v0.46~0.47)에 이어 ASCII fallback 확장자까지(c991f0b). `import_attachments.go:678` 은 비공개 헬퍼 `asciiFallbackExt`(점 + ASCII 영숫자 + 12자 이하)로 안전할 때만 확장자를 붙인다. 남는 차이는 fallback 기본 낱말(document/presentation/workspace/attachment)뿐 — 라우트마다 달라야 하는 값이라 통합 가치 없음. 수신 쪽 파서는 `internal/handoff/handoff.go` 의 `filenameOf`(= `mime.ParseMediaType`).
  - ★ `ai.go:238` `truncateRunes(value,max)`(넘치면 「[…문서 컨텍스트가 길어 일부 생략됨…]」 덧붙임)은 **더는 DB 이름/제목 절단에 쓰이지 않는다**(9e19ea8 로 제목 2·`attachments.name` 3·편집기 응답 1 = 여섯 자리가 `cutFilenameRunes` 로 옮겨감). 남은 `truncateRunes` 자리: 머리말·꼬리말 200(`import_attachments.go:174,330,331`), `mail.go:91,98`, AI 호출부(`ai.go:94`, `ai_patch.go:193`, `ai_tools.go:220,325`).
  - `import_attachments.go`: `parseUpload`/`importDocument`/`importIntoDocument`/`storeImportedDocument`/`uploadAttachment`/`downloadAttachment`. `upload.titleInBody` 가 .md/.html/.htm/.docx 신규 가져오기에서 참. 멀티파트 `header.Filename` 과 `r.FormValue("title")` 은 길이 검사 없이 들어와 `cutFilenameRunes(…,240)` 로만 잘린다(어떤 문자도 치환되지 않음).
  - `import_markdown.go`: `dropLeadingTitle` 은 확정 제목과 **정확히** 같은 첫 level-1 heading 만 제거(240룬 초과 제목에서 H1 중복이 남는 기존 공백). `splitTableRow` 는 끝 파이프를 TrimSuffix 하지 않음.
  - `workspace_export.go`: `exportWorkspace`(스트리밍 ZIP)/`folderPaths`(200)/`safeFolderSegment`(271)/`uniqueEntryName`(281)/`maxWorkspaceExport=2000`. 한도 판정은 `LIMIT maxWorkspaceExport+1` 로 읽고 `truncated` 를 정한 뒤 2000건으로 자른다(86476c4). `workspaceManifestName = "목록.md"` 는 문서 순회 **전에** `used` 에 예약된다(a8f56b6, `:149`). `uniqueEntryName` 의 `used` 맵은 **대소문자를 구분**한다(이번 회차 과제). `ORDER BY d.folder_id NULLS FIRST, d.title` 만 있어 동률 순서는 비결정적.
  - `internal/richdoc` 문서 JSON·블록 ID; `internal/docx,hwp,hwpx,pdfx,hangul` 형식 처리; `internal/database/migrations` 번호순 SQL(`documents.title`·`attachments.name` 은 길이 제한 없는 `text`); `internal/settings` DB 설정·비밀값 봉인.
  - `frontend/src`(pages/components/features/lib), `frontend/e2e`(Playwright), `frontend/scripts`. docs: USER_GUIDE/ADMIN_GUIDE(md·pdf), ARCHITECTURE, OPERATIONS, MCP, releases. 저장소 CLAUDE.md·AGENTS.md·로드맵 파일 없음.
- 빌드·테스트: `go test ./...`, `go vet ./...`, `gofmt -l .`, `scripts/check-webui-placeholder.sh`. `make test` = placeholder + Go + npm run lint + npm test. 프런트: `cd frontend && npm ci && npm run lint && npm test`(lint 가 `tsc -b` 타입 검사). `npm run build` 는 수 분. **`make build` 는 tracked `webui/dist/index.html` 을 덮으므로 정찰에서 돌리지 않음.**
- 관례: 커밋 메시지 한국어 `feat:`/`fix:`/`docs:`/`build:`. VERSION + `docs/releases` 로 릴리스 기록. 설정은 부트스트랩 환경변수와 `app_settings` 두 층. 주석은 "왜" 를 산문으로 길게 쓰는 편 — 새 코드도 그 밀도에 맞출 것. 테스트 이름도 문장형(`TestAWorkspaceExport…`). 아직 못 고친 결함은 테스트 안에 '알려진 공백' 주석 + `t.Logf` 로 남기는 관습이 있고, 그 자리를 고칠 때 주석도 함께 걷어낸다. 최근 다섯 회차는 모두 **실제 라우트를 지나는 live 테스트로 먼저 실패시킨 뒤** 고치고, 수정 한 줄만 되돌려 그 테스트만 다시 실패하는 것으로 인과를 확정했다 — 이 형식을 지킬 것.
