# Momento 프로필 (2026-09-26)
- 목적: 온프레미스에서 이벤트를 수집·소유하고 제품·직원·경험·AI 사용을 분석하는 사내 분석 플랫폼.
- 기준: main@715e60b, v0.34.44. 2026-09-20 프로필을 갱신함 — 그때 "미머지 주의" 로 적어 둔 origin/auto/2026-09-17-0103(비밀번호 재설정·문자 수 최소 길이)과 origin/auto/2026-09-18-1143(MCP OAuth)은 PR #13·#14 로 **모두 main 에 있다**(08f752a, 91e0f50). 미머지 브랜치 경고는 해제.
- 스택: Go 1.26.0(toolchain 1.26.7), net/http+chi, pgx, go-oidc, PostgreSQL 17; React 19/TypeScript/MUI 7/Vite/react-query; TypeScript 수집 SDK.
- 구조:
  - cmd/momento — 서비스 진입점.
  - internal/httpapi — REST/MCP 핸들러(admin.go 에 사용자·설정·역할 게이트), server.go 라우터, 실제 DB 통합 테스트.
  - internal/service — Collector·Worker·Automation·Maintenance(maintenance.go 가 이 디렉터리).
  - internal/auth — 세션·API 키·OAuth 주체. `roleRank`(auth.go:229), `RoleAtLeast`, `RoleAbove`(239) 가 역할 서열의 정본.
  - internal/database — 연결과 Migrate/MigrateThrough; embedded SQL 정본은 internal/database/migrations/001~018.
  - 루트 migrations/ — 001_initial.sql 하나뿐. 정본과 혼동 금지.
  - internal/privacy, secret, segment, insight — 개인정보·암호화·세그먼트·분석.
  - web/src/pages, components, contexts, api — 화면·공용 표(components/DataTable.tsx)·컨텍스트·API 호출.
  - web/src/pages/*.ts (확장자 .ts, 컴포넌트 아님) — 화면에서 뽑아낸 순수 로직 12개(passwordRule, visitorTrace, queryPolicyForm, mcpOauth …). web/test/*.test.mjs 23개가 이것을 `"../src/pages/X.ts"` 처럼 **확장자까지 적어** import 한다(node:test, tsconfig.app.json 의 allowImportingTsExtensions).
  - sdk/ — 브라우저 수집 SDK; scripts/guide/ — 실제 배포를 시드하고 puppeteer-core 로 가이드 캡처.
  - docs/ — 사용자/관리자 가이드와 PDF, ARCHITECTURE, ROADMAP, openapi.yaml. ROADMAP_PLAN 은 오래된 비전 문서.
- 빌드·테스트:
  - Go: `make test`, `go test -race ./cmd/... ./internal/...`(httpapi 60~70초), `go vet ./cmd/... ./internal/...`.
  - 웹: `cd web && npm ci && npm run lint && npm test && npm run build`(test = `node --test test/*.test.mjs`, build = `tsc -b && vite build`). **worktree 에 web/node_modules 가 없으므로 npm ci 가 선행**.
  - SDK: `cd sdk && npm ci && npm run typecheck && npm test && npm run build`. 전체 산출물은 `make build`.
- 관례: 한국어 conventional commit 이 주류(`fix(web): …`). 설정은 DB settings 테이블 + 환경변수. Migrate 는 advisory lock 으로 직렬화. 화면 순수 로직을 .ts 로 분리해 node:test 가 직접 import 하는 것이 이 저장소의 테스트 가능성 패턴이며 새 로직도 그 자리로 간다.
- 위험 구역: internal/auth(역할 서열·세션), internal/httpapi/admin.go·server.go(역할·세션·사이트 경계), internal/database/migrations, .github/workflows, docs/openapi.yaml(라우트 계약 테스트가 읽는다). 서버 검사가 권한의 정본이고 화면은 거울일 뿐 — 화면 게이팅을 이유로 서버 검사를 느슨하게 하지 말 것.
- 자주 깨지는 곳:
  - 순수 모듈 import 에서 `.ts` 확장자 누락 → node:test 가 모듈을 못 찾는다(2026-09-20 회차에서 실제로 걸림).
  - TestRetentionReportsEachUnattendedPass(integration_privacy_test.go) 가 전체 -race 실행에서 finished_at<started_at 로 한 번 실패한 기록이 있다(플레이크, 2026-09-26 재현 미확인).
  - 2026-09-20~22 세 회차가 「필수 technology 스킬 원문 부재」로 변경 없이 끝났다. 스킬이 실리지 않으면 회차가 통째로 낭비되므로 착수 전에 확인할 것.
