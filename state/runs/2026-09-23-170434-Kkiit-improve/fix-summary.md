# 수리 요약 (2026-09-23)

- 비평 두 건 모두 재현되어 맞았다. 스모크는 `POST .../policies: 400` 으로 77번 줄에서 죽었고(재현 로그 확인), 잘못된 조건이 저장된 행은 PUT 전환이 400 으로 막혔다.
- `updateApprovalPolicy`: 검증 실패 시 저장된 `conditions` 와 본문이 완전히 같으면(`storedPolicyConditions` + `DeepEqual`) 조건을 그대로 둔 채 나머지만 재검증해 통과시킨다 — 끄기·삭제가 모두 막히는 상태를 없앴다. *다른* 잘못된 값으로 바꾸는 것은 계속 400.
- 스모크: 잘못된 배열 두 케이스를 `400 + invalid_policy + 키 이름` 기대로 바꾸고, 같은 행을 psql 로 직접 심어 카드·레이아웃 검증 9→11 케이스를 모두 되살렸다. 심은 행으로 화면 전환 on/off 와 "조건을 바꾸면 여전히 거절" 까지 새로 검증한다.
- 검증(모두 실제 실행): 스모크 전체 PASS(11 케이스·docker·Chrome), `go test ./cmd/... ./internal/...` 통합 포함 PASS(새 DB, 86s), `npm --prefix web test` 10건, eslint, gofmt, go vet. 새 통합 테스트는 수정을 임시로 되돌리면 그 자리에서 400 으로 실패함을 확인했다.
- 단언을 느슨하게 하거나 테스트를 지우지 않았다. `internal/ui/dist` 의 기존 미커밋 빌드 산출물은 건드리지도 커밋하지도 않았다.
