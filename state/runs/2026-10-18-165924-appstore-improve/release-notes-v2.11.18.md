AppStore v2.11.18

즐겨찾기 화면이 검색 때문에 비었는지 담아 둔 앱이 없어서 비었는지 구분하지 못하던 문구 결함을 고친 patch 릴리스입니다.

- `/favorites` 에서 검색어를 넣어 맞는 앱이 없을 때도 "즐겨찾기한 앱이 없습니다" 와 "앱 상세 또는 카드에서 하트를 눌러 보관하세요" 가 보였습니다. 담아 둔 앱이 그대로 있는데도 보관함이 비워진 것처럼 읽혔습니다.
- 이제 검색어나 MCP·추천 조건으로 좁혀진 0건은 "검색 조건에 맞는 즐겨찾기 앱이 없습니다" 와 "검색 조건을 지우면 보관한 앱이 다시 보입니다" 로 알려 주고, **검색 조건 지우기** 버튼을 같은 자리에 둡니다.
- 그 버튼은 검색어·MCP·추천·페이지만 지웁니다. 보기 방식과 정렬, 카테고리는 고른 그대로 남습니다.
- 좁히는 조건이 없는 진짜 빈 보관함은 종전 문구와 안내를 그대로 유지합니다. 즐겨찾기가 브라우저에 저장되는 방식과 개수 표시·페이지 이동은 바뀌지 않았습니다.
- 실제 화면·라우터·API 클라이언트를 쓰고 HTTP 경계만 바꾼 React 테스트는 137건입니다(v2.11.17의 133건 +4). 실제 번들의 desktop·mobile E2E는 89건 통과(1건 skip)이며 검색 0건 안내와 조건 지우기를 함께 확인합니다.
- 버전 표기, 사용자 가이드의 즐겨찾기 안내와 사용자·관리자 가이드 PDF를 갱신했습니다. 전체 화면 캡처 90개를 재생성했으며 90개 모두 v2.11.17과 동일합니다.

schema 변경은 없습니다. 기존 설치는 image만 교체하면 됩니다.
