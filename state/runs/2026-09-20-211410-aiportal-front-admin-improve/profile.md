# aiportal-front-admin 프로필 (2026-09-20)

- 스택: Vue 3.5.25, vue-router 4.6.3, axios 1.19.0, TypeScript 5.9.3, Vite 7.3.6, vitest 4.1.11, jsdom 30.0.1. Java/Python API 연동, 이 프런트에 DB 없음.
- 구조:
  - 루트 src/·package.json: 운영 레거시 Vue 앱. mode별 Vite build.
  - upgrade/admin-v2/src/api/: http.ts envelope/pageInfo 처리, 기능 API와 mock.ts.
  - upgrade/admin-v2/src/modules/: overview·operations·policy·catalog·directory·content 화면과 테스트.
  - upgrade/admin-v2/src/auth/·src/app/router.ts: legacy session, SSO·만료 handler, 관리자 guard.
  - upgrade/admin-v2/src/shared/: async.ts 요청 순서, routeQuery.ts 딥링크, paging.ts·format.ts.
  - upgrade/admin-v2/src/config/·public/config/runtime.json: 런타임 URL 허용목록, 기능 flag. 정책 쓰기 기본 false.
  - upgrade/admin-v2/scripts/·deploy/: 설정/오프라인/integrity 검증과 배포 지원.
  - docs/: 루트 문서·ROADMAP. upgrade/admin-v2/docs/ARCHITECTURE.md와 QUICK_WINS.md: V2 화면/API 계약.
- 빌드·테스트: upgrade/admin-v2에서 npm ci(이번 설치 미실행), npm run verify(typecheck+vitest), npm run build(verify+vite+설정/offline/integrity, 전체 게이트).

- 위험 구역: auth/·app/router.ts(SSO 반복/세션 경합), .gitlab-ci.yml(사내 배포와 노출 자격증명; 값 복제 금지), scripts/ 배포 게이트. backend RBAC 전 정책 쓰기 flag 활성화 금지.
