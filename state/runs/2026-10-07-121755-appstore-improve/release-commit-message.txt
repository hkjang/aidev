Migration

서버·schema 변경은 없습니다. 기존 설치는 image만 교체하면 됩니다.
internal/webui/dist는 기존 관례대로 유지하며 Dockerfile이 번들을 새로 빌드합니다.

검증: Go race 전체 패키지·vet·gofmt, 새 React 번들을 embed한 Go build,
React 111건, lint(--max-warnings 0)·Prettier·build, 오프라인·환경·문서 검사 통과.
Playwright --workers=2 --retries=2는 retry 없이 81 passed/1 skipped입니다.
Skip 1건은 desktop 프로젝트의 모바일 전용 테스트입니다. DB DSN 미설정으로
DB 통합 검증은 skip이며 실제 DB·Keycloak·SecCheck는 검증하지 않았습니다.
Docker build/load/smoke, SHA-256 및 GitHub Release 게시는 태그 워크플로가
수행합니다. 이 세션에서는 원격 전송을 수행하지 않았습니다.
