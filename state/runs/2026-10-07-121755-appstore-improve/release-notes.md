AppStore v2.11.16

보안 심의 화면의 "최종 결과" 가 영문 내부값을 그대로 보여 주던 문제를 고친 patch 릴리스입니다.

- 소유자가 `/my/apps/:id/security` 에서 확인하는 "최종 결과" 를 `APPROVED`·`CONDITIONAL`·`REJECTED` 대신 승인됨·조건부 승인·반려됨으로 표시합니다.
- 결과가 없으면 종전처럼 — 를, 알 수 없는 값이면 받은 원문을 보여 줍니다.
- 조건부 승인은 앱 제출 허용을 뜻하지 않습니다. 제출 가능 여부는 기존 서버의 verified 판정을 그대로 따릅니다.
- 프로덕션 화면·라우터·실제 API 클라이언트를 쓰고 HTTP 경계만 바꾼 Vitest 6건을 더했습니다(전체 111건). Desktop·mobile E2E에서도 최종 결과 행을 확인합니다.
- 버전 표기와 사용자·관리자 가이드 PDF를 갱신했습니다. 전체 화면 캡처 90개를 재생성했으며 88개는 v2.11.15와 동일합니다.

schema 변경은 없습니다. 기존 설치는 image만 교체하면 됩니다.
