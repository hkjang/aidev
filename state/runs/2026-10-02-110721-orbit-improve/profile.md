- 검증 함정:
  - CI 에 postgres 가 없어 DB 시험은 전부 SKIP 된다. DB 변경·DB 시험은 DSN 을 직접 주고 PASS 를 봐야 증거가 된다.
  - 끊긴 행 스트림을 결정적으로 만드는 정본 기법: settings_db_test.go:30~58 breakUsersRowStream — 테이블을 RENAME 후 동명 뷰로 가리고 특정 행에서만 `::int` 로 터뜨린다. t.Cleanup 으로 반드시 원복, t.Parallel 금지. ORDER BY 가 블로킹 Sort 면 잘린 결과는 1행이 아니라 0행이고 오류는 rows.Err() 에만 남는다.
  - openTestStore 는 store.Open(ctx,dsn,nil), Bootstrap 미사용. seedUser/seedPerson/seedRelationship/seedPersonLink(timetravel_db_test.go:41~88)·seedNamedUser(settings_db_test.go:18) 재사용. seedPerson 은 display_name 을 고정하므로 이름이 필요하면 변형을 만들 것.
  - AI 시험의 settings 행은 전역이므로 기존 행 백업·복원, 병렬 금지. encrypted_value='' + 기억 0건이면 nil Vault 로도 맥락 조회 가능.
  - people.first_met 만 date, 나머지 시각은 timestamptz. time.Time 비교는 Equal.
  - people 컬럼은 001_init.sql:73~87 의 13개가 전부(이후 ALTER 없음). relationships 는 003 에서 anchored 추가.
  - requestHasScope 는 컨텍스트에 authInfo 가 없으면 true 를 준다 — MCP 시험에서 스코프 설정이 불필요하다.
  - Vitest 는 jsdom + src/test/setup.ts. MUI Slider pointer/hasPointerCapture, OrbitCanvas ResizeObserver 스텁이 필요하다는 과거 기록이 있다.
  - `npm run lint` 는 eslint devDependency 가 없어 돌지 않고 CI 도 lint 미실행. Docker/Make 는 설치 래퍼, CI 는 직접 npm ci.
