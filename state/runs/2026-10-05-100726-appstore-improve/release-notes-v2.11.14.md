AppStore v2.11.14

`/my/apps/:id/edit` 에서 앱을 찾지 못하면 쿼리 라이브러리의 영문 내부 문구가 한국어 UI 에 그대로 보이던 문제를 고친 patch 릴리스입니다.

- 내 앱 목록에 그 id 가 없으면 화면에 "화면을 불러오지 못했습니다" 와 함께 ``["my-app","<id>"] data is undefined`` 가 보였습니다. 영문 내부 문구에 쿼리 키 원문까지 붙은 것입니다.
- 삭제된 앱의 수정 주소를 북마크했거나 남의 앱 id 를 넣은 소유자가 이것을 읽었고, 돌아갈 링크도 없어 화면에서 막혔습니다.
- 이제 "앱을 찾을 수 없습니다" 와 `내가 등록한 앱` 으로 돌아가는 링크를 보여 줍니다. "없음" 을 오류가 아닌 정상 데이터로 다루고, 로딩과 오류 분기 뒤에서만 판단하므로 불러오는 중에 깜빡이지 않습니다.
- 401·500 같은 실제 HTTP 오류는 그대로 오류 화면과 "다시 시도" 로 남습니다. "없음" 과 "오류" 를 섞지 않았습니다.
- 프로덕션 라우터·Provider·실제 API 클라이언트를 쓰고 HTTP 경계만 바꾼 Vitest 4건을 더했습니다(전체 103건).
- 버전 표기와 사용자·관리자 가이드 PDF를 갱신했습니다. 화면 캡처 90개 중 89개는 v2.11.13과 동일합니다.

schema 변경은 없습니다. 기존 설치는 image만 교체하면 됩니다.
