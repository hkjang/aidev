# Orbit v0.6.4 — 런치 등급 판정 (marketing:product-launch)

**등급: 티어 3 (개선) — 릴리즈 노트만.**

- 변경 내용: `npm ci` 를 최대 3회 재시도 래퍼(`scripts/npm-install.sh`)로 감싸 레지스트리 일시
  장애가 Dockerfile 빌드·`make web` 을 죽이지 않게 함. 커밋 1개(fix(build)).
- 사용자에게 보이는 동작 변화: 없음. 제품 표면·API·UI 가 바뀌지 않는다. 빌드 파이프라인
  신뢰성만 올라간다.
- 대상: 이 저장소에서 오프라인 이미지를 빌드하는 사람. 그 밖에는 알릴 필요가 없다.
- 따라서 홍보·영업 브리핑·인앱 공지 없음. GitHub Release 의 자동 생성 노트가 전부다.
  (스킬 "Never": 팀이 자랑스럽다는 이유로 티어 3 변경에 티어 1 모션을 돌리지 않는다.)
- 릴리즈 후 관찰할 신호: 다음 회차 verify 와 태그 푸시 릴리즈 워크플로의 `npm ci` 단계가
  네트워크 오류로 죽는지. 그것이 이 변경의 유일한 채택 지표다. 발표 도달률이 아니다.

## 남은 노출 (릴리즈 범위 밖, 사람 몫)
`.github/workflows/ci.yml` 의 `npm ci` 는 같은 래퍼를 쓰지 않는다 — 보호 경로라 자동화가
손댈 수 없다. CI 는 `actions/setup-node` npm 캐시가 있어 노출이 작다. ideas.json 에 남아 있다.
