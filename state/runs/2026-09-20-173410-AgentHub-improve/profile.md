# AgentHub 프로필 (2026-09-20)
- 목적: 격리된 AI 런타임과 자동 작업을 정책·승인·DLP·감사로 통제하는 사내 플랫폼.
- 스택: Go 1.25(chi, pgx, go-oidc, OpenTelemetry), PostgreSQL, React 19/TypeScript/Vite, Kubernetes, Playwright/Node 22.
- 구조:
  - cmd/: control-plane, worker, runtime-proxy 실행 진입점.
  - internal/api/: 라우트 카탈로그·핸들러·인증·게이트웨이·단위/live 테스트.
  - internal/store/: PostgreSQL 저장소·마이그레이션·감사/메일 기록.
  - internal/execution/: 실행 및 이벤트 dispatcher; internal/mail/: 큐·릴레이 발송.
  - internal/dlp/, internal/tracking/: 내용 검사와 방문 추적/CSP.
  - web/src/: 사용자/관리자 콘솔; web/scripts/: 브라우저 e2e·캡처·Node 테스트.
  - deploy/kubernetes/: 클러스터 배포; Dockerfile.* 및 *_VERSION: 런타임 이미지.
  - docs/: ADMIN_GUIDE.md·USER_GUIDE.md와 PDF, architecture.md, decisions/의 검토/후속 계획.
- 빌드·테스트: 정찰에서 `go test ./internal/api ./cmd/runtime-proxy`, `node --check web/scripts/langflow-e2e.mjs`, `node --test web/scripts/silent-sso.test.mjs`(12건) 통과.
- 빌드·테스트: CI는 `go test -race ./cmd/... ./internal/...`; web/에서 `npm ci && npm run lint && npm run test:sso && npm run build`; `bash scripts/release-catalog-images.sh check-versions`; kustomize/compose 검사.
- 빌드·테스트: live DB 테스트에는 AGENTHUB_TEST_DSN 및 base64 32바이트 AGENTHUB_ENCRYPTION_KEY 필요. 기존 기록상 DB 테스트는 `-p 1` 권장. 대형 실제 에이전트 이미지 검증은 별도 live-agents.yaml(최대 90분).
- 관례: 한국어 문장/영어 conventional 커밋 혼용. system_settings는 키별 JSON 값+별도 secret 슬롯. 정본 가이드는 대문자 ADMIN_GUIDE/USER_GUIDE.
- 관례: main@6575e37, VERSION 0.249.0, BASE_VERSION 0.26.0. cmd/runtime-proxy와 internal/dlp 변경은 base 이미지 버전 및 관련 참조 상향 필요(이전 기록).
- 위험 구역: auth.go·mcpoauth.go·세션 게이트웨이·store migrations·.github/workflows. 정책 actor는 task.OwnerID, SCMTokenFor만 agent.OwnerID.
- 위험 구역: 감사 details에는 스크럽 전 원문 금지. DLP 재마스킹 bf1e062는 main에 없고 별도 브랜치에만 있음; 사람 판정 미확인으로 재구현 금지.
- 자주 깨지는 곳: gateway 문서와 엄격 API 디코더 불일치; 복사 필드의 중복/누락 스캔; 전역 설정 캡처 스크립트의 백업/복원; 문서 HTTP 메서드 오류.
- 검증 함정: GET /api/v1/admin/settings/{key}는 없다. 전체 GET의 body[key]를 읽고 PUT에는 {value: ...}를 보낸다. 조회 실패를 빈 설정으로 취급하지 말 것.
- 검증 함정: DSN 없는 go test 성공은 live 동작 증명이 아니다. 이번 정찰은 DB/browser live 미실행; 다른 서비스의 Docker 컨테이너가 있어도 테스트 DB로 재사용 금지.
- 검증 함정: 현재 web/node_modules 없음. scripts/*.mjs는 eslint의 src TS 범위 밖. release.yaml은 CI와 달리 test:sso를 실행하지 않는다.
- 검증 함정: Tasks.tsx는 run.modelName을 사용하며 서버 AgentRun의 JSON 태그도 modelName; 이전 보류의 대소문자 버그 주장은 근거 없어 rejected.
- 미확인: 현재 클러스터·Keycloak·SMTP 가용성. 요청된 세 부서 스킬은 현재 도구/로컬 검색에서 미발견. 루트 CLAUDE.md·별도 로드맵 파일도 미발견.
