AppStore v2.11.15

보안 심의 화면의 "앱 상태" 가 영문 내부값 `draft` 를 그대로 보여 주던 문제를 고친 patch 릴리스입니다.

- 소유자가 `/my/apps` 에서 들어가는 보안 심의 화면(`/my/apps/:id/security`)의 "심의 상태" 카드에서, "앱 상태" 가 서버가 보낸 DB enum 을 그대로 그렸습니다. 한국어 UI 한가운데서 "앱 상태: draft" 와 "pending_review" 가 보였습니다.
- 같은 카드의 "SecCheck 상태" 는 이미 한국어로 보여 주고 있었고, 관리자·내 앱·앱 상세는 모두 공용 표로 `초안`·`검토 대기` 라 부릅니다. 한 제품 안에서 같은 상태가 화면마다 갈렸습니다.
- 이제 심의 화면도 그 공용 표를 읽습니다. 라벨 표가 한 곳이라 화면 사이의 표기가 어긋날 수 없습니다. 배지의 색과 동작은 그대로입니다.
- 표에 없는 상태값은 종전처럼 받은 값을 그대로 보여 줍니다. 모르는 상태가 화면에서 사라지지 않습니다.
- 프로덕션 화면·라우터·실제 API 클라이언트를 쓰고 HTTP 경계만 바꾼 Vitest 2건을 더했습니다(전체 105건).
- 버전 표기와 사용자·관리자 가이드 PDF를 갱신했습니다. 화면 캡처 90개 중 87개는 v2.11.14와 동일합니다.

schema 변경은 없습니다. 기존 설치는 image만 교체하면 됩니다.
