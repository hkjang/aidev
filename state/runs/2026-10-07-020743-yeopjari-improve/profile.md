# 옆자리(yeopjari) 프로필 (2026-10-07)
- 기준: `main` 상태의 작업 트리 `cd18b14`. 2026-10-05 프로필을 갱신(테스트 수·신규 파일·머지 상태가 어긋났다). 운영 실환경은 검증하지 않았다.
- 목적: 회사 이메일 확인 기반 익명 커뮤니티, 기업 리뷰·연봉 집계, 업무 지역 중고거래를 클라우드와 오프라인 도커에서 제공한다.
- 스택: TypeScript/Node >=22, React 19·Mantine 9·Vite 8, PostgreSQL 16/RLS, postgres.js, Vitest 4, ESLint 9; Node 서버 esbuild 번들.
- 구조:
  - `packages/core/src`: 런타임 공통 app/http/routes/auth/settings/domain/jobs/reports/seo, JPEG 정제·storage·메일·SSO·AI·MCP. 라우트는 `routes/index.ts` 의 `buildRouter` 가 `router.merge(...)` 로 합친다.
  - `apps/server/src`: Node 어댑터와 `static.ts` StaticFiles, bootstrap·set-password·키 교체·공시·로고 수집 명령.
  - `apps/web/src`: React SPA(`main.tsx`, `components/ErrorBoundary.tsx`); `apps/web/public` 은 배포 정적 자산·헤더·robots.txt.
  - `functions/[[path]].ts`: Cloudflare Pages 어댑터(엣지 캐시 세대 10); `workers/scheduler`: cron 호출 Worker.
  - `db/migrations`: 번호순 SQL 스키마·RLS·함수·시드(최신 0050 대). `db/data`: 오프라인 기업 스냅샷.
  - `deploy`: PostgreSQL 포함 오프라인 Docker 이미지·entrypoint·백업. `supabase/functions`: heavy 어댑터.
  - `scripts`: migrate/seed/e2e, 문서 생성, 로고·공시·백업·측정·배포. `engineering`: architecture/security/performance/design 내부 문서. `docs`: `scripts/build-docs.mjs` 가 생성하는 공개 가이드(내부 문서를 넣지 않는다).
- 빌드·테스트:
  - 작업 트리에 `node_modules` 가 없다 — 먼저 `npm ci`(없으면 vitest exit 127).
  - `npm run check` = `npm run lint && npm run typecheck && npm run test`(3 워크스페이스 타입 검사).
  - `npm test` = `vitest run`; include `packages/**/*.test.ts`·`apps/**/*.test.ts`, Node 환경, timeout 20초.
  - 추적된 단위 테스트는 `packages/core/src/__tests__` 의 **26파일**. server/functions/web 에는 추적 테스트가 없다.
  - `npm run build`: core → web → server. `npm run dev` / `npm run dev:web` 존재.
  - 통합(느림·DB/서버 필요): `BASE=http://localhost:8787 DATABASE_URL=<격리 로컬 DB> node scripts/e2e.mjs`. migrate/seed/e2e 는 실제 DB·계정·설정·quota 를 바꾼다 — 운영 DB 금지.
- 관례: 커밋 메시지는 한국어 본문에 불릿으로 근거·날짜·수치를 적는다(접두사 혼용). npm workspaces(core/server/web). 소스 import 는 `.js` 확장자(`../util/validate.js`). 설정은 `.env.example`·`YEOPJARI_*` 와 `settings/registry.ts`(`def({type:'int', min, max, default})`). 마이그레이션은 `db/migrations` SQL 을 `scripts/migrate.mjs` 로 적용. `scripts/local.sh` 는 `~/.config/yeopjari/cloud.env` 를 읽으므로 무심코 실행하지 않는다.
- 위험 구역: `auth/`(session·cookies)·`http/pipeline.ts`·`db.ts`·`db/migrations` 는 익명성·행 격리·CSRF·MFA·권한에 직결. `functions` 의 엣지 캐시는 회원 응답 격리가 중요. `.github/workflows/release.yml`·`deploy`·`scripts/release.sh` 는 버전·태그·도커 배포 경로. 회원 사진·백업은 비공개, 기업 로고만 공개 버킷.
