AppStore v2.11.7

로그아웃하거나 관리 권한을 잃은 뒤에도 빠른 이동 팔레트(Ctrl+K)의 "최근 이동"이 관리자 메뉴를 계속 보여 주어, 익명 사용자가 닿을 수 없는 항목을 보고 누를 수 있던 문제를 고친 patch 릴리스입니다.

- `web/src/features/navigation/command-palette.tsx` 의 빈 검색 `results` 에서 localStorage 의 최근 목록을 현재 세션 기준으로 걸렀습니다. `menu:` 항목은 지금 세션의 `menuDestinations` 에 같은 id 가 있을 때만, `app-admin:` 은 `canManage` 일 때만 통과하며 `app:` 은 그대로 둡니다.
- localStorage `appstore.recentDestinations` 값은 지우지 않습니다. 다시 로그인하면 이전 최근 목록이 그대로 복원됩니다. 검색어를 입력했을 때의 결과와 이동 동작은 v2.11.6 과 똑같습니다.
- 프로덕션 `AuthProvider` 를 통해 관리자 세션과 익명 세션의 팔레트 표시를 검증하는 Vitest 2건을 더했습니다(전체 82건).
- 서버와 `internal/*` 는 바뀌지 않았고 schema 변경이 없어 기존 설치는 image만 교체하면 됩니다.
