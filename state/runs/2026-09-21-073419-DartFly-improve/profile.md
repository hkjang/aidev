# DartFly 프로필 (2026-09-21)
- 목적: 기존 Tadpole 메타 DB를 활용해 여러 DBMS 탐색·읽기 전용 SQL 실행·마스킹·감사·운영 관리를 제공하는 단일 바이너리 웹 플랫폼.
- 스택: go.mod Go 1.25.7, net/http·database/sql, MariaDB 메타 DB, MariaDB/MySQL·PostgreSQL·Oracle·SQL Server 드라이버; 임베드 HTML/CSS·ES 모듈 JS, Node 테스트, Python Playwright 스모크.
- 구조:
  - cmd/dartfly: 진입점; internal/app: 환경변수·서비스 기동.
  - internal/server: HTTP·세션 게이트·CSV; resultsave.go는 저장 결과 API.
  - internal/auth·sso·ssoconfig: 인증·서명 세션·OIDC·저장 설정.
  - internal/query·dbconn·masking: DB 실행·정책·마스킹·값 정규화.
  - internal/resultsave: 저장 결과 서비스; internal/store/mariadb: 저장소·마이그레이션.
  - internal/access·rbac·governance·settlement·retention: 권한·거버넌스·결재·보존 정리.
  - internal/apihub·mcphub: 외부 API/MCP; internal/webui: 임베드 pages/js/css, assets.go 서빙.
  - test/js: Node 회귀; test/livedb: 실제 DB; test/smoke: 실제 바이너리·배포 이미지·Chromium.
  - docs: 보증·설정·관리 가이드; deploy: 배포 스크립트·환경.
- 빌드·테스트: `go test -race ./...`, `go vet ./...`, `go build ./cmd/dartfly`; 정찰은 race 전체 통과(일부 캐시). 로컬 Go 1.26.7·Node 22.23.1, CI Go 1.25.x.
- 빌드·테스트: 화면 변경 시 `DF_SMOKE_REQUIRE_BROWSER=1 bash test/smoke/run.sh`(Docker·playwright·Chromium, 수분). 정찰에서는 미실행. CI는 artifact.sh로 배포 이미지도 실행.
- 빌드·테스트: `bash test/livedb/setup.sh --fast` 후 `set -a; . /tmp/dartfly-livedb.env; set +a` 및 `go test -tags livedb ./...`. 기본 전체 설정의 Oracle·SQL Server 준비는 오래 걸림.
- 관례: 한국어 feat:/fix:/test: 커밋과 PR 병합; 환경변수 DARTFLY_*·_FILE, SSO 저장 설정이 env 폴백보다 우선. 마이그레이션 파일은 internal/store/mariadb/migrations; 기존 설치 ALTER 관례는 이번 상세 미확인.
- 위험 구역: auth/session/SSO·return_to, 권한·마스킹·감사 정책, migrations, .github/workflows. CSV_FORMULA_GUARD는 서버 CSV 설정이며 TSV에는 현행 연동 없음.
- 자주 깨지는 곳: 임베드 자산 누락은 배포에서 발견된 이력; livedb 방치로 방언 회귀 누적. 폐기 시각 정밀도 문제는 authentication-hardening.md 참조. 제공된 교훈에 롤백 항목 없음.
- 검증 함정: jstest_test.go는 Node가 없으면 Skip. copyformats.test.mjs는 클릭 경로를 소스 정규식으로 검사하므로 실제 배선 증거가 아님. saved.test.mjs 역시 DOM/API 대역이어서 브라우저 검증을 대체하지 않음.
- 검증 함정: smoke는 REQUIRE_BROWSER 없으면 브라우저 생략 가능. pages.py는 페이지 로드만, editor.py는 편집기 실행을 확인; TSV 클립보드 동작은 현재 검사 없음. 전체 메타 스키마는 smoke, livedb --meta는 축소 성능 픽스처.
- 현재 기준: main@f09cfc0. 이전 상세 경합 수정(5cd5ca0)·로그인 302(d40c325)는 병합됨. 이전 프로필의 saved.js 경합 미해결 설명은 폐기.
