# Ptium 1.69.59

## 가져올 수 있었던 TSV와 일반 텍스트를 사용 가이드에도 적었습니다

제품 안의 **사용 가이드 → 기존 자료 가져오기**(`/guide#import`)에서 TSV와 일반 텍스트를
지원 형식으로 안내합니다. 두 형식은 이미 업로드하고 읽을 수 있었지만, 가이드의 형식 목록과
읽는 방식 설명에서 빠져 있었습니다. 기존 자료를 덱으로 옮기기 전에 지원 여부를 확인하는
사용자가 이 화면에서도 두 형식을 찾을 수 있도록 문구 두 곳을 보완했습니다.

- 첫 문단에 **TSV(`.tsv`)**와 **일반 텍스트(`.txt`)**를 넣었습니다.
- TSV의 읽기 설명을 엑셀·CSV와 함께 적었습니다. 라벨 한 열과 숫자 한 열이면 차트로,
  넓으면 표로 읽는다는 안내입니다.
- 일반 텍스트의 읽기 설명을 워드·마크다운과 함께 적고, **`.txt`도 마크다운과 같은 규칙으로
  읽는다**고 명시했습니다. 제목은 슬라이드, 그 아래 문장은 요점이라는 설명을 함께 봅니다.

~~~
이전: 지원 형식과 읽기 설명에 TSV·일반 텍스트가 없었습니다.
지금: .tsv와 .txt를 목록에 적고, .txt의 마크다운 읽기 규칙도 안내합니다.
~~~

업로드 기능을 새로 추가한 판은 아닙니다. 기능 변경은 `web/src/pages/GuidePage.tsx`의
문구 두 곳뿐이며, 파일 읽기·업로드 허용 형식·인증·API 동작·저장 데이터는 1.69.58과
같습니다. 이 안내 보완은 릴리즈 노트로 알리는 작은 개선이며, 별도 캠페인이나 가격·설정
변경은 없습니다.

## 지키는 장치

구현 단계에서는 변경 전후 웹 타입 검사·빌드와 기존 Vitest 48개 파일/271개 시험이
통과했고, Go 문서 읽기 시험과 `git diff --check`도 통과했습니다. 문구 전용 변경에
소스 문자열 검사나 구현을 복제하는 새 시험을 더하지 않았습니다. 기존 시험의 통과를
이번 안내 누락의 실패 재현이나 화면 검증으로 해석하지 않습니다.

실제 Chromium에서 변경 전후 `/guide#import`에 접근했지만 API 연결 실패로 로그인 경로와
502 오류 화면에 머물렀습니다. 안내의 실제 표시·목차·프레젠테이션 링크 이동, 변경을 되돌린
화면과의 비교는 확인하지 못했습니다. Go 문서 읽기 시험은 이 화면을 검증하지 않습니다.

릴리즈 준비에서 `go test -race ./...`·`go vet ./...`, 문서 패키지의 gofmt 검사,
`npm ci`·`npm run typecheck`·`npm run build`·`npm test`(48개 파일/271개 시험),
`npm audit --audit-level=high`를 통과했습니다. 기존 moderate 경고 2건은 남아 있습니다.
DB 단위 시험의 실제 DB 경로는 `PTIUM_TEST_DSN`이 없어 건너뜁니다.

버전 일치와 diff 검사도 릴리즈 조건입니다. 오프라인 이미지의 최초 실행과 이전 이미지에서의
업그레이드는 기존 빌드 스크립트가 검사하며, 이 검사가 실패하면 릴리즈를 중단합니다.
실행 결과와 환경상 건너뛴 검사는 릴리즈 실행 기록에 별도로 남깁니다.

## 설치와 되돌리기

기존 오프라인 설치 절차를 따라 1.69.59 이미지와 함께 제공되는 매니페스트를 사용합니다.
새 설정이나 데이터베이스 스키마 변경은 없습니다. 제공 파일은 Linux/AMD64 이미지 압축본과
SHA-256, Compose·Kubernetes 매니페스트, 환경 예제, PowerShell·셸 로드 스크립트입니다.

배포 담당자는 먼저 시험 환경에서 로그인한 일반 사용자에게 `/guide#import`를 처음부터
열어 보게 합니다. `.tsv`·`.txt` 표시와 TXT의 마크다운 규칙, 목차 이동, 프레젠테이션 링크를
확인한 뒤 적용 범위를 넓힙니다. 로그인·가이드 표시·링크 이동에서 오류가 한 건이라도
발견되면 배포 담당자가 확대를 멈추고 1.69.58 이미지와 해당 버전의 배포 설정으로 되돌립니다.

배포 후 7일 안에 지원 담당자는 TSV/TXT 가져오기를 문의한 사용자의 후속 질문을 확인합니다.
목표는 확인 가능한 문의 사례에서 지원 형식이나 TXT 읽기 규칙을 다시 설명해야 하는 사례가
0건인 것입니다. 문의 사례가 없으면 개선 효과는 미측정으로 남기며, 다운로드 수를 안내
이해도나 사용 성공으로 대신하지 않습니다.
