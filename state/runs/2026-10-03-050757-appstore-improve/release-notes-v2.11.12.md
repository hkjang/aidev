공개 앱 상세 머리말의 상태 배지가 영문 내부값 `published` 를 그대로 보여 주던 문제를 고친 patch 릴리스입니다.

- 한국어 UI 한가운데서 모든 사용자에게 영문 enum 이 보였습니다. 내 앱 목록은 같은 값을 `게시됨` 으로 보여 주므로 같은 상태가 화면마다 달랐습니다. 이제 두 화면이 같은 라벨을 씁니다.
- 목록이 이미 쓰던 공용 상태 배지를 상세 화면이 그대로 재사용합니다. 라벨 표가 한 곳이라 두 화면의 표기가 어긋날 수 없습니다. 게시된 앱의 배지 색은 그대로입니다.
- 상태 값이 없는 응답에서 배지를 그리지 않던 기존 동작은 유지됩니다.
- 프로덕션 Provider·라우터·실제 API 클라이언트를 쓰고 HTTP 경계만 바꾼 Vitest 2건을 더했습니다(전체 97건).
- 버전 표기와 사용자·관리자 가이드 PDF를 갱신했습니다.

schema 변경은 없습니다. 기존 설치는 image만 교체하면 됩니다.
