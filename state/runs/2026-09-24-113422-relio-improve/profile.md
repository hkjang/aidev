# relio 프로필 (2026-09-24)
- 목적: 에어갭 사내 B2B CRM 을 Go 단일 바이너리의 REST·MCP·React 웹으로 제공한다.
- 스택: Go(net/http, pgx/pgxpool), PostgreSQL, React 19·TypeScript·Vite, Keycloak OIDC.
- 구조:
  - cmd/relio 진입점. internal/server: REST 라우트·관리자 핸들러(admin*.go, mail.go, voice.go, voice_workspace.go, momento.go).
  - internal/auth·oidc·apikey: 인증·SSO·개인 키. internal/audit: 감사 기록.
  - internal/crm·intelligence·relationship·voice·approval: 업무 서비스와 분석. internal/mail: SMTP 릴레이 알림(신규).
  - internal/mcp/server.go: 도구 스키마·dispatch·OAuth 리소스 서버. internal/api/openapi.go: 명세 + 계약 테스트.
  - internal/admin·analytics·job·personal: 설정·방문자 분석·잡·개인 기능.
  - internal/platform: httpx·database·암호화·시간대 공용 기능. internal/webui: SPA embed.
  - migrations: SQL embed, **마지막 017_mail_notifications.sql** (014 Momento, 015 MCP OAuth, 016 voice workspaces, 017 mail).
  - web/src/pages: React 화면(AdminPages.tsx 가 매우 큼). web/test: Node 내장 테스트 4파일.
  - scripts/guide: puppeteer-core 캡처. docs: md/PDF 가이드·설계·릴리즈.
- 빌드·테스트: `go build ./...`; `go test ./...`; `go test -race ./...`; `go vet ./...`; `gofmt -l <변경 파일>`.
  - 프런트: `npm --prefix web ci`; `npm --prefix web run typecheck`; `npm --prefix web run build`; `npm --prefix web test`.
  - 추가 스크립트: `./scripts/check-env-contract.sh`, `./scripts/check-static-assets.sh`, `./scripts/previous-release-tag-test.sh`.
  - Docker offline/upgrade 테스트는 이미지+PostgreSQL 기동이 필요한 장시간 작업.
- 이번 정찰 검증: base main@54e94f3, `go test ./...` 실패 0(전부 ok/no test files). 작업 트리 깨끗. 프런트·스크립트 3종은 이번에 미실행.
