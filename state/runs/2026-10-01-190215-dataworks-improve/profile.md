- 검증 함정:
  - **워크트리에는 `web/node_modules` 가 없다.** `cd web && npm test` 를 설치 없이 돌리면 `sh: 1: vitest: not found` / **exit 127** 이다(2026-10-01 실행 확인). 러너가 exit 1 을 보고했다면 vitest 가 돌고 **테스트가 실제로 실패**한 것이다 — 두 경우를 섞지 말 것.
  - `web/package-lock.json`(lockfileVersion 3) 루트는 package.json 과 동기이고 `@rolldown/binding-*` 16종이 모두 들어 있다 → `npm ci` 실패·플랫폼 바이너리 누락을 먼저 의심하지 말 것. `npm install` 로 lock 을 재생성하지 말 것.
  - `web/src/test/keep-dist-placeholder.test.ts` 는 `build({ logLevel: 'silent' })` 로 실제 vite 빌드를 돌려 **실패해도 vite 쪽 원인이 로그에 남지 않는다**. 진단 중에만 logLevel 을 올릴 것.
  - CI 는 Go build/vet/test/API 감사 + web lint/test/build 만 돈다. 실행 환경 Node 는 22.23.1, **CI 는 24** — Node 버전 차이로 재현 여부가 갈릴 수 있다.
  - `gofmt -l internal/proxy/dataworks_runtime.go` 는 저장소의 기존 CRLF 때문에 HEAD 에서도 파일명을 출력한다 — 줄 끝을 건드리지 말 것.
  - `web/dist/*` 는 gitignore 되고 `!web/dist/.gitkeep` 만 추적된다. `npm run build` 뒤 `git status --short` 가 깨끗해야 한다.
  - 실제 Keycloak·SMTP 연동은 이 환경에 없어 가짜 IdP 로 대신한다. main 에 `internal/mail` 은 없다. PostgreSQL·브라우저 e2e 는 미검증.
