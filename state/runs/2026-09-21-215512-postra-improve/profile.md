# postra 프로필 (2026-09-21)
- 목적: 개인·사내 POP3/IMAP/SMTP 메일 수집·검색·작성·승인 발송과 AI·팀 업무를 REST/CLI/MCP/React로 제공하는 자체 호스팅 서비스. 확인 베이스 main@5dd0099, v0.23.3.
- 스택: Go 모듈 1.25.0, toolchain/CI 1.26.6(이번 로컬 1.26.7); SQLite/pgx PostgreSQL·pgvector; React 19/TypeScript/Vite, Vitest/jsdom·Playwright; Node >=22.12.
- 구조:
  - cmd/postra: 서버·CLI, 실제 pop3.Dialer 배선. cmd/postra-contracts: API 계약 생성/-check.
  - internal/domain: 엔티티·프로토콜 포트·SecretHandle·옵션.
  - internal/application: 수집/발송·계정·설정·OIDC·승인·리더 워커. app.go:dialInbound는 MaxMessageBytes를 전달.
  - internal/adapters/{pop3,imap,smtp,ai,mailparse}: 외부 프로토콜; SMTP 실제 TCP 테스트 존재, POP3는 아직 테스트 없음.
  - internal/adapters/{persistence,pgstore,secretstore,objectstore}: DB·비밀·원문/첨부 저장.
  - internal/transport/{httpapi,mcpserver,spa}: REST/MCP·OAuth 프록시·임베드된 React 자산.
  - internal/platform: 설정·암호·추적·계측; internal/mailrender: 메일 렌더링.
  - web/: React·npm 잠금 파일; api/: 생성 계약; docs/: 가이드·설계·releases/.
- 빌드·테스트: go build ./...; go vet ./...; go test -race ./... (전체 수 분 가능). make test는 race 테스트만 실행.
- 빌드·테스트: go run ./cmd/postra-contracts -check (읽기 전용); .github/workflows/contracts.yml 별도 계약 검사.
- 빌드·테스트: cd web && npm ci --no-audit --no-fund && npm run typecheck && npm test && npm run build.
- 빌드·테스트: make build는 프런트 설치/빌드 후 실행파일 생성. make build-offline은 GOPROXY=off/GOTOOLCHAIN=local, 사전 캐시 필요.
- 보안 검사: make lint = lint-format + lint-security. gofmt -l ./cmd ./internal 위반 시 실패, 소스 무수정. gosec v2.28.0 -severity medium -exclude-dir=scripts ./... 고정.
- 이번 검증: POP3/SMTP race 테스트 명령 통과(POP3 no test files), application TestSyncIdempotent/TestSyncWithoutUIDL 통과, make lint-format·계약 -check·go test -race ./... 통과(일부 캐시). 프런트·외부 PG·브라우저·보안 스캔은 이번 미실행.
- 관례: 최근 커밋 영어 conventional; 설정 카탈로그·환경 바인딩·SecretStore 참조 사용. SQLite/PostgreSQL 스키마 병행. 문서는 docs/ 및 docs/releases/.
- 관례: React 변경 시 internal/transport/spa/assets 재생성·커밋 필수; CI/release는 미추적 파일까지 검사. gosec 예외는 근거 있는 #nosec만 허용.

- 위험 구역: SMTP DATA 이후 응답 유실은 Uncertain으로 자동 재발송 금지. 현재 SMTP dial 이후 데드라인 없음; 이전 timeout 작업은 현 베이스 미반영, 재구현 금지.
