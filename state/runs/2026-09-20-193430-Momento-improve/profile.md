# Momento 프로필 (2026-09-20)
- 목적: 온프레미스에서 이벤트를 수집·소유하고 제품·직원·경험·AI 사용을 분석하는 사내 분석 플랫폼.
- 기준: main@52faf62, v0.34.42. 이전 프로필의 경로·미머지 기능·검증 명령 오차를 정정함.
- 스택: Go 1.26.0(toolchain 1.26.7), net/http+chi, pgx, go-oidc, PostgreSQL 17; React 19/TypeScript/MUI/Vite/react-query; TypeScript 수집 SDK.
- 구조:
  - cmd/momento — 서비스 진입점.
  - internal/httpapi — REST/MCP, 분석·관리 핸들러와 실제 DB 통합 테스트.
  - internal/service — Collector·Worker·Automation·Maintenance; maintenance.go는 이 디렉터리에 있음.
  - internal/database — DB 연결과 Migrate/MigrateThrough; 실제 embedded SQL은 internal/database/migrations/001~017.
  - 루트 migrations/ — 001_initial.sql만 존재; 실제 마이그레이션 정본과 혼동 금지.
  - internal/auth, privacy, secret, segment, insight — 인증·개인정보·암호화·세그먼트·분석 로직.
  - web/src/pages, components, contexts, api — 화면·공용 표·컨텍스트·API 호출; web/test/*.test.mjs는 node:test.
  - sdk/ — 브라우저 수집 SDK; scripts/guide/ — 실제 배포를 시드하고 puppeteer-core로 가이드 캡처.
  - docs/ — 사용자/관리자 가이드와 PDF, ARCHITECTURE, ROADMAP, openapi.yaml. ROADMAP_PLAN은 오래된 비전 문서.
- 빌드·테스트: `make test`; `go test -race ./cmd/... ./internal/...`; `go vet ./cmd/... ./internal/...`.
- 웹: `cd web && npm ci && npm run lint && npm test && npm run build`; SDK: `cd sdk && npm ci && npm run typecheck && npm test && npm run build`; 전체 산출물은 `make build`.
- 정찰 검증: Node v22.23.1에서 웹 100건 통과. node_modules 없음; lint/build·Go·실제 DB는 이번 정찰 미실행.
- 관례: 한국어 conventional commit이 주류; 설정은 DB settings와 환경변수; Migrate는 advisory lock 직렬화; 화면 순수 로직은 .ts로 분리해 node:test가 직접 import.
- 위험 구역: internal/auth, httpapi/admin.go·server.go(역할·세션·사이트 경계), internal/database/migrations, .github/workflows, docs/openapi.yaml(라우트 계약 검사).
- 미머지 주의: origin/auto/2026-09-17-0103의 비밀번호 재설정/문자 수 최소 길이와 origin/auto/2026-09-18-1143의 MCP OAuth는 현재 HEAD에 없음. 기록의 성공은 main 반영과 다름.
- 자주 깨지는 곳: 과거 seed의 개별 INSERT 비용은 현재 pgx.Batch로 해결됨. TestRetentionReportsEachUnattendedPass(integration_privacy_test.go)의 시간 플레이크는 기록에 있고 이번에는 재현 미확인.
- 검증 함정: MOMENTO_TEST_POSTGRES_DSN 없으면 통합 테스트가 skip; CI는 PostgreSQL 17과 Node 24, -race, govulncheck, npm audit, Docker build까지 실행.
- 검증 함정: web에 prettier 의존성/검사 스크립트 없음(.prettierignore만 존재), CI에도 prettier 없음. npx 최신 기본 포맷 검사를 필수 게이트로 삼지 않는다.
- 검증 함정: guide capture는 docs/assets/guide를 덮어씀. DB가 있는 Go 전체 테스트는 과거 기록상 약 1분 이상이며 이번 성능은 미측정.
