- 검증 함정: 환경변수 없으면 서비스 연동 테스트가 SKIP여도 성공 종료. make test는 SKIP 집계용 연동 명령을 다시 실행한다.
- 검증 함정: CI verify는 test-services.sh로 세 서비스를 준비하지만 release.yaml은 PostgreSQL만 준비한다. 두 workflow의 서비스 범위는 같지 않다.
- 검증 함정: CI lint는 npm 설치 전 실행, 로컬 make lint는 GO_PACKAGES로 vendored Go 제외. 빌드 산출물을 문서 변경에 섞지 않는다.
- 검증 함정: README 옛 수동 PostgreSQL은 스크립트와 컨테이너 이름은 같지만 비밀번호/포트가 다르다. 이번 선택 과제는 README 절차 통일이며 아직 구현 전.
- 검증 함정: 현재 Docker 실행 가능. 기존 resso-test-ldaps 마운트는 /tmp/resso-test-certs-0916; 스크립트 실행에 RESSO_TEST_CERT_DIR 지정 시 환경변수 정상 반환 확인. 새 컨테이너 생성·전체 CI/프런트는 이번 미확인.
- 최근 완료: POST UserInfo 폼 토큰과 중복 전달 거절, 1MiB 제한(3060a9b), 로그인 오류 안내, silent SSO 답별 지표. 반복 구현 금지.
- 현재 공백: oidcLogout은 ParseForm 오류를 무시한다(런타임 재현 미실행). 로그인 409 쿠키 경쟁 문제도 실제 경쟁 재현 미확인.
