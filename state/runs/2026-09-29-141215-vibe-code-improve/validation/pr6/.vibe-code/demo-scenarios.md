# Vibe Code 데모 시나리오

처음 사용하는 사용자를 위한 한국어 자율 코딩 예제 모음. 사이드바 채팅에 그대로 복붙해 보세요.

---

## 1. 빠른 탐색 — "이 코드베이스 뭐하는 거야?"

> 이 워크스페이스를 5분 안에 파악하고 싶어. 주요 진입점, 핵심 모듈, 데이터 흐름을 정리해서 보여줘.

에이전트가 자동으로 `package.json` → 진입점 → 의존성 → 핵심 모듈 순으로 읽고 구조도를 그려줍니다.

---

## 2. 테스트 자동 생성

> `src/utils/foo.ts`의 모든 export 함수에 대해 vitest 테스트 작성. 엣지 케이스 포함.

존재하지 않는 파일을 지정하면 에이전트가 워크스페이스를 검색해 적절한 후보를 제안.

---

## 3. 버그 수정 (디버그 모드)

> Debug 모드로 전환. 사용자가 "로그인 후 빈 화면" 이슈를 신고했어. 콘솔/네트워크 로그 보고 추적해줘.

Debug 모드는 가설 → 검증 → 수정 사이클을 따릅니다.

---

## 4. 한국어 주석 일괄 추가

> `src/api/` 폴더의 모든 함수에 JSDoc 한국어 주석 추가. 매개변수와 반환값 설명 포함.

---

## 5. 리팩터링

> 이 파일에서 반복되는 패턴 3가지 이상 찾아서 공통 함수로 추출. 테스트 통과 유지.

체크포인트 자동 생성 → 작업 → 검증.

---

## 6. 의존성 업그레이드

> package.json의 React를 19로 업그레이드. breaking change 모두 처리하고 빌드 통과시켜.

---

## 7. 문서 검색 + 코드 적용

> Next.js 15의 새 캐싱 동작 조사해서, 우리 `app/api/` 코드 호환되게 수정.

문서 검색(WebFetch) → 코드 분석 → 수정.

---

## 8. 멀티 파일 일관성 점검

> 이 프로젝트에서 에러 처리가 일관되지 않아 보여. 모든 파일 스캔해서 패턴 분류하고 통일안 제시.

---

## 9. 한국 시장 친화 변환

> 이 영문 SaaS 앱의 UI 라벨 모두 한국어로 변경. 날짜/숫자 포맷도 한국 로케일로.
