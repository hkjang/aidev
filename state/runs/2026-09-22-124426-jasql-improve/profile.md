# jasql 프로필 (2026-09-22)
- 목적: KCB JSON 메타데이터를 카탈로그·검색·조인·가드레일로 컴파일해 NL2SQL MCP/REST/웹 콘솔과 읽기 전용 Oracle 실행을 제공한다. 기준 main e9f3fb2, v0.31.0.
- 스택: go.mod Go 1.25.0 선언, 로컬 Go 1.26.7, Docker 빌더 Go 1.26. godror(oracle 태그), pgx PostgreSQL, x/crypto 및 go.sum. 프런트는 go:embed HTML/JS.
- 구조:
  - cmd/jasql-mcp: HTTP/stdio 서버 CLI; cmd/jasql-eval: 골든 평가; cmd/jasql-goldgen: 골든셋 생성.
  - internal/catalog: 로드·검색·조인·SQL 검증·시간 파싱·시멘틱·템플릿·평가, mcp 비의존.
  - internal/mcp: 도구·REST·인증/SSO/OAuth·실행 가드·개인화; webui는 정적 콘솔 자산.
  - internal/meta: 메모리/PostgreSQL 저장소, 사용자·세션·설정·프로파일.
  - internal/oracle: 프로파일·연결 풀·읽기 전용 실행·계획; 기본 드라이버는 연결 불가 stub.
  - data/kcb: 실데이터와 골든셋; 기존 테스트도 읽으므로 변경 테스트의 출력 대상으로 쓰지 않는다.
  - docs: 한국어 가이드; docs/reports/executive_report.md는 전사 확산·이중화·이기종 DB 로드맵.
  - scripts: 크로스 빌드와 오프라인 도커 이미지 릴리즈.
- 빌드·테스트: 이번 go build ./..., go vet ./..., go test ./... 통과. catalog 56.458초, mcp 9.798초, meta/oracle 캐시. cmd 3개는 no test files.
- 빌드·테스트: 이번 과제 부분 검증 go test ./cmd/jasql-eval -count=1 (신규 테스트 추가 후). 실제 CLI는 go run ./cmd/jasql-eval -data <임시 디렉터리> -verbose.
- 관례: 영어 명령형 커밋·한국어 PR 머지 제목. 버전은 server.go/OpenAPI·README/배포 문서 동기화. 설정은 flag/env/메타 DB settings.
- 관례: 카탈로그 로드 후 불변, 새 컴파일 결과로 원자 교체. 변경 테스트는 t.TempDir JSON을 catalog.Load로 로드(newFixtureServer 참고).
- 관례: tools()/callTool()/toolsForActor()가 도구 등록·디스패치·권한별 노출 담당. TestServeStdio는 전체 42개와 스키마를 실제 전송 경로로 단정.
- 관례: 메타 저장소는 internal/meta/pg.go; 이번 마이그레이션 구현 세부는 미확인. 문서 정본은 docs/README.md에서 찾는다.
- 위험 구역: auth.go/oauth.go/authapi.go(세션·권한), execguard.go 및 oracle/sqlguard.go(읽기 전용), dbapi.go(비밀번호/소유권), meta/pg.go, 전역 카탈로그 mutation.
- 위험 구역: goldgen 기본 출력 data/kcb/golden_queries.json을 덮어쓴다. CLI 테스트는 임시 -data/-out만 사용.
- 자주 깨지는 곳: 반복 실패 교훈 없음. SQL trailing 정리·숫자 날짜 검증·goldgen 음수 검증은 과거 성공 기록이 있지만 pinned HEAD에 관련 수정/테스트가 없어 재선정 금지.
- 검증 함정: 기본 driverAvailable=false라 기본 테스트가 Oracle 실 DB 실행을 증명하지 않음. JASQL_TEST_PG 현재 unset; PG 통합 테스트는 해당 환경변수 없으면 skip.
- 검증 함정: 저장소 CLAUDE.md/AGENTS.md와 .github/workflows 없음. docs/development.md의 Go 1.24+, 외부 의존성 0/go.sum 없음, 도구 24개는 소스와 불일치.
- 검증 함정: Go 1.25 자체 툴체인, Docker/Instant Client, 실 PostgreSQL은 이번 미검증.
- 평가 계약: RunEvaluationExec가 실제 평가와 Missing 진단을 만들고 CLI/MCP가 공유. docs/evaluation.md의 expected_columns는 베어 정규화 비교 계약이므로 한정자 보존은 단순 결함 수정이 아니다.
- 이번 정찰: eval -verbose가 컬럼 누락·SQL 검증 실패를 [ok]로 출력함을 실제 CLI에서 재현. MISS 표시와 실제 subprocess 회귀 테스트를 선정; 요약 지표·종료 기준은 유지.
