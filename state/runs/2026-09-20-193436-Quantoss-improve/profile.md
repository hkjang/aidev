# Quantoss 프로필 (2026-09-20)
- 목적: 토스증권 Open API 기반 국내·미국 자동 매매와 모의/백테스트·전진 검증을 수행하고 GitHub Pages·리포트·알림으로 운영 상태를 게시하는 Go 에이전트.
- 스택: Go 1.26(go1.26.7 실측), coder/websocket; go.mod에 Anthropic SDK 및 여러 간접 의존성도 있음(이전 프로필의 외부 의존 하나는 부정확). DB 대신 JSON/JSONL·파일 캐시, docs 정적 HTML/JS.
- 구조:
  - cmd/quantoss — 단일 CLI, agent/backtest/research/swing/laoer/copilot/doctor/verify 등의 실행 진입점.
  - internal/config — Default·FromEnv(.env/환경변수)·Validate·ForMarket·VersionHash. gap 설정 검증 누락이 이번 과제.
  - internal/toss — REST/WS·OAuth 토큰 캐시·TPS limiter. request 백오프는 Client.Sleep 주입 가능, nil이면 time.Sleep; limiter 대기는 별도.
  - internal/engine·broker·risk·strategy·indicators — 매매 판단·체결·리스크. broker 2단 매도/서버 손절 복원은 보호 대상.
  - internal/swing·backtest·exitlab·selection·evaluation — 일봉 전략·라오어/저빈도 실행과 연구. runner 청산은 현재 마지막 봉 기준.
  - internal/perf·journal·report·deck — 포지션 성과 계약, JSONL 거래/자산 기록, 리포트·대시보드·HTML 덱. weekly는 perf.ComputeFn 사용.
  - internal/agent·github·notify·copilot·funding — 데몬·게시/알림·텔레그램 명령/확인·자금 계획. LLM은 의도 해석용(README/PROPOSALS).
  - internal/universe·yahoo·catalyst·fundamentals·stockinfo·ontology — 가격/종목/공시·정보 수집.
  - docs — Pages 및 docs/PROPOSALS.md 설계, docs/reports 및 reports는 생성 리포트; testdata/dashboard는 브라우저 검증 fixture.
  - scripts — 운영 실행/서비스 및 check_dashboard.sh. 일반 check.sh·.github/workflows 없음. internal/zz_dbg는 zzdbg 태그 전용 운영자 스크래치.
- 빌드·테스트: go build ./... / go vet ./... / gofmt -l . / go test -count=1 ./... 모두 이번 정찰에서 통과, 포맷 출력 없음.
- 빌드·테스트: 테스트 패키지 실측 broker 7.775s, engine 2.022s, config 0.015s, toss 0.326s. 전체 벽시계 미계측(이전 회차 8.3s); 이전 35초 프로필은 오래된 수치.
- 빌드·테스트: go test -count=1 -race ./...는 권장 추가 검증이나 이번 정찰에서 미실행. scripts/check_dashboard.sh는 Chrome·로컬 HTTP 서버 의존, 이번 미실행.
- 관례: 한국어 설명형 커밋; 최근 git log -30 전부 자동 live.json 현황 게시. 설정은 .env/QUANTOSS_*·TOSS_*; DB 마이그레이션 없음. CLAUDE.md·AGENTS.md·별도 TODO/ROADMAP 파일은 검색에서 없었고 TODO/FIXME 코드 검색도 해당 표식 없음.
- 위험 구역: broker/live.go 주문 중복·미확정 결과·서버 손절 복원, toss 토큰 캐시(발급 시 다른 프로세스 무효화), copilot 확인/실매도, swing/runner.go 잦은 전략 확장, ForMarket 전략 우선순위, VersionHash 전진 표본 경계.
- 자주 깨지는 곳: 미국 가격을 %.0f로 표시하는 경로, 리터럴 객체 nil 필드, 스윙 일봉 누락, 거래 레코드와 포지션 통계 혼용. 과거 실제 반려/롤백 목록은 제공되지 않았음.
- 검증 함정: 시간 비교는 -count=1 필수. Sleep 주입은 toss 재시도만 대체하며 broker Sleep/TPS 대기는 남음. 현재 전체 테스트에 실패는 없음.
- 검증 함정: zzdbg는 실API·운영자 절대경로·실거래 토큰 캐시 사용하므로 실행하지 말 것. workflow 쓰기 권한은 미확인이라 CI 추가보다 로컬 스크립트 우선.
- 검증 함정: FromEnv는 .env를 읽고 프로세스 환경을 사용한다. 환경 테스트는 임시 디렉터리와 t.Setenv로 격리하고 병렬 실행하지 말 것.
