## 2026-09-17
- 선택: MCP OAuth 캠페인 mcp-oauth-2026-09 — `/mcp` 를 개인 키에 더해 Keycloak 액세스 토큰(OAuth 2.1 리소스 서버)으로도 열기 (가치 5 / 위험 2 / 작업량 M)
- 결과: 성공
- 요약: 이 저장소는 사용자별 계정과 `auth_providers` 다중 OIDC 로그인(`external_identities` 로 계정 연결)이 있어 표준을 그대로 적용했다. **고른 것과 이유**: (1) 설정 자리는 `system_settings` 의 `mcp.oauth` 한 행(`enabled`·`provider`·`resource`·`audience`·`scopes`, 마이그레이션 043, 기본 꺼짐)으로 두어 문서에서 `mcp.oauth.enabled` 식 표준 이름으로 읽히게 했고, 이 저장소에 `oidc.issuer_url`·`oidc.client_id` 는 없으므로 그 자리를 `mcp.oauth.provider`(OIDC 제공자 slug, 비우면 Issuer URL 이 있는 유일한 활성 OIDC 제공자, 둘 이상이면 저장 거부)가 대신하고 issuer·client id 는 그 제공자 행에서 재사용한다. (2) 리소스 식별자는 `mcp.oauth.resource` → 기존 공개 주소 설정 `auth.oauth.callback_base_url` + `/mcp` → 요청 Host(마지막 수단) 순서이고, 앞의 둘이 모두 비면 켜기를 400 으로 거부한다. (3) 대상 검사는 표준 문장 그대로 — `aud` 에 리소스 식별자, 또는 `aud`/`azp` 가 `mcp.oauth.audience` 에 — 이고 weekly 처럼 웹 로그인 클라이언트 ID 를 자동 허용하지는 않았다(postra 의 "웹 SSO client 를 재사용하지 않는다" 를 따름). (4) 범위는 키 권한 어휘(`mcp.use`·`orders.buy`·`orders.sell`)로 `mcp.oauth.scopes` ∩ 계정 역할 권한, 기본 `["mcp.use"]`, 토큰 `scope`/`role` 은 읽지 않으며 분당 한도는 `api.policy.default_rate_limit_per_minute` 를 계정별로 적용한다. 구현은 `internal/httpapi/mcpoauth.go` 한 파일(설정 읽기·검증, 제공자 해석, issuer 별 discovery 캐시(`context.WithoutCancel`), IdP 요청 분당 30회·10초·1MB 제한 트랜스포트, go-oidc `SkipClientIDCheck` + RS/ES/PS 알고리즘 목록으로 서명·iss·exp·nbf 검사, `typ=ID`·`cnf`·빈 `sub` 거부, aud/azp 검사와 고칠 값을 담은 거부 메시지, `external_identities` + `users.status='active'` 조회, `mcpChallenge`(MCP 경로에서만 `WWW-Authenticate: Bearer realm="Kkiit", resource_metadata="…"[, error="invalid_token"]`), RFC 9728 메타데이터 두 경로(맨 JSON·CORS *·꺼지면 404)), `authentication` 미들웨어에서 `/mcp` + `kkiit_` 아님 + JWT 모양일 때만 OAuth 로 가르고 나머지는 전과 동일, `putSetting` 이 `mcp.oauth` 저장 시 필드명을 든 400 으로 거부, `isNonPagePath` 에 `/.well-known/` 추가(좁은 CSP). 꺼져 있으면 메타데이터 404·헤더 없음·토큰 응답이 종전 `authentication_required` 와 동일함을 테스트로 고정했다. 화면: 인증 연동 페이지에 "MCP 를 SSO 로 연결" 카드(스위치·제공자 선택·리소스 식별자·허용 대상·허용 범위·MCP/메타데이터 주소 복사), `internal/ui/dist` 재빌드 커밋. 문서: ADMIN_GUIDE 3.2 표 한 행, 3.3 새 절(설정 표·켜지는 조건·검사 항목·Keycloak 공개 클라이언트/Redirect URI/Audience 매퍼/토큰 수명·curl 확인·거부 메시지별 조치 표), 6 장애 대응 한 행, md2pdf 로 PDF 재생성;
