# AgentHub 프로필 (2026-09-21)
- 목적: 사용자별 격리 AI 런타임과 자동 작업을 정책·승인·DLP·감사로 통제하는 사내 플랫폼.
- 스택: Go 모듈 1.25.0(chi, pgx, go-oidc, OpenTelemetry), PostgreSQL, React/TypeScript/Vite, Kubernetes, Playwright/Node 22.
- 구조:
  - cmd/: control-plane·worker·runtime-proxy·agenthub-offline 등 진입점.
  - internal/api/: catalog.go 라우트 등록, 핸들러·인증·게이트웨이·live 테스트.
  - internal/store/: PostgreSQL 접근·마이그레이션·감사 및 메일 저장.
  - internal/execution/, internal/mail/: 자동 실행/이벤트 전달 및 SMTP 알림 큐.
  - internal/runtimecfg/, internal/operator/: 런타임 설정 문서 및 Kubernetes 적용.
  - internal/dlp/, internal/tracking/: 내용 검사와 방문 추적/CSP.
  - web/src/, web/scripts/: 콘솔과 브라우저 e2e·Node 회귀·가이드 캡처.
  - deploy/, scripts/: Kubernetes/offline 배포와 릴리즈 이미지 검증.
  - docs/: ADMIN_GUIDE.md·USER_GUIDE.md와 PDF, architecture.md, decisions/검토 기록.
- 빌드·테스트: 정찰에서 go test ./internal/api ./cmd/runtime-proxy 통과; DB live는 DSN 미설정으로 미실행.
- 빌드·테스트: node --test web/scripts/session-gateway-check.test.mjs web/scripts/silent-sso.test.mjs 30건 통과; node --check web/scripts/guide-shots.mjs 통과.
- 빌드·테스트: CI는 go test -race ./cmd/... ./internal/...; web에서 npm ci && npm run lint && npm run test:sso && npm run build; bash scripts/release-catalog-images.sh check-versions; kustomize/compose 검사.
- 빌드·테스트: live DB에는 격리 AGENTHUB_TEST_DSN 및 base64 32바이트 AGENTHUB_ENCRYPTION_KEY 필요. 기존 패키지 동시 실행 충돌 때문에 DB 연결 검증은 -p 1 권장.
- 빌드·테스트: .github/workflows/live-agents.yaml은 대형 실제 이미지 빌드+실행(최대 90분). 일반 회귀와 구분.
- 관례: 한국어 문장/영어 conventional 커밋 혼용; 설정은 system_settings 키별 JSON과 별도 secret 슬롯; 정본 가이드는 대문자 파일.
- 관례: 현재 main 기준 94e9b5e, VERSION 0.250.0, BASE_VERSION 0.26.0. 런타임 base 소스 변경 시 이미지 버전 가드 주의.
- 위험 구역: auth.go·mcpoauth.go·session gateway·store migrations·.github/workflows. 정책 actor는 task.OwnerID, SCMTokenFor는 agent.OwnerID.
- 위험 구역: 감사 details에 스크럽 전 원문 금지. bf1e062 DLP 재마스킹은 별도 브랜치에만 포함; 사람 판정 미확인으로 재구현 금지.
- 위험 구역: putRuntimeSettings는 syncRuntimeEnvironment를 호출해 실행 중 Pod에 영향을 줄 수 있음. 스크립트 검증에 공유 배포 사용 금지.
- 자주 깨지는 곳: API 응답 래퍼·엄격 디코더와 스크립트 불일치, 전역 설정 백업/복원, DLP 복사 필드 중복/누락, 문서 HTTP 메서드.
- 검증 함정: runtime-settings GET은 {settings:{profiles:[]},suggestions,runtimes,targets}, PUT은 {profiles:[]}이며 {value:...}가 아님.
- 검증 함정: langflow-e2e.mjs는 현재 body.profiles를 읽어 정상 조회에도 빈 배열 복원. 이번 과제 대상이며 아직 미해결.
- 검증 함정: 일반 settings는 전체 GET body[key], 키별 PUT {value:...}; GET /admin/settings/{key}는 없음.
- 검증 함정: sessionGateway 문제는 withSessionGateway로 해결됐고 TestLangflowSettings가 실제 Handler+DB+Node 검증 제공. 관리자 세션+CSRF 사용(API 키 불가).
- 검증 함정: guide-shots는 백업 GET 실패에도 seed 실행, 복원 루프 throw 시 뒤 설정 복원 중단. 별도 미해결 후보.
- 검증 함정: 현재 web/node_modules 없음; eslint는 src TS만 검사. CI의 test:sso는 session-gateway-check.test.mjs를 포함하지 않고 release는 test:sso도 실행하지 않음.
- 검증 함정: DSN 없는 Go 성공은 DB 동작 증명이 아님. 현재 로컬 Node v22.23.1/Go go1.26.7로 CI 모듈 버전과 Go 도구가 다름.
- 미확인: 현재 클러스터·Keycloak·SMTP 가용성 및 DB live 동작. docs/decisions의 과거 클러스터 가용성을 현재 사실로 쓰지 말 것.
- 미확인: 요청된 세 부서 스킬은 현재 도구 및 로컬 SKILL.md 검색에서 미발견. CLAUDE.md·AGENTS.md·별도 roadmap 파일도 저장소 검색에서 미발견; TODO/FIXME 텍스트 검색 결과 없음.
