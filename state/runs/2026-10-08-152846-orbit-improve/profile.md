# orbit 프로필 (2026-10-08)
- 목적: 인간관계를 궤도로 시각화하고 교류·기억을 기록하며 AI·MCP로 활용하는 자체 호스팅 웹 앱.
- 스택: Go 1.26.6, chi v5·pgx v5·go-oidc v3, PostgreSQL; React 19·TypeScript 6·Vite 8·MUI·Vitest/jsdom. 웹 자산은 Go 바이너리에 내장.
- 구조:
  - cmd/orbit — 진입점; internal/webui/dist — 내장 웹 자산.
  - internal/server/data.go — 사람·교류·현재 궤도; timetravel.go — 과거 궤도·날짜 파싱.
  - internal/server/ai.go — AI 맥락 및 제공자 SSE 프록시; workflow.go — 기억·승인; mcp.go — JSON-RPC 도구.
  - internal/server/export.go — 복호화한 전체 기록 스트리밍 JSON; personal.go — 개인 설정·키.
  - internal/server/auth.go·throttle.go — 인증·제한; settings.go — 관리자 설정; respond.go — JSON·오류 공통 처리.
  - internal/server/server.go:New — 라우팅 정본; openapi.go — 공개 API 일부를 수동 기술(전체 라우트 목록이 아님).
  - internal/store — pgxpool·내장 SQL 마이그레이션·Bootstrap; internal/config·secure·id — 설정·암호화·UUID.
  - web/src — 계산 모듈과 동위치 시험·components·pages 9개; pages 시험은 없음.
  - docs — API.md·ARCHITECTURE.md·ADMIN_GUIDE.md·guide.md·cru-manual.md·OFFLINE.md. scripts/npm-install.sh — npm ci 재시도 래퍼.
- 빌드·테스트:
  - `go test -race -count=1 ./...` — 이번 정찰 직접 PASS(config·secure·server·scripts). ORBIT_TEST_DATABASE_URL 미설정; DB 시험은 SKIP.
  - `go vet ./...` / `go build ./...` / `gofmt -l internal/server` — 이전 프로필의 검증 명령, 이번 정찰 재실행 미확인.
  - `ORBIT_TEST_DATABASE_URL='postgres://…' go test -race -count=1 -v ./internal/server -run '<Test>'` — 격리 PostgreSQL 필요; 공유·운영 DB 사용 금지.
  - `cd web && npm ci --no-audit --no-fund` → `npm run test -- --run` → `npm run build`. 이번 정찰 프런트 실행 미확인; 설치·빌드는 느릴 수 있음.
  - `make build` = 웹 설치·빌드·Go 빌드, `make docker` = 이미지 빌드(느림). 정찰은 작업 트리 변경 금지라 실행하지 않음.
  - CI(ci.yml)는 Go race·npm ci·Vitest·Vite build·docker build. release.yml은 v*.*.* 태그에서 이미지·오프라인 tar·GitHub Release.
- 관례:
  - 현재 기준 main@5c97a1a, VERSION 0.7.12. 한국어 feat/fix/perf/chore(scope), 릴리즈 chore(release): vX.Y.Z.
  - 설정은 settings(namespace,key,value,encrypted_value)+readSetting. 마이그레이션은 기존 파일 수정 대신 새 NNN SQL 추가(이전 프로필; 이번 마이그레이션 파일 재독 미실시).
  - REST 오류는 writeError 및 internalError. MCP 호출 오류는 HTTP 200 + result.isError:true. UUID 모양 검사는 looksLikeUUID를 호출자에서 재사용.
  - 목록 rows.Next 뒤 rows.Err 검사. auth.go:userByAPIKey에는 아직 누락되지만 fail-closed이며 보호 경로.
  - CLAUDE.md·AGENTS.md·로드맵 파일은 저장소 파일 목록에서 찾지 못함; internal/web/src/docs/scripts의 TODO/FIXME 검색 결과 없음.

  - 9/24 orbitAt 포함 규칙·memory_count 시험은 verify 실패 이력이 있다. 9/21 OrbitPage 조기 반환·orbitRange first_met도 no-change 반복. 같은 접근 재선택 금지.
  - queryMemories/queryMemoriesLimit·personConnections·escapeLike는 REST·MCP·AI 공유. SQL·시그니처를 편의상 바꾸지 말고 호출자에 국한한다.
  - 기존 'openapi.go의 /orbit만 리터럴'은 좁은 예외를 위한 의도된 구조. 공통 operation 리팩터 금지.
  - safeAIError는 v0.7.9부터 실제 streamAI 실패 로깅에 사용됨. slog에는 식별자+오류 관례; 감사 s.audit의 details에는 민감 원문 대신 식별자만.
  - 새 확인: /personal/export는 auth.go:requiredScope에서 session-only, 쿠키 orbit_session 사용. OpenAPI는 아직 people:read Bearer로 오안내(이번 구현 과제, 아직 미수정).
  - docs/API.md는 아직 export 설명 없음. exportData는 complete:true 또는 complete:false/failed_section으로 끝나고 섹션 실패도 HTTP 200. 쓰기/연결 실패에는 JSON 자체가 잘릴 수 있음.
- 검증 함정:
  - openTestStore는 store.Open(ctx,dsn,nil), Bootstrap 미사용. DSN 없으면 SKIP이므로 Go 전체 초록을 DB 동작 검증으로 쓰지 않는다.
  - openapi.go 호출 시험은 아직 없음. 이번 구현은 New(nil, ...)의 실제 /openapi.json 요청 시험을 계획하지만 정찰은 이를 실행하지 않았다.
  - callWithoutStore(workflow_test.go)는 nil store 패닉으로 DB 도달을 구분하는 기존 가드 시험 헬퍼. HTTP 라우터 배선 시험과는 별개다.
  - seedUser/seedPerson/seedRelationship/seedPersonLink(timetravel_db_test.go), seedNamedPerson(mcp_db_test.go) 재사용. 사람+relationships를 함께 심어 JOIN 누락을 피한다.
  - 행 스트림 실패 주입은 기존 테이블 RENAME+동명 뷰 및 ::int 오류, t.Cleanup 원복·t.Parallel 금지. 블로킹 Sort면 잘린 결과는 1행이 아닌 0행이다(과거 실측).
  - SELECT EXISTS 장애 시험은 display_name을 깨뜨려도 플래너가 가지치기하므로 user_id를 깨뜨리는 breakPeopleUserIDLookup을 쓴다(과거 실측).
  - export 정상 시험은 Vault nil 때문에 빈 사용자를 사용; 비어 있지 않은 암호화 데이터에는 실제 Vault가 필요하다.
  - AI 설정·slog 기본 로거는 전역: preserveAISetting과 t.Cleanup으로 원복하고 병렬 실행하지 않는다. httptest 제공자와 ResponseRecorder로 실제 SSE 경로 검증 가능.
  - people.first_met는 date, 기타 시각은 timestamptz; 시간 비교는 Equal. orbitAt은 전체 교류를 스캔하지만 points는 1년 창만 보관하므로 '전체 이력 메모리 적재'로 단정하지 않는다.
  - Vitest는 jsdom+src/test/setup.ts. MUI Slider pointer/hasPointerCapture·OrbitCanvas ResizeObserver 스텁 필요 전력(이번 재현 미확인).
  - npm run lint는 eslint devDependency가 없고 CI도 미실행. Docker/Make는 설치 래퍼, CI는 직접 npm ci.
  - docs/cru-manual.md API 불일치 과거 기록은 이번 재검증하지 않음. 메서드와 경로는 server.go를 근거로 삼는다.
