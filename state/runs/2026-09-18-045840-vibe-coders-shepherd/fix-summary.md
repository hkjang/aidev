# PR #18 fix summary (commit bc62e48 on the PR branch)

1. **smtp.go** — Confirmed: stdlib `smtp.PlainAuth.Start` returns "unencrypted connection" for any non-localhost host without TLS, and `loginAuth`'s `server.Name != a.host` check was always false (both come from `config.Host`), so PLAIN always failed on a real relay while LOGIN leaked the password anywhere. Replaced PLAIN with an in-package `plainAuth` and gave both mechanisms one policy (`credentialsMayTravel`): credentials cross an unencrypted session only when the operator chose `mail.security=none`; under `auto` with no STARTTLS the send fails with an `ErrInvalid` naming `mail.security=none` (no AUTH/MAIL FROM is sent). Tests: policy against a named relay (`relay.corp.example`) for both mechanisms + auto/no-STARTTLS integration test; setting description and ADMIN_GUIDE updated.
2. **MailTab / API client** — Confirmed: 400/502 `{"sent":false,"error":...}` was flattened to a generic AppError, `lastResult` and the invalidation only ran on success. Kept the documented/tested backend contract and registered `errorSchemas` for 400/502 on `system.mail.test` (same pattern as `/ready`; a union that also accepts the standard error envelope for the recipient/JSON 400s), so the relay's reason survives as `error.message`/`error.details`. MailTab now uses `useMutation` directly: `onError` sets the inline result from the typed body, `onSettled` refreshes the delivery log. Tests: client 502/400 parsing, component test proving the reason is shown inline and the log is refetched (fails on the old MailTab).
3. **admin_text2sql.go** — Confirmed: the promote handler was the only writer of `text2sql_saved_reports` and left `created_by` empty, so `report.failed` mail never had a recipient. It now stamps `CreatedBy: s.mailActorID(r)` (signed-in account subject; empty for a bare operator token). Test: session-authenticated promote → `created_by` = user → `runScheduledReport` with invalid SQL → one `report.failed` mail reaches that user (fails on the old handler).
4. Verification: `gofmt`, `go vet ./...`, `go test ./...` (+ `-race` on internal/mail, internal/proxy), and `pnpm openapi:check / lint / format:check / typecheck / test` all pass. No tests removed or loosened; no CI files touched; not pushed.
