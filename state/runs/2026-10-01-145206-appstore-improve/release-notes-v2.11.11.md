검토 화면의 "스토어에서 보기" 가 아직 게시되지 않은 앱의 404 로 데려가던 문제를 고친 patch 릴리스입니다.

- 검토자가 결정을 내리는 상태(앱이 pending_review)에서는 공개 상세가 그 앱을 서빙하지 않아 머리말의 가장 눈에 띄는 버튼이 항상 "앱을 찾을 수 없습니다" 화면으로 갔고, 작업 중이던 검토 화면을 잃었습니다. 게시된 Private 앱도 같았습니다. 이제 공개로 볼 수 있는 앱에서만 링크가 보입니다.
- 앱 카드가 이미 쓰던 공개 열람 판정을 검토 화면이 그대로 읽습니다. 두 화면이 하나의 함수를 공유하므로 판정이 어긋날 수 없습니다. 앱 정보 자체는 화면 아래에 그대로 남아 검토자가 잃는 정보는 없습니다.
- 프로덕션 Provider·라우터·실제 API 클라이언트를 쓰고 HTTP 경계만 바꾼 Vitest 3건을 더했습니다(전체 95건).
- 버전 표기와 사용자·관리자 가이드 PDF를 갱신했습니다. 화면 캡처 90개는 v2.11.10과 동일합니다.
