# ai-admin 프로필 (2026-09-20)
- 목적: 폐쇄망에서 AI 공급자·사용자/RBAC·API 키·승인·레거시 AI Portal 데이터를 관리하는 단일 컨테이너 콘솔(v1.2.23, 기준 8cf9d2d).
- 스택: Go 1.26(go.mod toolchain 1.26.6, 정찰 로컬 1.26.7), chi/pgx/go-oidc, PostgreSQL 16+, React 19/TypeScript/Vite 8/antd 6/TanStack Query, Vitest/jsdom.
- 구조:
  - `cmd/ai-admin`, `internal/config`: 시작·환경변수 4개·고정 :8080.
  - `internal/server`: REST/AI 프록시/MCP/레거시/승인/감사/설정/SSO 핸들러 및 통합 테스트.
  - `internal/auth`, `internal/keyscope`, `internal/secrets`: 세션·API 키·RBAC·scope 정책·암호화.
  - `internal/database`: DB pool, seed, 내장 번호순 SQL migrations(001~005). 이전 프로필의 internal/db는 잘못된 경로.
  - `internal/settingscatalog`: 설정 카탈로그·검증·레거시 YAML 매핑. `system_setting`이 런타임 설정 저장소.
  - `internal/tracking`: 방문 추적 스니펫·nonce CSP. `internal/ui/dist`: 커밋된 내장 SPA 산출물.
  - `web/src`: React 화면·API 클라이언트·silentSso 유틸 및 Vitest 테스트.
  - `docs`: api/security/architecture/operations, USER_GUIDE·ADMIN_GUIDE(+PDF), screenshots. `scripts`: 캡처·버전/오프라인 패키지 검증.
- 현재 코드와 과거 기록의 차이: 이 고정 커밋에는 internal/mail·006 migration·mail 설정·MCP OAuth 설정/리소스 metadata 라우트가 없다. 과거 성공 기록만으로 존재한다고 가정하지 말 것. MCP는 기존 Authenticate와 mcp:tools scope 검사를 사용한다.
- 빌드·테스트:
  - `go test -count=1 ./...`, `make lint` 실제 통과(정찰). 통합 환경변수 없어서 DB/Keycloak 테스트는 미실행.
  - `TEST_POSTGRES_DSN`을 전용 테스트 DB로 설정한 뒤 `go test -race -count=1 ./...`; DB 통합 포함 시간은 이번 미측정(이전 회차 약 1분 이상).
  - `TEST_KEYCLOAK_ISSUER`도 설정하면 실제 OIDC e2e가 실행됨. CI는 PostgreSQL 16과 Keycloak 26.7.2, Go 1.26.6/Node 26을 준비한다.
  - `cd web && npm ci && npm test && npm run build`; Vitest jsdom, 15초 timeout. 이번 정찰에서 웹 테스트 미실행.
  - `make build`는 웹 빌드·internal/ui/dist 교체·Go 바이너리 생성; 읽기 전용 정찰에서는 실행하지 않음.
- 관례: fix/feat/docs/chore 접두에 한국어 또는 영어; VERSION/CHANGELOG/문서·웹 버전 동기화는 릴리즈 작업. API 계약은 docs/api.md. 오류는 writeError(status, code, 한국어 메시지).
- 위험 구역: internal/auth, server/auth_handlers.go·oidc.go(세션/SSO), workflow.go(승인 트랜잭션), database/migrations, .github/workflows 및 버전 검증(완화 금지), internal/ui/dist.
- 자주 깨지는 곳: 조회 오류를 0/빈 배열로 숨기는 처리; 입력 검증 누락으로 DB 500; 동일 값의 여러 소비 경로 불일치. listUsers q 200자·키 발급/회전 소유자 활성 검사는 현재 해결됨.
- 검증 함정: DB 테스트는 DSN 없으면 skip; 실제 실행 여부를 -v로 확인. 테스트가 DROP SCHEMA하므로 운영/공유 DB 금지, 동일 DB로 병렬 실행 금지. Keycloak e2e는 별도 서비스 필요.
- 검증 함정: docs Pages CI는 index/README/캡처 스크립트/실제 WebP가 정확히 44개로 일치해야 한다. 캡처 추가는 한 곳만 바꾸면 실패한다.
- 정찰 확인: 루트/상위 검사 범위에서 CLAUDE.md·AGENTS.md 없음, 저장소 내 로드맵/TODO/FIXME 검색 결과 없음. 최근 git log -30·CI 3개·주요 문서를 확인. 원격 CI 실행 결과는 미확인.
