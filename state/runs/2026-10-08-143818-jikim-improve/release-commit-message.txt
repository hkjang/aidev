fix: release the CSP report body size limit fix for v0.2.32

CSP 리포트가 8192바이트를 초과해도 앞부분의 유효 JSON만 파싱해 기록하던
문제를 고친 PR #54를 릴리즈합니다. receiveCSPReport가 최대 8193바이트를
읽고 파싱 전에 길이를 검사해 초과 본문을 버립니다. 정상 및 정확히 8192바이트인
리포트는 계속 기록하며, 204·빈 응답과 추적 비활성화·설정 장애 gate는 유지합니다.
실제 라우트 POST→Recorder→인증된 관리자 GET 경계 테스트 10개가 알려진 길이와
알 수 없는 길이 각각의 정상·8192·8193·9216바이트 및 잘못된 접미사를 검증합니다.
속도 제한이나 동일 출처 검증을 추가하는 변경은 아닙니다.

현재 소스에는 v0.2.31 릴리즈 커밋이 이미 있으므로 기존 패치 증가 관례에 따라
버전 파일, 문서 프로파일과 CHANGELOG를 v0.2.32로 갱신했습니다. 화면 캡처의
v0.2.9 출처와 두 가이드 PDF의 v0.2.18 표지는 유지합니다. 기존 PDF 변환기가
저장소에 없어 같은 판형으로 재생성하지 않았으며 Markdown 본문은 갱신했습니다.

./scripts/verify.sh 전체(Go test·vet·gofmt, 웹 테스트 59개·lint·build,
문서·Compose)와 CSP 경계·추적 테스트의 캐시 없는 실행, 소스 버전 일치 검사가
통과했습니다. 기존 500kB 청크 경고는 남습니다. 이미지 빌드, PostgreSQL 스모크,
브라우저 E2E, 번들 생성 및 GitHub Release 게이트는 태그 푸시 후 release.yml이
