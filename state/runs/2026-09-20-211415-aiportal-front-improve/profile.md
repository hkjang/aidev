# aiportal-front 프로필 (2026-09-20)
- 목적: KCB 사내 AI 포털의 Vue SPA로 AI 채팅·노트북·업무도구·OCR·공유/자료실·문서 뷰어를 제공한다.
- 스택: JavaScript ESM, Vue 3.5, Vite 7, Pinia 3, vue-router 4, axios, marked/highlight.js/DOMPurify, Monaco, PDF.js, Milkdown, Mermaid; DB는 프런트에 없고 Java/Python API를 사용. package.json name=kcb_ai, Node ^20.19 또는 >=22.12.
- 구조:
  - src/api/ — interface.js(Java), pythonInterface.js(Python), common/interceptors.js(인증·응답 처리).
  - src/storage/ — auth/user/common/sessionChat/myNoteBook/openApp/chatTransition/OCR 상태 저장. Stroage 오타가 있는 실제 파일명 유지.
  - src/stores/ — Pinia 및 별도 서비스 상태, src/composables/ — 앱 목록/이동 기능.
  - src/utils/ — common.js, page.js(usePaging), appList.js, appUpdateLog.js, 파일 첨부/검증, markdown, globalLoading, eventBus.
  - src/views/ — Chat, ChatStorage, MyAgent, Support, Notice, Library, Share 등 실제 페이지.
  - src/components/ — layout/Header·Sidemenu 및 공통 카드·팝업·입력·페이지네이션.
  - tests/unit/ — 19개 Vitest spec 파일; tests의 기타 파일은 수동 QA 데이터.
  - docs/ — 시작/아키텍처/API/상태/컴포넌트/빌드/개선/CI/테스트 및 인증·채팅 수동 시나리오 11개 문서. README.md와 README2.md도 존재.
- 빌드·테스트: npm ci → npm test(Vitest run), 특정 파일은 npm test -- tests/unit/page.spec.js. npm run build:dev(Vite, 과거 1~2분); core/ofc/int 및 *_dev 모드도 package.json에 있음. dev 서버는 server.key/server.crt 필요; build는 command==='serve' 분기로 인증서 읽기 제외.
- 관례: 한국어 fix:/feat: 및 PR merge 커밋. 환경값은 .env.*(gitignore), 예시는 .env.sample; 경로 @ alias. 마이그레이션 없음. ESLint/Prettier 스크립트 없음.
- CI: .github/workflows는 없으나 .gitlab-ci.yml이 실제 존재한다. main/develop에서 망별 고정 BUILD_DIR로 이동해 fetch/reset/build하고 PVC에 복사 배포한다. 해당 파일에 npm ci/npm test 단계가 없고 배포 환경의 기설치 의존성에 기대므로 로컬 새 설치와 다를 수 있다. 배포 스크립트 실행 금지.
- 위험 구역: src/api/common/interceptors.js·authStorage/userStorage·router(인증/세션), Chat/Main.vue·Index.vue(라우트/스트리밍/재전송), .gitlab-ci.yml(실배포). 두 로그아웃 경로 HeaderSetting.logout/common.redirectToLogin의 전체 캐시 정리와 모듈별 storage 동기화 플래그 유지.
