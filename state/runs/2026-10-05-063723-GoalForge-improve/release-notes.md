## 바뀐 것
- **완료 조건 파서와 CLI·MCP 저장 계약을 테스트로 고정했습니다** (#80). 공백·대소문자·구분자·잘못된 구문을 확인하고, 같은 원문을 실제 CLI `goal set`과 MCP `goal_set`으로 저장한 뒤 SQLite의 `Type`·`ExpectedValue`·`RequiredKind`가 같은지 검사합니다.
- **잘못된 조건으로 목표를 바꾸려 해도 기존 목표가 보존되는지 확인합니다.** 변경 사유와 유효한 조건 뒤에 빈 kind 또는 미등록 kind를 섞어 전달하고, 거절 뒤 활성 목표의 ID·Version·Criteria를 포함한 전체 값이 그대로인지 검사합니다. 미등록 kind를 구문 파서는 받아들이고 저장 정책이 거절하는 기존 책임 구분도 보호합니다.

테스트 파일 3개를 추가한 릴리즈입니다. 프로덕션 동작·저장 정책·데이터베이스 스키마는 바뀌지 않으며, 신규 테스트는 기존 코드에서 첫 실행부터 통과했습니다. 결함 수정이나 실패 재현을 주장하지 않습니다.

플랫폼별 실행 파일과 SHA256SUMS는 태그 푸시 후 기존 릴리즈 워크플로에서 빌드·검증하여 첨부합니다.
