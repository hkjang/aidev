# AgentHub 프로필 (2026-10-05)
- 목적: 사용자별 격리 AI 런타임과 자동 작업을 정책·승인·DLP·감사로 통제하는 사내 플랫폼.
- 스택: Go 1.25(chi, pgx, go-oidc, OpenTelemetry), PostgreSQL, React/TypeScript/Vite, Kubernetes, Node/Playwright. CI Node 22.
- 구조:
  - cmd/: control-plane·worker·runtime-proxy·offline 진입점.
  - internal/api/: REST·관리자·런타임 게이트웨이. server.go/catalog.go 라우팅, routes.go 설정 검증, tracking.go CSP/추적 프록시.
  - internal/store/: PostgreSQL 저장·마이그레이션·감사·알림·메일 큐.
  - internal/execution/, internal/mail/: 작업/이벤트 전달과 SMTP 큐.
  - internal/runtimecfg/, internal/operator/: 런타임 설정과 Kubernetes 리소스.
  - internal/dlp/, internal/tracking/: 내용 검사, 추적 스니펫/CSP/위반 기록.
  - web/src/: 콘솔. web/scripts/: 브라우저 e2e, Node 단위 회귀, 가이드 촬영.
  - deploy/, scripts/: 배포/이미지 검증. runtime-images.json: 이미지 sourcePaths·버전 계약.
  - docs/: ADMIN_GUIDE·USER_GUIDE(md/PDF), architecture.md, decisions/.
- 빌드·테스트: 실제 실행 `go test ./internal/tracking ./internal/api` 통과(tracking 0.005s/api 1.752s), `cd web && node --test scripts/*.test.mjs` 130건 통과, `node --check web/scripts/guide-shots.mjs` 통과.
- 빌드·테스트: CI `go test -race ./cmd/... ./internal/...`; web `npm ci && npm run lint && npm run test:sso && npm run build`; 이미지 `bash scripts/release-catalog-images.sh check-versions`, kustomize/compose 검사. 이번 정찰 전체 CI 미실행.
- 빌드·테스트: DB live는 격리 AGENTHUB_TEST_DSN과 암호화 키가 필요하고 DSN 없으면 skip하는 관례. 이번 DB/live·브라우저·클러스터·Keycloak·SMTP 미검증. 과거 DB 병렬 오염으로 -p 1 권장 기록.
- 관례: 영어 conventional prefix 뒤 한국어 설명 커밋. 산문 주석으로 이유를 명시. 설정은 system_settings JSON 키 + 별도 secret.
- 관례: HEAD 68d4f7c, v0.258.0. 프로덕션 internal/tracking·internal/api·web은 runtime-images.json의 어떤 sourcePaths에도 없음을 이번 직접 확인.
- 관례: cmd/runtime-proxy·internal/dlp·internal/policy 등 base sourcePaths 수정은 BASE_VERSION 연동 확인 필요. 이번 선택 과제는 해당 없음.
- 관례: 추적 설정 과대 입력은 잘라 저장하지 않고 거절한다. 문자열 길이 기준은 기존 룬 단위이며 바이트 단위와 구별한다.
- 위험 구역: auth.go·mcpoauth.go·session gateway·store migrations·.github/workflows. 이번 수정 대상에서 제외.
- 위험 구역: 과거 확인된 무인증 CSP 보고·런타임 게이트웨이 입력은 외부 문자열. 이번 라우터 등록은 미재확인.
- 위험 구역: 설정 쓰기 공통점은 tracking.Settings.Validate. routes.go:validateSetting 및 api/tracking.go:allowTrackingOrigin이 저장 전에 호출함을 이번 확인.
- 위험 구역: pagePolicy는 PolicySources의 출처를 세 지시문에 join. originOf는 scheme://Host만 반환하고 길이는 검사하지 않는다.
- 위험 구역: cachedTrackingSettings는 5초 캐시로 읽고 Normalized만 호출한다. 기존 저장값에 Validate를 다시 적용하지 않는다.
- 자주 깨지는 곳: API 응답 래퍼와 촬영 스크립트 접근 경로 불일치, 전역 설정 백업/복원, runtime 이미지 버전 누락.
- 자주 깨지는 곳: 이미 해결 — DLP 보고 문자열 512룬, CSP 위반 문자열 절단, 허용 출처 항목 300룬/세미콜론 거절, 목록 64개/4096룬, 한 번 클릭 허용 단일 출처 검증, 스니펫 출처 32개/1024룬.
- 자주 깨지는 곳: 아직 열린 제공자 출처 길이(이번 과제). MomentoURL·MatomoURL은 originOf를 거쳐도 길이가 무제한이다. dlp.tool direction enum은 미정.
- 자주 깨지는 곳: 16KiB는 전체 헤더 보장이 아니다. 현재 테스트는 최대 스니펫+목록이 ASCII 15921, 한국어 33513, 4바이트 문자 42309바이트임을 명시한다. 정찰 실행에서 기존 테스트 통과; 숫자는 소스 기록.
- 자주 깨지는 곳: Sources.all은 중복을 거르지만 pagePolicy는 이를 쓰지 않는다. 기존 테스트는 중복 출처를 기대한다.
- 검증 함정: CI test:sso는 silent-sso.test.mjs만 실행; 다른 세 Node 회귀 파일은 로컬 전체 명령으로만 검증된다.
- 검증 함정: guide-settings-check.test.mjs는 실제 소스를 requestTimeoutMs부터 `  if (problems.length)` 앞까지 잘라 vm에서 실행한다. 앵커 밖 변수·코드는 검증되지 않는다.
- 검증 함정: Node AbortSignal.timeout의 타이머는 이벤트 루프를 유지하지 않아 멈춤 회귀 하니스는 별도 interval로 유지한다.
- 검증 함정: web/node_modules 없음 확인. npm lint/build·실물 브라우저는 이번 미실행. Node 회귀는 의존성 설치 없이 실행됐다.
- 검증 함정: 관리자 API는 관리자 세션+CSRF 필요. validateSetting 단위 호출 통과를 실제 HTTP/DB 저장의 증명으로 쓰지 않는다.
- 검증 함정: TrackingForm은 스니펫 8KiB 바이트 카운터를 이미 표시한다. 허용 목록·스니펫 출처 상한 안내는 없다.
- 검증 함정: 소스 주석은 현 동작을 정확히 반영해야 한다. cbbc4fb·c9fa51f가 제공자 무제한 및 룬/바이트 혼동을 바로잡았다. 이번 제공자 검사를 추가하면 두 파일의 해당 주석도 고쳐야 한다.
- 탐색: CLAUDE.md·AGENTS.md·별도 roadmap/TODO 파일은 현재 저장소 파일 검색에서 발견하지 못함. cmd/internal/web/src/web/scripts의 TODO/FIXME도 검색 결과 없음.
- 미확인: 조직 운영의 실제 제공자 URL 길이/프록시 헤더 예산, 전체 배포 상태, PDF 재생성 절차. 정찰은 코드·커밋을 바꾸지 않음.
