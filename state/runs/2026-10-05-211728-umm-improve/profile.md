# umm 프로필 (2026-10-05)
- 기준: main@6aaf940, `VERSION` = 0.76.5. 이전 프로필(2026-09-29, main@2e1f29a / 0.76.1)에서 바뀐 것만 아래 "이후 변경" 에 적는다.
- 목적: 생각을 공간 캔버스에 붙이고 연결·갈래로 묶어 협업하고 Markdown 백업·문서 차례·발표로 내보내는 도구.
- 스택: Go 1.26, PostgreSQL 17, React 19 / TypeScript / Vite / Mantine / React Flow, Vitest + Playwright.
- 구조:
  - `cmd/umm`: 서버 진입점. `internal/httpapi/`: REST 핸들러·라우팅·정적 웹(파일 60+개, `*_integration_test.go` 는 DSN 필요).
  - `internal/store/`: PostgreSQL 접근·첨부·발표 출처·handoff. `migrations/`: 순차 SQL + `down/`.
  - `internal/presentation/`: `Compile`·`WriteSource`·`WriteOutline`·`usableHeading`·`sectionDeck`. 최근 네 회차가 집중적으로 손댄 곳.
  - `internal/auth/`: 세션·OIDC. `internal/analytics/`: 선택적 추적. `internal/mail/` 은 **없다**(가이드 문서가 언급해도 미구현).
  - `web/src/pages/CanvasPage.tsx`: 3500줄 넘는 캔버스 화면(공간 전환·되감기·내려받기·자리 기억). `web/src/api.ts`: 요청·오프라인 큐·`export interface Space`(:34).
  - `web/src/i18n/`: `translate.ts`(`msg`/`translate`/`setLocale`), `en.ts`(약 1060키). **번역 키는 한국어 원문**이고 ko 는 사전이 없다 — 영어 리터럴을 키로 쓰면 ko 에서 영어가 그대로 보인다(`en.ts:14 'My Space'` 가 그 예외).
  - `web/src/lib/`: 순수 모듈 + 인접 테스트(`edge-vocabulary.ts` 만 테스트 없음). `web/scripts/`: `run-on-supported-node.mjs`·`node-range.mjs`·`check-i18n.mjs`·`verify-pwa.mjs` 와 각자의 `.test.mjs`.
  - `web/e2e/`: Playwright. `docs/`: 가이드·OpenAPI·릴리즈 기록(PDF 는 .md 정본보다 뒤처질 수 있음).
- 빌드·테스트 (실제 명령):
  - **프런트엔드는 `npm ci --prefix web` 선행이 필수.** 새 체크아웃에는 `web/node_modules` 가 없고, 설치 없이는 `npm test` 가 `run-on-supported-node: vitest is not installed …` 로 exit 1 이다. 이것은 제품 결함이 아니다.
  - 저장소 루트에 `package.json`(private, 의존성 0)이 있어 루트에서도 `npm run lint|typecheck|test|build` 가 `npm --prefix web` 로 위임된다(333e1b1·88cdca1). 루트 밖으로 올라가지 않는다.
  - `npm --prefix web test` → 기준선 20파일 / 218시험. `run typecheck`, `run lint`(oxlint+prettier, 기존 경고 있음), `run build`, `node web/scripts/check-i18n.mjs`(1060키), `run verify:pwa`(build 선행, 150 assets).
  - `go vet ./...`; `go build ./cmd/...`(산출물 `umm` 은 커밋 전 삭제); `go test ./internal/presentation -count=1`(DB 불필요, 수 초).
  - 전체: `POSTGRES_DSN=<격리 PostgreSQL 17 DSN> go test -p 1 ./... -count=1` → 15패키지, 수 분. **DSN 없으면 통합 테스트는 SKIP** 이고 PASS 표시만으로 "돌았다" 고 쓰면 안 된다(`-v` 로 특정 integration 테스트가 SKIP 아닌지 확인하는 것이 관례).
  - `scripts/check-version.sh`(`web/package.json` 과 `VERSION` 대조), `scripts/migrate-dry-run.sh`(DB 필요). 릴리즈 경로 확인은 `docker build --build-arg VERSION=<v> .`
- 관례: 커밋 메시지는 영어 동작 설명 한 문장, 릴리즈는 `Release vX.Y.Z …`. 개선 회차는 버전을 올리지 않는다. 커밋에 Co-Authored-By/Claude 트레일러를 넣지 않는다. 설정은 DB `app_settings` + 관리자 UI + `internal/config/`. 가이드 정본은 `docs/USER_GUIDE.md`·`docs/ADMIN_GUIDE.md`.
- 위험 구역: `internal/auth/`(SSO 복귀 루프), `migrations/`(번호 충돌, 현재 마지막 029), `.github/workflows/`·`Dockerfile`(릴리즈를 반복해 깨뜨린 이력 — 건드리면 `docker build` 까지 확인), 비밀 설정 암호화·감사 기록, CSP nonce.
