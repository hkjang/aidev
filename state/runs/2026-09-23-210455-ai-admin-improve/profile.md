# ai-admin 프로필 (2026-09-23)
- 목적: 폐쇄망에서 AI 공급자·사용자/RBAC·API 키·승인·레거시 AI Portal 데이터를 관리하는 단일 컨테이너 콘솔. 기준 main@a7b64fe, VERSION 1.2.24.
- 스택: Go 1.26(chi/pgx/go-oidc), PostgreSQL 16+, React 19/TypeScript/Vite/antd 6/TanStack Query, Vitest/jsdom.
- 구조:
  - `cmd/ai-admin`, `internal/config`: 시작·환경변수·고정 :8080.
  - `internal/server`: REST/AI 프록시/MCP/레거시/승인/감사/설정/SSO 핸들러와 통합 테스트가 모두 한 패키지에 있다(파일 60여 개).
  - `internal/auth`(세션·API 키·RBAC 로드), `internal/keyscope`, `internal/secrets`.
  - `internal/database`: pool·`Seed`·번호순 내장 SQL migration 001~005. 역할 4개(super_admin/admin/team_lead/user)는 고정 UUID로 시드된다(`database.go:169-174`).
  - `internal/settingscatalog`: 설정 카탈로그·검증; `system_setting`이 런타임 설정 저장소.
  - `internal/tracking`, `internal/ui/dist`(커밋된 내장 SPA 산출물).
  - `web/src/pages`: 화면별 단일 파일(RolesPage.tsx 등). `docs`: api/security/architecture/operations + 가이드·PDF·캡처. `scripts`: 캡처·버전·오프라인 패키지 검증.
- 빌드·테스트:
  - `go test -count=1 ./...` — DSN 없으면 통합 테스트는 SKIP이라 빠르게 끝난다(그 결과를 "통합 통과"로 읽지 말 것).
  - 전용 폐기 DB로 `TEST_POSTGRES_DSN` 설정 후 `go test -race -count=1 ./...` — internal/server 약 70~80초.
  - `make lint`(`gofmt -l`·`go vet`·`scripts/verify-version.sh`), `go build ./...`.
  - `cd web && npm ci && npm test && npm run build`; jsdom timeout 15초. `make build`는 웹 빌드 후 `internal/ui/dist`를 교체한다.
  - `TEST_KEYCLOAK_ISSUER`가 있어야 실제 OIDC E2E가 돈다. 이 환경엔 Keycloak이 없어 항상 SKIP.
- 관례: `fix:`/`feat:`/`docs:`/`chore:` 접두, 한국어 또는 영어 본문. `writeError(status, code, 한국어 메시지[, details])`가 오류 계약이고 API 계약 문서는 `docs/api.md`. 입력 길이 상한은 바이트가 아니라 `len([]rune(x))` 기준(한국어 입력 때문). VERSION/CHANGELOG/웹·문서 버전 동기화는 릴리즈 단계 전용.
- 위험 구역: `internal/auth`, `internal/server/auth_handlers.go`·`oidc.go`(세션/SSO), `workflow.go`(승인 트랜잭션), `internal/database/migrations`, `.github/workflows`, `internal/ui/dist`. 레거시 범용 조회는 읽기 전용이고 쓰기는 전용 allowlist만.
- 자주 깨지는 곳: 조회·파싱 오류를 0/빈 배열/nil로 숨기는 처리(`_ = json.Unmarshal` 패턴), DB 컬럼 상한보다 느슨한 요청 검증(그래서 500이 난다), 같은 값을 읽는 두 경로의 계약 불일치(trim 여부·정렬). 해결된 것: listUsers `q` 상한, 키 발급·회전의 소유자 활성 검사, `safeCSVCell` tab/CR, listUsers 동률 정렬.
- 검증 함정: 통합 테스트가 `DROP SCHEMA ... CASCADE`를 하므로 운영·공유 DB 금지, 같은 DB로 병렬 실행 금지. 이 머신에는 다른 프로젝트의 postgres 컨테이너가 떠 있어 포트 55432·55433·55439·15434가 이미 점유돼 있다 — 새 포트로 전용 `postgres:16-alpine`을 띄울 것. DSN 없으면 SKIP이므로 새 테스트는 `-v`로 PASS를 확인해야 한다. Pages CI는 index/README/캡처 스크립트/실제 WebP가 정확히 44개로 일치해야 통과한다.
