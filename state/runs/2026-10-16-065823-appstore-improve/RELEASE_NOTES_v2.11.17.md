AppStore v2.11.17

v2.11.16 이후 머지된 사용자 화면 수정 3건을 묶은 patch 릴리스입니다.

- 앱 등록·수정 완료 화면이 저장 응답과 관계없이 "즉시 게시되거나 검토 대기" 를 예고하던 문구를 없앴습니다. 저장과 첨부 문서 적용이 끝난 뒤 서버가 돌려준 현재 상태(초안·검토 대기·게시됨)를 공용 라벨로 표시하고, 내 앱에서 다음 단계를 확인하도록 안내합니다.
- 가이드 문서를 여러 개 첨부하다 둘 이상 실패하면 첫 번째 사유만 보이고 나머지는 사라졌습니다. 이제 첫 사유와 함께 실패한 파일 개수를 알려 줍니다.
- 앱 상세의 가이드 문서 목록이 서버 오류나 네트워크 실패로 조회되지 않을 때, 첨부가 하나도 없는 앱과 화면상 구분되지 않았습니다. 이제 "가이드 문서를 불러오지 못했습니다." 안내와 다시 시도 버튼을 같은 카드에 보여 줍니다. 조회에 성공했고 첨부가 0건이면 종전처럼 아무것도 그리지 않습니다.
- 실제 화면·라우터·API 클라이언트를 쓰고 HTTP 경계만 바꾼 React 테스트는 133건입니다. 실제 번들의 desktop·mobile E2E는 87건 통과(1건 skip)이며 완료 화면과 가이드 문서 안내를 함께 확인합니다.
- 버전 표기, 사용자 가이드의 완료 안내와 사용자·관리자 가이드 PDF를 갱신했습니다. 전체 화면 캡처 90개를 재생성했으며 88개는 v2.11.16과 동일합니다.

schema 변경은 없습니다. 기존 설치는 image만 교체하면 됩니다.
