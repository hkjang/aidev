# v0.255.0

## 알림 메일의 점으로 시작하는 줄에 점이 하나 더 붙지 않습니다

메일을 보낼 때 본문이 끝났음을 알리는 신호는 점 하나만 있는 줄입니다. 그래서
SMTP 는 본문 안에서 점으로 시작하는 줄에 점을 하나 더 붙여 보내고, 받는
쪽이 그 하나를 떼어 냅니다(RFC 5321 4.5.2). 붙이는 일은 **한 번만** 일어나야
합니다.

kanpic 은 두 번 붙이고 있었습니다. 본문을 만드는 곳에서 손으로 하나를 붙였고,
실제로 와이어에 쓰는 곳(Go 표준 라이브러리가 주는 dot writer)이 규약대로 또
하나를 붙였습니다. 받는 쪽은 하나만 떼므로, 보낸 사람이 적은 `.기준가`
는 받는 사람에게 `..기준가` 로 보였습니다.

눈에 띄는 것은 본문 줄이 점으로 시작할 때입니다 — 표시 이름이 `.` 로
시작하는 분이 워크북을 공유하거나 댓글을 남기면 알림 첫 줄이 그렇게 되고,
점으로 시작하는 값이 그런 자리에 들어가도 같습니다. 이제 이스케이프는 와이어에
쓰는 곳 한 군데에서만 일어나므로, 받는 사람이 읽는 본문은 kanpic 이 적은
본문과 글자 하나까지 같습니다.

## 그 밖에 메일에서 바뀌는 것은 없습니다

- 줄바꿈 정규화(CRLF)와 본문 끝 줄바꿈 보장은 그대로입니다. 본문이 끝나기 전에
  DATA 가 끊기는 일은 없습니다.
- SMTP 주소·TLS·인증, 누구에게 보낼지 정하는 규칙, 제목과 본문 문구는 손대지
  않았습니다.
- 워크북에 담긴 자료는 이 릴리즈와 무관합니다. 바뀐 것은 메일 본문이 와이어에
  실리는 방식 하나입니다.

## 확인

- `internal/mail/mail_test.go` — 이미 있던 in-process 가짜 릴레이로 `Deliver`
  를 통과시켜 **와이어에 실제로 실린 DATA** 를 받는 쪽처럼 되돌린 뒤(헤더를
  떼고 규약대로 줄 앞 점 하나를 제거) `Message.Body` 의 각 줄과 정확히
  비교합니다. 점으로 시작하는 줄·이미 점이 두 개인 줄·첫 줄이 점 하나·마지막
  줄이 점 하나, 네 사례를 봅니다. 고치기 전 빨강 5 → 고친 뒤 초록 9 이고,
  지운 두 줄 중 하나를 되살리면 다섯 개가 다시 빨강이 되는 것까지 봤습니다.
- 이 결함을 여태 가린 것은 느슨한 단언이었습니다. 기존 테스트는 본문에
  `..기준가` 가 **들어 있는지**만 보았으므로, 와이어에 점이 셋 실려도 통과했습니다.
  그 단언도 정확 비교로 바꿨습니다.
- `go test ./...`(18개 패키지 통과), `gofmt -l ./cmd ./internal ./pkg`(출력
  없음), `go vet ./...`, `go build ./...`,
  `scripts/check-release-docs.sh`, `scripts/check-commit-identities.sh` 를
  돌렸습니다.
- 웹 테스트·DB 통합·브라우저 E2E 는 돌리지 않았습니다 — 바뀐 곳이 Go 서버
  안쪽에서 메일 본문을 다듬는 함수 한 군데이고, 브라우저에 실리는 자산은 이
  릴리즈에서 달라지지 않습니다.

## 올리실 때

마이그레이션도 새 설정도 없고 필수 런타임 환경 변수는 계속 `POSTGRES_DSN`
하나입니다. v0.254.0 에서 올라오시는 분은 이미지만 바꿔 다시 띄우시면 됩니다.

이미 나간 메일이 되돌아오지는 않습니다 — 이 릴리즈 뒤에 발송되는 알림부터
적힌 대로 도착합니다. 관리자 화면의 SMTP 발송 테스트로 확인하실 수 있고,
본문에 점으로 시작하는 줄을 넣어 보시면 받은 메일에 점이 하나만 남습니다.

## 오프라인 설치

이 릴리즈는 웹 자산과 서버 바이너리를 포함한 Docker 이미지 아카이브로 제공됩니다.

```bash
sha256sum -c kanpic-v0.255.0.tar.gz.sha256
gzip -dc kanpic-v0.255.0.tar.gz | docker load
docker run --rm -p 8080:8080 \
  -e POSTGRES_DSN='postgres://kanpic:password@postgres.internal:5432/kanpic?sslmode=require' \
  kanpic:v0.255.0
```

- 필수 런타임 환경 변수: `POSTGRES_DSN`
- Redis 및 외부 인터넷 연결: 불필요
- 관리자 초기 로그인을 보호하려면 `BOOTSTRAP_ADMIN_ID`와 `BOOTSTRAP_ADMIN_PASSWORD`를 함께 지정합니다.
- 무결성 검증 파일: `kanpic-v0.255.0.tar.gz.sha256`
