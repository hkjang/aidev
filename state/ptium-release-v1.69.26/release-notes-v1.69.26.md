# Ptium 1.69.26

## 빨간 마이너스로 적은 금액이 1903년의 날짜가 되었습니다

엑셀에서 숫자가 무엇인지는 숫자가 아니라 **서식**에 적혀 있습니다. 날짜는
날 수로, 백분율은 분수로 저장되므로 리더는 서식 코드를 읽어 `yyyy-mm-dd` 면
날짜, `0.0%` 면 백분율로 옮깁니다.

서식 코드에는 숫자의 모양이 아닌 것도 함께 적힙니다. 대괄호 안이 그렇습니다 —
색(`[Red]`), 조건(`[>=1000]`), 지역(`[$-409]`), 통화 기호(`[$₩-412]`). 리더는
이 대괄호를 숫자의 모양으로 함께 읽었고, `[Red]` 에는 `d` 가 들어 있습니다.

```
서식:   #,##0;[Red]-#,##0      ← 음수를 빨갛게, 서식 대화상자의 기본
시트:   국내 | 1200 / 해외 | -350
이전:   국내 | 1903-04-14 / 해외 | -350   (표)
지금:   국내 | 1200 / 해외 | -350         (막대 차트)
```

음수를 빨갛게 보여주는 통화·회계 서식은 어느 금액 시트에나 있습니다. 그 시트를
올리면 양수 금액이 전부 1903년 어느 날이 되었고, 열이 더 이상 숫자가 아니므로
차트로 그려지지도 않았습니다. 표 하나에 날짜와 음수가 섞여 나왔습니다.

이제 서식 코드에서 대괄호 구역은 따옴표 안의 글자와 마찬가지로 "어떻게
찍을지"로 보고, 숫자의 종류를 정할 때 세지 않습니다. `[$-409]mmm-yy` 처럼 지역
뒤에 진짜 날짜가 오는 서식은 전과 같이 날짜이고, `[Red]0.0%` 는 전과 같이
백분율입니다. 닫히지 않은 대괄호는 대괄호로 보지 않고 적힌 그대로 읽습니다.
