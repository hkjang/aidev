## 이 캠페인에서 다른 저장소가 이미 걸린 것 — 시작 전에 확인하고, 끝내기 전에 다시 확인하세요
(캠페인 "mail-2026-09" 의 리뷰 거절·심사 거절·회귀 53건에서 정제한 규칙. 러너가 자동으로 붙였습니다.)
- **평문(TLS 없는) 연결에서 자격증명을 보낼지 정책을 먼저 문서에 정하고 구현한다. `!server.TLS && server.Name != host` 류의 가드는 NewClient가 Name에 같은 host를 넣어 항상 거짓이므로 쓰지 않는다. TLS 없고 username이 있으면 인증하지 않고 명확한 오류로 실패시키고(명시적 none 선택 시에만 허용), 비-localhost 평문에서 PLAIN은 stdlib가 거부하므로 방식 선택도 확인한다. 회귀 테스트는 비-루프백 주소에 STARTTLS 없이 AUTH LOGIN(및 PLAIN** — 12개 저장소가 같은 가드로 비밀번호를 base64 평문으로 내보냈고, 루프백 테스트는 localhost 예외 때문에 이를 잡지 못했다 (근거: DartFly, appstore, dataworks, igame, jupiq, madi, moyro, qurio, relio, seaton, vibe-coders, visitflow, 12회)
- **발송 결과 기록(UPDATE)과 다음 수신자 INSERT는 발송용 컨텍스트가 아니라 별도(만료되지 않은) 컨텍스트로 수행하고, 오류를 버리지 않는다. 응답 없는 TCP 리스너를 릴레이로 둔 테스트를 추가한다** — 연결 마감 2×timeout과 재시도를 합치면 발송 예산을 넘겨 기록이 영원히 queued/sending으로 남아 '시도마다 기록'이 정확히 장애 상황에서 깨진다 (근거: ai-admin, hunter, seaton, 3회)
- **배경 발송 고루틴 수에 상한(버퍼 채널 세마포어)을 두고, 상한을 넘으면 발송만 대기시키되 기록은 즉시 남긴다** — 응답 없는 릴레이에서 고루틴과 열린 TCP 연결이 요청 속도만큼 무한히 쌓인다 (근거: ai-admin, dataworks, 2회)
- **작업은 origin/main 최신에서 시작하고, 제출 직전 origin/main 위로 rebase한 뒤 merge-tree로 충돌 없음을 확인하고 낸다** — 코드 문제와 무관하게 base 충돌만으로 자동 처리가 멈추고 사람 손에 넘어간 저장소가 5개였다 (근거: DartFly, appstore, moina, postra, weekly, 5회)
- **이벤트→메일 매핑은 상태 전이 코드에서 직접 확인한다: 같은 요청의 재시도나 부분 승인이 같은 메일을 다시 보내지 않도록 디바운스/중복 억제를 두고, 다른 알림이 있다고 메일을 억제할 때는 그 알림이 실제로 발송되는지(요약 묶음·사용자/관리자 설정)까지 확인한다** — 상태값만 보고 이벤트를 판정하면 승인자가 제출자로 찍히거나 관리자 전원에게 요청당 N통이 가고, 근거 없는 억제는 알림 누락이 된다 (근거: dataworks, sqlon, moina, 3회)
- **메일 본문의 안내 문구와 링크 경로는 소스(라우터·해시 파서·실제 핸들러·관련 동작 코드)에서 확인한 뒤 쓰고, 테스트는 그 확인된 값을 단언한다** — 존재하지 않는 경로, 실제 게이트 동작과 다른 재전송 안내, 회전해도 만료를 못 벗어나는 키 안내가 각각 거절됐고 잘못된 링크를 단언한 테스트가 결함을 고정했다 (근거: dataworks, seaton, sqlon, 3회)
- **비밀·시크릿 처리 파일(secret_handlers, secret_fields 등)은 캠페인 PR에서 건드리지 않고, 필요하면 별도 PR로 분리한다** — 사람만 승인할 수 있는 파일이라 건드리는 순간 자동 처리가 멈춘다 (근거: jikim, umm, 2회)
- **메일 트리거에 쓰는 필드(작성자 등)가 실제 제품 경로에서 채워지는지 grep으로 확인하고, 시험 발송 실패 응답의 상태코드·JSON 형태가 프론트 API 클라이언트의 오류 파싱과 맞는지 실제 화면 경로로 확인한다. 테스트가 값을 직접 주입해 통과하는 것으로 갈음하지 않는다** — 테스트는 통과하지만 제품에서는 한 번도 발송되지 않거나, 실패가 사용자에게 다른 메시지로 보이고 기록도 갱신되지 않았다 (근거: vibe-coders, 1회)
