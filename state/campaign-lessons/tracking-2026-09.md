- **스니펫 HTML에서 <script 태그나 http(s) 출처를 대소문자 무시로 찾을 때는 ToLower 사본의 인덱스를 원본에 적용하지 말고 ASCII 전용 case-fold(EqualFold 기반 탐색 또는 소문자 사본만 사용)로 구현하고, 'İ'(U+0130)·'K'(U+212A)가 앞에 붙은 스니펫으로 출처 추출과 nonce 삽입을 모두 테스트한다** — 소문자화로 UTF-8 바이트 길이가 바뀌는 문자가 있으면 오프셋이 어긋나 panic·무한 루프가 나거나 nonce가 태그 중간에 박혀 스니펫이 조용히 실행되지 않는다 (근거: ai-admin, moyro, 4회)
- **CSP(script-src/connect-src/img-src)에 이어붙는 관리자 입력(허용 호스트 목록 등)은 저장 시점에 토큰 단위로 검증해 스킴+호스트 형태만 통과시키고 'unsafe-inline', *, data:, 따옴표 키워드는 거절한다** — 길이 제한만 걸면 어떤 토큰이든 그대로 헤더에 실려 '절대 unsafe-inline로 넓히지 않는다'는 약속이 깨진다 (근거: qurio, vibe-coders, 2회)
- **같은 오리진 프록시는 수집기 스크립트·이벤트 경로만 allowlist로 통과시키고, 요청 경로는 path.Clean 후 '..' 이나 allowlist 밖 경로를 거절한다** — 접두어만 떼고 전부 넘기면 익명 방문자가 수집기 오리진의 관리 로그인·OIDC·버전 API나 '../' 경로에 프록시를 거쳐 도달한다 (근거: DartFly, qurio, 2회)
- **설정 UI를 만들기 전에 서버 기본값과 '빈값의 의미'(예: 빈값=꺼짐인지 켜짐인지)를 소스에서 확인하고, 화면이 미설정 상태를 그리는 방식과 저장 시 전송하는 값이 그 기본값과 일치하는지 새 설치 상태로 저장해 검증한다** — UI가 서버와 다른 기본을 보여주거나 미설정 값을 항상 명시적 false로 보내면, 관리자가 무관한 설정만 저장해도 provider 없이 전송되거나 프록시가 꺼져 수집기 주소와 CSP가 어긋난다 (근거: AgentHub, sqlon, 2회)

- **프록시가 업스트림 URL을 만들 때 설정된 수집기 주소의 base path를 유지하고, 요청 경로로 Path를 덮어쓰지 않으며 base path가 있는 수집기 주소로 테스트한다** — SetURL 뒤에 Out.URL.Path를 다시 대입하면 '/collect' 같은 base path가 사라져 검증은 통과했는데 요청은 잘못된 경로로 간다 (근거: ptium, 1회)
