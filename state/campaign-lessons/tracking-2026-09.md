## 이 캠페인에서 다른 저장소가 이미 걸린 것 — 시작 전에 확인하고, 끝내기 전에 다시 확인하세요
(캠페인 "tracking-2026-09" 의 리뷰 거절·심사 거절·회귀 16건에서 정제한 규칙. 러너가 자동으로 붙였습니다.)
- **스니펫에서 <script·http 위치를 찾을 때 strings.ToLower 사본의 바이트 인덱스를 원본에 적용하지 않는다. ASCII 전용 case-fold(EqualFold 기반 탐색)로 찾고, İ(U+0130)·켈빈 기호(U+212A) 같이 소문자화로 UTF-8 길이가 바뀌는 문자가 섞인 스니펫으로 무한루프·panic·nonce 삽입 위치를 테스트한다.** — 소문자화로 바이트 길이가 바뀌면 오프셋이 어긋나 무한루프·slice panic 이 나거나 nonce 가 태그 중간에 들어가 스니펫이 조용히 실행되지 않는다. (근거: ai-admin, moyro, 4회)
- **같은 오리진 프록시는 수집기 엔드포인트(tracker 스크립트, collect)만 허용목록으로 통과시킨다. 구현 전에 수집기 오리진이 관리 API·로그인·OIDC·health 를 같은 오리진에서 내는지 확인하고, 요청 경로를 path.Clean 으로 정규화해 '..' 을 거부하며, 저장된 수집기 URL 의 base path 를 덮어쓰지 않고 보존한다.** — 경로를 그대로 넘기면 익명 방문자가 프록시를 거쳐 관리 API 에 닿거나 상위 경로로 탈출하고, base path 를 버리면 정상 수집기 주소가 동작하지 않는다. (근거: DartFly, qurio, ptium, 3회)
- **allowed_hosts 는 길이 제한만으로 받지 않는다. 토큰마다 파싱해 host[:port] 또는 scheme://host 형태의 오리진만 통과시키고 'unsafe-inline'·*·data:·CSP 키워드는 거부한다. 검증기가 실제 저장 경로(관리 API 의 by-key 저장 포함)에 등록됐는지 확인한다.** — 토큰이 script-src/connect-src/img-src 에 그대로 이어붙여지므로 무검증이면 CSP 가 'unsafe-inline' 이나 * 로 넓어져 기능의 전제가 무너진다. (근거: qurio, vibe-coders, 2회)
- **설정 화면의 모든 컨트롤에 대해 값이 없을 때 보이는 상태가 서버 Defaults 와 같은지 하나씩 대조하고, 화면이 보여 주는 값과 저장 시 전송하는 값이 다르지 않게 한다(select 기본 선택이 전송 안 됨, 체크박스 미설정이 false 로 전송 금지). 설정 키가 전혀 없는 신규 설치 상태에서 다른 항목만 바꾸고 저장하는 시나리오를 검증한다.** — 화면 기본값과 서버 기본값이 어긋나면 관리자가 건드리지 않은 필드가 잘못된 값으로 영속화되어 저장 실패나 프록시 꺼짐이 조용히 일어난다. (근거: AgentHub, sqlon, 2회)
- **추적 설정 저장은 조합 전체를 먼저 검증한 뒤 한 번에 쓴다. 키별 검증을 저장 루프 안에서 돌리지 않고, 읽기 실패를 삼켜 빈 설정을 돌려주는 헬퍼를 read-modify-write 에 쓰지 않는다(읽기 실패면 저장을 거부).** — 부분 저장이나 빈 값 위에 덮어쓰기는 기존 허용목록을 지우거나 비결정적으로 절반만 저장된 상태를 만든다. (근거: sqlon, qurio, 2회)
- **프록시용 http.Transport/ReverseProxy 는 서버 시작 시(또는 설정 변경 시) 한 번 만들어 재사용하고 요청마다 생성하지 않는다.** — 요청마다 Transport 를 만들면 keep-alive 연결과 readLoop/writeLoop 고루틴이 방문자 비콘마다 누적된다. (근거: vibe-coders, 1회)
- **.github/workflows/ 등 사람만 승인할 수 있는 파일은 캠페인 변경에서 건드리지 않는다. CI 변경이 꼭 필요하면 별도 PR 로 분리해 사람에게 넘긴다.** — 그 파일을 포함하면 처리기가 자동 승인하지 못해 전체 변경이 needs-human 으로 멈춘다. (근거: madi, 1회)
- **작업 시작 전에 base 를 최신으로 맞추고, 라우트 등록·설정 키 목록 같은 공유 파일은 삽입 위치를 최소화한다(새 코드는 새 파일에 모으고 연결 한 줄만 추가).** — 공유 파일을 넓게 고치면 자동 리베이스가 풀지 못하는 충돌이 나서 수동 개입이 필요해진다. (근거: DartFly, 1회)
