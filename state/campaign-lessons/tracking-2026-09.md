## 이 캠페인에서 다른 저장소가 이미 걸린 것 — 시작 전에 확인하고, 끝내기 전에 다시 확인하세요
(캠페인 "tracking-2026-09" 의 리뷰 거절·심사 거절·회귀 21건에서 정제한 규칙. 러너가 자동으로 붙였습니다.)
- **/momento/* 프록시를 만들기 전에 수집기 저장소의 라우트 표에서 관리 API·로그인·health 가 같은 오리진에 있음을 확인하고, path.Clean(TrimPrefix(...)) 결과가 /tracker.js 와 수집 끝점의 정확한 경로와 문자열로 같을 때만, 필요한 메서드(GET/POST)만 넘긴다. '..'·'.'·'//'·%2e%2e 거부만으로는 부족하다.** — 프록시는 인증 없이 열리므로 접두어 검사만 하면 익명 방문자가 수집기의 관리 API·로그인에 도달한다. (근거: DartFly, orbit, qurio, sqlon, 5회)
- **스니펫에서 <script·http 를 찾을 때 strings.ToLower 사본의 바이트 인덱스를 원본에 적용하지 않는다. ASCII 전용 case-fold 또는 EqualFold 기반 탐색을 쓰고 İ(U+0130)·켈빈 기호(U+212A)가 포함된 입력으로 무한 루프·panic·nonce 삽입 위치 테스트를 넣는다.** — 소문자화로 UTF-8 길이가 바뀌면 오프셋이 어긋나 panic·무한 루프·깨진 태그(이 기능이 없애려던 '조용히 막힘')가 생긴다. (근거: ai-admin, moyro, 4회)
- **시작 전에 저장소의 보호 파일(CI·릴리스 워크플로 등) 목록을 확인해 건드리지 않고, 최신 base 로 리베이스한 뒤 공용 파일(라우터·설정 목록) 수정은 최소 줄로 한정한다.** — 자동 리베이스로 안 풀리는 충돌이나 사람 승인이 필요한 파일 수정은 리뷰 전에 needs-human 으로 멈춘다. (근거: DartFly, orbit, qurio, madi, 4회)
- **CSP 에 이어붙는 allowed_hosts 류 설정은 길이 제한이 아니라 토큰마다 host/origin 형식으로 검증하고 'unsafe-inline'·*·data:·따옴표 키워드를 저장 시점에 거부한다.** — 토큰이 script-src/connect-src 에 그대로 들어가 문서와 UI 가 약속한 'unsafe-inline 으로 넓히지 않음'이 깨진다. (근거: qurio, vibe-coders, 2회)
- **화면을 만들기 전에 서버의 Defaults()와 '빈값 = 켜짐' 같은 해석을 소스에서 확인해 미설정 값을 서버 기본값과 같은 상태로 그리고, 사용자가 바꾸지 않은 컨트롤 값을 임의의 false/기본 선택으로 전송하지 않는다.** — 화면과 서버 기본값이 다르면 관리자가 무관한 항목만 저장해도 프록시가 꺼지거나 provider 없이 저장되어 실패한다. (근거: AgentHub, sqlon, 2회)
- **여러 설정 키를 함께 저장할 때는 켜짐 여부와 무관하게 모든 키를 먼저 검증한 뒤 한 번에 쓰고, read-modify-write 는 읽기 실패를 빈 값으로 간주하지 말고 오류로 중단한다.** — 순회 순서에 따른 부분 저장이나 일시적 읽기 실패로 기존 허용 목록이 통째로 지워진다. (근거: sqlon, qurio, 2회)
- **프록시 업스트림 URL 은 수집기 주소의 base path 를 유지해 조립한다(SetURL 이 이미 이어붙였으면 Out.URL.Path 를 덮어쓰지 않음). https://host/base/ 형태 주소로 /base/collect/... 에 도달하는 테스트를 넣는다.** — 검증을 통과하는 주소인데 프록시가 base path 를 버리면 기본 모드(프록시 켜짐)에서 수집이 조용히 실패한다. (근거: ptium, 1회)
- **ReverseProxy 와 Transport 는 시작 시 한 번 만들어 재사용하고 커스텀 Transport 에는 IdleConnTimeout 을 설정한다.** — 요청마다 만든 Transport 는 keep-alive 연결과 goroutine 을 남겨 방문자 비콘마다 TCP 연결이 누수된다. (근거: vibe-coders, 1회)
