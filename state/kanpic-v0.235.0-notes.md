# v0.235.0

## 표시 형식의 넷째 구역이 글자 값을 그린다

엑셀 표시 형식은 `;` 로 나눈 네 구역까지 담습니다 — **양수 ; 음수 ; 0 ;
글자** 입니다. 마지막 구역은 숫자가 아니라 **글자가 담긴 칸** 에만 걸립니다.
엑셀의 기본 회계 서식이 바로 그 꼴이라(`_-* #,##0_-;-* #,##0_-;_-* "-"_-;_-@_-`)
XLSX 로 들어오는 표에 흔히 붙어 있고, 숫자 칸 사이에 섞인 `미정`·`해당없음`
같은 칸을 괄호에 넣어 눈에 띄게 하는 데도 씁니다.

kanpic 은 그 구역을 아예 읽지 않았습니다. 그래서 `#,##0;(#,##0);"-";"["@"]"`
가 걸린 칸에 `미정` 이 담겨 있으면 `[미정]` 이 아니라 그냥 **`미정`** 으로
보였고, `@" 님"` 처럼 이름 뒤에 말을 붙이는 서식은 값이 들어갈 자리인 `@` 를
글자로 그려 **`@ 님`** 이라고 적혔습니다.

이제 양쪽 다 엑셀대로 그립니다.

- 구역이 넷이면 넷째 구역이 글자 값을 그립니다. `@` 가 값이 들어갈 자리입니다.
  - `#,##0;(#,##0);"-";"["@"]"` → `미정` 은 **[미정]** 입니다.
  - 회계 서식의 `_-@_-` 처럼 자리 맞추기(`_`·`*`)만 있는 구역은 값만 적습니다.
  - `@` 가 없는 구역이면 모든 글자를 그 구역대로 적습니다 — `0;;;"기타"` 는
    어떤 글자든 **기타** 입니다.
- 넷째 구역을 비워 두면 글자를 감춥니다. `#,##0;;;` 는 글자 칸을 비웁니다.
- 구역이 셋 이하면 글자를 손대지 않습니다. `#,##0;(#,##0);"-"` 에서 `미정` 은
  그대로 **미정** 입니다.
- 구역이 하나뿐인데 `@` 가 있으면 그 구역이 곧 글자 구역입니다.
  - `@" 님"` → `홍길동` 은 **홍길동 님**, `"("@")"` → **(홍길동)** 입니다.
  - `@` 는 "값을 있는 그대로" 라는 뜻이라 숫자에도 걸립니다. `@" 님"` 은 `5` 를
    **5 님** 으로 적습니다. 예전에는 `@ 님` 이었습니다.

앞의 세 구역은 그대로입니다. `#,##0;(#,##0);"-";"["@"]"` 는 `1234` 를
`1,234`, `-1234` 를 `(1,234)`, `0` 을 `-` 로 적습니다.

## 오프라인 설치

이 릴리즈는 웹 자산과 서버 바이너리를 포함한 Docker 이미지 아카이브로 제공됩니다.

```bash
sha256sum -c kanpic-v0.235.0.tar.gz.sha256
gzip -dc kanpic-v0.235.0.tar.gz | docker load
docker run --rm -p 8080:8080 \
  -e POSTGRES_DSN='postgres://kanpic:password@postgres.internal:5432/kanpic?sslmode=require' \
  kanpic:v0.235.0
```

- 필수 런타임 환경 변수: `POSTGRES_DSN`
- Redis 및 외부 인터넷 연결: 불필요
- 관리자 초기 로그인을 보호하려면 `BOOTSTRAP_ADMIN_ID`와 `BOOTSTRAP_ADMIN_PASSWORD`를 함께 지정합니다.
- 무결성 검증 파일: `kanpic-v0.235.0.tar.gz.sha256`
