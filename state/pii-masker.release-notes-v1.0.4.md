Validate async job uploads before they are persisted. `POST /v1/jobs` now runs the same size, MIME type, and PDF page-count checks as the synchronous `/v1/mask` path, so unsupported or oversized files are rejected with a 400 `invalid_request` instead of being written to disk and failing later in the background. Also fixes a data race on the global pdfcpu `ConfigPath` by setting it once at package init rather than on every request, and adds integration coverage for the three rejection cases.
