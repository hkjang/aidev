# Ptium 1.69.25

## 체크박스 시트가 0 과 1 의 막대 차트가 되었습니다

엑셀에서 셀은 자기가 무엇인지를 `t` 로 말합니다. 글자면 `t="s"`,
참·거짓이면 `t="b"`, 수식이 돌려준 글자면 `t="str"`, 수식이 끝난 오류면
`t="e"` 입니다. 리더는 이 가운데 글자 두 가지만 알아보고, 나머지는 전부
숫자로 취급했습니다.

참·거짓 셀은 TRUE 를 `1`, FALSE 를 `0` 으로 저장합니다. 화면에는 TRUE 라고
적혀 있는데 리더는 저장된 숫자를 그대로 읽었고, 그래서 점검표 한 장이
0 과 1 만 남은 열이 되었습니다. 게다가 그 열은 전부 숫자였으므로 표가 아니라
**막대 차트**로 그려졌습니다.

```
시트:   설계 | TRUE
        개발 | FALSE
이전:   설계 | 1 / 개발 | 0     (0 과 1 의 막대 차트)
지금:   설계 | TRUE / 개발 | FALSE   (표)
```

셀에 서식이 붙어 있으면 더 나빴습니다. 숫자 서식 변환(1.69.x 에서 들어온,
날짜는 날짜로 백분율은 백분율로 읽는 기능)이 참·거짓에도 걸려서, 날짜 서식이
붙은 TRUE 는 `1899-12-31` 이 되고 백분율 서식이 붙은 FALSE 는 `0%` 가
되었습니다. 둘 다 셀에 없는 이야기입니다.

수식이 돌려준 글자(`t="str"`)와 오류(`t="e"`)도 같은 길을 탔습니다. 수식이
문자열 `"45678"` 을 돌려준 날짜 서식 셀은 `2025-01-21` 로 읽혔습니다. 수식이
돌려준 것은 글자이고, 글자는 날짜가 아닙니다.

이제 `t="b"` 는 시트가 보여주는 대로 TRUE·FALSE 로 읽고, `t="str"` 과
`t="e"` 는 적힌 그대로 둡니다. 서식 변환은 숫자 셀에만 걸립니다. 참·거짓 셀이
1 도 0 도 아닌 무언가를 들고 있으면 짐작하지 않고 그대로 둡니다.

보통의 숫자 시트는 읽히는 결과가 한 글자도 달라지지 않습니다 — 매출 표는
그대로 막대 차트이고, 날짜 서식이 붙은 착수일은 그대로 `2025-01-21` 입니다.

## 지키는 장치

`internal/docs/sheetkinds_test.go` 가 서식 없는 참·거짓 시트, 날짜·백분율
서식이 붙은 참·거짓 시트, 날짜 서식 셀에 수식이 넣은 글자, 수식 오류,
1 도 0 도 아닌 참·거짓 셀, 그리고 보통의 숫자 시트와 날짜 서식 셀이 전과 같이
읽히는지를 봅니다. `truthOf` 자체도 따로 확인합니다.
